## 范围与职责

- 顶部常驻设备连接、实际型号/轴角色、APP/Loader/硬件版本，顶部工作区标签取代宽侧栏。
- 调试页主曲线加两张辅助曲线，右侧集中模式、使能/失能、目标与 STOP；观察与输出独立。
- 参数统一电机/控制/阈值分类；控制再分电流/速度/位置环，收录134项展示元数据和现有48项标量目录。
  设备值必须来自回读，扩展、标定和编译项注明来源；不把界面稿示例数值放入生产路径。
- 保留型号CAN配置、APP/SWD升级、标定、故障清除、诊断、CSV及独立通信/曲线线程。
- 默认字号14、辅助12、标题18；DPI/窗口变化重新计算列宽、行高和绘图区。
  故障/未知状态与STOP全工作区可见，UI不新增台架勾选门槛。

界面壳只负责导航与全局身份，参数目录/编解码独立于设备，设备线程独占参数事务和安全门禁。
参数 UI 独占草稿、过滤和回读视图，不复制维护固件的范围或伪造当前值。

## 验证与实机场景

离线执行 Rust 测试、Clippy、优化构建、原生页面预览与仓库PR/release适用检查。
预览覆盖深浅主题、1024/1366、100/125/150%缩放、参数分类、断联及故障状态。

实机前核对任务交接、当前板卡完整UID、节点、型号、APP/Loader和能力；
只使用已架空台架和用户明确授权的低幅使能/失能、Vq/Iq/速度/位置场景。
先做静止通信、STOP/IDLE和参数只读验证，再分模式小幅测试并逐次停机核对。
遇到超时、故障或输出未知立即中止运动，按实际结果记录，不自动复位/升级或恢复运动。
本计划不授权写入新型号、重标定、下载固件或更改持久参数。
