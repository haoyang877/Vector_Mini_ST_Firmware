## 目标与边界

按用户要求，先接通v1.1用例需要的代码，后续再做测试。本轮只实现并离线编译、检查格式；
不运行单元/原生/台架测试，不连接适配器或探针、不烧录、不启相，不生成伪实测结果。

只在AT32 Commissioning镜像启用测试命令和4KiB定长波形缓冲；普通APP默认关闭。
测试入口复用生命周期、FOC、速度环和标定，不另建控制器。默认未配置运行限值，不允许动力测试；
需要显式设置电流、速度、行程、时限与主机租期，板端逐拍执行截止，STOP走原生命周期。

新增独立测试命令0x7F00及版本化文档/向量，正常协议与持久化ABI不变。
提供静态/触发采集、板端Id/短Iq/速度激励、标定观测、关相后数据/LUT读回、主机统一报告。
已有CAN FD端口、编解码及绘图依赖复用；输出七项状态、波形、原始数据和缺项原因。

## 结果

代码接入和离线构建完成；功能测试、实机联调和v1.1验收仍未执行。
使用入口及未覆盖范围见[统一电机采集](../../guides/unified_motor_bench.md)。
