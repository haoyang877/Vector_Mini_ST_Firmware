# 正式APP全局调试命令 v1

## 目标与范围

按用户确认方案，在正式APP增加可由Keil Watch写入的命令与目标变量。
命令0为空闲，1请求启动，2更新目标，3请求停止；支持电流、速度、位置三种已有控制模式。
默认无命令、目标为零，不上电自动启相，不增加自动重试、清错、标定或保存行为。

## 实施约束

全局变量放在现有app.c，由单一前台处理函数消费，不增加BSP或中断职责。
App_Process在标定发布后、协议状态刷新前处理一次命令，沿用正常生命周期三个请求接口。
参数先写、命令最后写；命令非零时主机不修改参数或提交新命令。
CPU先发布结果、最后清零命令，作为一次请求的完成确认。
启动受理与实际RUNNING区分；故障或拒绝后不保留请求，也不自动再次启动。

## 验收与证据

修改前app.c/h及生命周期基线保存在outputs/keil-global-control-20261103/。
验证无命令无动作、三个模式转交、目标未用字段清零、非法命令/模式、返回码、
一次性消费、停止不依赖目标有效性，以及原生命周期准入不变。
运行完整PR、四个正式目标构建并记录资源变化；只离线验证，不烧录或驱动电机。
参数记录、CAN协议和PWM/ADC配置不在本轮修改范围。

## 回退

仅撤销本轮调试变量、前台调用、相关用例与文档，保留此前中断迁移和用户未提交改动。
