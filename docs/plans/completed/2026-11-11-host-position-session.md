# 上位机位置控制会话不限位

日期：2026-11-11。用户确认同时取消主机单次±10°和固件位置/行程限制，仅作用于上位机控制。
基线：主机 v2.7.2 断联修复候选、APP1.6.1及已有工作树修改；保留其他任务变更和运行中的人工会话。

## 目标、不变项与实现

主机位置目标允许协议可表示的有限绝对值，不做角度步长限制；依然要求新鲜有效反馈。
Type117保留4字节，位置模式明确请求host不限位标志，合并后GET_CAPS使用能力位18；旧零标志保持原语义。
固件只在此请求被受理后设置易失权限，贯穿启动、目标校验、外环输入和轨迹参考检查。
STOP、故障和复位清除；位置会话保持Type108反馈及Type118运动续租，两者均受500ms时限约束，普通请求不能继承。
不改变轴持久记录、速度/电流/电压/温度保护、标定要求和其他控制来源的原有策略。
旧固件不宣告能力时，主机不伪装已解除限位；明确提示需配套固件。
