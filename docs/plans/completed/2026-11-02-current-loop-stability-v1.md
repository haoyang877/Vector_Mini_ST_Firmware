# 电流环稳定性与采样噪声实测 v1

用户要求先测试电流环稳定性，并确认当前带宽和采样噪声。速度测试暂不推进。
沿用AT32F456＋YQ-5708（8:1）、电机固定、输出轴自由、用户已确认3A/50rad/s上限。
先核对当前设备身份、固件能力、实际PI参数和标定；不烧录、不改PI或标定、不写Flash。

## 场景

1. 关相静止：多次采集20kHz三相原码/电流窗口及慢速长窗口，分别统计去均值RMS和峰峰值。
2. 零电流闭环：Id/Iq=0，确认无持续振荡及正常关相。
3. Id=0.3A、Iq=0：使用原私有RUN做定值电流，分布采集多个快窗及长趋势，检验平均误差和纹波。
4. 仅在低档通过后测试Id=0.75A、Iq=0。相电流截止3A，额外收紧速度5rad/s、累计行程1rad、时限8秒、租约500ms。
5. 输出轴无锁定装置，不进行持续非零Iq锁轴试验；Id/Iq阶跃和扫频不冒充已完成的带宽实测。

## 判据和边界

按原v1.1建议值：原码RMS≤2counts、峰峰值≤12counts；dq平均误差及去均值RMS≤60mA，峰峰值≤300mA。
保留各窗口独立结果，波形未显示持续增长振荡；任何硬截止、故障、通信失败或指标失败后结束后续启相。
时间间隔由板端tick核验；主机趋势不能代替20kHz纹波样本。
配置目标带宽与按实际R/L、PI估算的带宽分开报告，未经扫频不宣称真实−3dB带宽已测得。
采样链为板载ADC，缺少电流探头，不宣称测得绕组真实PWM纹波或独立绝对精度。

## 证据

输出放`outputs/current-loop-stability-20261102/`，包括当前配置、逐帧日志、原始CSV、统计和波形。
结束确认关相、故障、标定标志、零位及LUT与开始一致。只新增批次脚本和文档，执行quick及文档检查。

## 完成结果

13个窗口通过：关相三相噪声7.67～9.31mA RMS，零电流及两档Id运行的dq误差RMS约8～9.5mA。
实读Id/Iq的Kp=0.895354、Ki=3455.752、周期50μs，按现有R/L估算整定带宽约1kHz，未声称完成频响测量。
最终关相、故障0，LUT与零位保持；详见[当日实测报告](../../reports/2026-11/current_loop_stability_20261102.md)。
