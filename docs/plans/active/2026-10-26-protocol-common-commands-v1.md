# 通信公共头与命令目录整理 v1

## 目标

将业务协议目录 `firmware/communication/protocol/` 改为 `commands/`。
将共用的类型、字节读写、请求检查和四字节结果写入集中到
`shared/protocol/yg_protocol_common.h`，协议主体从 32 个文件减为 30 个。

## 边界

只整理文件和包含关系，保留函数名、数据结构、命令编号、线上字节、状态归属和执行顺序。
APP 内部业务结果、服务绑定和主站权限配置仍放在命令模块。
公共目录不依赖 APP、电机状态机、Loader 运行状态或硬件。
旧头文件删除，不保留转发头；工程、工具、测试及当前文档同步修改。

## 步骤和验收

1. 保存本轮改动前的文件快照，基线采用第三轮简化后的工作区。
2. 合并公共头文件并迁移业务目录，更新全部有效构建引用。
3. 检查公共头无产品依赖，协议文件数量为 30，旧有效路径不再存在。
4. 运行协议、升级和数值相关原生回归，以及仓库 PR 检查。
5. 重建四个 APP 目标及独立 Loader，检查错误、警告和资源变化；验证主机 C++ 调用。
6. 更新协议入口和文件职责说明，记录结果。

本轮不下载、不驱动电机。离线通过不代替实机时序或多轴 1 kHz 验收。

## 回退与证据

快照、日志和检查结果放在 `outputs/protocol_common_v4/`。
必要时只恢复本轮快照对应的修改，不回退其他 BSP、工程迁移或既有协议改动。
历史文档可以保留当时名称；实际文件链接应指向当前文件。
