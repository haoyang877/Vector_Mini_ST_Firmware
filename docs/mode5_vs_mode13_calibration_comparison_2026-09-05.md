# Mode 5 与 Mode 13 编码器标定结果对比（2026-09-05）

## 结论

两种方法得到的编码器非线性补偿形状高度一致。对同一组 1024 个原始机械角 LUT 桶
分别去除常量偏置后，波形相关系数为 `0.94470`，点对点差异 RMS 为 `0.07212°`、
平均绝对差为 `0.05669°`、峰值差为 `0.23948°`。

Mode 13 自身两次成功标定的去偏置波形相关系数为 `0.98852`，差异 RMS 为
`0.03324°`。因此 Mode 5 与 Mode 13 的差异约为 Mode 13 重复性误差的 2.17 倍，
存在小幅方法相关差异，但两者对编码器主要非线性的判断一致。

新电机首次适配推荐 Mode 5；电机模型和磁链观察器已验证、机械系统允许较高转速时，
Mode 13 可作为更强的闭环标定和交叉验证方法。无论选择哪一种，之后都必须执行
Mode 15 标定电角零位。

## 数据与比较方法

输入数据：

- Mode 5：`validation/mode13_debug_2026-09-05/mode5_encoder_lut.csv`；
- Mode 13 最终结果：
  `validation/mode13_debug_2026-09-05/mode13_final_lut/mode13_encoder_lut.csv`；
- 两组数据均为 1024 点，原始角度坐标逐点完全一致，最大坐标差为 `0°`。

LUT 中包含“编码器周期非线性 + 标定参考的常量相位”。为了比较编码器非线性，先对
每套 LUT 减去自身均值，再计算相关系数及逐点差异。绝对均值只记录，不作为两种方法
精度的比较依据。

同一 Mode 13 两次整体相差约 `120.16°`，接近 21 极对电机 7 个机械磁极节距
（`7 × 360° / 21 = 120°`）。这说明静态对齐可能落入不同的等效磁极位置，LUT 的
整体常量不能直接解释为编码器误差。Mode 15 会重新建立电角零位并消除该常量。

## 方法差异

| 项目 | Mode 5 | Mode 13 |
| --- | --- | --- |
| 参考角 | 电流闭环驱动的连续电角指令 | 磁链观察器连续角度 |
| 观察器依赖 | 无 | 必须先验证 R/L/磁链和观察器等效电阻 |
| 当前机械速度 | 约 6 rad/s | 约 20 rad/s |
| 当前阻尼器采样 | 1 个机械圈 | 5 个机械圈，另加 1 圈验证 |
| 能量和机械风险 | 较低 | 较高 |
| 主要系统误差 | 阻尼负载造成的电流矢量—转子负载角 | 观察器模型、逆变器电压模型和动态相位误差 |
| 新电机首次标定 | 推荐 | 不推荐直接使用 |
| LUT 内部验证 | 每桶覆盖和堵转检查 | 每桶覆盖、闭环跟踪及独立验证圈 |
| 后续 Mode 15 | 必须 | 必须 |

Mode 5 的优势是启动条件少、能量较低，不会形成“用未标定观察器标定编码器”的循环
依赖。Mode 13 的优势是多圈采样和独立验证，并在实际旋转闭环工况下建立参考；其前提
是观察器已经用独立证据证明能够正确锁速。本次故障正是该前提不满足时被锁速门限
正确阻止。
