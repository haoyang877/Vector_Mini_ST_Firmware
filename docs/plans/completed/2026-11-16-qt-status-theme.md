# Qt状态展开与浅色主题修正

基线68f6b503 / v2.0.0。按用户截图展开版本、运行状态、模式与故障；统一浅色调色板及控件边界。
不修改协议、刷新节拍、固件、温度测量或扫描行为。保留用户已有两处Keil工程修改。
主题独立文件维护，Qt主窗口负责状态投影；避免系统深色主题混入默认控件背景。
验收：离屏Qt测试正常/未知/过期/故障字段，深色系统调色板下浅色主题，1280×900及1536×960截图、PR和Windows包自检。
