# APP 体积优化计划 v1

## 目标与基线

基于已提交 v0.5.2（2add54e1），在保留 mode 3、速度环、mode 13/15 标定、
CAN、保护和参数持久化的前提下，增加 96 KiB APP 分区余量。
基线重新构建：Flash 93,880 B，RAM 27,856 B，Keil 0 错误、0 警告。
原工作区有未完成的热保护合并；本方案在独立工作区实现，不覆盖该合并。

## 方案与行为边界

1. 移除 APP 对 mode 18 阻抗控制器的调用与复位引用，让链接器裁剪未引用实现。
   保留模式编号、参数布局及备用摩擦常量。通信准入拒绝 mode 18；调试器直接
   写入 mode 18 时清零电流指令、报现有参数错误并走正常关相路径。
2. 将 1024 点全周期正弦表缩为 512 点半波表，按索引镜像取负恢复后半周期。
   原表包含周期两端，实际间隔为 2π/1023，不能直接按 256 点四分之一周期镜像。
   保留原归一化、索引比例及所有合法旧索引的逐位结果；归一化舍入到 2π 时
   将索引 1024 环回 0，避免旧实现越界。

不调整位置/速度增益、前馈、限流、运动范围、RTT、堆栈、Flash schema、Loader
或参数分区。mode 18 属于有意减少的功能，其余控制状态和输出保持不变。

## 验收与证据

- 全部 1024 个旧表值逐位比较；覆盖正负角、多周期和查表边界。
- 回归 mode 3、速度环、标定、CAN 和保护的已有离线检查；补充 mode 18 拒绝测试。
- Keil 正常及 HIL 构建均 0 错误、0 警告；对比 map、BIN 和资源占用。
- 检查 ARM 反汇编新增路径，记录执行时间证据的范围；主机耗时不能冒充 MCU
  的 20 kHz 中断实测。无本轮台架授权时不下载、不启动电机，不宣称实机验证完成。
- 输出、日志、补丁及哈希保存到 outputs/app_size_v1/；跟踪源码不含本机路径。
- 此历史分支若缺少 verify/format/lint profile，记录缺失并运行现有测试和构建入口。

## 回退

恢复上述调用、模式准入及全周期表即可回到 v0.5.2；参数 ABI 不变，无需迁移。
未完成的热保护工作不属于本补丁；后续集成需重新构建、核验保护和资源占用。

## 完成记录

离线验证及正常/HIL 构建完成，净省 Flash 7,972 B、RAM 152 B；没有硬件操作。
