采用此前0.5A±0.1A扫频拟合的等效对象：R≈0.719Ω、L≈153.2μH；额外延迟拟合约48.8μs，
设计取一拍50μs，并在离散RL对象中计入零阶保持。额外延迟与保持效应不能重复计算。
这些参数来自同一批闭环数据辨识，不等于独立测量的绕组参数或硬件延迟。

离散对象为G(z)=[(1−a)/R]z⁻¹/(1−az⁻¹)，a=exp(−R Ts/L)，另乘一拍z⁻¹。
沿用现有后向积分PI：C(z)=Kp+Ki Ts/(1−z⁻¹)，取Kp/(Kp+Ki Ts)=a，
再按闭环幅值在1200Hz处为1/√2求增益。模型无增益隆起；这些均为预测，不能替代实测。

实现只改变AT32/YQ组合的PI选择和参数装载；复用现有FOC与台架接口。
采样/PWM时序、观测器R/L、Flash记录格式及标定不变，其他板卡/电机仍采用原派生策略。

## 实测结果

| 项目 | 结果 |
| --- | --- |
| D轴扫频0.5A±0.1A、Iq=0 | 27个频点、54组有效记录；1193.9Hz，目标偏差−0.51%；两次分别1164.3/1208.3Hz |
| 增益隆起 | 相对低频最大+0.056dB，未见明显隆起；最大采集残差约8.3mA RMS |
| 扫频运行状态 | 正常结束，无保护截止；快窗速度峰值0.350rad/s，电压矢量估计峰值0.761V |
| 关相三相噪声 | 5个20kHz快窗及1个抽取窗口通过；7.03～9.53mA RMS |
| 零电流 | Id 7.17mA、Iq 9.41mA RMS，通过 |
| Id=0.3A | 三次5秒运行通过；快窗Id 6.04～7.81mA、Iq 8.98～10.30mA RMS；长趋势检查通过 |
| Id=0.75A第1次 | 设备run_state=4、reason=2（速度截止）、fault=0；正式采集0点，失败 |
| Id=0.75A第2/3次 | 未执行 |
| Id=0.3/0.75A六次阶跃 | 保护截止后取消，未执行 |

限值沿用3A、5rad/s、1rad、500ms租约；不重试上轮高偏置触发限速的工况。
扫频交点由相对低频增益下降至1/√2定义，在1171.875～1250Hz两点之间按对数频率插值。
此值是0.5A±0.1A工况下参考到板载原始Id反馈的闭环带宽；不是Q轴、所有偏置或负载的带宽结论。
相位裕度70.7°仍为模型值，本轮没有独立开环注入测量。

0.75A截止前只有2个主机趋势点，最后一点Id=0.73367A、Iq=−0.01122A、速度2.82756rad/s；
该点早于保护触发，不能用它否定板端的速度截止原因。正式采集前已停止，尚无该工况电流振荡证据，
不能据此判断是PI失稳或确认角度问题。原始设备reason=2保存在单项记录中；
主机批次随后报“长趋势点数不足”，总报告按原始设备状态显示失败，而非仅记录主机后续错误。

CAN打开问题经用户重连USB后恢复。所有运动完成后再次核对关相、故障0、LUT、零位18681、
标志3、极对数14、实际PI、完整Flash及看门狗分频0/重载511/调试冻结0。
