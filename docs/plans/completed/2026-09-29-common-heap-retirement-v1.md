# 取消 common 与通用堆分配器 v1

日期：2026-09-29。基线：8aec70ad1912f29ee860e680ad35dc0d797bfdd6。

## 目标与不变行为

取消 firmware/common。数学实现归 motor/math/control_math，删除链表式 heap，
用 APP 私有固定联合工作区复用编码器采样、schema12 参数记录和齿槽候选空间。
编码器任务通过明确参数借用采样对象，不调用 APP 或分配器；不创建三份大数组。

保持控制公式、标定阶段与结果、协议/参数 ABI、16 KiB 存储区和主状态优先级。
工作区占用更新有短临界区；任务取消不等于内存可以立即复用，只有实际任务/后台
归还后释放。启动参数借用在调度启用前完成，保存仍在前台执行并核对原任务身份。
删除空闲链表和块头，资源变化单独记录；不把新镜像当作旧候选的实机证据。

## 实施范围

1. 保存基线源码、工程输入和用户未提交修改，记录当前候选与产物。
2. 数学源文件改路径和包含名，保留公式；同步实际调用、测试与工程输入。
3. 编码器工作区类型与借用参数归标定接口；取消/完成仅清除借用，不释放内存。
4. APP 维护工作区唯一持有类型联合体，维护组合层负责占用和实际释放确认。
5. 删除 heap、碎片合并测试和 common 架构分类；新增固定工作区互斥及归还检查。
6. Keil 删除 Common 组，数学并入 Motor，工作区并入 App；保留用户配置与源码选项。

检查三种实际对象容量/对齐、重入借用、冲突拒绝、错误归还无副作用和归还后复用。
使用现有标定/状态机测试核对成功、失败、STOP/FAULT 清理接线。
最终执行仓库 PR 门禁与 normal 主工程编译一次，不扩大多目标或实机验收。
