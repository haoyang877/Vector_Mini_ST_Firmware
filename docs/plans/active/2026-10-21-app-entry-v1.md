# APP四入口收口 v1

日期：2026-10-21。用户要求统一初始化、前台、20kHz快环和2kHz监督入口，
清理旧命名与多余跳转，保持控制算法、保护阈值和Keil Watch入口不变。

## 基线与目标

基线提交：`b10a7698140fe53e4fecaea906d434a6876fdf36`，APP1.5.6 / Loader2.1.0。
参考产物：`outputs/delivery/naming-layering-b266c21d-20261021/summary.json`。
配套APP Flash81360 B / RAM18552 B；Loader Flash14520 B / RAM4344 B。
工作树原有参数说明、两份计划及`.vscode/`改动保留，不纳入本批。

统一公开头为`firmware/app/composition/app.h`，只声明四个void入口：

| 新入口 | 实现与原路径 |
| --- | --- |
| App_Init | app_startup.c；原Board_Init，保持参数、电机、采样和通信绑定次序 |
| App_Process | app_startup.c；主循环四句后台编排集中至此，原序不变 |
| App_FastTick | app_tasks.c；原FOC20kHzIRQHandler，调用MotorAxis_FastTick |
| App_SupervisorTick | app_tasks.c；原BSP2kHzIRQHandler，直接调用MotorAxis_SupervisorTick后执行原指示器分频 |

Board_ServiceBoot改为私有service_boot，公开入口前置，辅助实现后置；
删除FOC2kHzSupervisor单调用跳板及两份旧入口头，不保留旧API兼容包装。
main和ADC/TIM回调只经app.h调用四入口；CubeMX仅改USER CODE区。
不增加调度器、注册表、可变状态或功能开关，不迁移算法和硬件职责。
本批候选APP1.5.7；Loader2.1.0、layout6、schema14及12/13兼容读取不变。

## 不变项

- BootHw_Init、HAL/时钟/外设初始化和预取启用位置不变。
- App_Init在MotorAxis_Init后才启动采样，再绑定并启动通信；失败关相行为不变。
- App_Process保持后台事务、状态刷新、通信Service、启动交接顺序；
  两次time_hw_now_ms仍分别在原位置求值，不合并时间快照。
- ADC完整JEOS资格、20kHz快速关断路径、TIM7监督及指示器执行顺序不变。
- 控制公式、浮点求值、采样、状态/故障、保护阈值、协议及参数字节不变。
- 14个关键Watch对象名称、声明、大小及所属模块不变；调试使用新镜像匹配AXF。
- Keil源登记、逐文件优化、调试/下载/Watch设置不变；不重新格式化生成区。

先对原入口归一化函数体、四后台调用序列、CubeMX非USER CODE区域和Watch声明作只读对照。

执行PR及适用release profile，normal和配套APP编译并记录资源、镜像/AXF身份。
现场未提交修改如阻止正式release门禁，明确记失败，不清理用户内容或伪称发布通过。
本轮不连接硬件、不烧录、复位或运动，不继承旧二进制实机及中断时序结论。

回退以本批独立提交为单位，参照上述基线；不reset/clean或改其他工作树引用。
若出现控制/输出/状态/阈值或调用顺序变化，停止入口迁移并修正，不以降低保护绕过。
