## 不变条件

- 不改算法、参数取值、计算顺序、调度频率、启停/故障/保存/取消语义。
- 不重排结构成员、不改变类型宽度、枚举数值、持久记录和线路布局。
- 单轴所有权及显式借用保持，不为改名增设大型上下文副本或跨层可写全局。
- HAL、CubeMX 生成区、第三方及冻结共享线路标识保持；生成文件只调整 USER CODE 调用，
  Keil 工程与生成工具同步维护自有文件路径，不增加兼容包装。
- 不新增风格/架构/接口豁免，格式整改不改变可执行语义。

## 命名约定

文件 snake_case；自有类型 PascalCase，移除冗余 TypeDef 后缀；公开函数 Module_Action，
私有函数 snake_case；文件私有变量 s_，必须公开可写对象 g_ 加模块名；结构成员、参数、
局部变量 snake_case。只读配置仍 s_，由 const 表明只读。宏与枚举大写并保留数值。
物理量按实际表达添加 rad/rad_s/a/v/ohm/h/wb/ms/us/ticks/counts 等单位。
编码器按 rotor 角色命名，为后续输出轴传感器保留清晰词汇，不增加新传感器功能。
