# Vd/Vq修复与1.2kHz电流环实测

2026-11-02，AT32F456＋YQ-5708（8:1）。新固件已烧录，实际PI对应1.2kHz整定；
Vd/Vq和已测Id工况通过。Iq第二次短脉冲触发5rad/s台架速度截止，因此本轮不能判定Iq完整验收通过。
测试结束已关相，故障0，编码器标定和参数Flash未变，板上保留本次1.2kHz固件。

## 最小实现

生产代码仅改3个文件，没有新增模块、接口、滤波或状态机：

- `foc.c`在完成阶段从限幅后调制量和母线电压更新`voltage_dq_v`，原PI输出跟踪复用该值；复位清零。
- `application_config.h`目标带宽由1000改为1200Hz。
- `parameter_record.c`装载参数时按活动R/L生成电流PI，避免已存1kHz增益覆盖新目标。

参数记录布局和CRC未变；保存的四个电流PI值不再覆盖固定带宽策略，模型、标定、外环和保护仍按原接口装载。
详见[整定和兼容说明](../../guides/current_loop_tuning_v1.md)。Vd/Vq是下发调制对应的电压估计，
包含母线测量、不含独立绕组电压测量，不能用来声称死区和管压降已被测量。

实机读取R=0.550000Ω、Ld=Lq=142.500μH；d/q均为Kp=1.07442474、Ki=4146.90283、Ts=50μs。
四种Kp/L、Ki/R反算均约1200Hz。目标整定值与下面的阶跃等效值分别记录。

## 已执行结果

截止仍为相电流3A；本轮附加电机速度5rad/s、累计行程1rad、500ms通信租约。
每次Iq脉冲前检查速度和位置停稳；没有提高保护门限重试。

| 项目 | 结果 |
| --- | --- |
| 108查询、124推送 | 正负50mA目标下Vd/Vq有效，Vq分别读到+173/+147mV和−201/−216mV；CRC、关联序号和限幅范围通过 |
| 关相采样噪声 | 6个128点窗口通过，三相7.46～9.48mA RMS；原1kHz为7.67～9.31mA |
| 零电流稳态 | Id 9.58mA、Iq 12.38mA RMS，通过60mA建议限值；比原8.15/8.67mA有所增加 |
| Id=0.3A稳态 | 3次5秒运行，Id 7.50～8.11mA、Iq 7.92～9.00mA RMS，通过 |
| Id=0.75A稳态 | 3次5秒运行，Id 6.76～7.95mA、Iq 8.64～9.09mA RMS，通过 |
| Id阶跃 | 6次全部通过；最大超调6.32%，稳定时间0.85～1.40ms |
| Iq=0.3A、5ms脉冲 | 第1次通过，上升0.784ms、稳定2.45ms、超调3.26%；第2次速度保护停止，第3次取消 |

快采样为20kHz，每窗128点；稳态窗口分别取约0.2、2、4秒，另有主机低速趋势。
这些离散快窗不拼接成连续高速记录。Iq失败原因来自设备原始`reason=2`；
快窗中的速度峰值不一定覆盖稍后触发截止的时刻，因此不以快窗峰值改写设备停止原因。

## 前后阶跃对比

下面使用相同参考幅值、50μs周期和32点预触发。10%–90%过阈值做线性插值；
`f_eq=ln(9)/(2π·t10–90)`只是一阶大信号阶跃等效值，不是扫频−3dB带宽。

| --- | --- | --- | --- | --- |
| Id 0→0.3A | 0.865～0.939ms | 0.674～0.776ms | 372～404Hz | 451～519Hz |
| Id 0→0.75A | 0.546～0.595ms | 0.487～0.542ms | 587～640Hz | 646～718Hz |
| Iq 0→0.3A | 0.780～0.983ms，2次正常结束 | 0.784ms，仅1次正常结束 | 356～448Hz | 446Hz，仅单次 |

已测Id响应变快，未见持续振荡，超调未超过10%。六次Id阶跃的最大电压矢量估计约1.12V，
这些低电流工况未接近约30.8V母线的调制上限。不能将此推到3A、大转速、锁轴Iq或满负载工况。
1kHz基线也发生过Iq速度截止，本轮不以该现象单独证明增益导致失稳；也不把Iq完整验收写成通过。
