重新测量相电阻与双向摩擦，并据此更新 `position_impedance_config.h` 的动摩擦/
启动电流常数。**这不是发布记录**；分支的实验性质与母线电压约束不变。

## 1. 相电阻（mode 17）

| 项 | 值 |
| --- | ---: |
| 三相电阻 | A 2.1862 / B 2.2188 / C 2.2054 Ω |
| 均值 | **2.2035 Ω** |
| 不平衡度 | 1.48 %（`valid = 1`，`warning = 0`，`balanced = 1`）|
| 参数中原值 | 1.9050 Ω（数据手册"相间 3.81 Ω ÷ 2"）→ **偏低 13.5 %** |

由此得到 28 V 母线的转矩预算：调制上限 `0.8227 × 27.86 / 1.5 = 15.28 V`，
堵转电流上限 `15.28 / 2.2035 ≈ 6.93 A`（不是 8 A）。**电流环在 28 V 下是被电压
限制的**；31 V 时上限提高到 `17.0 / 2.2035 ≈ 7.7 A`。

## 2. 双向摩擦扫描（运动中逐点降速，正反向各 5 点）

先正转再在运动中换向，避免"从静止突破"污染数据。编码器实测：

| 指令 | 正转：平均转速 / iq | 反转：平均转速 / iq |
| --- | --- | --- |
| 0.60 rad/s（5.7 rpm）| +3.93 rpm / +3.395 A（静止 51 %）| −7.41 rpm / −3.746 A（静止 42 %）|
| 1.19（11.4）| +10.97 rpm / +3.787 A | −10.47 rpm / −3.336 A |
| 1.79（17.1）| +17.17 rpm / +3.253 A | −17.65 rpm / −3.265 A |
| 2.40（22.9）| +23.83 rpm / +3.225 A | −23.66 rpm / −3.079 A |
| 2.99（28.6）| +29.02 rpm / +3.303 A | −29.30 rpm / −3.184 A |

结论：

- **正反向对称**：≥14 rpm 平台区 3.260 A（正）/ 3.176 A（反），差 2.6 %；
  <14 rpm 的 Stribeck 区 3.591 / 3.541 A，差 1.4 %。反向摩擦并不更大。
- 摩擦随速度升高而下降（低速 Stribeck 特征），平台约 3.2 A ≈ 1.8–2.2 Nm。
- **<10 rpm 两侧都进入爬行-突跳**（静止占比 42–51 %），瞬时转速峰峰达均值的
  155–347 %；该波动来自齿槽 + 静摩擦 + 测速环带宽，不是前馈数值能解决的。

## 3. 从静止突破（唯一的不对称）

| 场景 | 结果 |
| --- | --- |
| 正向从静止启动 | 爬行 0.7 s，电流升至 **4.5 A** 后突破，过冲至 63 rpm |
| 反向从静止启动（28 V）| 电流到 **5.1 A** 仍未突破 |
| 反向从静止启动（31 V）| t = 0.59 s **成功起步**（−4.7 A，冲到 −38.7 rpm），但 2.7–3.1 s 又停住 |
| 运动中反向 | ≈3.3 A 即可维持（-8.6 rpm）|

31 V 那次"起步后又停住"的原因是控制侧：速度环过冲后把电流降到 −2.1…−2.7 A
（≈1.4–1.7 Nm），低于维持运动的动摩擦（≈3.2 A）→ 减速停转，再突破时绕组已发热
（母线轨电流从 −4.81 衰减到 −4.35 A）。**不是转矩不足。**

## 4. mode 3 位置串级 0°→180° 的摩擦前馈 A/B

工况：`pos_maxspeed = 45 °/s`、加减速 0.7854 rad/s²、母线 30.95 V。

| 摩擦前馈 | 最终位置误差 | 过程峰值误差 | 峰值 Iq |
| --- | ---: | ---: | ---: |
| 实测模型 `friction_coulomb_pos/neg = 3.6/3.5 A`（`friction_model_valid = 1`）| **−0.182°** | 38.46° | 3.89 A |
| 编译期旧值 `POSITION_IMPEDANCE_FRICTION_* = 1.55/1.50 A` | **+4.273°** | 16.54° | 4.22 A |

- 终点精度改善约 23 倍：旧值只有实测动摩擦的约 43 %，稳定欠力、停在目标前 4.3°。
- 过程峰值误差反而变大（38.5° vs 16.5°）：mode 3 的启动电流 = 动摩擦 ×
  `FRICTION_BREAKAWAY_RATIO(1.20) = 4.32 A`，且 `ATTACK_SLEW = 200 A/s`（21 ms 到位），
  超过实际突破需求 → 起步"窜"在轨迹前。**这是后续整定点。**
- 两次运行 `isReachTargetPos` 都未置位：该标志要求误差 ≤ `pos_error_window = 0.001 rad
  = 0.057°`，而稳态残差约 0.18–0.23°（静摩擦平衡偏置）。

## 6. 已知限制（后续仍需处理）

1. **反向"从长时间静止"启动**在 28 V 下无法完成（实测 >5.1 A 未突破），
   4.2 A 只是下界；31 V 可起步但随后被速度环的电流回落拖停。需要提高母线
   （本分支的 36 V 方向，注意 `BUS_VOLTAGE_ENABLE_MAX_V = 33.8 V` 与硬件 >35 V 约束）
   或给速度模式加摩擦前馈。
2. **`FOC.temp` 读数为 −273.15 °C**，`temp >= 100 °C` 的过温保护永远不触发；
   在提高电流/电压之前必须先修该采样通道。
3. **启动过冲 38°**：建议把 `POSITION_SERVO_FRICTION_ATTACK_SLEW_A_PER_S`
   由 200 A/s 降到 20–50 A/s，或把 `FRICTION_BREAKAWAY_RATIO` 由 1.20 降到
   1.0–1.05，再复测同一 180° 轨迹。
4. 本次未验证：带载、温升、CAN 路径、反向长时间静止启动在 33.8 V 下的表现。

## 7. 跑合（run-in）效应实测

在转速闭环下让电机恒速运行，观察维持转速所需的摩擦电流是否随时间下降。曲线见
`outputs/damping_ring_20260922/04_runin_friction.svg`（本地证据）。

方法：speed mode 恒定 2.0 rad/s（19.1 rpm）连续运行 180 s，按秒统计 iq 均值；
用 mode 17 在运行前后各测一次相电阻，按 `R_hot/R_cold ≈ 1 + 0.00393·ΔT` 推算绕组温升
（`FOC.temp` 读数失效，这是唯一可用的温度代理）。

**同一次连续运行内的趋势（转速恒定 19.05 rpm）：**

| 窗口 | iq 均值 |
| --- | ---: |
| 0–30 s | 3.329 A |
| 30–60 s | 3.303 A |
| 60–90 s | 3.180 A |
| 90–120 s | 3.148 A |
| 120–150 s | 3.130 A |
| 150–180 s | 3.140 A |

前 30 s → 后 30 s **−5.7%**，约 90 s 后趋于稳定。

**冷态对冷态（分离"跑合"与"升温"）：**

| 条件 | 相电阻（温度代理）| 19.1 rpm 维持电流 |
| --- | ---: | ---: |
| 跑合前（冷） | 2.1272 Ω | ~3.24 A（由跑合前双向扫描插值）|
| 跑合中（热，稳定后） | 2.4738 Ω | 3.140 A |
| **跑合后（冷，冷却 7 min 至 2.2113 Ω）** | 2.2113 Ω | **2.958 A** |

**冷态对冷态 −8.7%**；跑合后复测的 60 s 内已无进一步趋势（2.947→2.965 A），说明
**跑合在约 3 分钟内基本完成**。近静止（<0.48 rpm）样本占比从 36.3% 降到 25.3%。

**对已提交常数的影响**：第 5 节的 3.6/3.5 A 是跑合**前**测的，跑合后平台约降到
2.97 A、Stribeck 区约 3.28 A（按 −8.7% 折算）。即当前前馈比跑合后的实际摩擦高约 10%，
属于轻微过驱动。是否下调需在跑合状态下重新扫描一次正反向（并复测反向启动）后决定。
