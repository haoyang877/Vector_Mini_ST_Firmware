# 模式3位置控制优化过程（2026-09-08）

本轮针对大惯量、大摩擦直驱机构的到位顿挫和停止抖动，保留串级位置/速度反馈，逐步柔化减速、摩擦前馈卸载，并增加静止点到点的连续加速度轨迹。最终实机版本为 `image33_c3_bounded_plan`。±20°及大范围复测的末段保持精度满足电机端±0.3°；用户反馈“有改善，但仍有抖动”，结构抖动尚未解决。

## 目标与起点

- 用户允许运动范围±90°，最大巡航速度8 s/rev，即45°/s。
- 自动验证目标限制±85°，主机/板端位置停止边界为±88°/±90°，包含+85°到−85°的170°行程。
- 问题发生在到达目标、仍使能保持时。优化不能只靠关闭驱动消除抖动，也必须保留位置保持能力。
- 前一提交 `2a37d34` 已完成模式3跟踪、摩擦补偿、捕获保持和实时路径整定；其过程见 [初始验证记录](mode3_validation_20260908.md)。本次提交在其基础上处理停止平顺性。

## 最终控制设置与实现

| 项目 | 本轮台架设置或有效限制 |
| --- | --- |
| 巡航速度 | 45°/s（8 s/rev），短行程可低于此值 |
| 加速度 / 减速度 | 45°/s² / `min(posDec, 30°/s²)` |
| jerk限制 | `max(有效加速度, 有效减速度) / 0.20 s`，本台架为225°/s³ |
| 位置Kp / Kd | 8 / 2 |
| 速度Kp / Ki | 0.5 / 1；沿用既有参数缩放含义 |
| 速度滤波 | 40 Hz |
| 到位摩擦卸载 | 最高30 A/s；越过目标和换向沿用快速卸载 |
| 保持进入 / 退出位置窗口 | 0.18° / 0.26° |
| 既有电流上限 | 6 A |

这些是本台架整定值，不是通用机械额定能力。Flash中的posDec仍为45°/s²，30°/s²由模式3适配器限制；本轮没有保存新Flash参数。没有确定负载惯量与转矩常数，加速度电流前馈Ka保持0。

新模块 [position_smooth_trajectory.c](../Foc/position_smooth_trajectory.c) 为调用方持有状态的纯C算法，不依赖MCU、HAL或动态分配。静止定位用五次速度多项式同时生成q/v/a，段间jerk连续；运动中改目标、改限值或启用参考治理时，保留q/v/a并转原在线限jerk路径。后者不承诺切换处jerk连续。

每控制周期最多进行4次峰值速度搜索，规划准备期间保留原支撑电流，准备收尾周期不叠加完整外环计算。传感器/参数有效性检查与原快保护仍在。具体接口、公式和退回在线轨迹的条件见 [控制器说明](position_servo_control.md)。

## 验证结果与未解决问题

最终±20°测试最大保持误差0.120°，最大超调0.078°，末段均保持HOLD，无到位前持续低速停留。大范围测试最大保持误差约0.230°，Iq记录峰值3.052 A，末段HOLD占比100%，未记录RTT丢帧或限流标志。

大范围仍存在+85°约0.34 s、−85°约0.10 s的低于2°/s末段收敛；+85°还伴随摩擦前馈脱困。相较image29，+85°持续进入±0.3°由3.547 s增至4.067 s，170°行程由5.204 s增至5.764 s。轨迹更平滑有时间代价，未证明消除了原有顿挫。

最终大范围DWT记录最大8448周期（约49.69 μs），1200780次记录均低于50 μs。测量不含全部异常入栈/返回开销，不能据此声称完整最坏执行时间验收通过。NTC未安装，本轮不包含热保护验收。后续需要同步观察实际Iq、速度和结构振动，区分摩擦脱困、力矩变化与机械响应；不能仅根据电机端位置曲线判定结构抖动已消除。
