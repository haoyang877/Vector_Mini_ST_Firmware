# 公共接口中文契约补全

## 目标

让公共头文件说明接口用途、参数单位与所有权、返回条件、调用上下文、副作用和安全限制，
避免调用方必须阅读实现才能正确使用接口。

## 验收条件

- 新增 `check_interfaces`，机械要求中文 `@brief`、逐参数 `@param` 和非 `void` 的 `@return`。
- 新增或发生内容变化的公共头文件不能使用历史豁免。
- 黄金模板以及 platform API、遥测、CAN 状态和调度入口全部满足新契约格式。
- PR profile 包含接口检查且既有离线测试保持通过。
- 不改变固件行为、协议或参数 ABI，不修改并行开发中的未跟踪保护模块。

## 决策

- 注释使用简洁中文；协议名、类型名和命令字保留规范拼写。
- 历史债务按“文件哈希 + 接口名”固定；文件一旦修改，全部公共接口必须补齐。
- `@note` 由语义决定，不用无意义占位文字满足检查。
