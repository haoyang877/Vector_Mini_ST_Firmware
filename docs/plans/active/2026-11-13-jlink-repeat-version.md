# J-Link重复烧录与版本回读

基线GUI1.10.2，APP1.8.4/Loader2.3.4不变。烧录结束清掉GUI身份且相同镜像跳过写入，
导致用户无法直接重复烧录；现有CAN版本核验未展示实际版本值。
目标：桌面烧录每次按相同保护流程执行（同镜像也写），保留已校验身份供下一次操作，
每次重新核对探针/芯片；默认烧后复位并查询板端版本，明确显示APP/Loader及核验状态。
CAN失败和烧录失败分别展示，不把配置中的预期版本当成板端查询结果。初装重复只更新
固件，不重新覆盖参数；保留断点恢复和保护区逐字节校验。内部保留显式跳过重写和暂停
接口兼容性，桌面入口固定使用重复写入及烧后查询流程。
实现沿用现有program_motor、query_restarted_motor和GUI状态，不新增协议或模块。
验收：两次实际写入的内存替身、参数保护、重复按钮、CAN返回版本与不匹配/超时、
初装后的二次烧录回归；Release、打包。不自动烧录现场仍由用户操作的电机。
回退：旧上位机，无固件/参数迁移。
