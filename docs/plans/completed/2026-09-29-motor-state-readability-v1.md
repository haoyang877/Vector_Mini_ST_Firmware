# 电机主状态机可读性优化 v1

状态：实现与离线验收完成，合并主线并归档临时 worktree 收尾。
行为基线与回滚点：`e7c0f75d`；代码提交：`1e3e9c8`。

## 目标

将按完成事件/请求展开的转换规则改为按当前状态展开，公共优先级与
身份校验集中在入口。监督函数以明确阶段组织，保持同一拍的原调用顺序。
不使用 goto，不新增通用状态机框架、回调表、兼容头或第二条生产运行路径。
规则仍是唯一 APP 所有者使用的纯函数，数据仍由一个私有上下文持有。

## 保持不变的行为

- 九个主状态、控制模式、维护类型、CAN 编号、参数 schema12 及镜像契约不变。
- FATAL、故障、STOP、CANCEL、完成、新请求的优先级与拒绝原因不变。
- 有效任务失败不能被 STOP 隐藏，FAULT 中仍可确认取消归还。
- 请求时效、完成的创建时代际、取消身份、SAVE 提交效果和代际耗尽处理不变。
- 自检四个连续监督拍、500 ms 截止时间、未配置/未标定留 READY 的策略不变。
- STOP 关闭输出；停止确认要求真实关相和资源归还；CLEAR 后重新自检。
- 前台受理、20 kHz 快环、2 kHz 监督、后台保存与最终启相临界区复核不变。
- 同一监督拍仍可多次迁移；动作后的事实需重新回读，不能整拍共用旧快照。
- 不烧录、不写设备参数、不控制电机；不新增功能或更改保护策略。
