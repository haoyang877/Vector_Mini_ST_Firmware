## 实施与职责

1. ROOT 在独立发布工作树冻结实际输入，保留现场树和现有调试配置；不修改其他引用。
2. 主状态机专项完成用户批准的八状态和出口：INIT/IDLE STOP 原地，停止完成仅回 IDLE，
   FAULT 经显式 CLEAR 及真实恢复回 IDLE，FATAL 仅程序复位恢复。保持 STOP 屏障、
   功率回读、真实资源释放、任务/SAVE 身份与结果、控制数学及保护阈值。
3. ROOT 审真实差异与状态反馈映射后选择性集成，更新当前架构、状态图及协议版本说明。
4. 反馈与感测模块的实际平台采样接口保留；本批不为追求“全部纯函数”增加空适配层。
   计算与 I/O 的明确契约满足边界，新增违反 HAL/对象所有权规则的依赖必须修复。
5. 最终源码冻结后仅运行一次 release profile 和有用途的打包；失败只修具体问题，
   不增加五工程构建或重新验证旧控制数学。
6. T 只离线核对匹配证据和最小实机步骤，D 只核对升级产品/容量/包依赖；ROOT 不访问
   硬件，不替换正在运行镜像。实机前必须明确当前现场、硬件占用、产物和授权。
