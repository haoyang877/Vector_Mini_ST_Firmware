# D轴电流正弦扫频实测

2026-11-02，AT32F456＋YQ-5708（8:1），电机本体固定、输出自由，无外部电流探头或锁轴装置。
在Id=0.5A±0.1A、Iq=0的工作点，参考到板载原始Id反馈的闭环−3dB带宽约**2.96kHz**。
25个频点各测两次，包含带宽附近3个加密点；两轮交点约2.92kHz和3.02kHz。
用户允许的1.5～2A偏置档未通过：首次1.5A偏置建立初段触发5rad/s速度保护，未进入正式记录窗口。

## 工况和范围调整

原计划先用1.5A±0.3A完整扫描，再用2A±0.5A复核。但第1个频点的偏置建立初段即发生限速：

- 原始状态`run_kind=8、run_state=4、reason=2、fault=0`。
- 停止前快照：Id参考1.5A、反馈1.50059A、Iq反馈−0.01557A、编码器速度反馈3.267rad/s。
- 随后5rad/s保护触发；延迟触发的正式采集还未开始，冻结记录为0点。
- 仅靠现有快照不能精确区分截止在预热结束前还是正弦刚开始之后，不把这次称为高电流频响数据。
- 保存该失败后取消高电流测试，没有提高速度保护。另开0.5A±0.1A批次，峰值0.6A，复用此前低电流稳态依据。

较低电流批次25点、50次采集全部完成，未触发保护。采样窗口内速度最大0.400rad/s、
电压矢量估计最大0.877V，远低于约30.8V母线的调制上限；跨轴Iq基波幅值最大7.72mA。
本轮仍使用相电流3A、编码器速度5rad/s、累计行程1rad、500ms租约和本机运行时限。

## 方法

原FOC和PI不变。只在原Commissioning测试RUN增加kind=8正弦参考；使用现有Math_SinCos、
20kHz控制前钩子、GROUP_DQ冻结缓冲和原停止流程。正常AT32和STM32镜像逐字节不变。
测试镜像相对上轮增加约304字节代码、16字节ZI，没有新增控制模块或公共控制接口。
参数布局、标定与1.2kHz整定策略没有改变；协议说明见[台架v1.1](../../protocols/README.md#implementation)。

每次独立启动，偏置预热20ms，再给正弦；等待至少5周期且不小于50ms后，记录128点。
采样stride按频率选择，窗口至少4个完整周期，所有频率来自名义20kHz时基。
以同拍实际Id参考和原始Id反馈做含直流项的正弦/余弦最小二乘拟合，计算基波复数比H=Id/Id_ref。
低频增益基准取19.53125、39.0625、78.125Hz的均值；对相邻有效点按对数频率插值求1/√2交点。
这种方法使用稳定周期的幅相比；方法背景见[MathWorks正弦频响估计说明](https://www.mathworks.com/help/slcontrol/ug/frequency-response-estimation-using-simulation-based-techniques.html)。

主机拟合先通过已知幅值0.37、相位−0.85rad的合成信号自检。实测基波拟合残差最大8.78mA RMS；
同频两轮增益差最大0.86dB，最大差异出现在高频衰减区。−3dB附近两轮给出的交点差约100Hz，
因此最终报告约3.0kHz，不把插值的小数位作为测量精度。
停机下跨约2秒的INFO计数器检查约19.98kHz，与名义20kHz一致；短CAN往返时间不作为精密采样时钟。

## 结果

| --- | --- |
| 实际PI | d/q均为Kp=1.07442474、Ki=4146.90283、Ts=50μs |
| 主扫描 | 19.53125～3906.25Hz，22点×2次 |
| 加密点 | 2656.25、2812.5、2968.75Hz，各2次 |
| 低频增益 | 1.00341 A/A |
| 两轮平均响应−3dB交点 | 2963Hz；平均曲线由2812.5～2968.75Hz包围 |
| 第1轮交点 | 2923Hz |
| 第2轮交点 | 3023Hz；由2968.75～3125Hz包围 |
| 交点附近闭环相位 | 约−154°，含本实现的采样和控制延迟 |
| 1.5～2A偏置工况 | 未得到频响；1.5A档在正式记录前限速，2A未执行 |

1.2kHz是使用配置R/L计算PI的目标值；本次2.96kHz是特定工作点的闭环频率响应测量。
此前0.45～0.72kHz来自0→0.3/0.75A大阶跃的一阶折算，不是频响测量，不能用它替代本次结果。
二者的偏置、幅值、非线性和计算定义不同；本次也不能外推到1.5～2A、高速、带载工况。
没有开环注入，不能仅凭这里的闭环相位宣称已测得开环相位裕度；无外部探头，不能独立验证板载采样链的绝对频响。
