# 电机主状态机核心精简 v1

## 目标与范围

在当前工作区已有重构基础上，保留全部对外功能和行为，精简状态机及其私有规则的生产路径，删除无实际生产用途的通用机制和重复逻辑。优先删除而非仅移动代码；跨执行上下文的状态仍由同一所有者管理，不为缩短单文件引入额外可变状态或依赖。

## 不变项

保持八状态及迁移、启动和维护准入、故障锁存与恢复、停止优先、启相和实际关闭确认、异步完成代际、取消与资源归还、Flash提交语义、通信重试和序号、启动自检和就绪查询、Loader交接、对外协议与参数ABI、20 kHz/2 kHz顺序和功率许可。修复快故障抢占目标准入后错误报告已应用的既有竞态；不得弱化中断下复核，不接触硬件。

## 基线与验收

修改前工作区源快照及原生状态测试保存在 `outputs/state_simplification_20261029/`。逐项确认私有接口的全部生产调用，使用原生状态/功率轨迹和规则测试核对，再运行PR验证、格式及lint；可用时比较目标构建、Flash和RAM。记录失败、不可运行项及实机时序未测，不能把行数下降作为行为等价证据。

## 阶段与回退

1. 根据真实调用删除无生产用途的规则动作、事件组合或身份镜像，配套保留有意义的行为测试。
2. 合并能够证明等价的重复所有者逻辑，保留跨上下文原子性；不为达到目标数字而删除功能。
3. 更新架构说明，记录源代码体量、验证和剩余约束。

仅回退本计划的改动，保留此前用户工作树改动和ignored数据。

## 本轮结果

- 规则只接收生产所有者串行提交的单事件；删除无生产消费的启控/开始维护动作、未使用的通信恢复事件、同步请求的冗余代际和内部首故障镜像。异步完成代际、请求新鲜度、实际对外故障代码及故障位锁存保留。
- 不再为快环唯一写入的对齐32位采样计数单次读取设置BASEPRI；ADC本就可抢占。Loader停机请求在已持有同一控制临界区时直接调用锁内停止逻辑，去掉一次嵌套屏蔽。
- 模拟ADC在目标准入检查期间抢占发现：故障已关相、原请求已拒绝，但监督仍会覆盖为已应用。最终目标及进度提交改为短PRIMASK区间，区间入口重新检查故障；完整目标校验不在该区间。原生夹具加入同一抢占反例，复核故障、关相、目标和拒绝结果。区间实际耗时尚未在目标上测量。
- 改前冻结工作区快照和改后比较见 `outputs/state_simplification_20261029/`：单事件262144项规则摘要、所有者功率/事件轨迹及R40温度可选配置轨迹一致；去除未被生产使用的动作位与内部诊断字段后进行比较。已有样本进展、停止及升级交接用例通过。
- 最终PR通过：`outputs/runs/20261029T103945942015Z-2dbb4003/summary.json`。使用Keil 5.36在独立源码快照重建STM32G431与AT32F456 APP，均为0错误、0警告；日志在 `outputs/state_simplification_20261029/target_snapshot/`。未连接硬件或测量实机中断耗时。
- 当前实现仍有必要的低优先级临界区；原生夹具把控制锁视为完全互斥，不能证明ADC可抢占时所有竞态均安全。
