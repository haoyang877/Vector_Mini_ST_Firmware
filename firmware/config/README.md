# 固件配置

两个正式工程共用四个配置文件：

| 文件 | 作用 |
| --- | --- |
| `config.h` | 全局选择当前使用的一套板卡和电机。 |
| `board_config.h` | 两块板的资源、引脚、采样电路和时钟。 |
| `motor_profile_config.h` | 两种电机的物理参数、标定输入和热参数。 |
| `application_config.h` | 应用限值、控制参数、保护和自动派生公式。 |

| 工程 | 板卡 | 默认电机 | 输出 |
| --- | --- | --- | --- |
| STM32 APP | STM32G4，默认 6 mΩ 分流 | HT8115-4 | 由正常保护和状态机管理 |
| AT32 OFF | AT32F456 | YQ-5708 | 硬件永久关相 |

在 `config.h` 中全局选择一套板卡和电机；切换正式工程前手动修改这两项，选择的板卡必须匹配工程 MCU。更换同 MCU 板卡时，还需在 `board_config.h` 中核实或修改板卡参数；更换电机时，在 `motor_profile_config.h` 中核实或增加型号参数。更换 MCU 或硬件连接还需要同步修改 BSP 和工程。电流环默认 PI、采样比例和已确认同轴的标定电角速度由输入自动派生；速度 PI、安全限值和热时间常数须按实际系统确认。

板卡功能直接由板卡资源决定，不提供独立的逐项开关。STM32 当前固定使用 6 mΩ 分流电阻和对应补偿；更换为 2 mΩ 时需同时确认并修改采样电阻、路径补偿与可靠量程。两套工程的命令/标定上限均为 10 A、过流阈值为 18 A；AT32 限值由用户确认硬件能力后调整。首次默认电流固定为 6 A，修改板级限值时需同步检查。AT32 正式工程不再构建 RTT 调试遥测。

YQ-5708 尚缺少确认的热模型参数。AT32 空白设备的热模型为无效占位，初始化会报告参数故障，硬件保持关相。取得实际热参数后，需要在电机配置中填写热模型并将该型号的 `PARAM_MOTOR_APP_DEFAULTS_READY` 设为 1，重新构建；当前逐字段配置流程不能从全零热模型直接完成初始化。不要把临时值当成正式电机数据。

已有有效 schema 14 Flash 记录仍优先于首次默认值，模型、手动整定 PI 和设备标定不会因更改电机默认值自动更新；更换电机后需要确认并更新实际设备参数。AT32 的温度校准也尚未确认，补充电机热数据不会自动解除硬件关相。
