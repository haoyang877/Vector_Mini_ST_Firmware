# Qt自动连接与状态刷新修复

基线d17a0d45 / v2.0.1。扫描临时连接与常驻刷新断开、单台扫描未选中，导致未读取。
将Qt扫描接入常驻会话；启动只读扫描一次，单台自动选中，多台保留在线选择或首个在线节点。
扫描完成立即状态读取，此后1秒刷新。显式断开不自动重连；失败不循环扫描。离线自检关闭启动连接。
不改变SWD、升级、运动、参数、固件；任务仍串行且释放确认后才交接。已有Keil改动保留。
验证常驻扫描/状态复用、单/多台/空扫描、断开/失败、无JLink路径、原互斥；PR及包自检。
发布v2.0.2，冻结固件不变；回退v2.0.1。当前只离线验证，不访问硬件。

Qt扫描使用常驻CAN，单台自动选中，多台保留有效选择；扫描完成后立即读状态，之后1秒刷新。

JLink识别失败保留CAN身份；离线自检不执行启动扫描。
