2026-10-10策略说明。用户确认位置测量噪声约±0.025°，
并希望停靠后依靠阻尼环保持，避免摩擦模型往复助推及速度积分产生大保持电流。
对应[实施计划](../plans/2026-10-10-damped-passive-hold-v1.md)。

| 判据 | 默认范围 | 含义 |
| --- | --- | --- |
| 精确到位 | ±0.08°，0.0013962634 rad | 连续位置/低速资格50 ms后标记到位 |
| 被动停靠进入 | ±0.5° | 参考轨迹结束、速度≤0.003 rad/s连续50 ms后卸流 |
| 窗口内 | 原始或资格偏差≤0.5° | 不产生保持/纠偏电流；清除纠偏积分及电流指令 |
| 越界纠偏 | 原始及资格偏差均>1°持续50 ms | 原电流卸完后复用位置内速度PI积分，限幅为运行电流上限，模型前馈关闭 |
| 滞环 | 0.5°～1° | 保持原状态：未触发者零电流，已触发者继续有限纠偏 |
| 持续偏差 | 已触发且尚未回到±0.5° | 不因500 ms停滞自动撤流，但总电流始终不超过运行上限 |

精确到位与停靠均使用独立滤波的资格位置。位置/速度反馈控制仍使用原位置和基础
速度滤波，未增加运动控制位置低通。停靠进入使用0.003 rad/s（0.172°/s）速度门限，
减少运动尚未结束时的提前撤力。停靠之后测速噪声本身不会唤醒出力。
滤波速度不能单独证明机械静止。

进入停靠确认时冻结新增积分，确认期间保留原接近前馈；确认停靠后清除速度PI积分，关闭
位置/速度PI及摩擦、加速度前馈。总IqRef以2 A/s向0卸载，卸流时仍遵守当前限流，
之后窗口内恒为0。此2 A/s只保留第一次停止的有限卸流过渡，不是稳态保持。
越界不能打断初始卸流，归零并确认越界后使用位置内速度PI，根据速度误差逐步积分，总电流不超过运行上限，
变化率2 A/s，输出跟踪参与PI抗饱和。回到窗口当拍清除Ui及纠偏电流，不继续用卸流斜坡推轴。
取消旧版受阻锁存与测速重试资格；静止误差超过1°也能触发。新目标恢复正常运动，关闭阻尼策略则恢复原主动控制。
静止零电流时的新目标若本就在当前位置±0.5°内，直接保持零电流，不为这个小角度命令启动新行程。
纠偏开始后不依赖外推速度，持续到回到0.5°；不保证在运行限流内能克服实际阻尼。
STOP、故障、电流保护与机械软限位不变，越界受阻也不能假报精确到位。
停靠仍为mode3，电流环仍工作；零IqRef不表示三相关断，也不保证实测Iq严格为零。

后续近区禁积分：阻尼轴实际误差与轨迹剩余均进入±0.5°后，禁用速度Ki、静摩擦
积分和饱和回算写Ui；仍运动时冻结同向旧Ui，避免提前撤掉负载补偿；过冲/反向
沿用有界释放。近区向目标每推进0.06°刷新500 ms计时；持续没有有效推进时，
旧Ui按2 A/s归零。0.06°超过已知测量噪声峰峰值0.05°，向外回退不刷新计时。
不再把低速50 ms直接判为停滞；进入
被动停靠则清Ui并统一卸总电流。停滞判定不依赖摩擦前馈开关。
在尚未完成首次停靠的接近阶段，偏差超过±0.7°、策略关闭或新目标清除此禁积分锁存。
一旦完成停靠，同一目标越过1°后恢复位置内速度PI积分；该恢复路径绕开接近阶段禁积分，摩擦/惯量前馈仍为零。
运行限流可能不足以克服真实阻尼，此时PI抗饱和限制继续累积，不能承诺任何外力位移都能实际回位。
1°是纠偏触发阈值；±0.5°是撤流阈值，精度指标需单独验收，不等于`target_reached`精确标志。
早期近区实现见[近区禁积分计划](../plans/2026-10-10-near-target-no-integral-v1.md)。

进入停靠后允许在滞环内保持，例如卸流后误差0.09°仍停靠，但`target_reached=false`。
误差0.09°满足位置停靠条件，仍需轨迹结束及静止确认；被动状态内进入±0.08°并确认后才标记
精确到位。阻尼档旧主动HOLD不再独立接管撤力，摩擦下降带不早于被动入口，
50 ms资格期间保留同向接近补偿；越过目标仍允许制动。
`PositionCascadeTelemetry.passive_hold`表示卸流/停靠状态，独立于
到位标志；未增加RTT或CAN字段。停车后测速噪声不再通过外环产生IqRef。
只有实际剩余距离已进入捕获区且明确制动时，阻尼档才锁存关闭同向摩擦助推；
远处速度纠偏反向保留模型摩擦补偿，避免先停再走。失速恢复或换目标解除锁存。

通过已有`load_profile_flags`启用：1或3为有阻尼环，启用被动停靠；0为无阻尼环，
保留主动保持。Roll/Pitch/Yaw目标表均为3，左右轮为0，不需要分别编译电机宏。
这不改变运行限流、控制增益、滤波频率、轴范围或个体标定。

修改精确默认值的位置为`position_cascade_config.h`中的
`POSITION_SERVO_DAMPED_ERROR_WINDOW_RAD`。启动及装配配置切换将其赋给
`MotorControl.pos_error_window`；无阻尼默认保留0.001 rad。变量可在RAM整定，
目前不是Flash字段，重启会恢复对应默认。mode18读取同一容差变量，但未增加
mode18被动停靠算法。

兼容边界：v6～v7未新增公开C或参数字段，Flash schema、DMP1标志、CRC、CAN与RTT载荷不变。较早版本公开C配置新增
`passive_hold_enabled`，所有调用者必须显式初始化；遥测新增`passive_hold`，
所有模块需一起重编译，不能混用旧目标文件。配置比较显式检查策略，忽略填充字节。

离线验证可证明输出、时序和状态契约，不能证明负载能被阻尼承托，或承诺每次
一次达到±0.08°。实机需检查接近过程、卸流后的漂移、重新纠偏和持续温升；
固定03采样不随新命令运动，不能当成新闭环的实物预测。
