# MT6835收发帧结构化 v1

用本文件内的发送/接收帧结构体替代AT32编码器两个匿名三半字数组。
字段按三个16位SPI字排列，并用编译期大小/偏移检查固定DMA所需的6字节连续布局。
保持收发变量名称与链接属性、命令0xA003、两个空字、DMA半字宽度与数量、
SPI模式、片选时序和高16位角度返回值；不新增CRC/状态检查或改变公开接口。

基线为本轮开始时的工作树，含用户移除缓冲static的修改；原始源码、原生验证和AT32构建
保存到`outputs/mt6835-frame-struct-20261103/before/`。
同步明确MT6835原始角度为21位，返回ANGLE[20:5]；先前文档中的18位描述更正。

验收：真实结构体布局与模拟DMA缓冲检查、全65536角度域回归、完整PR档、AT32编译及
前后资源/镜像对照。回退仅撤销本轮结构与测试文档增量，不覆盖用户的其他修改。
不增加位域、打包属性、额外拷贝或新固件编译单元，不烧录或操作硬件。

## 结果

已用`Mt6835TxFrame`和`Mt6835RxFrame`替代两个数组，DMA直接引用结构体首地址。
发送字段为命令/地址和两个空字；接收字段为命令阶段响应、角度高16位和低位/状态/CRC组合字。
两种结构均为6字节，字段偏移0/2/4由编译期检查固定，原变量名、volatile和外部链接属性保留。

原生测试复用生产类型，模拟DMA半字写入并检查真实内存顺序；65536种角度返回值、
命令、传输数量、CS延迟和收尾均通过，STM32编码器回归同时通过。
完整PR通过：124项单元、16项集成、43组原生，以及格式、lint、布局、架构、接口、文档和卫生检查。
证据：`outputs/runs/mt6835-frame-struct-20261103/summary.json`。

AT32正式APP重编译0错误、0警告；前后HEX逐字节相同，Code/RO/RW/ZI不变。
资源与哈希见`outputs/mt6835-frame-struct-20261103/build-comparison.json`。
未连接硬件或烧录，仍不使用角度低5位及状态/CRC校验。
