# Roll / wheel 共用固件计划 v1

## 目标与范围

同一驱动板（6 mΩ）、同一电机及编码器装配，仅切换阻尼环有无。
在 codex/ovp-36v 的 8f336a3c 基线上，将编译期差异改成停机时选择的运行参数。
本次只改代码和离线验证，不连接台架、不下载固件。板上 a174e00d 属于另一版本。

## 决策

- 配置位 0 表示阻尼环，位 1 表示摩擦前馈；允许值为 0（wheel）、1（roll，前馈关）、3（roll，前馈开）。
- 轴身份、节点地址、机械范围与阻尼配置独立。选择 roll 配置不自动改节点或解除位置限位。
- 共用采样、R/L/磁链、电流 PI、编码器 LUT/方向/零位；不因切换清除电气标定。
- 沿用本分支两套标定整定，将其编译进同一个镜像；这些是初始整定，不宣称适合所有 2 N·m 工况。
- 切换不自动提高电流/速度限值，不覆盖用户 PI。阻尼状态变化时失效旧摩擦模型和候选。
- CAN 仅提交请求，快环在 mode0、上一模式为 0、无故障且关相后应用并复位运行态；运行中拒绝。
- Flash schema10 原字段不移动，在尾部添加独立版本和 CRC 的 DMP1 扩展；旧空白尾部默认为无阻尼、无前馈。损坏扩展阻止使能，不自动恢复成可运行默认值。
- 新 CAN 0x68/0x69 为设置/查询配置，0x6A 查询此扩展版本；既有 SI 线路版本 2 保持不变。

## 验收

单个本机测试程序覆盖两配置切换、非法值、运行/停止过渡拒绝、控制状态清理、标定保留、CRC/旧数据加载、CAN 黄金字节。
检查两套启动电流向量与限流准入、电零位电流不足拒绝，以及正常无阻尼回归。
执行可用离线测试、布局检查、普通 Keil 全量构建；本旧工作树没有新版 verify/format/lint 路由，记录替代验证与失败基线。

回退本次代码即可恢复编译期选择；旧固件不识别扩展，不能保证回退后仍保留所选阻尼状态。
禁止把本分支 schema10 镜像直接覆盖板上 schema11 新版参数。构建、基线和测试日志在 outputs/roll_wheel_runtime_20260928/。
