# KF600 速度估计器接入指南

本模块实现固定增益两状态 KF600 和 15 点整数递推均值，输入机械单圈角度，输出机械角速度。
[接口](../../firmware/motor/feedback/speed_estimator.h)和[实现](../../firmware/motor/feedback/speed_estimator.c)
仅依赖标准 C 库，不依赖负载观测器、PI 或板级驱动；需要 C99 和单精度数学函数支持。
模块没有自动注册或运行开关。使用方需把实现文件加入构建，并按本文接入采样与速度控制。

## 信号链和执行频率

本文以当前方案 **20 kHz KF600 → 20 kHz 的 15 点整数均值 → 2 kHz 速度控制** 为接入参考。
KF 每次处理一个机械角度样本，均值每次处理一个 KF 速度样本；每 10 次快环更新后，慢环读取最新均值。
不能先把角度降采样为 2 kHz，也不能把连续调用 10 次同一角度作为 20 kHz 采样。

| 信号 | 含义 | 使用位置 |
| --- | --- | --- |
| `angle_rad` | 方向、编码器非线性校正后的机械单圈角度，[0,2π) rad | KF 输入 |
| `state.speed_rad_s` | 均值前的 KF 机械速度，rad/s | 需要较低延迟的速度或电角速度通路 |
| `SpeedEstimator_Update` 返回值 | 有效采样时为 15 点均值，rad/s | 速度 PI；若使用 OBS，两者消费同一快照 |
| `state.speed_rad_s × pole_pairs` | 电角速度，rad/s | 电流控制中的电角速度补偿；`pole_pairs` 是电机极对数 |

机械角度转电角度仍由调用方处理，本模块不替代方向、标定表、电零位或 Park 变换。
若已有测速器，速度 PI 的输入应明确切换为本模块返回值，不再把旧测速低通或陷波串在它后面。
原工程其它通路需要哪一路速度，由调用方明确连接；本模块不会自动停掉旧测速器。
若用来替换电角速度通路，使用均值前的机械速度乘极对数，避免把均值延迟引入该通路。

## 初始化与周期调用

每台电机各有一个持久 `SpeedEstimator` 对象，同一个采样上下文独占更新。
先复位，再以固定 50 μs 周期调用；以下片段中的输入由编码器驱动提供：

```c
#include "speed_estimator.h"

static SpeedEstimator s_estimator;

/* 初始化或停机复位时执行，不能和周期更新并发。 */
SpeedEstimator_Reset(&s_estimator);

/* 每个 50 μs 采样周期执行。 */
float feedback_rad_s = SpeedEstimator_Update(
    &s_estimator, corrected_mechanical_angle_rad, angle_sample_valid);
float raw_speed_rad_s = s_estimator.speed_rad_s;
```

若输入为一圈 65536 个计数的无符号编码器值，换算为
`angle_rad = counts * (2π / 65536)`。这是单圈角度编码，与均值内部的速度 Q15 格式不同。
先处理方向和非线性校正，再送入算法，正速度方向应与正 Iq 产生的加速方向一致。

首个有效角度对齐 KF，初始速度为零；均值首次有效时用当前速度填满窗口，避免零填充瞬态。
无效采样仍调用一次 `Update` 并传 `false`：KF 只预测，均值失效，返回值为预测速度。
恢复有效采样后重新填窗。调用方需单独保留采样有效性，不能因为预测值有限就认定编码器正常。
连续缺帧、传感器故障和控制停机由上层处理，本模块不驱动功率输出。

停机、重新使能、速度控制模式切换或角度坐标重定时复位；复位后首拍速度为零，应与 PI/目标斜坡的启动状态对齐。
20 kHz 采样与 2 kHz 控制分属中断/任务时，用短临界区或等价一致性机制发布完整快照。
不要在慢环同时更新估计器，也不要在未排除快环访问时清空它。

## 公式与参数

令 T=50 μs，`wrap` 把角度归一到 [0,2π)，`wrap_to_pi` 取最短有符号角差：

```text
角度预测 = wrap(上一拍角度 + T × 上一拍速度)
e = wrap_to_pi(测量角度 - 角度预测)
角度更新 = wrap(角度预测 + α × e)
速度更新 = clamp(上一拍速度 + (β/T) × e, -2000, +2000)
q[k] = trunc(速度更新 × 32768)
sum[k] = sum[k-1] - 窗口最旧q + q[k]
输出 = sum[k] / (15 × 32768)
```

| 参数 | 当前值 | 含义 |
| --- | --- | --- |
| 更新频率 | 20000 Hz | 固定系数对应的调用频率 |
| KF 档位 | KF600 | 固定增益设计标识，不是每秒调用次数 |
| α | 0.23399980789699215 | 角度校正系数 |
| β | 0.03109687052554217 | 速度校正使用 β/T，约 621.9374 s⁻¹ |
| 数值速度边界 | ±2000 rad/s | 约束数值范围；不是电机运行限速 |
| 均值长度 | 15 点 | 对连续 KF 速度求均值 |
| 速度量化 | 1/32768 rad/s | 转整数向零截断；窗口和为 int32 |
| 最大窗口和绝对值 | 983040000 | 15×2000×32768，可由 int32 表示 |
| 均值群延迟 | 0.35 ms | (15−1)/(2×20000)，不包含 KF 和调度延迟 |

KF 运算仍为 float，只有均值样本和递推和采用整数。正常更新先减旧样本再加新样本；首次和恢复时遍历固定窗口。
这是固定增益 KF，不在每拍计算协方差。采样频率或窗口改变时必须重新评估系数、频率响应、整数范围及闭环延迟。
模块不包含 Kp/Ki，速度控制器必须使用与目标一致的 rad/s 量纲。

要保持此方案的控制响应，关键是固定采样周期、使用均值前后的正确速度通路、让慢环消费最新快照，
以及避免重复滤波和额外整拍延迟。机械模型、速度 PI、限流和前馈由调用方配置，单独替换测速器并不决定整个闭环响应。
