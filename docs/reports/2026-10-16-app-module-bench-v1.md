## 结果

| 检查 | 实机结果 |
|---|---|
| 下载与启动 | 全镜像匹配；Loader、保留区和 16 KiB 参数区不变；启动 mode 0、无故障、三相高阻 |
| 参数保存 | 临时更改速度加速度，差异仅位于对应 4 字节字段内（实际 3 字节改变）；保存结果 1；复位恢复一致 |
| 相同参数保存 | 修改前、复位后及恢复后均返回结果 2，跳过重复擦写 |
| 参数恢复 | 恢复原加速度并保存/复位，整个参数区与备份逐字节相同 |
| 候选 LUT 阶段 STOP | mode 13 阶段 28 停止；有效 LUT、零位、标志与 Flash 不变；工作区指针及忙标志清空 |
| 不复位重标 | 等待轴停稳后再次 mode 13，约 9.5 s 完成并自动保存；候选 LUT 与 Flash 一致 |
| 电零位 | mode 15 完成，标志 3，电零位 18723 Q15；保存并复位回读一致 |
| 速度闭环与停止 | mode 2 正反向 ±5 rad/s、1 rad/s² 加减速、最终 STOP 均通过 |

mode 13 完整标定的残差样本 8376，峰值 11 Q15，RMS 3.034 Q15，满足现有内部
验收条件。这是算法相对观测器的残差，不等于外部标准仪器验证的绝对角度精度。
主机记录的 mode 13 最高速度 20.625 rad/s、最大相电流 2.001 A；mode 15 最大
相电流 2.713 A。试验的 RAM 限流为 2.7 A，实测停止门限为 3 A，未改热保护配置。

速度闭环末 1 s 统计如下；该表单位仍与固件一致，目标 ±5 rad/s 约为 ±47.75 rpm。

## 结束状态与结论边界

最终 mode 0、ErrorNow 0、Id/Iq 指令均为 0，六路相输出高阻，编码器错误计数 0。
原运行限流 6 A、标定配置 3 A、加减速度、速度 PI 和热参数均已恢复。
仅保留本轮新 LUT 与其配套电零位；新参数区 SHA-256 为
`cc87b3b3fde56cd4a6b977e161fe9d27051a61705d1259da1adf6c313785c426`。
完整参数比较确认没有其他配置差异；速度试验期间 Flash 未变化。

主机采样中位间隔约 16–20 ms，最大间隔 122.5 ms，并非快环同步采样；上述最大值是
已采样最大值，不证明两次读取之间没有更短的峰值。固件保护仍保持启用。
标定期间手工 RTT 通道新增 71 帧丢弃，速度试验新增 0；捕获通道丢弃均为 0。
RTT 字节流未做首尾帧对齐验证，不作为连续完整同步记录；图表和上述统计均使用主机 JSON 记录。
不能把这些记录用于 50 µs 中断最坏耗时或高频电流纹波验收。

首次保存脚本在入口发现 CPU 已暂停而退出，尚未开始写参数或使能电机。
后续仅在已匹配镜像、mode 0、零电流指令、无 CPU 故障及关相核验后恢复运行。
本轮没有 STOP 失效、紧急关相或清故障后继续运行。

本结论覆盖上述轮电机回归，未测试 CAN、位置负载、热故障注入或 Flash 掉电故障。
后续模块整理必须单独给出验证证据，不能继承本次硬件通过结论。
