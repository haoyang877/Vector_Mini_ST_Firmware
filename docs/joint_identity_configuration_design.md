# 关节身份识别与自动参数配置

状态：固定编号、AXS2 记录、启动参数选择与未配置保护已实现并通过离线验证；未下载固件，未修改板卡 Flash。当前沿用 Flash 作为身份来源。

| 固定编号 | 类型 | 配置版本 1 |
| ---: | --- | --- |
| 0 | UNKNOWN | 不可使能 |
| 1 | ROLL | 位置 Kp/Kd=8/2，速度 Kp/Ki=0.5/1 |
| 2 | PITCH | 位置 Kp/Kd=8/2，速度 Kp/Ki=0.5/2 |
| 3 | YAW | 未配置，不可使能 |
| 4 | WHEEL_RIGHT | 未配置，不可使能 |
| 5 | WHEEL_LEFT | 未配置，不可使能 |

编号发布后不重新排序、不复用。名称只用于显示；持久化字段为 `uint32_t`，不依赖编译器的枚举长度。

## 目标与身份来源

roll、pitch、yaw、wheel_right、wheel_left 共用固件。装配时赋予关节身份，上电读取身份并选择对应的已验证配置；不通过试转、摩擦或电机电气参数猜测关节位置。当前 roll 与 pitch 型号、硬件相同，电机参数辨识不能区分这两个装配角色。

推荐固定电机/驱动总成在装配时写入身份记录。若驱动板会交换，应改由主控绑定，或从电机侧非易失器件读取身份。MCU UID 只能区分驱动芯片，不能自行说明其安装在什么关节，也不能在更换外接电机后证明校准仍适用。

身份选择与电机使能分开：识别和配置完成只进入可接受命令状态，仍须独立的使能命令。

## 修改前的实现与差距

- `software/config/motor_axis_profile.*` 已提供 AXS1：32 字节、CRC、roll/pitch 名称、范围与速度。
- `Foc/foc_param.c` 从持久化参数直接恢复 PID，最后加载轴记录；当前没有按轴身份解析参数集的步骤。
- AXS1 的 `name[8]` 无法容纳 `wheel_right` 或 `wheel_left`；不能截断名称或直接扩大原结构来解释旧 Flash。
- `Foc/position_cascade_config.h` 中轨迹整形、保持窗口等仍是公共常量。需要按关节配置的项目应进入运行配置，而非按关节编译多份控制器。
- 当前 `Bsp/flash.c` 混合参数存储与 MCU Flash 操作，`Foc/foc_param.h` 直接依赖硬件头文件，且参数恢复存在回退默认值/重写路径。新增设计不能通过继续增加全局变量或上层 HAL 调用扩大这些耦合。

## 数据职责

| 数据 | 所属职责 | 示例 |
| --- | --- | --- |
| 板级信息 | BSP / Hardware Config | 采样电阻、增益、NTC 接线 |
| 总成身份 | Factory / Identity | 序列号、关节类型、兼容的电机和硬件型号 |
| 电机型号参数 | Motor Config | 极对数、Rs/Ld/Lq/磁链、型号额定约束 |
| 关节配置 | Control / Protection Config | PID、轨迹、角度边界、速度、电流时间限制、允许控制模式 |
| 个体校准 | Calibration Data | 编码器电角零位、机械零位、LUT、电流偏置 |
| 调试覆盖 | Runtime Config | 停用时显式设置的 RAM 参数 |

关节模板不能覆盖个体校准；相同型号也不能复制零位和 LUT。模板中的安全上限与硬件/电机额定约束取交集，运行命令只能进一步收窄。

## 后续扩展的数据设计（不代表本次已全部实现）

使用固定宽度整数作为持久化关节类型，显示名称由查表得到。建议预留 UNKNOWN，并为 ROLL、PITCH、YAW、WHEEL_RIGHT、WHEEL_LEFT 分配稳定编号；编号发布后不复用。CAN 节点地址独立配置，不默认等于关节编号。

身份记录应具有 magic、格式版本、记录长度、序列号、关节类型、兼容型号、profile_id、profile_revision 和 CRC。具体布局、Flash 地址及掉电提交机制在检查现有存储区域后确定，本设计不分配未经验证的地址。

同一关节可能有多个硬件代次和调参版本，不能只靠 `role -> 一套永久参数`。以类型和兼容信息找到参数集，并核对版本。固件升级不能静默改变已部署的机械范围、电流额度或校准数据；旧版本无法识别的新记录必须明确报错。

模板是经过验证的基线；调试完成后显式保存的个体控制参数具有版本与来源，启动时按既定优先级加载。实际生效配置可回读：身份、模板版本、覆盖项、边界和校准有效性，避免“看似识别正确但使用了另一套增益”。

## 完整平台的启动目标

1. 保持功率级停用，读取身份和校准记录。
2. 检查完整性、格式版本、兼容型号和身份来源。
3. 解析关节配置，再加载兼容的个体控制覆盖及独立校准。
4. 验证所有必需参数与安全边界，形成完整候选配置。
5. 在控制循环启动前一次性发布有效配置；运行中不得半途更换身份或逐字段替换 PID。
6. 配置有效后等待正常使能命令。未知身份、缺少模板或损坏记录进入未配置状态，保留诊断与配置通信。

不得因身份未知而自动按 roll 运行，也不得将未知 yaw/轮电机参数填成 roll/pitch 数值。恢复出厂默认控制参数与擦除身份/校准应是不同操作。

## 当前关节清单

| 类型 | 已知边界 | 已知速度 | 参数状态 |
| --- | --- | --- | --- |

| pitch | −0.3～+0.9 rad | 45°/s | 当前候选位置 Kp/Kd=8/2、速度 Kp/Ki=0.5/2；仍须区分候选与 Flash 基线 |

pitch 的 6 A 峰值、超过 4 A 累计 30 s 是当前 HIL 测试保护。它不能自动成为所有关节的量产保护，也不能在普通固件尚无对应监督逻辑时标记为已生效。轮电机不应自动套用 mode 3 的到位保持策略。

## 当前实现与迁移

AXS2 与 AXS1 同为 32 字节：

| 偏移 | AXS2 内容 |
| ---: | --- |
| 0 | magic=`0x32535841` |
| 4 | 格式版本=2 |
| 8 | `joint_type`，固定类型编号 |
| 12 | `config_revision` |
| 16、20、24 | 最小角度 rad、最大角度 rad、最大速度 rad/s |
| 28 | 前 28 字节的 CRC32 |

版本 0 只登记身份，三个范围/速度字段必须为零；这些零不表示实际机械边界。所有类型都可登记，均不可使能。版本 1 仅有 roll/pitch 参数集；范围允许比上表更窄，不允许更宽。速度不超过 45°/s，加速度和存储减速度基线均为 45°/s²，mode 3 仍使用原有 30°/s² 减速度上限及公共轨迹整形/保持参数。电流配置最多 6 A，并保留已加载的更低限制。

`Param_Download()` 在完成原有电机/校准加载后调用纯 C 配置选择器，经现有适配入口设置位置/速度 PID 和轨迹参数。只有 AXS2 才启用此自动选择；AXS1 保持原增益与字节不变，并可解码出 roll=1、pitch=2。不会仅因升级固件就把 pitch 的旧 Flash 增益悄悄换成候选增益。

AXS2 版本 1 的模板是这几项控制参数的启动来源：RAM 临时调参可继续使用，重启重新应用模板。保存普通 PID 字段不等于更新模板；若要把新整定值设为后续启动值，需要受控更新配置版本。个体控制覆盖、型号兼容 ID、独立身份分区和双槽掉电提交仍是后续扩展。

AXS2 无配置、格式不支持或 CRC 错误时，轴配置有效标志为 false。启动不执行电流偏置校准，不启动三相 PWM；采样时钟和通信保留。正常模式入口拒绝使能，快环也阻止内部模式赋值绕过，存储/清错路径不能因此开启 PWM。全零/全 FF 的无 AXS 旧固件参数仍按既有未绑定兼容路径工作，本次未把所有旧设备强制改为必须登记。

新配置文件在 `tests/joints/`，与记录实测运行数据的 `tests/mode3/` 分开。离线生成 pitch 数字记录的例子：

```powershell
python tools/motor_axis_record.py --parameters <当前参数区备份.bin> --offsets <匹配固件的参数偏移.json> --profile tests/joints/pitch.json --out <新的输出目录>
```

此工具只生成补丁和清单，不连接 J-Link。旧参数区其余字节不变，AXS1/AXS2 轴记录偏移也不变；写板前必须使用支持 AXS2 且外层参数 schema 相匹配的固件。类型编号不是 MCU UID，也不自动改变 CAN 节点地址。

## 后续存储迁移的验收要求

保留 AXS1 旧记录的读取方式，将已确认的 roll/pitch 映射为新身份。新增记录采用独立版本；禁止直接改变旧字段偏移。新旧记录冲突时显式报错，不能静默优先选择其中之一。全零/全 FF 的旧记录表示未配置，不能推断出关节类型。

先实现纯 C 身份/配置解析模块及测试，通过现有参数加载的受控适配点接入。身份识别不放进 FOC ISR，不新增 Vendor 依赖；持久化通过存储服务与硬件边界执行。现有 Flash 默认重写策略需在迁移前审查，防止身份错误引起校准或边界被默认值替换。

验收至少覆盖：

- 五类身份与未知/损坏/不支持版本；未整定类型不得成为可运行配置。
- AXS1 roll/pitch 兼容读取；名称不截断；新旧记录冲突拒绝加载。
- 参数版本不匹配、非有限值、超限、缺少校准、硬件不兼容。
- 两个相同型号关节加载不同 PID 与边界，但各自校准字节不变。
- 断电保存恢复、升级保留身份/校准、恢复默认值的分离语义。
- 运行中身份写入被拒绝；识别完成不自动使能；通信可读回实际配置。
- 实机逐轴验证上电、复位、限位与保持；轮电机按确认的独立工况验证。
