# motor 分层与命名整理 v1

## 目标与范围

以现有单轴控制为基线，逐步按控制、测量、反馈、保护、标定和配置职责整理 motor。
第一阶段将混合测量模块从 foc 移到 sensing，统一文件与公共函数命名；保留其他模块及接口，后续阶段继续整理。
同步项目、离线测试与当前架构文档；历史基线源码路径保持原样。

## 必须保持

20 kHz 快环及 2 kHz 监督拍的调用顺序、采样重叠、零偏发布、故障与关相行为、
计算顺序、保护阈值、配置默认值、参数/Flash/协议 ABI、运行状态所有权和任务语义不变。
不得接触硬件；不把目录迁移视为已完成算法与 BSP 解耦。

## 基线和验收

以本次修改前工作区为基线，运行 PR 验证并记录环境及结果；迁移后运行 PR、格式和 lint，
检查全部 Keil 工程源码与头文件搜索路径、历史对照测试，比较相关控制输出及故障测试。
目标编译、镜像、时序和资源对比视环境能力执行并如实报告，缺失不视为通过。

## 回退

按文件迁移和调用点整体回退本计划对应改动；不覆盖其他工作区修改，不更改 Flash 或设备状态。

## 阶段

1. 测量模块迁移和接口命名，验证后记录证据。
2. 控制、反馈及配置入口按调用链逐步迁移；每阶段独立构建与验证。
3. 检查接口所有权及是否可安全分离硬件操作，任何行为改变另行设计验证。
