# AT32F456 五轴启动配置 v1

在现有重构工作树和 schema14 上新增 AXS2 修订 2。使用同一 APP 从 CRC 校验过的节点和角色装载模型、整定与限额。旧地址或身份冲突保持关相。工装仅生成离线记录，不连接设备。
验证覆盖五节点、交叉错配、旧记录、损坏记录、标定/重启与实际工程构建。控制与协议继续使用电机轴 SI 单位。撤回本功能需恢复匹配版本的 APP 和设备备份。
