# Mode13/Mode15 编码器标定任务职责 v1

日期：2026-10-08。对应 `firmware/motor/calibration/encoder_calibration_task.c/.h`。
本文保留第一批职责基线；v1.3.0现行职责先读[核心维护模块](../../architecture/motor_maintenance_core_v3.md)，计算边界见[核心/外围数据流 v2](encoder_calibration_core_v2.md)。

任务只拥有标定阶段、计数、累积值和借用引用；不拥有电机主状态、功率许可或 Flash。
`MotorAxis` 在 20 kHz 快任务调用 `MotorMaintenance_Step`，APP 显式借出固定 6 KiB 工作区。
任务返回 `MotorTaskResult`，主状态机接受结果、关相并衔接独立 SAVE；后台导出参数和写 Flash。
`COMPLETED` 表示 RAM 标定完成，不等于保存已提交。

输入量：方向修正/线性化角为 uint16 环形 Q15，一圈 65536 counts；LUT 为
1024 个 int16 Q15 修正。观测器累计位置为电气 rad、速度为电气 rad/s；目标和编码器速度
为机械 rad/s，极对数负责换算；电流为 A，周期 `Current_Ts` 为 s。

| 阶段 | 核心测量/计算及输出 | 准入与任务适配 |
| --- | --- | --- |
| Mode13 初始化/静态对齐 | 对齐末 0.1 s 的 directed_q15 相对首样本解卷绕并平均，得到机械原点 | 在线、极对数、R/L/磁链/电流检查；清工作区和控制器，运行既有无感启动 |
| 等待闭环/稳定 | 记录观测器 position_epoch；连续稳定窗口后进入找原点 | 必须闭环、epoch 不变，反馈与斜坡速度误差均在 20%；不稳定重置连续计数，超时失败 |
| 找原点 | 先见原点负侧小于 -64 counts，再对负到非负过零插值，得到 observer_position_origin | 跟踪准入仅要求闭环与 epoch；保留找原点超时 |
| 正向采样 | 相对观测位置/极对数转换机械 Q15；按 directed_q15 所在 bin 累积环形误差与样本数 | 仅稳定样本计入，正观测位移累加有效行程；每帧更新前次位置，计数饱和保护及超时不变 |
| 分批构表 | 依次检查覆盖、求 bin 均值并连续解卷绕、求整表均值决定整圈平移、范围检查并写候选 | 四遍每周期最多 8 bin；候选复用 samples 的 union，构表期间保持跟踪 |
| 正向验证 | 候选线性插值后的 Q15 与同一观测参考比较，累积平方残差/峰值/样本数 | 稳定样本与正行程准入同采样；1 机械圈后检查非空、峰值 ≤1024、RMS ≤256 counts；超时失败 |
| 发布/停止 | 验证通过才复制候选；置线性化有效、清电/机械零位，请求多圈 rebase、重置测速 | 先释放采样引用，再减速/负 iq 卸流；低于可用观测速度或独立编码器测速条件失效则零指令完成，避免驱动过零 |
| Mode15 对齐/平均 | d 轴电流 0.5 s 斜坡、保持 1 s；仅 READ_OK 的线性化角按首锚点 int16 环形差平均，写电零位 | 在线且 LUT 已有效；保留最小对齐电流和应用限流；结束归零 id/iq、复位电流 PI，再报完成/失败 |

纯计算是环形差、候选插值、累积/均值/整圈平移及残差判断。任务适配是阶段计时、
观测器准入、调用无感启动/电流环和组织 `MotorTaskResult`。保存不在这两者内。
当前计算已提取到encoder_calibration_core，任务持有单份阶段和计算状态；不另建通用标定框架。

Mode13 所有失败维持原错误码，先 `MotorFault_Report`，再释放采样引用、复位 startup/
电流 PI/速度 PI、清速度与 id/iq 指令、阶段归零。完成执行同样的控制状态复位，返回无故障完成；
进入停止段前候选已发布且引用已释放。`Cancel` 仅清模块阶段/计数/引用，可重复调用。
Mode15 某些早期失败只上报，控制状态清理由 owner 的取消路径执行；不能泛化合并以改变顺序。

实际功率关断由主状态机先调用平台 stop，再取消任务并回读关相事实；任务自身不操作硬件。
APP 确认 `IsReleased` 后才归还/复用工作区。20 kHz 编码器快路径拥有角度采样与校正，
2 kHz 慢估计拥有多圈和速度状态；LUT 发布只请求 rebase，不直接改慢估计所有的多圈影子。
Keil 阶段枚举保持历史编号，Mode15 依靠独立计数而非新增公共阶段机。

本轮只合并同语义的 Mode13 失败收尾和复位重复，不合并 Mode15 不同语义的失败路径，
不删除覆盖/残差/跟踪门禁。历史成功与 SENSORLESS13 失败均为历史条件证据，不能替代本轮实测。
