# 资源配置最简化 v1

## 目标与不变边界

精简 `firmware/config/board_config.h` 中重复的能力校验、未被使用的旧名称与资源声明，统一同族电机的差异输入，能从板级时钟输入准确计算的数值自动派生。保持两套正式工程的 MCU、板卡、电机、软件阈值、温度与 AT32 关相行为，保留四种已有型号及自定义资源入口，不修改 schema14 和已保存参数优先级。

AT32 晶振输入也供厂商时钟计算使用，核心、定时器、快环周期限额和 CAN 时序由同一输入派生。CAN 保持原有 1M/5M 和 75% 采样点，不可精确实现时拒绝编译；基于现有 ADC/SPI 时序，核心时钟限制在 180 MHz 以内。MCU 的 PLL 后分频仍固定为 4。运行时使用 32 位时钟值，避免在快环中引入 64 位运算。

## 验收与回退

先冻结同一源码作为构建基线，仅在副本应用本次相关更改后重建并逐字节比较两套 APP HEX；覆盖所有电机型号、非法能力与 ADC 输入、可变板卡/电机派生、Flash 保留及温度/关相行为。运行完整 PR 检查，不连接硬件。回退只针对本次资源配置、相关测试与文档，保留已有工作区修改。

## 实际结果与证据

资源头由 737 行减少至 685 行：合并能力检查实现，移除无使用方的旧别名和资源声明，四种电机型号的差异改为直接选择，删除继承后 `#undef` 覆盖。AT32 晶振、时钟、CAN 位时序和快环限额使用单一输入；80 MHz 离线变体验证 1M/5M CAN 实际端口和 75% 采样点，非法时钟和高于 180 MHz 的组合拒绝编译。

两套正式工程均为 0 错误、0 警告，HEX 与同一冻结源码的基线逐字节一致。PR 验证全项通过，汇总为 `outputs/runs/resource-config-final2-20261029/summary.json`。未连接硬件。
