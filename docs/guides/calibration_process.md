# 编码器标定流程

2026-11-06 更新，适用于 `the-system-refactor` 分支。

## 核心功能与请求入口

编码器标定包含线性化 LUT、电角度零位和机械零位。PITCH、YAW 的 LUT 请求自动联合
Hall 幅值/偏置标定和电零位对齐，完成后统一保存。机械零位仍需在工装零点单独请求。
其他轴分别请求 LUT 和电零位，前一项完成并回到空闲后再开始下一项。

| 功能 | CAN 请求 | 完成结果 |
| --- | --- | --- |
| 线性化 LUT | Type160，kind 1 | 发布 1024 点校正表，置线性化有效位，清除旧电零位和机械零位有效位 |
| 电角度零位 | Type160，kind 2 | d 轴对齐并平均线性化角度，写入电零位和有效位 |
| 机械零位 | Type160，kind 6 | 将当前线性化角度设为机械参考，慢环更新多圈位置原点 |

APP 将请求交给 `MotorLifecycle_RequestCalibration()`。生命周期负责空闲状态、
配置有效性、采样、编码器、母线电压和功率输出准入。电零位标定要求已有有效 LUT。
回复 `ACCEPTED` 表示请求受理，运行状态随后报告标定、空闲或故障。
停止请求使用 Type110，STOP 会取消当前标定。请求字段见[协议说明](../protocols/README.md#parameters)。

## LUT 核心流程

20 kHz 快环依次执行控制和阶段推进，工作区由 `MotorAxis` 独占。

| 阶段 | 工作 |
| --- | --- |
| 启动 | 首拍建立会话，随后运行无感启动并每拍清理 4 个 bin，闭环转速连续稳定 0.5 s 后记录相对采样参考 |
| 正向采样 | 按内部编码器净位移累计 100 个机械圈，稳速帧按编码器角度分 bin 累加校正量 |
| 构表 | 每拍最多处理 8 个 bin，分两遍生成候选 LUT |
| 减速与卸流 | 先降低转速，再将制动电流降至零，低于有效制动条件时结束输出 |
| 发布 | 返回 `MOTOR_TASK_FINALIZE`，生命周期关相后由主循环发布候选 LUT |

启动阶段统一使用 8 s 超时，覆盖清表、无感启动和连续稳速。
稳速完成时记录观测器位置及当前方向校正角，随后直接开始采样。

PITCH、YAW 在正向采样期间，由 4 kHz 外环同步记录 Hall sin/cos 原码极值。
启动、构表、减速和电零位对齐阶段不采集极值，不再另行驱动输出轴扫圈。
发布 LUT 前等待转速低于 1 rad/s 持续 200 ms，最多等候 6 s。发布后继续电零位对齐。

构表第一遍检查每个 bin 有采样，计算均值，连续展开环形校正量并累计全表均值。
第二遍按整圈平移，将校正量放入 `int16_t` 范围并写入候选表。
采样覆盖、角度环绕和整数范围检查确保生成的数据可用于反馈插值。

LUT 使用相对角度参考。稳速结束时记录的起始角会引入整体常量，
后续电零位标定吸收该常量。此次精简删去对齐原点均值、寻找原点、额外一圈残差验证
和 RMS/峰值门槛，每 bin 的采样要求改为非空。
模型参数校验由生命周期准入、监督层和共用无感启动负责。

## 零位标定

电零位使用已有 LUT 的线性化角度。d 轴电流逐渐升至标定电流，保持对齐期间按环形角度
计算均值，再发布电角度零位。样本锚点、和与计数归同一均值状态所有，
均值计算在固定保持窗口完成采样后执行。
完成后快环上报 `MOTOR_TASK_COMPLETED`，生命周期关相，前台保存完成后回到空闲。

机械零位直接记录当前线性化角，设置重定位置原点请求。外环消费请求并更新多圈位置。

## 所有权与结果发布

`encoder_calibration.c/.h` 集中保存标定阶段、采样、构表和运动控制。
计时与数据按启动、采样、构表和停止阶段组织，会话保存工作区、阶段、阶段状态联合体和独立标定速度 PI。
采样与构表各自保存观测器位置代际，转换时传递，持续检查参考连续性。
停止阶段依据实际闭环状态、观测器相位和速度、编码器低速条件决定制动截止。

任务入口的编码器就绪和 LUT 资格由生命周期检查，控制对象和非空固定工作区由 Axis 绑定。
共用无感启动入口完成控制器初始化，标定首拍负责建立会话。

`MotorAxis_ControlFast()` 在标定和正常控制之间选择当前执行路径。
`MotorLifecycle_PostOutcome()` 处理完成和失败结果，统一管理关相。
主循环在同一全中断临界区检查待发布会话、STOP、故障和关相状态，再调用
`EncoderCalibration_PublishLut()`。发布函数检查待发布阶段，复制候选表，
将有效位设为 `ENC_CALIB_LINEARIZED`。外层临界区覆盖完整发布过程。
发布后反馈请求重定多圈基准和速度估计，
工作区随会话释放。相关接口见[标定模块](../../firmware/motor/calibration/README.md)。

## RAM 与持久化

LUT 和零位成功后写入 `MotorConfiguration.device.encoder`，结果首先保存在 RAM。
`MotorAxis_ProcessCalibrationPublication()` 在 PITCH、YAW 联合标定结束后编码记录，
擦写前复核会话、STOP/故障和关相状态，
写入 LUT、电零位、Hall 四个系数和成功/故障标志，再报告完成。启动时从 Flash 装载已有标定记录。
STOP 或运动故障取消时不保存部分结果；Hall 极值不合格时保留旧系数并保存失败原因。

工作区为 6144 字节，采样计数与候选 LUT 共用存储。
持久化沿用 2288 字节 schema14 记录。存储字段和 CRC 契约见
[参数说明](../../firmware/parameters/README.md#storage)。

## 输出轴绝对位置

直驱与整数减速轴共用 `OutputEncoder_GetPos(MotorAxis_Feedback.output_encoder)`，使用前查询 `OutputEncoder_IsReady`。4 kHz 更新连续输出轴位置，单位 rad；现有位置环和 CAN 位置单位仍为电机轴。

Hall 轴同步采集 256 对稀疏原码，标定完成后用新 Hall 幅值/偏置和新编码器 LUT 求方向、相位。计算在前台执行。直驱不依赖 Hall，减速比为 1。工装机械零位命令同时设置输出轴零位，必须先完成输出定位。

两种传动的标定结果都由前台关相保存，Flash 回读完成后才报告完成。输出参数通过 [OEN1 扩展](../protocols/output_encoder_v1.md) 上电恢复。更换减速比或重做编码器 LUT 后重新建立对应关系及机械零位。
