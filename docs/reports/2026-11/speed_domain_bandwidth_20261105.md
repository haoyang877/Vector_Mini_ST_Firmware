# 速度域阶梯与闭环带宽上限 2026-11-05

## 结论

当前2 kHz速度环、90 Hz测速PLL、3 A限流下，本轮中高速重复测量支持约70 Hz的可用带宽，
不同运行点与拟合窗口给出的−3 dB位置约65至72 Hz。
这里采用共振峰不超过3 dB、无持续增长振荡、无饱和和保护截止作为可用判据。

0至5 rad/s存在大幅转角同步波动，小信号频响的前后半段差异明显，
目前尚不能建立覆盖这一段的统一线性带宽保证。
本轮同时确认编码器补偿表中的电周期项会产生速度纹波，详见
[补偿表A/B诊断](speed_order_diagnosis_20261105.md)。

硬件为AT32F456、YQ-5708、8比1减速器，电机固定、输出轴自由，母线约30.8 V。
用户授权电机侧±50 rad/s和3 A。本轮阶梯覆盖正反向1、3、5、10、20、30、40、45、48 rad/s。
±49 rad/s目标触及50 rad/s反馈截止，50 rad/s稳态点未执行。

测试期间在关相状态下暂时将速度包络设为50 rad/s，结束恢复原值。
所有启停及目标经CAN正常入口，结束逐项核对空闲、无故障和相输出关闭。

## 频响矩阵

完整频响矩阵包括0以及正反向1、3、5、10、20、30、40、45 rad/s，
各运行点测试多个频率，主要频点为2、20、40、60、75、90 Hz。
45及48 rad/s附近、10 rad/s截止附近另有复测。
归因后的主矩阵使用临时去除LUT第14阶的配置，每次测试后恢复原表。
反向48 rad/s另有一组默认原表对照，单独保存，随后补做相同去14阶配置。

| 电机侧运行点 | −3 dB位置与适用性 |
| --- | --- |
| 0 | 小信号响应很弱，受静止工况影响，未定义线性带宽 |
| ±1、±3、±5 rad/s | 多个频点重复性差，保留曲线，带宽数值不作保证 |
| ±10 rad/s | 截止附近复测约67至70 Hz |
| ±20 rad/s | 约66至70 Hz |
| ±30 rad/s | 约67至69 Hz |
| ±40 rad/s | 约66至68 Hz |
| ±45 rad/s | 原75 Hz点存在偏离，70/80 Hz复测支持约66至69 Hz |
| ±48 rad/s | 60/70 Hz包围−3 dB点，约67 Hz；部分80 Hz记录重复性差 |

以上为有限离散频点的插值与复测范围，保留到Hz量级。
频响输入为已受理速度目标，输出为板载编码器速度，包含参考斜坡、速度PI、电流环和测速PLL。
机电负载、速度域、参考斜坡或PLL改变后应重新验证。

## 增益上界

| Kp / Ki | 关键观测 | 决定 |
| --- | --- | --- |
| 0.015 / 0.3 | 中高速峰值通常约2至3 dB，截止约70 Hz | 本轮全域基线 |
| 0.016 / 0.32 | 30 rad/s复测74 Hz约−3.75 dB，部分较低频点重复性受背景影响 | 临界候选，未作全域固化 |
| 0.0175 / 0.35 | 30 rad/s、45.36 Hz约+4.60 dB，前后半段约+4.42/+4.38 dB | 超过3 dB可用判据 |
| 0.03 / 0.5 | 前轮约70 Hz出现约15 dB峰值 | 裕量不足 |
| 0.05 / 0.5 | 前轮出现饱和快振 | 已拒绝 |

增大Kp所得带宽提升有限，共振峰先成为约束。
本轮主要沿Ki/Kp=20 rad/s整定，并用0.016/0.1做辅助对照；
结论适用于这组控制结构和已测参数范围，低速精度问题仍需继续修复。

## 采样和重复性

最终矩阵使用RTT完整帧直接读取，校验单一读取端和读指针边界，
用各批次最后一帧的主机时刻拟合采样时钟，实际约1998帧/秒。
保存每次CAN目标的发送/应答时刻，按零阶保持重建输入。
除在线最小二乘拟合，还保留Hann加权重算和前后半段拟合，检查背景谱线的影响。

首次矩阵在45 rad/s发生字节错位并自动停机，该段已排除。
当时存在LKS Scope进程，后续确认其J-Link连接关闭，并改用直接读指针竞争检查。
第一批SDK读取结果保留作历史证据，最终矩阵以direct_ring_v1记录为准。
字段错位产生的异常值按采样故障处理。
