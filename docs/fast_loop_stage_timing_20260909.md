# 20 kHz分段计时与编码器等待优化

日期：2026-09-09。分支：`codex/optimize-20khz-loop`。前序分析见 [快环计时报告](fast_loop_timing_20260909.md)。

本轮先对上一版（ADC直接分派、四倍过采样、配置复用）做分段上板测量，再优化最大的单项开销：同步编码器读取。用户已明确授权运行实测，沿用pitch台架的±3°范围、既有机械限位、速度上限45°/s及保护配置。

最终平均IRQ区间从约32.07 μs降至29.29 μs；包括额外负向补测在内，本次观测最大值为42.29 μs，上一版为44.01 μs。一次保持状态占比未达原验收值，后续两轮未重现；耗时改善不等于全部闭环验收完成。

## 分段测量结果

独立诊断镜像通过 `FAST_LOOP_STAGE_PROFILE=1` 启用分段计时。每次选择一个阶段，使用相同的 `0,+3,0,-3,0` 指令，每目标3秒，包含运动与到位保持。约30万次IRQ/阶段，ARM后的首0.5秒单列，不混入累计平均。

|---|---:|---:|
| 电压/电流换算、快保护及HIL相电流观察 | 3.215～3.220 μs | 3.324 μs |
| 编码器读取、线性化、角度与分频速度估算 | **10.286～10.299 μs** | 11.259 μs |
| HIL命令/状态发布及模式前置检查 | 1.958～1.960 μs | 4.247 μs |

这些是带插桩的区间值，没有简单扣减空区间成本；实际寄存器分配、调用保存和嵌套标记也会改变开销。各阶段在独立轮次测量，不能把各自最大值相加，也不能把表中包含电流环的模式3分支与电流环再重复相加。

模式3位置适配/配置检查/2 kHz控制的平均额外开销可由两项平均差估算为约6.19 μs；其独立峰值本次未直接测量。模式3整体峰值明显高于其平均值，后续值得进一步拆分轨迹准备、2 kHz计算和目标切换。RTT虽然平均小，但到期帧的瞬时开销大，既有错峰措施仍需保留。

## 优化实现

编码器原有两次16位SPI传输均在调用中等待。当前SPI时钟配置下，单个命令字线传输约3 μs，而电压/电流换算和快保护约3.2 μs，可以重叠执行。

新的同周期流程：

1. `Encoder_BeginSample()`在总线空闲、已启用且没有待收数据/溢出时，拉低片选并发送原命令`0x8021`，立即返回令牌。它不执行轮询等待。
2. 执行原电压/电流换算及快保护。
3. `Encoder_CompleteSample()`消费令牌，接收命令完成结果，按原顺序切换数据线、读取角度字、恢复数据线并释放片选，然后运行原方向处理、LUT、角度和速度估算。
4. 若提前发起条件不满足，返回false令牌，在原调用位置使用原同步读取/恢复路径。原`Encoder_Update()`接口继续提供完整同步操作。

令牌保存在本次IRQ栈上，没有新增跨模块全局状态或静态RAM；必须由同一快环调用者在每周期配对消费，中间不得再访问该传感器总线。当前调用路径即使电流保护置故障，也会先完成事务清理，再走原输出关闭处理。

保留20 kHz反馈、两字传输、SPI频率、角度处理、速度分频、ADC过采样和保护阈值；没有使用上一周期角度替代本周期读取。命令在本周期内提前发起，因此完整高速工况下仍需检查采样时间点与控制时序，不能只由低速台架结果推广。

硬件操作仍限制在现有`Bsp/encoder.c`适配中；FOC调度层只调用采样能力接口。`System/fast_loop_profile.h`仅声明无MCU类型的诊断钩子，DWT及私有计数保存在硬件IRQ文件。现有仓库尚未完成encoder驱动与HAL Port的整体拆分，本轮没有以新增HAL调用到算法层的方式绕过边界。

三轮合计1,804,222个运行窗口样本，入口间隔均8498～8502 cycles，即49.988～50.012 μs。取覆盖所有已测工况的最大值42.294 μs，距50 μs周期剩余7.706 μs。平均区间约占周期58.6%。末次STOP后约−0.110°，mode=0、HIL inactive，三相输出使能位关闭。各轮完整Flash前后相同，参数未写入NVM。

相对上一版两轮实测平均约32.07 μs，平均减少约2.78 μs（约8.7%）。上一版观测最大值44.012 μs，本次所有工况最大42.294 μs，减少约1.718 μs；相同±3°往返的前两轮最大为41.182 μs，但不采用这个较低值覆盖额外负向补测。起始位置、调度相位与采样窗口不同，这些是有限窗口对比，不是固定每周期节省量或WCET证明。

首轮−3°目标末尾2秒的HOLD比例为73.45%，不满足既有“末段全程HOLD”条件，虽然位置误差始终未超过0.3°。随后完整重复和专项负向重复的各目标末段均为100%；没有故障、遥测丢帧或饱和标志，相电流未触发4 A暴露累计。该一次性保持比例不足的原因仍未确定，不以复测通过抹去原记录，也不把本轮声明为全部闭环验收通过。

后续优先级：继续分拆模式3峰值中的轨迹准备/2 kHz控制成本；研究RTT快照后移到低优先级发送，但需先解决RAM余量和一致性；对保持占比异常进行更长时间、多次ARM回归。SPI异步跨周期、控制频率调整或直接复用旧角度均未用于本次提速。
