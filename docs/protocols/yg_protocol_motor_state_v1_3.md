# 电机状态语义 v1.3

日期：2026-10-30。本文记录五状态重写的语义变化，帧布局、字段宽度、命令号和Flash格式不变。

| 内部状态 | 既有线上state值 |
| --- | --- |
| IDLE | 5 |
| SELF_TEST（当前仅占位，不主动进入） | 3 |
| CALIBRATION | 标定模式7/8时为4，其他维护为5 |
| RUNNING | 6 |
| FAULT或快环已锁存故障 | 8 |

不再发布STARTING=2、STOPPING=7、FATAL=9这些内部阶段的实时状态。
等待启相时发布空闲，只有实际启相后才发布运行；请求是否仍待处理由原进度字段表示。
取消尚未归还资源时空闲不等于可立即重启，请求仍可能返回BUSY。
自检未实现，参数0x50的自检检查位保持零；不要将空闲解释为自检已经通过。

兼容性：旧主机仍能解码既有状态号；依赖观察2/7/9阶段的逻辑应改为查询请求进度和故障。
STOP、CLEAR、控制/维护请求格式及结果枚举不变；清错成功回空闲，仍需重新明确启动。
