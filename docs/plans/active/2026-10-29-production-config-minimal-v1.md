# 简化两套正式工程配置 v1

目标：仅保留 STM32 APP 和 AT32 OFF 的板卡、电机与应用配置，删除配置目录中的台架、限时测试及临时热参数，并对齐参数定义。

约束：保留既有 Flash 参数优先级及 schema 14；AT32 PWM 保持硬件关相，STM32 安全保护不放宽。YQ-5708 热模型尚无正式数据，空白设备使用无效占位并报参数故障，不把临时测试值视为真实数据。

基线：同源构建于 outputs/board-motor-split-20261029/，本次修改前配置备份于 outputs/production-config-minimal-20261029/。已知配置调整可能改变 AT32 空白设备行为，STM32 行为应保持不变。

验收：检查配置不再暴露台架与限时运行选项；检查关相和无效参数拒绝；构建两个正式工程；运行离线验证，记录不再支持的非正式工程测试。禁止硬件操作。

回退：恢复本次备份的配置文件和热模型默认值实现，不覆盖其他用户工作。

当前实施与证据：三份配置删除台架/调试目标选择、额外型号和外部资源头入口；板卡使能由资源直接派生，AT32 的 RTT 遥测从正式工程及链接脚本移除。AT32 MCU 不允许绕过正式关相目标。

两套正式工程 Keil 构建均为 0 错误、0 警告；STM32 HEX 与基线一致。离线检查验证 AT32 关相的重复启相拒绝，两个正式目标的默认值、有效记录热参数及手动 PI 装载。AT32 空白记录现在有意报无效参数，后续填写真实热参数并重新构建。

仓库 PR 和 release 全量验证尚未通过：其中旧测试依赖已移除的测试工程、资源头和可组合的功能开关；release 还要求干净提交，当前工作区有大量用户未提交变更。未触及硬件，也未将这些失败标记为通过。
