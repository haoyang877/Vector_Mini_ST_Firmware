# 核心运行语义 v1.4

日期：2026-10-30。用户明确要求仅保留启停、目标控制、状态迁移及必要保护。
这次删除附加功能，替代v1.3的标定、保存与请求进度语义。

| 请求/反馈 | 当前行为 |
| --- | --- |
| 117 START | 只提交零目标启动，返回ACCEPTED；是否实际运行读取state=6。重复请求重新判断当前状态，不重放旧成功 |
| 116目标 | 保留同模式目标校验、单槽提交及控制周期复核；不再提供按来源/序号的执行进度 |
| 110 STOP | 保留关相确认；停止撤销当前待启相和待应用目标，旧计算不能再次生效 |
| 120/121参数读写 | 每次读取当前值；只在关相空闲时写入，仍检查expected_revision；不维护来源去重缓存 |
| 122 SAVE | 返回UNSUPPORTED，错误负载为`02 00 01 00`；没有Flash写入 |
| 160/161/162维护启动、查询、取消 | 未绑定维护后端，合法请求返回UNSUPPORTED；不创建票据 |
| 运动反馈中的控制进度字段 | 全零，表示没有进度记录，不能解释为目标已应用 |

状态枚举和线路字段宽度不变。运行路径只有IDLE=5、RUNNING=6、FAULT=8；SELF_TEST与
CALIBRATION保留内部编号，但没有执行入口。参数0x50自检检查位保持零。
GET_CAPS的速度、CAN FD、分片及反馈能力位保持；没有发布标定或保存能力。

旧Flash参数记录仍按原schema读取，包括既有编码器校准数据。运行期间的参数修改只影响
RAM，复位后重新读取旧记录。没有通过“恢复默认”或隐式保存改变Flash。

主机兼容：不能再轮询启动身份、等待维护票据或把重复START视为旧请求成功；应读取实际
状态和故障。升级交接保留独占停机票据，防止关相确认后重新启动。

[回归向量](yg_protocol_motor_state_v1_4_vectors.json)由真实参数/维护编码函数验证。
不改变旧消息号、参数字节布局或固件目标布局。
