# 位置分支继续优化与板上计时（2026-09-09）

## 基线与范围

当前 20 kHz 优化已提交为 `3980f92`，分支为 `codex/optimize-20khz-loop`。提交包含编码器通信与采样计算重叠、配置复用、ADC 快速分发及已有测试/报告。工作区中其他任务的参数、阻抗模式和上位机改动保留在原处，没有混入该提交。

本轮板测仍使用共享工作区的冻结源代码，而非宣称固件只包含该提交：优化前快照 `outputs/fast_loop_20260909/phase5_profile_source/`，优化后最终快照 `phase5_source/`，每份均有 `source_sha256.json`。SPI 保持 5.3125 MHz，ADC 四倍过采样保持启用。控制增益、控制频率、轨迹形状和保护策略没有调整。

## 细分计时

扩展现有可选诊断接口，增加 stage 10～14。单个阶段仍复用同一个 32 字节计数器，没有新增数组。控制代码只见阶段编号，DWT 读数仍在板级中断适配器。普通/HIL 默认构建不包含分段计时调用与存储；额外诊断镜像仅用于分段测试。

运行目标 `0,+3,0,-3,0`，每目标 3 秒。stage 10 覆盖位置任务入口至调用电流 FOC 前；stage 11 覆盖轨迹更新；stage 12 为摩擦补偿；stage 13 覆盖速度 PI 配置/运行及总电流抗饱和回算（不含此前的静摩擦积分处理）；stage 14 是平滑轨迹的 Prepare 调用。

位置支路每 10 个 20 kHz 周期才做一次完整 2 kHz 更新，造成明显的轻/重路径差异。轨迹准备的限次迭代、摩擦补偿状态判断和速度 PI 是重路径的主要组成。轨迹 Prepare 最高约 6.16 μs，不能将整个位置分支峰值都归因于它。

## 本轮修改与验证

将位置模块的绝对值辅助函数从条件比较/取负改成 C99 `fabsf`。这是纯软件数学实现，没有引入 MCU 专用头文件，也没有新增控制状态缓存。最终反汇编中，位置模块出现 38 条 `VABS.F32`；浮点比较从 178 处减少到 131 处，`VMRS` 从 198 处减少到 154 处（静态指令数量，不等于每周期执行次数）。

新增 `tools/test_position_core_equivalence.py`，从 Git 的 `3980f92` 提取旧核心，使用现有位置场景向旧、新核心喂入完全相同的输入。每次调用对比返回值、输出和完整私有状态字节，覆盖 730,054 个周期，全部一致。该结果限定于测试覆盖，不声称所有浮点位模式均等价；`fabsf(-0)` 的数学幅值语义为正零。测试中的全部内部状态及控制输出未出现差异。

配置缓存回归另有 25,200 个周期通过，包括在线参数、NaN、正负零、边界和复位。完整主机测试通过，包含 72 种合成运行条件、轨迹连续性/限幅、ADC 分发、编码器估算和 HIL 保护。

普通版和 HIL 版 Keil 构建均为 0 error / 0 warning。最终 HIL Code=98,732，RO=5,176，RW=996，ZI=31,732；普通版 Code=97,268，RO=5,168，RW=784，ZI=31,712。相对上一轮最终镜像，两种构建的代码均减少 592 字节，RAM 不变。最终 map 中没有分段计时函数或计数器。

最终 HIL AXF SHA-256：`d8e72a64e52aea3ecd83ed5b4253b18d0f7c4dc57b4bd63f1e1d4ab1b5cef64a`。下载验证 104,144 个镜像字节，ADC2 IER=`0x40`、CFGR2=`0x46`。参数区 SHA-256 保持 `160ba507965334ab3bc9b0327cc55e1705653b41767a71ffef6e86db9c076c6e`。

前两轮目标为 `0,+3,0,-3,0`，第三轮为 `0,-3,0,-3,0`，每目标 6 秒。初始 ARM 的 0.5 秒单独统计，运行窗口在 STOP 前读取。

合计 1,803,115 个运行窗口样本，没有超时、故障、遥测丢帧或饱和。入口间隔为 8498～8502 cycles。相对上一版同类三轮测量，运行最大值从 42.294 μs 降到 40.512 μs；若把本轮 ARM 也计入，最大观测值为 **41.453 μs**，距 50 μs 剩 8.547 μs。平均值从约 29.29 μs 降到约 29.20 μs。ARM 本身的最大值略高于上一轮的 41.376 μs，因此不能声称所有路径都变快。峰值比较是有限运动窗口的观测，不能将下降量全部视为固定指令节省。

第二轮 −3° 的末尾 2 秒约前 1.75 秒处于 SETTLE，最后约 0.25 秒才进入 HOLD；记录中是一次 SETTLE→HOLD 转移，而非来回抖动退出。末段绝对误差约 0.166～0.259°，前馈已为零，积分支持电流约 −1.056～−2.152 A。当前 HOLD 进入窗口为 0.18°、退出窗口为 0.26°；“位置始终在 0.3° 内”与“末段全程 HOLD”是不同条件，不能互相替代。延迟收敛的根因未证明；本轮不修改增益/窗口来使验收数字通过。第三轮负向复测均全程 HOLD，也不抹去第二轮失败。

结论：耗时优化及数值等价检查通过，**整套闭环验收未全部通过**。最终板上保留本轮 HIL 镜像，末次 STOP 后位置约 −0.110°，mode=0、HIL inactive，三相使能关闭；三轮都验证了完整 Flash 前后相同。

## 计时范围与后续方向

完整 IRQ 结果使用关闭额外分段插桩的最终 HIL 镜像。DWT 统计仍不包含前面的 ADC 转换序列，以及全部异常入口/退出和最后统计自身；最大观测值不等于已证明的 WCET，也不直接证明 PWM 更新截止时间。

本轮的数值等价优化主要压缩摩擦补偿判断成本，对位置峰值改善有限。后续若继续压缩更大的峰值，应优先研究轨迹准备的重复除法/搜索成本，并单独验证规划完成时刻、短行程和边界参数；不能仅凭平均耗时降低就调整迭代次数。此前出现的一次末段 HOLD 比例不足仍保留为历史未定位问题，本轮优化不改变保持判定逻辑。
