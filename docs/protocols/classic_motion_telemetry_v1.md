# 经典CAN内部规划快照 v1

仅v0.7.0及以后显式支持本扩展的APP可用；不修改既有控制参数和读参数的编码。

| 奇数只读参数 | 含义 | 单位 |
|---|---|---|
| 0x93 | 锁存同一快环发布的三量，返回规划位置 | rad |
| 0x95 | 返回该锁存快照的规划速度 | rad/s |
| 0x97 | 返回该锁存快照的速度环参考 | rad/s |

完整11位标准ID为`node<<8 | 参数`，请求载荷4字节零，回复经典CAN DLC8。回复：字节0版本1；字节1有效标志0/1；字节2..3设备完整发布序号uint16大端；字节4..7数值float32大端。无效值为NaN且标志0。设备序号允许回绕及零，不因重复读取递增；不同查询回复可能不同接收时间。

主控按0x93→0x95→0x97读取，只在三个回复版本/序号一致、有效且20ms内完整时发布规划快照；不能混合不同周期。接收侧还应严格匹配节点、ID、DLC和在途查询。重复设备序号不能刷新采样时间。发布快照超过40ms、锁存超过20ms、模式非3或故障时无效。字段在驱动机械坐标中，产品方向由主控统一转换一次。设备未提供原始采样时钟，主控只能标记接收时间。

三项查询沿用回复槽所有权和非阻塞重试；槽满时不更新锁存或覆盖旧回复。只读查询走本节点白名单，不接受偶数0x92/94/96写命令。源擎协议与配置不变；主控必须重新审计新增完整ID与CANopen全部COB-ID的冲突。

黄金数据：设备序号7、规划位置0.25rad、规划速度−0.5rad/s、速度参考−0.75rad/s，回复依次`010100073e800000`、`01010007bf000000`、`01010007bf400000`。实际CAN适配器原生测试直接校验以上字节，不以模拟控制器代替生产编解码。
