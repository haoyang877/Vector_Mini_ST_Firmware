# ADC 快环预算整机复核 v3

日期：2026-10-15。继承 `codex/ovp-36v` 的 v2 未提交优化。

## 目标与台架

用户指定探针进行调试。本轮只操作已核对 UID 和完整固件的轮电机，
沿用架空、无阻尼环、21 极对、6 mΩ、其他运动命令暂停和现场可断电的条件。
标定相电流及 d/q 矢量均以 3 A 为停止边界，机械速度边界 30 rad/s。
探针编号、UID、工作站路径仅写入忽略的 `outputs/` 证据，不写入产品配置。

目标仍为含观测器的完整 ADC IRQ 最大占用小于 40 μs，覆盖准备、PWM 使能、
锁速交接、闭环采集、验证、减速、关相和提交，不能以平均值或主体计时替代。

## 基线与推进

v2 离线产物和测试见 `2026-10-15-fast-irq-40us-v2.md`。
首次两轮整机标定均通过，准备/PWM/提交已低于 35 μs，但主体峰值仍约 41.9 μs。
临时插桩仅位于 `outputs/` 快照，分别记录主体、统计尾部与入口间隔。
继续以分段计时确认峰值来源，再修改实际热点，不凭发生频率直接认定热模型责任。

保持 20 kHz 电流/观测器、2 kHz 速度 PI、1 kHz 热模型和逐拍保护。
不改变电流/热阈值、参数协议、编码器方向和残差判据；不以清除热状态取得预算。
每次下载先核对已知镜像、停机高阻，再备份并校验 Loader/参数不被 APP 下载改变。
试验过程中先检查故障和边界，再判断标定完成。STOP/关相无法核实即硬失败，
必须现场干预，禁止自动重试。

## 验收、收尾与回退

- 修改热点后执行相应确定性对照、原生回归及 normal/HIL 构建。
- 计时记录阶段最大值、超 40/50 μs 次数、连续入口间隔、标定残差及控制曲线。
- 解释插桩开销；未测的异常入口/退出或未覆盖工况必须单列，不能宣称整机全面达标。
- 最终恢复普通固件，恢复试验前运行参数；新 LUT 必须配套电零位，否则恢复原参数备份。
- 留在 mode 0、三相关断，回读镜像和保存参数；不得把部分标定状态当作可用配置交付。

原 Flash、各轮参数、源码快照、构建产物、散列与曲线归档于
`outputs/irq_budget_v2_bench_20261015/`。回退只恢复本轮差异与该板的已备份参数，
保留其他任务的未提交工作。旧工作树无新版 verify 入口，沿用现有回归与构建入口，
明确记录验证范围。

## 分段证据驱动的候选

热采样三相固定展开、四通道积分用私有内联函数，保持原除法与错误时部分更新。
独立旧实现对照覆盖累计 100,180 状态和更新 288,035 窗口；同插桩实测热更新段
约 5.14→4.76 μs。该收益不足以完成整体预算，不改热窗口相位。

进一步分段测得电流环本体约 9.7 μs。先通过平台 scatter 选择 FOC 两个函数和
PI 四个函数到 CCM，再加入热累计/更新两个函数；最终采纳八函数布局，源公式不改。
G431 的 CCM 与普通 RAM 顶部是别名，不能算额外容量：
预留原生地址 `0x10002000..0x100027ff`，同时排除普通地址
`0x20007800..0x20007fff`，保留前 32 B 邮箱、原栈堆和 DMA 数据所在区域。
先在输出副本构建和实测，确认收益后已修改生产共用 scatter；两项链接断言防止代码/数据越界。

验收增加：链接边界、实际总 RAM（数据加执行代码）、Flash→CCM 启动复制、两个别名
回读一致、APP 启动记录及 CRC、normal/HIL 构建和普通镜像启动。远跳转 veneer 的时间
计入实测，不以 RAM 的理论访问速度推算收益。布局失败则回退该候选，不压缩栈堆补空间。

## 执行结果与测量边界

十轮计时加一轮普通固件的 mode 13 标定与停机检查通过。最终八函数 CCM 候选两次同口径测得主体最大
37.376 μs、主体加统计尾段最大 38.318 μs；另用普通镜像副本的汇编包装测得完整原
C 中断处理窗口 171,320 拍，最大 37.118 μs，`>=40 μs` 计数为 0。
硬件异常入栈/返回未被该窗口直接覆盖，不能宣称严格完整异常占用已获证明。

最终 normal/HIL 构建均 0 错误、0 警告；CCM 代码 1,960 B，实际应用 RAM
normal 为 29,944 B、HIL 为 30,200 B，另各保留 32 B 邮箱，栈仍为 3 KiB。
普通无插桩镜像已下载并核验 CCM 启动复制，补跑 mode 13 后完成 mode 15、保存和复位回读，
恢复原运行限流 6 A/标定电流 3 A，热配置未改，保留本轮 LUT 和对应电零位。
最终 mode 0、ErrorNow 0、三相高阻、标定标志 3。
详见[本轮报告](../reports/2026-10-15-fast-irq-40us-bench-v3.md)及输出目录 `summary.json`。
