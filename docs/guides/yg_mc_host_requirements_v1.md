**未接入功能仍先评审后择期实现。用户另行授权的误断联修复、日志、仅上位机位置会话不限位、故障栏及三项标定已在v2.8.1候选接入；各项实现、离线验证与实机验收分别登记。**

本清单分开记录两件事：**目标功能与待确认边界**，以及**已有候选的实现/验证快照**。
“已提出”表示功能方向已明确；“待细化”表示规则尚未确定；“候选代码已有”不等于正式验收通过。

YG_MC_HOST 用于在 Windows 上识别和调试 Vector Mini 与 AT32F456 电机控制器，查看运行趋势，执行受安全门禁约束的 Vq、Iq、速度与位置控制和固件维护。APP、Loader 和共享目标契约仍可独立构建；上位机不代替固件安全保护或台架检查。

表中“已实现”表示 Rust 源码已有对应流程，不代表该功能已经通过所有目标板的发布验收。实机通过情况必须以对应日期、固件版本和设备 UID 的测试报告为准。禁用入口或只显示目录的页面按“部分实现”记录，不能视为可执行功能。

### 1.3 已明确的约定

- 产品名为 **YG_MC_HOST**，沿用 Rust 上位机与 VS Code 风格工具界面。
- 自动发现后让用户选择连接，不自动连接并启动电机。
- 调试覆盖 Vq、Iq 力矩、速度、位置四模式，力矩目标采用 **Iq（A）**。
- 提供清楚的使能、失能和 STOP；曲线观察与电机输出控制相互独立。
- 用户关注的是**曲线新数据更新率**，默认至少 **60 Hz**，曲线由独立线程处理。
- 升级需求包括 APP、Loader、Loader+APP 三种；参数读取与写入是独立功能，不由升级替代。
- 电机类型要实际切换型号与配套参数，采用 **CAN 在线配置并配套更新固件**，不是只改生产身份编号。
- 已有功能要保留，未实现和未验收功能明确标识；代码存在不能视为完整开发收尾。

### FR-19 验收细则

- 切换任意工作区仍能看到底部故障码、状态和指示灯；正常新鲜回读显示无故障，有故障显示红灯。
- 故障码显示原始位图，多个故障位可同时解释；不将主机超时或门禁拒绝伪造成设备故障码。
- 断联/过期标为未知，保留历史故障时明确标记历史；不能以最后一次零故障显示当前正常。
- “清除故障”仅在身份、连接和设备能力有效且无升级/配置独占作业时可执行，复用现有Type107服务；执行中避免重复提交。
- 回复受理不等于已清除；随后Type108故障为零并回到空闲才显示清除完成。故障源未恢复、设备拒绝或通信失败时保留具体原因。
- 清除后仍停机，需要再次明确使能和下发目标；故障及清除全过程写入现有持久日志。

## 3. 非功能需求

1. **默认安全**：程序启动时断开；不得自动连接、自动启动、自动重放或在 STOP 后自动恢复。
2. **单一设备所有者**：一个设备工作线程独占 CAN 句柄，页面通过命令/事件交换数据；UI 不直接调用 SDK。
3. **及时失效**：身份超过 5 s 或反馈超过 500 ms 即不能作为实时操作依据。
4. **目标契约驱动**：产品、硬件、分区、schema、ABI 和 Loader 版本来自共享目标 JSON，不在页面中复制维护。
5. **明确错误处理**：超时、身份变化、超限、STOP 未确认、包不匹配和维护任务失败均显示可执行的下一步；不能用“成功”替代设备实际回读。
6. **独立构建**：Rust 主机应用不要求固件目标与 GUI 共用编译产物；维护脚本仅通过明确命令行边界启动。
7. **边界公开**：未实现的功能保持禁用并说明原因，不用演示数据冒充设备能力。

## 4. 典型验收场景

### 4.1 连接与读取

- 未选 SDK 或连接参数不合法时，连接按钮不可用并给出原因。
- 连接成功后应显示目标、节点、UID 和状态；连接动作本身不得启动电机。
- 选择不匹配目标或 UID 改变后，控制和升级必须禁用，并提示重新识别/现场核查。

### 4.2 调试与停机

- 未连接、反馈过期、能力缺失、配置/标定不合格、状态错误或数据超限时，启动/目标按钮禁用，并在按钮旁显示具体原因。
- 进入运行状态后，速度/电流/母线测量必须满足限制；位置模式还要求有效位置，Vq 模式要求有效 Vq；关键测量缺失、过期或越限时请求 STOP。
- STOP 确认前不能启动或切换模式；位置启动保持当前位置，目标下发不能隐式启动或切换模式。
- STOP 只有在最终 0/0 和新鲜 IDLE 回读后才显示通信停机确认；用户仍须核对物理输出。

### 4.3 记录与升级

- 曲线只接收当前 UID 的新鲜反馈；切换 UID 前要求导出或清空旧记录。
- CSV 包含单位、设备标识、样本时间基准和数据来源。
- APP 升级只有在包校验、目标匹配、Loader 匹配、STOP/IDLE、台架确认全部通过后可执行。
- SWD 整机包操作只有在 CAN 断开、探针和 UID 确认、整机目录已选且操作独占时可执行。

## 5. 暂不承诺的能力

多适配器并行、RS-485、Loader独立救援连接、GUI辨识、记录回放、高速同步采集、远程运维均不属于当前可用功能。三项GUI标定属于v2.8.1已接入候选，尚无本轮实机标定验收。协议支持或代码存在不等于具体板卡实机验收通过。
