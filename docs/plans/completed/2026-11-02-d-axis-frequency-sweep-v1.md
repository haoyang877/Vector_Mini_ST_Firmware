# D轴电流分点扫频 v1

实施与受限实测已完成，见[结果](../../reports/2026-11/d_axis_sweep_20261102.md)。
低电流25点×2次完成，−3dB约2.96kHz；高电流1.5A档在记录前限速，未判定其频响通过。

用户要求对D轴电流扫频，沿用AT32F456＋YQ-5708（8:1）、3A上限和当前1.2kHz PI。
本轮直接执行已授权的台架测试；无示波器、探头、锁轴和加载装置。

## 最小实现与边界

- 先核对当前镜像、活动PI、标定和关相状态，保留完整Flash和原镜像用于回退。
- 只扩展原Commissioning测试RUN入口，新增kind=8、24字节正弦参数；旧16字节入口不变。
  在原20kHz测试钩子用既有Math_SinCos生成参考，复用原FOC、采集、停止和租约；不新增控制模块。
- 用户补充允许1.5～2A偏置、0.3～0.5A摆幅。主扫频Id=1.5A＋0.3A×sin，Iq=0；
  约20Hz至4kHz分点，每点至少4个完整周期，两次独立采集；通过后用2A＋0.5A×sin复核
  带宽附近频点和低频参考，不提高3A相电流截止。
  先给偏置稳定20ms，再给正弦；等待至少5周期且不小于50ms，读取128点冻结样本。
- 本机保护沿用3A、5rad/s、1rad、500ms租约，每次结束关相；保护、通信、标定或数据异常立即中止。
- 频率由20kHz时基和采样stride选择，使128点记录包含整数周期；记录真实参考和原始dq反馈，
  用同频正弦最小二乘拟合H(f)=Id反馈/Id参考，保留相位、残差、重复差异和电压余量。
  相位包含本实现从参考提交到电流采样的离散延迟。
- −3dB点相对低频增益计算，仅在相邻有效点包围时插值；重复差异/失真显著则说明不确定性，
  不将PI整定值或阶跃折算当成扫频测量。

## 实测中的范围调整

首次1.5A偏置在正式采集窗口前触发5rad/s保护，保留`raw/`和`result.json`；
停止1.5～2A高电流扫频。此前0.3/0.75A Id稳态已通过，因此另开`low_current/`批次，
采用0.5A±0.1A，峰值0.6A，其他保护不变；不执行2A复核。
若低电流批次再次触发保护，则结束全部励磁，保留未完成的频点。
低电流批次完成后，在交点附近补测2656.25、2812.5、2968.75Hz，均保持原低电流与保护。
