# 模式3验证记录（2026-09-08）

## 变更范围

模式3使用2 kHz jerk限制轨迹、连续低速反馈与40 Hz滤波、位置/速度串级反馈、受斜率限制的摩擦前馈及迟滞保持。临近目标时保留摩擦补偿至捕获区，减速时保留已学习的负载积分，补齐MOVE到SETTLE间的前馈间隙，并修正轨迹制动预留造成的末段速度回升。

同时提交12通道RTT、专用HIL工程和主机回归测试。正常工程默认禁用HIL服务。温度换算移至1 kHz监督任务，模式3跳过未使用的无感观测器，相关实时编译单元启用O3/Otime。控制核心未增加MCU依赖，未修改Vendor源文件。

## 历史台架结果

对象为直驱、大惯量和大摩擦机构，精度以电机编码器为准。用户允许范围为±90°；自动目标限制±85°，主机/板端位置停止阈值为±88°/±90°。巡航45°/s（8 s/rev），加减速度45°/s²。位置Kp=8、Kd=2，原速度参数Kp=0.5、Ki=1，电流上限6 A，主机采样电流停止阈值4 A。上述整定参数已在台架保存，但本提交不将其强制写成所有电机的出厂默认值。
