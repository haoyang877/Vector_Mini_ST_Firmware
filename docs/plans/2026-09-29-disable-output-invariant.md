# Disable 功率输出状态核验 v0.1

## 问题与目标

新电机电气快速检查时，经 J-Link 异步写模式 0 后正常 STOP 超时。现场断开母线后，
零电压模式切换诊断在第 263 次复现：模式和上一模式均为 0，三相使能仍为 0x1555，
CPU 持续运行且没有故障。仅依赖模式边沿的关相路径无法保证 Disable 输出状态。

目标是保证进入 Disable 后，下一次快中断发现三相通道或引脚仍处于输出状态时补执行停机。

## 实现与边界

在现有停机条件中加入平台接口 `motor_hw_phase_outputs_disabled()` 检查，复用现有
`Clear_RunningData()` 和 `Stop_PWM_Generate()`。不增加模式、参数或通信 ABI。
正常模式 0 仍保留 CH4/MOE 的 ADC 触发用途；三相通道关闭且六路驱动输入高阻才表示关相。
不把本次修复等同于所有异步 START 命令已可靠串行化；台架需继续核验实际使能状态。

阻尼档同时固化上一台实际标定使用的 5 A 慢启动配置：Iq 4.97 A、Id 0.5 A、
6 s 电角速度爬升至 315 rad/s、机械速度 15 rad/s、启动超时 16 s。
不复用上一台电机的 LUT 或任何电角/机械零位、摩擦标定数据；电零位对齐仍保留 8 A 上限。

## 验收

- 正常固件构建无错误；现有离线测试通过。
- 现场母线断电、功率级无有效供电情况下，零电压切换至少 500 次，逐次核验模式和三相关断。
- 修复后正常启动电流零偏流程完成并回到 Disable。
- 重新做六方向低压检查后才进入 mode 13/15、摩擦与闭环测试。
- STOP 失败不得自动恢复试验，现场断电后再分析。

## 回滚与证据

回滚本文件对应的停机条件即可恢复原代码；回滚后不得继续宣称停机问题已解决。
原镜像和逐次诊断保存在忽略目录 `outputs/new_motor_commissioning_20260929/`，
记录固件哈希、未关相状态、现场断电和最终硬件关断结果。新增镜像应独立归档匹配 ELF、
HEX 和符号信息，禁止复用不同镜像的 RAM 地址。
