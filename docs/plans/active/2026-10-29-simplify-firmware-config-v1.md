# 固件配置文件简化 v1

## 目标

合并职责相近、独立文件没有实际必要的配置头，减少用户切换板卡和电机时需要查找的文件；在两个文件内保留板卡、电机、目标、功能准入和PWM许可的逻辑边界。

## 不变边界

两套APP当前板卡/电机选择、派生表达式、编译期保护检查、固定阈值、Flash schema14、保存参数优先级和AT32永久关相行为不变；2 mΩ和6 mΩ仍共用用户确认的10 A/18 A策略。保留新板/新电机可直接选择配置头的能力。保留工作区并发更改与其他项目。

## 基线、验收和回退

冻结同一份源码并构建两套APP作为基线；在该副本仅应用本次配置合并和包含路径调整后重建，比较HEX及资源。补充配置组合及非法值拒绝的离线测试，运行PR检查。不接触硬件。回退仅针对本计划的文件合并、引用和文档，不能覆盖其他未提交工作。

## 用户追加：收敛为两个配置头

`firmware/config` 最终仅保留应用配置头和板卡/电机资源配置头；目标选择通过两套正式工程的构建输入和资源配置完成。应用头集中控制输入、软件策略、派生表达式及准入校验；资源头按板卡和电机分段保存物理输入。保留永久关相、已有 Flash 参数优先级、完整 APP 电机数据校验和自定义资源扩展能力。删除旧头前先完成可恢复备份，并更新源码、测试、构建输入和有效文档；不得仅用转发头伪装成两个文件。

## 用户追加：减少硬件准入重复检查

移除没有产品运行时消费者的重复 `BSP_REQUIRED_*` 可选开关，直接验证固定必需的相电流、母线电压、编码器、PWM 和完整 APP CAN。MCU 温度要求仍参与运行时故障与自检，保留 STM32 必需以及 AT32 关相/限时约束。电流环带宽归应用控制配置。

## 离线证据

两套正式 APP 冻结同一源码后重构前后 HEX 字节完全一致；各次构建均为 0 错误、0 警告。配置组合、非法值拒绝、已有 Flash 参数优先级和电流阈值由主机测试覆盖。验证不连接硬件。

最终验证：`outputs/runs/two-config-minimal-requirements-20261029/summary.json` 的 PR 全项通过；STM32G431 和 AT32F456 正式工程各为 0 错误、0 警告，HEX 分别与本轮冻结基线逐字节一致。删减后保留 24 组非法配置编译拒绝测试。原始工作区输入备份在 `outputs/config-simplify-20261029/`。未连接硬件。
