## 1. 串级控制核心

核心完成“位置误差 → 速度指令 → 电流指令”的闭环计算，拥有速度 PI 状态。
不拥有目标规划、MOVE/SETTLE/HOLD、摩擦模型、起步/着陆状态或外部机构装配选择。

当前数学应保留：

```text
位置误差 = 参考位置 - 测量位置
速度误差 = 参考速度 - 控制反馈速度
速度指令 = 限幅(参考速度 + 位置 Kp × 位置误差 + 位置 Kd × 速度误差)
反馈电流 = 速度 PI(速度指令 - 控制反馈速度)
总前馈 = 限幅(各附加模块电流之和)
电流指令 = 限幅(反馈电流 + 总前馈)
实际反馈份额 = 限幅(电流指令 - 总前馈)
速度 PI 跟踪实际反馈份额，修正积分抗饱和
```

现有 `speed_kp/speed_ki` 均乘 `current_limit_a` 后进入安培域 PI，拆分不能静默改变
调参语义。速度指令上限由组合层按现有 `min(电机速度上限, 1.5 × 轨迹巡航上限)` 提供。
有限性校验、速度/电流限幅、PI 条件积分与输出跟踪属于必保契约。

核心最低输入：参考位置 rad、参考速度 rad/s、测量位置 rad、控制反馈速度 rad/s、
更新周期 s、位置/速度增益、速度指令上限 rad/s、电流上限 A、外部总前馈 A。
核心输出：速度指令 rad/s、反馈电流 A、最终电流指令 A、饱和/有效标志，以及供策略读取
的 PI 比例项和积分项只读快照。参考加速度和最终目标无需进入核心。

完整旧行为还需要明确的积分策略输入：是否允许普通速度积分、有界卸载请求及静差增量。
由具名接口在核心内应用，不能让摩擦模块获得 PI 可写地址。其调用顺序待组合设计明确，
不能把两次调整随意相加或重排，以免改变浮点结果和限幅行为。

## 2. 现有功能归属

| 当前内容 | 归属 | 可选性与保留理由 |
| --- | --- | --- |
| 位置 P/速度误差 D、速度 PI | 串级核心 | 闭环本体 |
| 限幅、有限性检查、实际输出跟踪 | 核心及输入边界 | 安全/失败契约，不删除 |
| 精确静止到静止轨迹、在线换目标规划 | 参考生成 | 附加能力；两者适用条件不同，不能当重复路径删除 |
| 软跟随误差调速 | 参考生成 | 可选 governor，不是故障保护 |
| MOVE/SETTLE/HOLD、到位确认、滞回 | 伺服运行策略 | 完整产品需要，纯核心无需知道阶段 |
| 基础速度滤波、额外 HOLD 滤波 | 反馈整形 | 可旁路；不等于已无用 |
| 库仑/粘性模型、起步辅助、距离卸载、反转先归零、恢复 | 摩擦补偿 | 独立状态和启停，输出补偿电流 |
| 加速度乘前馈增益 | 加速度前馈 | 独立无状态运算；当前默认增益为零，不能据此删除可配置能力 |
| 阻碍纠正的积分卸载、静差积分增强 | 积分管理策略 | 与普通 PI 抗饱和不同；无需并入摩擦模型 |
| 配置缓存、分频、遥测延后、快照 | 组合/调度适配 | 不属于闭环数学，现有调用者仍使用 |

“核心以外”不代表“多余”。本轮未发现可直接删除的完整功能。已确认的冗余仅为重复
HOLD 判据、被更宽着陆条件覆盖的子判据及重复展开的标量下界校验。

## 3. 摩擦补偿最低模型与完整旧策略

最低模型只需要运动方向、模型参考速度 rad/s、正负方向库仑电流 A 和粘性系数
A/(rad/s)，输出有符号电流 A。现有模型使用**轨迹参考速度的绝对值**，不是测量速度：

```text
幅值 = 本方向库仑电流 + 本方向粘性系数 × |轨迹参考速度|
模型电流 = 方向 × 幅值
```

仅为模型更换文件位置不能解耦现有完整摩擦策略。距离判断、起步、着陆、恢复和电流
斜率限制全部应归摩擦模块；其核心数据契约如下。

| 每拍输入 | 单位/语义 | 用途 |
| --- | --- | --- |
| 最终目标、当前参考位置、测量位置 | rad | 方向选择、剩余距离、是否越过目标、恢复和起步位移 |
| 轨迹参考速度 | rad/s | 模型速度及正常运动方向 |
| 基础滤波后的测量速度 | rad/s | 停止/运动识别、惯性制动距离；不用额外 HOLD 整形后的速度 |
| 有效减速度幅值 | rad/s²，正值 | 保留现有 `v²/(2a)` 制动包络 |
| 更新周期 | s | 计时和电流斜率 |
| 运动进行、保持有效、捕获已锁存 | 组合层提供的只读事实 | 从旧阶段映射；模块无需访问串级控制器状态 |
| 新目标事件、全复位事件、启用状态 | 显式命令 | 保留不同事件的复位语义 |
| 当前电流上限 | A | 模块内部限幅；最终总电流仍统一限幅 |

静态配置分两组：模型参数（四个正负库仑/粘性参数），策略参数（参考/停止/运动速度
rad/s、起步距离 rad、停滞时间 s、起步倍率、进入/退出/零补偿距离 rad、建立/快速释放/
捕获释放/普通释放斜率 A/s）。现有捕获距离与保持窗口同值，由组合层传入；它们不是
对串级内部状态的借用。先保持全部现有参数数值，不把固定常量新增为持久参数 ABI。

摩擦模块独占：补偿电流、方向锁存、停滞计数、起步位置、起步有效、着陆有效、恢复有效。
输出：补偿电流 A、电流幅值正在建立标志，以及只读起步/着陆/恢复诊断。补偿剩余量
用于组合层的 HOLD 资格与积分协调，摩擦模块不写 HOLD 阶段或 PI 积分。

现有卸载有两层：距离比例降低模型目标电流，再按 A/s 限制实际电流变化；两者都保留在
摩擦模块。线性距离卸载发生在捕获区，制动包络用于锁存着陆，不等于从整个制动距离
开始线性卸载。反转先卸至零、着陆后停住再缓慢起步恢复也归该模块。

关闭语义按旧行为：当拍补偿电流归零，清除方向、计数、起步/着陆/恢复/建立标志；
不清除速度 PI 的负载支撑积分。运行中关闭会产生前馈阶跃，改成平滑关闭是独立行为变更。
新目标事件只清除旧实现清除的标志/计数，保留已有补偿电流和方向，不能等同全复位。
有无摩擦环、有效辨识模型或回退模型选择由外部装配/参数策略决定，不放入核心判断。

## 4. 加速度前馈与组合边界

摩擦补偿本身也是前馈的一种。代码中应明确区分摩擦前馈和加速度前馈，再汇总两者，
避免“前馈补偿”成为包含模型选择、运动阶段和 PI 写入的万能模块。
加速度前馈最低输入：参考加速度 rad/s²、增益 A/(rad/s²)、电流上限 A；输出有符号
电流 A；无摩擦、目标距离和阶段依赖。零增益保持当前关闭语义。

建议数据流：参考生成 → 串级速度指令；参考运动及伺服事实 → 摩擦模块；参考加速度
→ 加速度前馈；附加电流汇总 → 核心电流计算及抗饱和。伺服运行策略独占到位/保持状态。
当前两条真实交互必须显式保留：HOLD 确认等待前馈卸载，前馈建立时暂停同方向速度积分。
不能要求各模块互读私有状态，也不能删除交互来换取表面独立。

另一个现存耦合是静差积分：即使 `friction_feedforward_enabled=false`，它仍可运行，
却复用了 `friction_stop_speed/friction_stuck_time/friction_breakaway_distance`。
应明确它属于独立的残余负载积分策略；未来给它自有配置，由适配层先传入旧值以维持行为。
关闭摩擦模型不能自动关闭这一能力或清掉保持积分。
