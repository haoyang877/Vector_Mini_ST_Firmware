## 目前保持的行为

- STOP 关闭输出；速度为零、位置保持仍属于普通控制，停止运动模式没有在本轮新增。
- 参数未确认或标定不完整但基础数值和健康有效时允许待命，拒绝相关启动；真实采样或参数故障仍按原路径锁存。
- 任务完成、RAM 候选发布、保存提交、取消及资源归还分别表达；原任务和 SAVE 不共用终态身份。
- 故障优先于普通请求，CLEAR 不恢复旧目标；FATAL 不允许普通清错。真实关相、任务取消和后台资源归还是不同确认。
- 现有控制数学、保护阈值、参数 ABI、调度时基及 Loader 边界保持。本轮不烧录、不写参数、不运行电机。

## 已发现的复杂度与待决事项

| 事项 | 当前实现 | 讨论方向和决定条件 |
| --- | --- | --- |
| 初始化 | BOOT → SELF_TEST | 合并为 INIT；保留零点采样、期限、输出关闭确认 |
| 待命名称 | READY 并非全部具备启动资格 | 改为 IDLE，启动受限原因独立读取 |
| 空闲 STOP | 已关相状态也经 STOPPING 往返 | 保持原状态同时撤销请求和核对关相；不能省掉初始化自检 |
| 维护与保存 | MAINTENANCE → STOPPING → READY → MAINTENANCE〔SAVE〕 | 维护内部串行保存后只退出一次；先确定是否保留自动保存和独立 SAVE 身份 |
| 故障种类 | FAULT 和 FATAL 重复关断／清理 | 合并前明确不可清除的故障码及恢复资格，不能把 FATAL 变为普通可恢复错误 |
| 启动等待 | STARTING 等速度／位置外环准备 | 只有证明准备可同步完成后再删除；不以隐藏标志代替同一等待 |
| 提交结构 | 同拍多次事件、规则与动作交接 | 集中主流程和出口，优先删重复状态／动作镜像；保留提交边界的动态复核 |

建议先审七状态草案：INIT、IDLE、STARTING、RUNNING、MAINTENANCE、STOPPING、FAULT。六状态版本额外要求控制准备同步完成。上述是待确认方向，用户尚未批准具体状态删减或外部行为改变。
