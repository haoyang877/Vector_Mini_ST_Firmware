# 电调协议简化决策与实施顺序 v0.1

日期：2026-09-23，2026-09-24 开始分步实施。用户已确认按候选首批 Type 编号定版，且新设计优先于旧代码；公司消息类型表仍待同步登记。硬件功率动作仍须经过明确 bench 场景验证。线路字段以[单轴线路契约 v1](../../protocols/yg_protocol_motor_wire_v1.md)为准。依据[飞书《电调通信协议》](https://wcnxj7iyqdkp.feishu.cn/wiki/M5KJwCZApilqfjk251XcktAPnxa)和[简化版电调协议](../../protocols/yg_protocol_simplified_motor_v0_1.md)。此前[业务重构实施方案](2026-09-23-yg-protocol-business-implementation.md)中的控制会话、独立 SET_MODE 和大量管理 Type 不是本轮默认路线。

## 目标、基线与不可变行为

正常位置控制由 101 使能进入 mode 5 三相低侧导通状态、116 模式加目标两条控制请求完成；以后每个新目标只发 116。mode 5 在页面被称为“高阻态”，但用户已明确它的物理动作为 PWM 使能且三相下管全开，因此实施时按低侧制动评审，不能按全桥关断实现。电压模式首版需要，项目候选为 mode 6、q 轴电压 i32 mV。保留公司 16B 头/2B CRC16、小端、CAN FD 1M/5M、业务回复和本地电机保护。当前可运行基线是 1/2/108 只读和 110/111 未绑定停止路由；101/116 尚未实现，124 尚不周期发送。旧标准 CAN 已删除，不恢复兼容入口。

## 分步实施与验收

1. **契约冻结**：先按[CMD ID 核对表](../../protocols/yg_protocol_cmd_id_review_v0_1.md)和[CMD 功能契约](../../protocols/yg_protocol_cmd_function_contract_v0_1.md)完成公司 Type 登记与项目评审，再核对原文不完整处（mode 5 的低侧制动安全边界、mode 6 的 q 轴电压范围、MIT 增益与单位），确定 101/116 的逐字节 payload、回复和序号语义；新增正常/错误/重试黄金向量以及主机同源解码测试。未定字段不得靠固件猜测。
2. **使能与失能**：把 101 交给现有生命周期/功率所有者；验证 `enable=1` 时三相低侧导通、上侧关闭及制动电流/温升，`enable=0` 时实际输出关闭。111 旧候选同义入口须删除或明确迁移；不能只凭通信 ACK 判定输出关闭。
3. **单轴目标**：116 只解码和值校验，控制所有者在 2 kHz 监督周期应用模式和目标；用当前位置建立初始位置参考，后续目标不得触发重复模式初始化。范围、故障、编码器与参数配置检查沿用现有电机保护。接入前 GET_CAPS 不宣称该功能。
4. **反馈**：按[逐命令反馈契约 v0.2](../../protocols/yg_protocol_motor_feedback_v0_2.md)把飞书全量字段与控制序号关联；每条 116 均须返回同 Type 业务回复及一条关联 124，108 按新契约迁移。主机根据回复、反馈与实测位置分别判定“已受理”“已应用”“已到位”，不混为一次 ACK。
5. **同步和升级**：五轴 193/125 先单轴、两轴、五轴测截止时间和输出相位；升级按 BEGIN/WRITE/FINISH/STATUS 的最小通用流程另立 Loader/主机契约，不挤占实时总线时隙。

参数业务另按[读写参数表 v0.1](../../protocols/yg_protocol_parameter_catalog_v0_1.md)冻结 `u8 Param ID`、权限与单位；先复用已有 ID 0/1/2 只读来源，再逐步接写入与保存，不将尚无变量的飞书条目注册为可用能力。

每个协议/固件阶段分别提交、运行 PR 验证。硬件测试必须使用显式 bench 场景；若 STOP/失能未能验证输出关闭，停止测试并人工介入。回退新 101/116/124 路由时，主机协议版本和能力声明一起回退，不留下两套同 Type 解释。

2026-09-24 进度：已冻结首批线路字段并增加黄金向量；已退役 111、接入 101/116 安全拒绝路由与逐条 124 反馈、实现 256 条单轴序号去重；108 已改为空请求与 45B 全量状态回复，删除旧会话前缀及 34B 状态编码；已将 110/101 失能接到现有停机服务并让板级上电默认不使能相输出。控制使能与位置目标仍保持 `UNSUPPORTED`，待 mode 5 低侧制动的真实功率接口和边界验证后接入。单轴 200 Hz、五轴 1 kHz、参数/升级均尚未实测或实现。
