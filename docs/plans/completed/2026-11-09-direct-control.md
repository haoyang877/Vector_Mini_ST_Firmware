# 删除目标与外环结果的 ADC 交接

基线 `780d6162`。前台按当前模式校验并直接写目标，外环在结束计算时写入本轴控制字段。删除 ADC 拍首应用结果的接口、槽、序号及待处理副本。ADC 可在多字段写入中途抢占，此时可能看到新旧字段的组合。

保留六个控制模式的准入和限幅、通信去重、独立轴实例、STOP 与故障优先、实际启相复核、标定及 Loader 链。检查设置目标和外环提交返回时的实际值，验证过期外环及 STOP、两板原生回归、PR 和三个生产镜像构建。回退此提交可恢复原交接时机。

## 结果

- 删除目标双槽及其代际、序号、待处理外环副本和配套私有头文件。提交有效外环计算时直接写控制字段及速度 PI。每次计算仍使用本次调用的栈上工作区，以便提交前拒绝来自其他轴或已停止会话的结果。
- STM32G431 与 AT32F456 分别对照了六种控制模式共 8,448 组输入。新代码在请求返回时的七个目标字段和返回码，逐项等于基线在下一 ADC 拍后的结果。离线覆盖连续覆盖目标、外环立即写入、启动许可、STOP、故障关相及嵌套双轴。证据在 `outputs/direct-control/target-comparison.json`。
- G431 普通 APP、AT32F456 普通 APP、G431 LoaderApp 全量构建均为零错误、零警告。相对基线，静态 RAM 分别减少 224、216、224 字节，ROM 分别减少 408、432、408 字节。镜像哈希见 `outputs/direct-control/images.json`。
- PR 检查中 45 组原生测试、21 项集成测试通过。单元测试 124 项中通过 122 项。既有 RTT 哈希失败以及 104 项文档诊断与基线一致，整仓检查仍为 FAIL。见 `outputs/runs/20261109-direct-control/summary.json`。未烧录，未测实板抢占时序。
