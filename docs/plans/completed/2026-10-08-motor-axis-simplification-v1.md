## 核心职责与数据流

| 阶段 | 输入 → 输出及单位 | 状态写入及归属 |
| --- | --- | --- |
| 启动 Init | 固定工作区参数记录 → 活动模型/设备/应用参数、PI 配置 | MotorAxis 组装运行对象；参数服务解包，端口读取 Flash；读取失败采用既有默认值，归还工作区 |
| 上电零点 | 每帧三相四次 ADC 原始和 → 1 秒平均 counts → 相电流 A | MotorAxis 唯一持有累计值；只在关相且 NONE 模式采样；异常锁存故障，不自动重试；完成增一次活动修订，不保存、不启动 |
| 快拍采样 20 kHz | 编码器事务、母线 V、ADC counts → 电角 rad、电流 A、母线滤波 V | 端口负责 I/O；反馈/采样算法写显式对象；母线额度只更新电流 PI 上下限，不改积分/增益 |
| 快拍调度 | 故障、维护许可、生命周期、epoch → 单个 worker 结果 | Axis 选择维护/运行/空闲预载；MotorExecution 和 MotorMaintenance 执行实际功能；状态机消费结果，Axis 不写生命周期或输出使能 |
| 快拍收尾 | worker 结果与捕获 epoch → 完成事实、修订、RTT | COMPLETED/FINALIZE 每个维护 epoch 只增一次修订；两次 FastFaultStop 保留，遥测有界 |
| 慢拍 2 kHz | 编码器快状态、目标 rad/rad_s → 多圈位置、速度、iq_target_a | 顺序固定：反馈慢估计 → MotorOuterLoop → 主状态机 → 温度 ℃；每类慢状态由现有函数单写 |
| 状态读取 | 活动对象 → 测量/规划快照与有效位 | 同一短临界区读状态、维护类型及进展；模式3速度采用位置外环滤波值；无规划值返回 NaN |
| 参数读/写 | ID、原始 i32/u32、来源/序号、修订 → 活动值/新修订 | Axis 持有最近读/写和修订；参数服务负责类型、范围与单位缩放；重复原请求重放，冲突/陈旧请求拒绝；写成功复位既有控制器，不自动保存 |
| 保存受理/轮询 | expected_revision → 原 ticket → ACCEPTED/终态/持久修订 | Axis 只持有业务票据；主状态机受理 SAVE 并决定准入、取消和释放；入口不写 Flash |
| 前台保存/齿槽发布 | 有效 claim + 借用工作区 → 完整记录/候选与成功事实 | 主状态机认领；Axis 组装记录，核对 claim 后调用存储/发布，归还工作区，再提交完成事实；存储端口负责擦写与回读 |

启动和维护请求由唯一主状态机决定；STOP、故障或 epoch 失效撤销工作。
保存终态仅在真实后台完成后报告 OK；旧票据取消在新请求和轮询入口主动收敛。
任务算法负责计算，平台负责 I/O，Axis 负责固定调度/组装，参数服务负责字段转换，
状态机负责生命周期、功率使能、取消及收尾。Watch 观测符号保留，外部不得成为运行写者。

## 简化与验收

`MaintenanceRunnable` 是无副作用的读取；ADC IRQ 优先级 0，高于 CAN 1、监督 TIM7 3。
快拍捕获 epoch/许可后到 worker 选择之间没有会写维护状态的调用，故可显式传入该许可，
避免第二次跨所有者读取。故障与零点未完成检查仍在 worker 入口，种类/状态仍在原分支读取。
不同保存/齿槽资源的借用与释放保持独立，不用泛化包装合并。

验收：已有启动零点/PI、调度矩阵、参数身份夹具；调度夹具对冻结基线比较；PR profile、
format --check、lint；同冻结输入的对象和整包链接容量比较。无实机时序/运动验证。
若空间无净收益则据实记录；不靠关闭功能或放宽链接边界交付镜像。
