# Mode 3 ±150° 大范围实机测试

## 目标

把现有位置环自动验收标准作为本轮判据，并为可连续多圈旋转的 roll 裸轴增加相对当前位置 ±150° 的分段往返测试。

## 基线与范围

- 模式3旧 roll 参数：位置环 Kp=8、Kd=2；速度环 Kp=0.5、Ki=1.0。
- 新阻尼电机摩擦补偿使用已辨识的正/反向 Coulomb 电流，黏性项为0；方向 `reverse=0`。
- 运动阶段临时 RAM 限制：Iq 指令上限5 A，规划速度0.1 rad/s，加减速度0.2 rad/s²；实测峰值速度硬停止阈值90°/s（1.571 rad/s），测试相对位置硬停止阈值±155°。速度保护上限与规划速度分别记录；调整前者不会自动提高后者。
- 只允许当前已确认裸轴/连续旋转工况；动作以开始时连续编码器位置为中心。不得更改Flash或校准参数。

## 通过标准

每个目标完整采集，且末2秒最大绝对位置误差≤0.3°、HOLD比例100%、记录到的Iq峰值<4 A、丢帧/限流标志均为0；目标命令接受、镜像标识有效、最终正常STOP确认并关闭三相输出。任一目标不满足时立即停止，不自动继续扩展行程。

## 执行序列

先检查停机、故障、母线、校准方向、连续位置、AXS1限制和Flash哈希。每次先走 ±30° 递增的目标，到每个端点并满足完整采集验收后才走下一点：

`0 → +30 → +60 → +90 → +120 → +150 → +120 → +90 → +60 → +30 → 0 → −30 → −60 → −90 → −120 → −150 → −120 → −90 → −60 → −30 → 0°`。

## 回滚与证据

结束先发STOP并验证 mode=0、故障清零、三相输出关闭，再恢复测试前RAM配置并读回校验；Flash前后SHA-256必须一致。任何STOP或功率输出关闭无法验证都视为失败，要求现场断电介入，不允许自动恢复。完整记录、样本、每段结果和校验数据保存在忽略的 `outputs/` 下。
