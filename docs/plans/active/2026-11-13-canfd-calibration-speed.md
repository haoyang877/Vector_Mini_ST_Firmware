# CAN FD 桌面角度标定与速度控制

基线：`the-system-refactor` 的 `f5a4ef7a`，APP v1.8.2、Loader v2.3.4、GUI v1.7.4。
用户要求在现有 CAN FD 测试上位机加入角度标定及速度控制使能。保持固件、协议、
参数ABI、检测阈值、既有标定算法和控制PI；用户七个未提交配置及outputs证据保留。

GUI升级v1.8.0，新增独立页面，SDK仍由单一工作进程独占。角度标定使用160 kind1，
另可显式选择kind2电角零位，不设置机械零位；
跟踪161票据，只有phase2/effects2且保存修订回读匹配才显示成功；取消使用162/110，
启动应答未知不能重放。已有任务、故障、非APP或能力缺失拒绝新操作。

速度使能使用117 mode2，默认电机轴0 rad/s；运行态确认后116更新目标，118定期续租。
UI通过有界队列更新目标，按UID持久预留计数，跨预留块不回退或重复；同一工作进程
处理反馈和STOP。失联/拒绝立即STOP，不重使能。关闭窗口先停止并确认，保留原始帧。
读取本机速度/电流上限与有效反馈；台架默认输出行程360°，不写运行限值或PI。

按职责新增CAN电机操作模块，GUI保留输入、展示及进程生命周期；不将工装的SWD烧录、
参数生成或固定等待逻辑搬入页面。仅复用已有帧请求、STOP与计数持久化契约。

验收覆盖标定成功/失败/取消/丢应答、速度模式/续租/序号/更新/停止/关闭路径，离线
回归不访问硬件。按当前已授权节点6空载28V台架验证一次标准联合标定、零速使能、
低速正反转及STOP，保留标定前后备份。release档与GUI打包另记匹配哈希；旧发布包
不覆盖。失败保留新旧参数和真实票据，不自动恢复运动或宣称已保存。
