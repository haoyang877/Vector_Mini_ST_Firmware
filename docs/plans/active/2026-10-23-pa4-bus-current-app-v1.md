# PA4实测母线电流接入完整APP v1

## 目标与边界

初始交付按用户要求仅完成代码及离线验证，不连接探针、不烧录、不复位、不启相。
随后用户单独授权关相烧录、复位及静态/CAN实机验证，结果见文末；全程禁止驱动电机。
根据板级是否具备独立母线电流采样链路选择反馈；旧板保留估算结果。
本次是新增反馈功能，不将其描述为行为等价重构。

冻结中间层、控制算法、状态机、参数/协议ABI及既有BSP接口。
控制内的`FocState.bus_current_a/bus_current_filtered_a/power_filtered_w`继续保留
原估算，避免改变运行时对象所有权或从底层反向写入控制对象。
在APP状态装配时选择实测反馈，CAN既有母线电流字段及有效位随之反映实测数据。
`MotorAxis_ReadStatus`仍返回控制所有者的原始快照，顶层诊断需要与协议使用相同装配。

## 实现

- 板级只读数据`BOARD_HAS_BUS_CURRENT_SENSOR`：旧板0，新板1。
- `app/composition/app_bus_current.h`是APP内部装配扩展，不是BSP接口。
  旧板内联空操作，保留原电流及全部有效位，不链接AT32代码。
- AT32独立APP装配`application/bus_current_feedback.c`，通过原有
  `R40_AdcReadAux`读取PA4；新板TMR6每个2kHz监督拍处理上一帧已完成的DMA结果。
  不改变20kHz控制路径、ADC序列、DMA实现或CAN的1M/5M时序。
- 仅`yg_protocol_status_adapter.c`在已有状态快照后调用装配；协议编码器不变。
- 有硬件而读数无效时清除APP测量位0x40，写NAN；既有编码器发送
  `INT16_MIN`并清除线路有效位5，不伪装为0A或自动回退到估算。

## 偏置与换算

每次启动记录独立PA4偏置，不复用三相偏置、不使用固定2048、不写Flash。
`g_r40_bus_current_diagnostic`供Keil只读观察：

| 字段 | 含义 |
| --- | --- |
| raw_counts / sequence / milliseconds | 最近处理的12位单次原码、序号、处理时间 |
| offset_samples / offset_counts / offset_valid | 校准样本数、实测零点（可带小数）、资格 |
| current_a / filtered_a / sample_valid | 名义换算值、滤波值及当前资格 |
| status | 0等待校零、1有效、2缺样本、3近电源轨、4偏置窗口拒绝 |

只有软件关相且连续128个不同序号样本稳定时完成校零（2kHz约64ms）。
候选均在2048±256计数内，峰峰不超过16计数；缺帧、失效或启相中断未完成窗口。
校零后偏置固定，后续关相也不重新追踪，以免真实电流被抵消。
偏置只留本次上电RAM记录；复位重新测量，不修改参数记录及Flash布局。

换算采用3.3V、4095满量程、独立2mΩ分流、20倍增益：
`Ibus=(raw-offset)*3.3/4095/20/0.002`，约0.02015A/count。
正号按原理图放大器接法及此前开环原码升高定义为母线供电方向；
完整正负电流及增益精度仍需外部仪表实测确认。

新鲜序号每帧滤波系数0.05（正常2kHz时约9.75ms时间常数）；重复帧不推进滤波。
序号缺口或失效恢复重新以当前值初始化滤波，不虚构中间数据。
底层拒绝样本、处理结果年龄超过2ms或计数<=2/>=4093时反馈无效。
所有无效值必须同时检查`sample_valid`/线路有效位，旧诊断数值保留仅用于排查。
