# APP v1.3.0 核心候选

日期：2026-10-08。按用户要求直接删减辅助功能，旧v1.1/v1.2归档包不覆盖。
本页说明源码范围；实际构建提交、Flash/RAM和Loader包是否生成以本轮输出清单为准。

## 保留

- 电流、速度、直接位置串级和必要VQ调试；原控制增益、限幅及故障阈值。
- 编码器LUT、电气/机械零位和必要电流偏置初始化，及它们所需观测/启动算法。
- 单项任务取消、参数默认值、schema12读取/校验和真实存储保存。
- 明确START/STOP、同模式目标更新、FAULT快速关断，CLEAR只回空闲不启动。
- CAN基本控制、反馈、参数和原Loader镜像/升级/交接/恢复链。

## 删除

运行租约/续租、持久启动计数、泛化组合标定计划、新会话命令；
摩擦/相电阻辨识、齿槽标定/补偿、复杂轨迹与HOLD编排、自动RTT及其依赖。
对应执行代码与工程登记实际移除，不以编译宏或能力位隐藏。
运行模式变更采用STOP→IDLE→明确START。

0x0076和0x00A6撤回且不复用；117保留原6B布局，复用明确模式1/2/3/6启动。
旧速度模式2字节保持；目标116不负责启动，107 CLEAR不启动。
普通启动不包含持久跨重启身份契约，不能继承v1.2扩展设计的防重放声明。
维护kind3/4/5及参数0x47..0x4B退役，不生成成功结果或复用旧编号。

## 存储与部署

schema12 4304B记录和16KiB总参数/身份区保持，历史摩擦/齿槽槽仅占位，读取忽略、导出清零。
本工作没有连接设备或擦写现场数据；历史计数页也不擦除。
独立normal APP从0x08000000链接，不能当CAN升级镜像使用，会覆盖原Loader区域。
配套LoaderApp仍必须装入原layout5的94208B槽；是否可打包由实际匹配构建确认。
未经匹配台架验证，不称正式发布或实机PASS。
