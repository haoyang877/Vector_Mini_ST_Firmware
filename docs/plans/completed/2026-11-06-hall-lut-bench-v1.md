# PITCH Hall LUT 实机验收

范围：下载本次 128 点 Hall LUT，在已确认可连续多圈的 PITCH 0x06 上完成联合标定，
比较独立数据的校正前后误差，检查抖动、超时、保存与启动恢复；通过后提交本功能。
沿用已确认的线束、限位及现场断电条件，保持 100 电机圈、原独立标定 PI 和电流限制。

工作树有并行的轴参数变更。以当前已提交基线加 Hall LUT 指定文件冻结测试源码，
参数文件只取 Hall 扩展部分，测试及提交不夹带轴配置、Keil Watch 或其他未提交修改。
诊断版只在 outputs 快照增加有限 SRAM 采样和 DWT 统计，测试后恢复正式版，不提交诊断。

验收顺序：

1. CAN/SWD 双重身份、状态和 PWM 核对；停稳后备份固件及完整参数区。
2. 下载回读核对，参数区保持原样。诊断版完整标定中，建表所用首个 1.01 输出圈之后，
   每 20 个外环节拍保存一组配对原码，共 512 组，作为未参与建表的验证集。
3. 结束后用本次新电机 LUT 校正验证集电机连续角并除减速比；同一参考与角度方向比较
   Hall 原角和校正角。去掉固定相位，报告峰值、RMS、P95、覆盖及首尾关系。
   本轮参考一致性目标：峰值和 RMS 均降低至少 50%，校正后峰值不超过 0.5°。
   这不是外部量具测量的机械绝对精度，也不证明回差被消除。
4. 临时 DWT 统计覆盖标定期间 20 kHz 和 4 kHz 处理体的最大耗时与超过周期次数；
   要求无超周期、无故障。处理体计时不包含所有异常进出开销，保留该测量边界。
5. 现场确认起步、匀速和停机无明显抖动。STOP/异常时结束试验并保持关相。
6. 恢复正式版，重新完整标定；无故障、LUT/对应关系成功、Flash CRC/绑定正确，
   重启恢复一致。诊断数据与正式版的建表算法保持一致；正式版不保留耗时诊断。
7. release 离线检查、产物哈希及实际限制归档；只提交匹配测试快照的 Hall 变更。

独立快照、Flash 备份、监控日志和镜像放 outputs；出现失败保留原始证据，不改门槛掩盖失败。
本计划只为开发验收，不自动扩大为量产发布或其他电机测试。

实测修正：旧板分析脚本误将电机 LUT 起点读为 48，实际 ABI 偏移为 44；真实 C 复算确认
修正后的峰值为 0.639°，原 6° 尖峰为分析错误。为减少建表采样纹波，256 组数据改用
小角度区间内三路配对均值，并在降至 128 点之前作三点误差平滑。ADC 不过采样，运行反馈
不增加滤波。离线模型 144 组通过；仍必须重新实测，不能用模型结果代替 0.5° 验收。

用户换用全新板后，独立备份新板 Flash，按 PITCH 型号生成空标定记录，不迁移旧板系数。
首次新板完整标定无故障，用户反馈无明显抖动；独立 512 点峰值 0.556°、RMS 0.183°，
快环最大 39.094 µs、外环最大 60.189 µs，均无超周期，精度尚未通过。
继续对照 Hall 单次 ADC 采样时间，实验只在 outputs 快照实施，未经验证不进入生产源码。

新板对照与正式版恢复结果见[新板报告](../../reports/2026-11/2026-11-06-hall-lut-new-board-v1.md)。
ADC 对照仍未通过 0.5° 门槛，已撤掉实验设置和临时诊断。正式版再次标定及软件复位恢复
通过，机械工装零位未设置；本计划保持未完成，不提交。
