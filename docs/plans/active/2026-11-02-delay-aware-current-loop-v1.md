# 含内部延迟的电流PI重整定 v1

用户要求考虑电流环内部延迟重新设计参数并执行测试。目标解释为闭环参考到反馈−3dB约1.2kHz，
不把整定常量或开环交越频率当成闭环验收结果。

## 已有依据与实现

- 20kHz控制；现有0.5A±0.1A D轴扫频约2.96kHz，实际PI为1.07442474/4146.90283。
- 对应波形的等效离散RL模型：R≈0.719Ω、L≈153.2μH、额外延迟≈48.8μs。
  R/L与延迟来自同一批数据拟合，不是独立物理测量；设计先按额外50μs计算并留裕量。
- 保留现有PI实现、采样/PWM时序、标定、观测器R/L、协议和保护；只在AT32/YQ组合选用重算的固定增益。
  其他板卡/电机继续沿用原派生策略。新候选Kp≈0.60995855、Ki≈3226.22067，d/q先采用同值。
- 新参数为该组合的整定值；保存的旧PI不覆盖它。更换硬件、电机或时序需要重新整定。

## 离散设计

令采样周期Ts=50μs，a=exp(−R Ts/L)，离散对象为
G(z)=[(1−a)/R]z⁻¹/(1−az⁻¹)，再计入额外一拍延迟。
现有后向积分PI为C(z)=Kp+Ki Ts/(1−z⁻¹)，取Kp/(Kp+Ki Ts)=a消去模型极点。
按1.2kHz处闭环幅值1/√2求比例，检查交越相位裕度、峰值和时域响应；保存可重算设计脚本。

## 验证

1. 备份当前镜像、完整Flash和活动配置；读回确认身份、停机、PI与完整LUT。
2. 定向测试默认/保存参数均选中新PI且不改变模型/标定/记录；PR、冻结源码release及双板构建。
3. 烧录后全量核对HEX加载字节、原参数区、活动PI、标定和看门狗配置。
4. 先0.5A±0.1A D轴扫频，不重试上轮1.5A偏置触发限速的高电流工况。
   限值仍为3A、5rad/s、1rad、500ms租约，异常即停。
5. 验收闭环−3dB为1.2kHz±10%、无明显增益隆起，独立记录相位和重复误差。
   复测0.3/0.75A Id阶跃和稳态纹波；相位裕度仅在单位反馈假设下估计，不冒充开环注入实测。
6. 若候选未达标，先解释差异再调整；保留失败与每版参数。出现保护不提高截止门限重试。
   结束核对关相、故障0、标定和参数区不变；必要时回退备份镜像。

输出目录：`outputs/delay-aware-current-loop-20261102/`。Q轴无锁轴频响未测，不以D轴通过宣称整机全工况通过。
