# 单轴位置 S 曲线 OTG v1

在 the-system-refactor 的 POSITION 监督外环生成限 jerk 的位置、速度和加速度参考。
收到新目标时从上一已生成参考接续，终点速度和加速度为零。普通拍只采样恒 jerk 多项式。
使用活动位置巡航速度、轴速度上限和位置加减速度；首版以较小加减速度作为对称上限，
用 100 ms 定义从零加速度升至上限的时间。协议及持久化记录布局沿用现有版本。

离线验收覆盖短行程、巡航、非零加速度反向换目标、重复或连续换目标、复位、边界与故障。
检查每拍位移、速度、加速度、jerk 和最终静止位置，同时运行生产外环夹具及 PR 验证。
板上跟随误差与重规划最坏耗时需要独立实测。

## 离线验证记录

正反向在加速、匀加速、巡航和制动时换目标，逐拍检查位置、速度、加速度的接续。
固定种子 2,000 个初态，每个初态六条计划，按双精度独立积分核对段边界、段内速度极值和静止终点。
两个实例交错调用通过；生产外环的反向接续、到位、速度指令限幅和状态回报测试通过。
STM32G431、STM32G431 LoaderApp、AT32F456 三个 Keil 工程均为零错误、零警告。

整仓验证记录为 outputs/runs/position-otg-final/summary.json。位置相关夹具、工程布局、
架构、接口和 lint 通过。整仓仍有其他工作树改动的格式、AT32 工程/RTT 校验、中断夹具和
历史文档链接失败。本次未接入硬件，板上普通拍及重规划最坏周期数待测。

## 命名与重复校验整理

沿用 Reset、SetTarget、Sample 三个入口和逐拍参考合同。段数、当前段下标、段内时间分别使用
segment_count、segment_index、segment_elapsed_s；建表计算显式区分位置和有符号位移。
同目标同约束命中已验证计划时跳过输入复检。每拍仍检查当前轴与最终目标，生成参考后只复核行程边界。
以原有连续性、限值、交错实例和外环回归为基线，增加同目标无效限值拒绝及中途参考越界用例。
