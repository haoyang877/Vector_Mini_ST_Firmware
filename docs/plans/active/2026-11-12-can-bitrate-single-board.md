# AT32F456 单板波特率实测与桌面工具集成

本次在一台连接 J-Link 和 USB-CAN 的板上验证已交付的 APP v0.7.1、Loader v2.3.1。固定源为 `9bf44955`，先核对芯片 UID、CAN 回报、当前运行速率、六路关相和 FLASH 双读备份。关相完成全程通信测试并保留可复原的原始镜像与标定。

总线上有其他在线节点。按本次授权，实机始终使用 1M/5M，只读 0x71 的 RAM 与 Flash 值，验证复位、APP 与 Loader 同速应答及两端寄存器。12 种组合保留离线验证。退出时恢复测试前现场状态并复核。只有本次实机验收通过才合并。重构工作树中已确认的工具基线为 CAN-Link-Test v1.6.0，界面沿用其现有工作进程、适配器设置和节点身份识别。

共线复位时记录到主站每 200 ms 轮询五轴。v2.3.1 在 8 次复位中有 2 次于 APP 镜像校验期间出现 CAN RX 溢出并驻留 Loader。补丁将 AT32 Loader 的硬件接收范围限定到本机与广播，继续保留溢出和 bus-off 救援逻辑。使用同一主站流量复验，交付配对版本为 APP v0.7.2、Loader v2.3.2。
