# v0.6.0 绕组热保护基础实机验证

日期：2026-10-15。分支：codex/ovp-36v。
受测固件源码节点为 a11a8d94；使用离线归档的正常APP镜像，未修改固件控制逻辑。
本记录仅证明下述固定磁场注入场景的动作，不作为真实绕组温升标定或量产验收。

## 台架和写入

轮电机架空、21极对、无阻尼环，原角度LUT及电零位标志均为3。
用户确认可连续旋转、其他命令暂停、现场可断电；本轮相电流及d/q向量监测上限3 A，
单次注入预算不超过10秒。临时加速门限仅用于动作验证。
下载前后保留Loader程序与个体参数，APP v0.5.2升级至v0.6.0。
更新启动记录时按既有Loader契约将90,692 B镜像补FF至90,696 B，重新计算记录CRC并回读。
初次未对齐的记录被Loader拒绝启动，纠正后正常进入APP；没有修改Loader校验规则。

## 前序异常

编码器反馈电流模式mode 1向3 A升流时，Id指令仅0.35 A，机械速度已达29.51 rad/s，
超过20 rad/s停止阈值。正常STOP及关相验证通过，默认参数已恢复。
原电零位与相序尚需核查，不能据此宣称mode 1已完成3 A热注入。

## 固定磁场验证

复用现有mode 15固定电角度0的Id对齐路径，仅作为短时电流注入。
在1.2秒预算内、标定完成保存之前退出，保留原电零位并恢复原标定标志，不生成新标定结果。

临时配置如下，未写入Flash：

| 项目 | 临时值 |
| --- | ---: |
| Id对齐请求 | 3 A |
| 实测电流停止边界 | 3 A |
| 模型向量峰值/连续参考 | 2.7 A / 2.7 A |
| 相RMS参考 | 2.7/√2 A |
| 升温/冷却时间常数 | 65.985 s / 120 s |
| 降额进入/退出 | 1.2% / 1.1% |
| 热量停机/允许清故障 | 2.0% / 1.05% |

mode 15属于标定模式，进入降额即锁存故障并退出，不继续执行缩减电流的标定。
因此本轮在1.2%进入门限动作，未到2.0%热量停机门限；不能将其描述为验证了100%热量触发，
也未覆盖mode 1的持续降额闭环行为。

| 实测项目 | 结果 |
| --- | --- |
| Id请求峰值 / 实测Id峰值 | 3.000 A / 2.713 A |
| 实测相电流峰值 | 2.700 A |
| 机械速度峰值 | 2.253 rad/s |
| 主机首次观测到故障的延时 | 约0.739 s |
| 动作热量 | 1.2027%，A相热点主导 |
| 故障与输出 | 故障16，mode 0，Id/Iq参考归零，三相关断 |
| 未冷却时清故障 | 拒绝，热锁存保持 |

| 参数恢复 | 默认热参数、原6 A运行上限与3 A标定电流恢复 |

电流与速度为主机SWD离散采样峰值，不代表20 kHz全样本极值；
故障时延包含主机采集间隔，不能作为MCU保护中断延迟。
