# 可关闭的速度惯量前馈

接口/Flash版本v1，文档修订v3，2026-10-12；功能已从`codex/wheel-speed-feedforward`合入`codex/ovp-36v`，APP v0.4.0候选。
本功能默认关闭，尚未下载或实机验收，不影响正在调试的ovp-36v工作树。

本页用于开关、保存和调试；原理、公式、状态所有权、代码入口见
[速度前馈实现设计](../architecture/wheel_speed_feedforward_design_v1.md)。

速查：`MotorControl.speed_ff_config.enabled`为开关；CAN写0x70、读0x71；
所有配置写入仅限停机，通过现有mode9保存，并在复位后逐项回读核验。

## 行为与默认值

仅在有感纯速度mode2且开关开启时使用；位置、无感、标定/辨识模式不参与。
关闭时执行原速度PI/斜坡，不自动修改既有Kp/Ki、电流上限或speedAcc/speedDec。
开启时独立的二阶临界阻尼目标整形限制规划加速度及jerk，取代旧线性斜坡。
加减速使用共同上限，连续变目标保留当前规划状态；前馈从规划加速度计算，
不对实测噪声或CAN阶跃求导。正常降速发送mode2速度目标0，紧急STOP/故障仍
立即走既有关相路径，不等待平滑规划。

| 设置 | RAM变量 | 默认值 | 通信范围/单位 |
| --- | --- | ---: | --- |
| 开关 | `MotorControl.speed_ff_config.enabled` | 0关闭 | 只接受0/1 |
| J/Kt系数 | `gain_a_per_rad_s2` | 0.028 | 0～0.2 A/(rad/s²) |
| 加减速上限 | `acceleration_limit_rad_s2` | 20 | 0.1～100 rad/s² |
| jerk上限 | `jerk_limit_rad_s3` | 200 | 1～2000 rad/s³ |
| 前馈电流上限 | `current_limit_a` | 2 | 0～10 A，实际同时不超过总限流50% |

按100mm轮径，默认加减速为1m/s²≈1145.9°/s²，jerk为10m/s³≈11459.2°/s³。
系数约为25kg两轮直驱理论值的50%；按度计算为0.000489 A/(°/s²)。这些只是
保守候选，不是整车最佳值；还未计轮子/转子惯量、转向惯量及地面滚动阻力。

默认前馈峰值约0.56A（0.028×20），2A是限流上限，不是固定注入值。
在默认系数和加速度不变时，仅调大前馈限流不会增加前馈。
显示可按度换算，但CAN系数应写0.028；不能把显示值0.000489直接写入，
否则按A/(rad/s²)解释后前馈会约小57.3倍。

合成电流=`PI电流+前馈电流`。前馈限制给PI留出余量，并将总限流换算成剩余
PI输出区间，积分准入和实际限幅跟踪都包含前馈。没有解除电压圆、过流、速度
或故障保护，没有新增摩擦补偿、零速增益切换或自动惯量辨识。

## CAN配置与保存

下面均为旧式标准帧，ID=`(node_id<<8)|参数ID`；载荷是4字节大端float32。
这些新参数没有使用现有速度/电流命令的定点编码。与其他分支公司协议无关。

| 参数 | 写入ID | 查询ID |
| --- | --- | --- |
| 开关 | 0x70 | 0x71 |
| J/Kt | 0x72 | 0x73 |
| 加减速上限 | 0x74 | 0x75 |
| jerk上限 | 0x76 | 0x77 |
| 前馈电流上限 | 0x78 | 0x79 |
| 当前前馈电流，A | — | 0x7A |
| 当前规划加速度，rad/s² | — | 0x7B |

所有写入都要求mode0、上一个模式已停机、没有故障/待切档，且功率输出已关闭。
成功后在对应查询ID返回已应用值；拒绝返回float32的−1，原配置不变。
查询不修改模式。开关只能写入精确0或1；NaN、无穷、越界和运行中写入均拒绝。

以左轮节点1为例：

1. 停机后写开关：ID `0x170`、数据`3F 80 00 00`（1）；ACK ID `0x171`。
2. 关闭：同ID、数据`00 00 00 00`（0）。右轮使用`0x270/0x271`。
3. 系数0.028：ID `0x172`、载荷`3C E5 60 42`；随后查询`0x173`核对。
4. 停机用现有mode9保存：ID `0x100`、载荷`41 10 00 00`（9）。查询mode已回0，
   再查询新设置；复位后再次查询0x71～0x79。写RAM成功并不代表已保存Flash。

mode9回到0仅表示保存流程结束，不独立证明写入成功；复位后回读为最终核验。
关闭也必须保存，否则重启可能恢复此前保存的开启状态。

完整默认配置报文如下，均在已停机状态发送。右轮将帧ID的`0x1xx`改成`0x2xx`，数据不变。

| 设置 | 左轮写入帧ID | 数据 | 查询/ACK帧ID |
| --- | --- | --- | --- |
| 关闭 | 0x170 | 00 00 00 00 | 0x171 |
| 系数0.028 | 0x172 | 3C E5 60 42 | 0x173 |
| 加减速20 rad/s² | 0x174 | 41 A0 00 00 | 0x175 |
| jerk 200 rad/s³ | 0x176 | 43 48 00 00 | 0x177 |
| 前馈限流2 A | 0x178 | 40 00 00 00 | 0x179 |
| 开启 | 0x170 | 3F 80 00 00 | 0x171 |
| mode9保存 | 0x100 | 41 10 00 00 | 查询模式0x101 |

主机现有`Client.write/read/verify`已支持0x70/72/74/76/78配对配置。
实时反馈沿用现有速度目标/规划速度、实测速度、IqRef和Iq；新增两个只读查询
用于分辨前馈与反馈贡献。J-Link/LKS可用新AXF读取`MotorControl.speed_ff_state`
中的`speed_rad_s/acceleration_rad_s2/current_a`，不沿用旧地址。本次未改RTT帧或
自动增加通道，CAN查询不是2kHz同步采样，也不能当成同拍数据。

现有mode3 RTT摩擦/前馈字段不能当作本功能mode2的惯量前馈。
建议观测`MotorControl.speedRef`、`speedShadow`、`iqRef`，新`speed_ff_state`中的
规划速度/加速度/前馈电流，`OnBoard_Encoder.vel_mech`、`FOC.Iq/Id`以及调制/故障状态。
同拍的`IqRef−Iff`只用于估算反馈贡献，不能把多次CAN查询拼成同拍电流分量。

## 空载与整车调试

空载阶段保持关闭并保存，验证原速度功能。整车阶段在新的实际台架边界下先
比较三种情况：关闭；开启且系数为0（只用平滑规划）；开启且系数0.028。

A/B同时改变规划，不能把差异全部归因于前馈；B/C应使用相同规划、PI、限流
和目标序列，分离前馈效果。每组从相同静止状态开始，覆盖正反方向、正常降速
到0和低速换向；每次只调整一个参数，记录全部配置、固件哈希及采样率。

| 现象 | 优先检查 |
| --- | --- |
| 加减速时滞后且未饱和 | 在B/C对照中逐步调整系数 |
| 系数增大后超前/反向纠偏增加 | 减小系数，核对采样是否同拍 |
| 规划滞后但实测跟随规划 | 核对加速度和jerk配比；jerk同时影响整形时间尺度 |
| 总电流贴限或Iq跟不上IqRef | 降低加减速要求，检查电压限幅，不单纯放大前馈 |
| 匀速/静止仍振动 | 检查测速、反馈PI或机械共振；零加速度时惯量前馈应趋近0 |

应记录最大/RMS速度误差、停车反向峰值、按统一阈值定义的安定时间、前馈和
总电流峰值、限流/电压饱和时长、故障及最终停机状态。上述是待执行流程，
不是实测结论；STOP或关相不能确认时按仓库要求现场干预，不自动继续下一组。
高转速电压不足时仍可能出现跟随误差，不应单纯通过放大前馈解决。
电压饱和、打滑和共振下的数据不用于直接估计惯量。

独立的前馈开关与模式开关不同：开启配置本身不会启动电机。调试回退为停机、
写开关0、mode9保存；关闭后仍保留调出的系数，方便之后再次启用。

## Flash兼容

schema10及旧字段偏移保持，SFF1/v1记录追加在参数区相对偏移2312：

| 偏移 | 字段 | 大小 |
| ---: | --- | ---: |
| 2312 | magic=`SFF1`，0x31464653 | 4 |
| 2316 | version=1 | 4 |
| 2320 | enabled，uint32 0/1 | 4 |
| 2324 | J/Kt，float32 | 4 |
| 2328 | 加减速上限，float32 | 4 |
| 2332 | jerk上限，float32 | 4 |
| 2336 | 前馈电流上限，float32 | 4 |
| 2340 | CRC32 | 4 |

小端存储，标准反射CRC32覆盖前28字节；黄金向量见
`tests/vectors/speed_feedforward_v1.json`。参数总长2344字节，仍占两页且已按8字节对齐。旧记录全零/全0xFF时默认关闭，不因此自动保存；新
记录非空且CRC、版本、开关或数值非法时拒绝参数准入，不自动覆盖坏记录。
旧固件忽略尾部；旧固件保存擦除新尾部，再升级会默认关闭。LUT、电零位、
机械零位、轴范围、原PI和既有PSP1记录位置不变。

调参前应先查询0x6F，确认板端已经下载v0.4.0；本次合并没有下载设备或改写
任何板卡Flash。其他分支的未知格式不能仅凭同属schema10互刷。

FSL1/v1斜率记录固定保留在2292～2311，SFF1位于其后2312。合并保留目标分支
mode3摩擦斜率控制及实际加载/保存行为；旧空FSL1使用2/15 A/s默认值，显式
保存时生成有效记录。非空损坏FSL1或SFF1拒绝准入。启用速度前馈后保存、
关闭再保存均保留摩擦斜率、LUT、零位和两套PI，离线测试覆盖此组合。
