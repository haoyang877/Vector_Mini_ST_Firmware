# 电流阶跃等效带宽核验 v1

用户要求打开实测结果，明确当前实测电流环带宽以及能否提高。
已有稳态噪声不能直接给出频响带宽；本轮复用原板端Id阶跃和20kHz触发采集，补测阶跃响应。
不改PI、不下载固件、不新增控制接口，保存独立原始数据。

## 试验

- 使用当前已验证的AT32F456＋YQ-5708（8:1）；先确认关相、故障0、标定未变。
- 先重复3次0→0.3A Id，Iq=0；低档通过原阶跃建议指标后再重复3次0→0.75A Id。
- 每次阶跃由板端施加，保留32点预触发和96点后触发，50μs间隔；短时运行后关相才导出。
- Id检查完成后，用3次+0.3A、5ms的Iq短脉冲检查q轴响应；同档重复用于重复性统计，失败后不升档。
- 相电流上限3A；附加速度5rad/s、累计行程1rad、1秒时限和500ms租约，不锁轴、不持续非零Iq。
- 原建议上升时间≤1ms、超调≤10%、稳定时间≤3ms。任何故障、截止或指标失败停止升档。

## 分析边界

按原始数据计算10%–90%上升时间，线性插值结果与50μs采样网格结果同时记录。
在单调一阶近似适用时，以ln(9)/(2π·tr)计算阶跃等效带宽；不能称为扫频实测−3dB带宽或相位裕度。
检查稳态值、超调、重复性和电压饱和，避免把噪声峰或瞬态未完成误算成快响应。
提高建议只描述候选验证路线；用户尚未要求实际提高增益，本轮保持原值。

输出位于`outputs/current-bandwidth-20261102/`，当前与历史结果分别保留；文档/quick检查后交付。
