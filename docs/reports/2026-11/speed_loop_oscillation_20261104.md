# 速度闭环持续振荡的根因分析 2026-11-04

## 后续实测修正

本页保留原离线推导作为历史记录。2026-11-04 后续台架试验已证明
0.05/0.5 会引发饱和快振，0.03/0.5 在约 70 Hz 出现约 15 dB 共振峰，
因此下文的增益推荐与稳定裕量估算不能作为上板依据。
实际整定与带宽结论见[台架整定报告](speed_loop_tuning_20261104.md)。

原文“穿越频率”公式中平方根前的符号错误。对
L(s)=Kt·I_limit·(Kp·s+Ki)/(J·s²)，单位增益穿越频率应为
ωc=ωn·sqrt(2ζ²+sqrt(1+4ζ⁴))，其中 ωn 为自然角频率。
自然频率、开环穿越频率和闭环 −3 dB 带宽是不同指标。
后续实测显示原惯量模型不足以预测高频裕量，实际扫频优先。

本轮只做离线分析：读取 20:09 的 20 kHz RTT 曲线、18:34 的 CAN 速度测试记录和 19:36 的
活动参数 RAM 副本，未改固件、未烧录、未写 Flash、未启停电机。结论只适用于当时镜像
（`9d9b2eb5` 附近的工作区构建）、AT32F456＋YQ-5708（8:1）台架和所列工况。

## 结论

1. 20:09 曲线在约 10 rad/s 运行点存在**持续、不衰减**的机械转速振荡：20 Hz 低通后均值
   10.04 rad/s、标准差 1.19 rad/s、范围 5.74～13.22 rad/s（峰峰 7.48 rad/s，约均值的 74%）。
   主频在 1.0～1.7 Hz，2 次谐波明显，并呈频率/幅度调制；在 3 s 记录内不衰减，不是阶跃瞬态。
2. 直接原因：速度环 PI 的**活动参数是 Kp=0.005、Ki=0.05、限流 3.0 A**，只有源码默认
   0.05/0.5 的 1/10。按转子惯量 J=0.0005 kg·m²、Kt=0.0801 N·m/A 折算，当前闭环
   ωn≈0.78 Hz、ζ≈0.25、相位裕度≈27°，明显欠阻尼；振荡落在该环路带宽附近，被
   摩擦/齿隙非线性维持。
3. 这不是算错或单位错：实测 q 轴电流对转速的低频比例增益为 0.0152 A/(rad/s)，与
   `Kp × 限流 = 0.005 × 3.0 = 0.0150` 相差 1.3%，证明环路确按上面的活动参数工作；
   同一组参数在 18:34 的 0.5 rad/s 低速测试里，iq 指令斜率 73 mA/s 与
   `Ki × 限流 × 误差 = 0.05 × 3.0 × 0.5 = 75 mA/s` 一致。
4. 建议先把速度环恢复到源码默认 **0.05/0.5**（3 A 限流下等效 0.15 A/(rad/s) 与
   1.5 A/(rad/s²)）：预计 ωn≈2.47 Hz、ζ≈0.78、相位裕度≈69°，0.5 rad/s 下达到
   0.26 A 的时间由 3.47 s 缩短到 0.35 s。若负载等效惯量约为转子的 4 倍，该组参数
   仍为 ωn≈1.23 Hz、ζ≈0.39、PM≈42° 的临界可用状态，必须台架确认后再固化。
5. 18:34 记录的 0.5 rad/s 测试在 3.50 s 出现单帧 8.426 rad/s，按 0.26 A 与 J=0.0005
   折算 50 ms 内不可能产生该加速度，倾向速度反馈跃升或粘滑释放；两板编码器帧的
   CRC/状态位未校验是已知缺口，需独立计划处理，**不作为本次持续振荡的根因**。
6. 20:32/20:37 追加的闭环与电压/角度开环两组 2 kHz 采集（见文末“追加数据”）把有效
   惯量修正为约 1.5×10⁻⁴ kg·m²（不是铭牌 5×10⁻⁴）：旧增益下闭环 fn≈1.4 Hz、
   ζ≈0.45、|S(1.5 Hz)|≈+1.4 dB，与实测 1.5～1.9 Hz 主振吻合；开环同转速下 1～3 Hz
   慢分量只有闭环的约 1/3，说明慢振荡主要是闭环放大。

## 为什么这组增益会振荡

速度环是归一化 PI：输出先按 [−1,1] 限幅、再乘 `current_limit_a` 变为 iq 指令，因此
等效增益为 `Kp_eff = Kp × I_limit`、`Ki_eff = Ki × I_limit`。以 J、Kt 建二阶模型：

- ωn = sqrt(Kt × Ki_eff / J)
- ζ = Kp_eff × Kt / (2 × sqrt(J × Kt × Ki_eff))

按 J=0.0005 kg·m²、Kt=0.0801 N·m/A、限流 3 A 计算：

| Kp/Ki（归一化） | Kp_eff / Ki_eff | 等效带宽 fn | 阻尼 ζ | 穿越频率 | 相位裕度 |
| --- | --- | ---: | ---: | ---: | ---: |
| **0.005 / 0.05（当前）** | 0.015 / 0.15 | **0.78 Hz** | **0.25** | 0.73 Hz | **27.5°** |
| 0.01 / 0.1 | 0.03 / 0.3 | 1.10 Hz | 0.35 | 0.98 Hz | 38.0° |
| 0.02 / 0.2 | 0.06 / 0.6 | 1.56 Hz | 0.49 | 1.24 Hz | 51.0° |
| **0.05 / 0.5（建议）** | 0.15 / 1.5 | **2.47 Hz** | **0.78** | 1.48 Hz | **68.8°** |
| 0.1 / 1.0 | 0.30 / 3.0 | 3.49 Hz | 1.10 | 1.56 Hz | 78.5° |

（Kp/Ki 分别为归一化 `1/(rad/s)` 与 `1/(rad/s·s)`；Kp_eff/Ki_eff 为 `A/(rad/s)` 与
`A/(rad/s²)`。穿越频率按二阶闭环 `sqrt(sqrt(1+4ζ⁴)−2ζ²)·ωn` 计算，未计额外延迟；
2.9 ms 延迟在 1.5 Hz 处只损失约 1.5°。）

当前参数下环路穿越频率 0.73 Hz，低于实测 1.0～1.7 Hz 主振，环路无法有效抑制该频段扰动；
ζ=0.25 又使扰动衰减很慢，摩擦/齿隙的非线性把能量维持在 1 Hz 附近，形成 2 Hz 谐波。
比例通道电流摆幅只有约 ±0.06 A（限流 3 A 的 2%），说明还有很大增益余量，
“增大增益会立刻饱和”不是当前限制。

位置级联也使用同一对 `speed_kp/speed_ki`（`firmware/motor/control/position_control.c`
中按 `current_limit_a` 反归一化），并对速度反馈再叠加 10 Hz 低通，相位滞后更大；因此
同一组参数在位置模式下只会更欠阻尼，本次整定方向同样适用。

### 惯量不确定性的影响（建议参数 0.05/0.5，3 A）

| 电机侧等效惯量 J | fn | ζ | PM |
| --- | ---: | ---: | ---: |
| 0.0005（仅转子标称） | 2.47 Hz | 0.78 | 68.8° |
| 0.0010（2×） | 1.74 Hz | 0.55 | 55.5° |
| 0.0020（4×） | 1.23 Hz | 0.39 | 41.9° |
| 0.0050（10×，偏保守） | 0.78 Hz | 0.25 | 27.5° |

输出轴自由、未接负载时等效惯量应接近转子值，但减速器自身惯量与齿隙未辨识，
故给出阶梯而不是单一“最优”参数。

## 建议参数与应用方式

### 建议

1. **首档：`speed_kp=0.05`、`speed_ki=0.5`**（归一化，3 A 限流；等效 0.15 A/(rad/s)、
   1.5 A/(rad/s²)）。相当于把当前环路带宽提高约 3 倍、阻尼比由 0.25 提到 0.78。
2. 若阶跃仍有明显超调/持续振荡：退到 `0.02/0.2`（PM 51°）或 `0.03/0.3`。
3. 若响应偏慢且无超调、电流未饱和：再试 `0.08/0.8`、`0.1/1.0`，每次都要有阶跃数据。
4. 不建议直接上更高增益：同一重建曲线在 35～42 Hz 也有谱峰（来源可能是机械谐振或
   测量/重建混叠，未独立确认），编码器 PLL 带宽 90 Hz，需要先确认机械共振与噪声不被放大。

注意：速度环是归一化 PI，**等效增益随 `current_limit_a` 线性变化**。台架记录当前限流
是 3 A，而源码默认是 6 A；同一对归一化增益在 6 A 下等效增益翻倍。整定和验收必须在
同一限流下进行，并记录限流值。

### 如何写入（本轮不改固件）

- 源码默认 `application_config.h` 已经是 0.05/0.5，但设备上电时从 Flash 参数记录装载
  0.005/0.05；**只改源码不会改变现有台架**。
- 参数服务里 ID 16/17（`speed_kp`/`speed_ki`）目前是**只读**（`READ_FIELD`），不能用
  CAN 写入；`cascade_position_kp/kd`（ID 21/22）和限流/速度上限倒是可写。
- 因此本轮之后若要做台架验证，只有两条路：
  1. 用 J-Link 按匹配镜像的 map 找到 `s_motor_configuration`，在结构体偏移 88/92 处
     直接写两个 float（仅 RAM，重启即恢复；**不要**在写 RAM 后执行标定保存）；
  2. 由参数所有者重写 Flash 记录（改默认 + 重新 provision），或把 16/17 纳入可写参数。
     后者属于参数 ABI 变更，需要版本化文档、兼容说明和测试，须另立计划，不在本轮范围。
- 测试结束必须恢复原值（0.005/0.05）或复位，避免把临时试验值留在运行设备上。
- 若以后装配有效的 AXS 关节记录，启动装载会按关节修订 1 把速度增益覆盖为
  `0.5/1.0～2.0`（见 `param_apply_joint_profile`）；本次建议值以当前没有有效轴记录为前提。

## 台架验证建议（待用户授权后执行）

1. 记录母线、限流、速度上限、目标、固件提交与 AXF；确认输出轴自由、电机固定。
2. 先只写 RAM 的速度 Kp/Ki，不写 Flash。
3. 20 kHz RTT 记录电角度、机械转速、q 轴电流（现有 RTT 通道已够），另记录目标。
4. 阶跃序列：0→1、1→3、3→10 rad/s，每档 ≥2 s，正反向各一次。
5. 判据：超调 <10%，2% 稳定时间 <0.2 s，稳态 ±2% 内无 >0.5 Hz 持续振荡，iq 不进入限幅；
   同时确认位置/速度模式切换和 STOP 行为不变。
6. 失败时退回上一档并保存原始波形；通过后再决定固化路径。

## 局限与未决

- 20:09 采集只保存了波形，未保存当时的模式、目标和限流/速度上限。19:36 读回的
  速度上限是 π rad/s，若该次是速度模式且运行在 10 rad/s，说明上限在运行前被临时改写。
  结论依赖“该次为速度外环运行”：q 轴电流与转速的比例关系唯一对应速度 PI 比例通道，
  可支持这一判断；位置级联的内环使用同一 Kp/Ki，建议同样适用。
- 主频 1.0～1.7 Hz 与线性模型 0.78 Hz 不完全一致，原因是摩擦/齿隙非线性和负载惯量未知；
  因此给阶梯参数并保留台架确认。
- 18:34 的 8.426 rad/s 单帧跃升未定性：0.26 A 在 50 ms 内只能把转子加速约 2 rad/s，
  数值上更像反馈跃升或粘滑释放。两板编码器（MT6835/TLE5012B）帧的 CRC/STAT 未校验，
  是决策 0002 已记录的缺口；若要区分，需要在低速工况下同步记录角度、转速、iq 并
  增加帧校验计数（独立计划）。
- 本文没有验证更高转速、带载、温升、反向或位置模式下的表现；未测项不因已测子项通过。
- 本轮只改文档，未运行硬件测试。`check_hygiene` 通过与 `lint` 通过（用临时缓存）；
  `format --check` 只报并行未提交改动中的 `projects/at32f456/application/main.c`；
  完整 quick profile 因当前受限文件权限和其它未完成改动未能执行，不能声称通过。

   （J=1.5×10⁻⁴）一致，而不是机械源直接产生。
2. 30–60 Hz 分量开环、闭环都大，且速度环的 |S| 在该频带≈0 dB，改增益影响不到它。
   同频带 q 轴电流纹波 RMS 只有 0.017 A（闭环）和 0.043 A（开环）；若它是纯转子惯量
   运动，按 J≈1.5×10⁻⁴ 需要约 0.2–0.5 A。差值说明能量可能经减速器/轴系交换（真实的
   扭转谐振），或角度/测速通道本身有纹波。两种可能都需要专门试验区分，不能靠调速度环消除。
3. 开环均值跟随指令良好，说明本次“波动大”不是角度开环频率、极对数或刻度错误。

### 下一步判别

1. 先按 0.03/0.5（或保守 0.02/0.2）复测同一 10 rad/s 点：预期 1–3 Hz 分量下降 10 倍
   以上；剩余总标准差将由 30–60 Hz 分量主导（约 1.3 rad/s），若该分量为测速伪影，
   真实误差会更小。
2. 30–60 Hz 来源判别：多转速开环重复，看峰值是固定频率（结构谐振）还是随转速成比例
   （转频阶次/测速相关）；锁死输出轴复测（扭转谐振会变，测速伪影不变）；用 20 kHz
   采样通道复核同一工况，排除 2 kHz 采样的混叠。
3. 编码器帧 CRC/STAT 校验缺口与上述判别共用同一套同步记录；仍不在本轮修改范围。

### 局限

- 闭环目标、模式和限流未随数据保存；开环 V/f 没有电流闭环，不是理想的频响辨识激励，
  只用于同工况对比，不作为精确传函。
- 2 kHz 采样对 >1 kHz 内容有混叠；30–60 Hz 在 Nyquist 内可分辨，但快环 20 kHz 噪声
  可能折叠进来，需 20 kHz 采样复核后才能把它定性为机械或测量问题。
