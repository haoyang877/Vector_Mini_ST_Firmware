# Mode 3 测试用例与执行入口

当前电机已命名roll；roll/pitch持久化范围与连接状态见 [轴配置记录](motor_axis_profiles.md)。

本套测试分主机软件回归、实机动作及采集验收。主机回归不打开J-Link、不下载固件、不使能电机；实机动作与采集验收依赖的 HIL 台架工装已于 2026-09-19 退役，见 [HIL 退役计划](../plans/active/2026-09-19-hil-retirement.md)。参数含义见 [核心参数说明](mode3_parameter_guide.md)。

## 1. 主机回归

依赖Python 3.10+和C99编译器（Zig、GCC或Clang）。默认不需要NumPy、Keil或J-Link。原一键入口 `tools/bench/run_mode3_validation.py` 已随 HIL 退役删除；保留的原生C回归在仓库根目录执行：

```powershell
python tests/unit/native/run_position_servo_tests.py --cc <zig-executable> --out outputs/mode3_native
```

也可将编译器路径放入环境变量 `SERVO_CC`，或将编译器加入PATH后省略 `--cc`。退出码0为通过，非0为失败；这不是实机验收。

| 编号 | 主机用例 | 覆盖/判据 |
| --- | --- | --- |
| U01 | 非法参数、NaN/Inf、无效输出指针、配置变更 | 拒绝无效配置；有效配置可继续，填充字节不误触发重校验 |
| U02 | 连续低速反馈、实际编码器估算器 | 正反向低速、复位、旧接口兼容；不以滤波零速代替真实静止 |
| U03 | 保持噪声、支撑力、外扰、窗口迟滞 | HOLD保留支撑电流，越界退出；先捕获与从未捕获的行为不同 |
| U04 | 制动、着陆、提前到位、摩擦卸载及恢复 | 无补偿断档、软捕获卸载、越过目标快速卸载、受阻后恢复 |
| U05 | 反转、总电流限幅及积分 | 保留必要负载积分，错误方向积分卸载，限幅与抗饱和 |
| U06 | 静止纠偏、关闭治理/纠偏选项 | 确认静止后有界积累，运动/换目标/饱和/复位处理 |
| U07 | 5/20/85°轨迹、运动中改目标、连续目标流 | 参考限制、制动、q/v/a接续、规划不饥饿 |
| U08 | 独立五次速度轨迹 | 极短/短/长行程、双方向、巡航、q/v/a/jerk段间连续、速度积分等于位移、静止终点 |
| U09 | 20 kHz调用 / 2 kHz控制分频 | 状态与遥测节奏，无重复执行控制 |
| U11 | 72组工况组合 | 电流上限1/3/6 A × 摩擦比例0/0.2/0.6 × 0.1/5/20/85° × 双方向；包含不对称摩擦、速度/加减速度变化 |

U11是**合成输入与理想跟随传感器夹具**，检查有限输出、限流、轨迹约束与保持状态；没有负载J/Kt模型，不能预测新电机闭环稳定性。当前C伺服测试共23个分组（原22组加U11矩阵），另有独立轨迹和编码器测试；原 HIL 命令服务主机桩（U10）与计划/验收脚本检查（U12）已随 HIL 退役删除。

## 5. 需要额外执行的验收

| 用例 | 操作与记录 | 通过依据 |
| --- | --- | --- |
| 负载/摩擦变化 | 为每种装配分别记录参数、重新辨识或核对模型，运行small/medium/range | 全部自动指标及人工抖动评价，不能用一个负载结果代替其他负载 |
| HOLD外扰 | 仅在已有夹具与操作条件允许时施加可控扰动，记录偏移和恢复 | 保持退出与恢复符合定义、无持续振荡；外力大小不得由脚本猜测 |
| 运动中改目标 | 通过已验证入口在加速、巡航、减速时改变目标，记录q/v/a与Iq | 无非法跳变/超限，终点保持合格；主机已有接续测试，实机不由上述定点脚本自动覆盖 |
| 重复性 | 每个工况重复small/medium/range，保存所有记录，不只保留最好一次 | 每次均满足设定指标；建议至少3次作为本项目初始对照，不代表寿命验收 |
| 使能/停止与超时 | 使用已验证流程核对STOP、心跳和驱动关闭；无保护旁路 | 模式/输出状态正确，失败时保留现场；当前脚本每次验证正常退出停机 |
| 实时性 | Keil 主工程构建，需要时示波器检查 | 无编译错误；中断总成本及PWM时序单独验收 |
