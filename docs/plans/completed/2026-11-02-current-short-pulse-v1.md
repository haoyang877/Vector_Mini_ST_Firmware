# 低电流短脉冲阶跃与角度速度复核 v1

用户已授权按方案1执行0.1、0.2、0.3A短脉冲，复用现有接口并保持保护限值。
硬件沿用AT32F456＋YQ-5708（8:1），本体固定、输出轴自由；不重复0.75A工况。

## 范围和不变量

- 使用已实测1193.9Hz的镜像，d/q Kp=0.60995855、Ki=3226.22067，控制20kHz。
- 不改固件、PI、标定或协议。开始前及结束后核对镜像、实际PI、完整LUT和参数区。
- 沿用相电流3A、电机速度5rad/s、累计行程1rad、500ms租约；运行时间仍受板端限时监护。
- 每次10ms零参考准备后，Id从0跳到目标，保持10ms后关相。每次运行前核对静止与身份。
- 使用原OP_CAPTURE、OP_RUN、OP_READ、OP_SNAPSHOT及108查询。

## 顺序与采集

1. 关相采集原始角度、电角度和零电流噪声，核对已保存的零位、方向、极对数、LUT映射。
2. 每档0.1、0.2、0.3A分别采集3次dq阶跃，阶跃边沿触发、32点预触发、128点、stride=1。
   20kHz对应1.6ms预触发和约4.8ms阶跃后窗口。
3. 每档另做1次相同10ms脉冲，用已有speed组同步采集机械角、机械角速度和Iq。
   不把分次采集的dq与角度/速度曲线拼成一次同步采样。108用于每次运行前后静止与连续性复核。
4. 总计12次短脉冲；任一次设备保护、故障、身份/标定改变、测量不连续或未关相，停止后续脉冲。

## 判定

- 保留既有阶跃建议指标：10%～90%上升≤1ms、稳定≤3ms、超调≤10%、交叉电流≤0.15A。
  稳定带沿用max(2%阶跃幅值, 0.03A)，持续覆盖至少1ms。
- 所有原始指标与未达到的条目都显示。小电流下单点峰值可能受约8mA采样噪声影响，
  不用平滑结果替代原始验收，不因性能指标单独未通过而推断失稳；没有安全异常时完成其余低电流档。
- 同步角度/速度以Δ机械角和速度积分交叉核对；位置2kHz、速度20kHz，允许0.5ms位置更新延迟。
  差异参考界限为3个编码器计数加最大速度×4ms，包含90Hz PLL跟踪差及位置更新延迟。
  若运动不足，明确仅验证静止一致性，
  不宣称已校准绝对角度精度或速度比例。额外保留108查询的毫弧度量化限制。
- 本轮不验证0.75A稳态、Iq带载或长期稳定性，不修改此前失败记录。

## 证据和回退

输出：`outputs/current-short-pulses-20261102/`。复用上一轮相同镜像的PR/release证据，
本轮核对产物哈希；脚本自检和文档quick另行执行。若发现当前镜像不符，停止并报告，不自动烧录。
无固件或参数修改需要回退；结束必须关相、故障0并复核原标定。

## 执行结果

12次短脉冲全部正常结束，没有保护截止；9组dq和3组同步机械角/速度均取得128点连续记录。
关相角度变换检查通过，开始和结束的镜像、PI、标定及参数区一致。
0.3A三次阶跃通过既有建议指标；0.1A三次未过，0.2A两次未过、一次稳定窗口不足。
已完成指定工况，不将执行完成表述为所有性能达标；不据此推断0.75A问题解决。
