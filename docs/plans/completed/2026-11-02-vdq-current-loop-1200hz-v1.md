# Vd/Vq反馈与1.2kHz电流环实测 v1

已完成实施与本轮受限实测，见[结果报告](../../reports/2026-11/current_loop_1200hz_20261102.md)。
Vd/Vq、13个稳态/噪声窗口和6次Id阶跃通过；Iq第二次速度截止，剩余取消，不作为全项验收通过。

用户明确要求修复Vd/Vq反馈，将电流环目标带宽提高到1.2kHz并实测，保持最简单实现。
沿用现有FOC、参数装载、108/124和台架采集，不增加模块、控制接口或滤波器。

## 实现

- 在FOC完成阶段记录矢量限幅后的d/q命令电压，复用同一值进行原有PI输出跟踪；复位时清零。
- 电压是基于调制比和母线电压的估计，不是独立相电压传感器实测。
- 固定目标带宽由1kHz改为1.2kHz；参数装载按活动R/L重新生成四个电流环增益，
  避免Flash中旧1kHz增益覆盖新目标。保存布局、标定、外环参数与电流/速度保护不变。
- 保留原FOC/PWM算术与执行顺序，更新等价测试中有意改变的诊断值，并验证电压限幅与复位。

## 验证

1. 保存原镜像、当前Flash与RAM配置/标定。离线验证控制输出等价、已保存参数装载、实时状态编码。
2. 执行PR、双板应用构建及冻结源码release；新镜像烧录后逐字节回读，参数Flash不变。
3. 读取实际PI，确认Kp约1.074425、Ki约4146.903，采样周期仍50μs；标定恢复并核对。
4. 先关相与零电流，再Id 0.3A/0.75A稳态及阶跃。沿用3A相电流上限；
  附加5rad/s、1rad行程、500ms租约和短时限，保留旧1kHz实测作为对照。
5. 验证Vd/Vq随命令改变、与限幅后调制一致、108/124和台架数据均有效；
  不将超调或噪声超限当成带宽提升成功。
6. Iq仅允许0.3A/≤5ms空载短脉冲；每次确认停稳。鉴于原1kHz第三次触发限速，
  任一异常立即停止后续励磁，不提高截止门限或自动清错重试。

阶跃建议指标保持上升≤1ms、稳定≤3ms、超调≤10%；稳态dq误差/RMS≤60mA、峰峰值≤300mA。
报告给出相同工况前后对比和一阶阶跃等效带宽，未扫频不声称真实−3dB频响已测得。
结束确认关相、故障与标定一致，说明1.2kHz是否通过已测范围。

## 证据与回退

需要回退时用已备份1kHz镜像，恢复原活动配置和标定，不覆盖此前原始记录。
