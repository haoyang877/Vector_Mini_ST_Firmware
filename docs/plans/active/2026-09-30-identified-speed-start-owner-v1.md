# 有身份的速度启动所有者接入 v1

基线：`83f39c60113f5db6341f0d258f23bdc971d41cee`。本批只实现 APP 领域入口，不注册候选 Type117，不下载固件。

## 目的与不变项

正式线路需要以来源、序号明确申请速度模式零目标启动。现有 `MotorStateMachine_RequestEnable` 已拥有准入和监督拍启相流程，本批只在同一运行所有者内绑定身份、重试结果与 STOP 序号屏障。保留 101 的低侧制动候选语义、116 仅运行中同模式更新，以及全部控制数学、保护阈值、时基、参数布局、Loader 边界和硬件配置。

## 契约与顺序

- 首批只受理内部 `MOTOR_CONTROL_SPEED`，进入速度模式时目标为 0 rad/s。受理进展为 PENDING；只有监督拍达到 RUNNING、模式仍匹配且数字输出已开启才记 STARTED。STARTED 是原身份历史事实，不代表当前仍运行或转子运动。
- 同来源、序号、模式的重试返回原结果，不再调用启相；同序号不同模式拒绝冲突。拒绝的有效新请求也消耗序号；活动请求不被后续 BUSY 请求覆盖。最近请求和活动请求各保留一条，淘汰后旧序号按半范围窗口拒绝。
- STOP、失能、故障撤销未启动身份。带来源/序号 STOP 即使是旧序号也执行原安全停止路径；只有新的同源序号推进屏障，防止旧 START 迟到后启相。普通本地 STOP 仍沿原入口，不伪造线上序号。
- 本记录是易失的单远程来源状态。复位后无法单凭 16 位序号阻止跨复位重放；Type117 定版前需单独裁决这一边界。不同来源的启动拒绝，STOP 无论来源仍执行。

## 验收、证据与回退

运行既有真实所有者原生夹具，增加重复/冲突/BUSY/STOP 屏障/故障进展断言；运行格式、lint 和固件 PR 验证。只读核对 117 组合层尚未接线，未开放线上功率路由。集成后由 ROOT 审查窄差异及 H 的实际 STOP 源序号透传，再交测试会话按授权流程另行冻结候选。可独立 revert 本提交；无需参数迁移。
