# Mode 3 测试用例与执行入口

当前电机已命名roll；roll/pitch持久化范围、带轴身份核验的台架入口和连接状态见 [轴配置记录](motor_axis_profiles.md)。后端源文件随本次提交纳入，所需DLL、Python依赖、匹配镜像及会话符号文件仍由本地环境提供。

本套测试分主机软件回归、实机动作及采集验收。主机回归和历史数据分析不打开J-Link、不下载固件、不使能电机。参数含义见 [核心参数说明](mode3_parameter_guide.md)。

## 1. 一键执行主机回归

依赖Python 3.10+和C99编译器（Zig、GCC或Clang）。默认不需要NumPy、Keil或J-Link；只有旧数据重放功能需要NumPy。在仓库根目录执行：

```powershell
python tools/run_mode3_validation.py host --cc 'C:/path/to/zig.exe'
```

也可将编译器路径放入环境变量 `SERVO_CC`，或将编译器加入PATH后省略 `--cc`。每次在 `outputs/mode3_validation/host_<时间>/` 新建目录，保留 `result.json`、Git版本/工作区状态、核心文件哈希及每步日志。目录已存在会拒绝覆盖。退出码0为通过，非0为失败；这不是实机验收。

只运行原生C回归：

```powershell
python tools/run_position_servo_tests.py --cc 'C:/path/to/zig.exe' --out outputs/mode3_native
```

| 编号 | 主机用例 | 覆盖/判据 |
| --- | --- | --- |
| U01 | 非法参数、NaN/Inf、无效输出指针、配置变更 | 拒绝无效配置；有效配置可继续，填充字节不误触发重校验 |
| U02 | 连续低速反馈、实际编码器估算器 | 正反向低速、复位、旧接口兼容；不以滤波零速代替真实静止 |
| U03 | 保持噪声、支撑力、外扰、窗口迟滞 | HOLD保留支撑电流，越界退出；先捕获与从未捕获的行为不同 |
| U04 | 制动、着陆、提前到位、摩擦卸载及恢复 | 无补偿断档、软捕获卸载、越过目标快速卸载、受阻后恢复 |
| U05 | 反转、总电流限幅及积分 | 保留必要负载积分，错误方向积分卸载，限幅与抗饱和 |
| U06 | 静止纠偏、关闭治理/纠偏选项 | 确认静止后有界积累，运动/换目标/饱和/复位处理 |
| U07 | 5/20/85°轨迹、运动中改目标、连续目标流 | 参考限制、制动、q/v/a接续、规划不饥饿 |
| U08 | 独立五次速度轨迹 | 极短/短/长行程、双方向、巡航、q/v/a/jerk段间连续、速度积分等于位移、静止终点 |
| U09 | 20 kHz调用 / 2 kHz控制分频 | 状态与遥测节奏，无重复执行控制 |

## 2. 生成实机动作表

```powershell
python tools/run_mode3_validation.py plan --profile tests/mode3/bench_20260908.json
```

生成 `plan.md`、`plan.json`、冻结的 `profile.json`；同时计算有效减速度、jerk限值和实际电流域速度PI系数。**生成动作表不会运动，也不会应用JSON参数。** 改用新电机时复制模板填写，不要修改历史基准配置。

动作按“允许区间减去两端留量”生成，以区间中点为中心。半径R下，小角度为 `min(5°, R/4)`，中角度为 `min(20°, R/2)`，全行程在两端测试点往返。无需机械照搬±85°，也支持不以0°为中心的区间。

| 用例 | 当前台架目标/° | 每点时间 | 验证重点 |
| --- | --- | --- | --- |
| hold | 0 | 10 s | 使能后的静止保持、支撑电流、噪声 |
| micro | 0、+0.09、−0.09、0 | 8 s | 窗口内指令；允许保持不动，验收误差而非强制微动 |
| small | +5、0、−5、0 | 6 s | 小行程启停、正反向重复性 |
| medium | +20、0、−20、+20、0 | 7 s | 停止抖动对比、反转、捕获 |
| range | +85、−85、0、+5、−5、0 | 10 s | 最大行程、170°跨区运动、长短行程混合 |

不同速度、范围或阻力可能需要更长等待时间。应确保轨迹时间、实际收敛时间和末2 s验收窗口均被覆盖；不能通过缩短采集尾段来掩盖迟迟未到位。

## 3. 当前台架直接执行

只有配置与当前已验证台架的电机标识、运动限制、运行参数和核心配置一致时，生成器才提供 `run_bench.ps1`。从生成目录中逐项执行，例如：

```powershell
# 替换为刚才生成的实际目录；执行此脚本会使电机运动。
& 'outputs/mode3_validation/plan_<时间>/run_bench.ps1' -Case small
& 'outputs/mode3_validation/plan_<时间>/run_bench.ps1' -Case medium
& 'outputs/mode3_validation/plan_<时间>/run_bench.ps1' -Case range
```

每次只执行一个用例，调用既有 `servo_hil_run.py --keep-parameters`，试验名称唯一。成功停机后自动执行数据验收；任一步失败返回非0，先检查失败记录和停机状态，再继续。脚本不烧写固件、不保存Flash，也不主动修改RAM增益；后端会核对位置/速度增益及巡航速度。电流上限、加减速度、编译宏、摩擦模型仍需核对实际板卡，不能只相信JSON。

**台架依赖边界：** 现有后端 `tools/servo_hil_run.py`、`servo_hil_emergency.py` 随本次源码提交提供，当前实现绑定STM32G431CB、J-Link序号602722271、SEGGER V9.64 DLL及 `outputs/servo_hil_20260908/` 会话目录。其中需要匹配已装载HIL固件的 `symbols.json`、`member_offsets.json`、`active_image.json` 和本地pylink依赖。依赖及会话文件不随源码分发；全新checkout需先配置匹配的台架环境，不能只凭源码直接驱动电机。缺少后端时生成脚本会明确报错，不能伪称实机验证通过。

现有HIL板端目标/保护边界为±85°/±90°，主机位置停止阈值±88°，速度停止阈值主机85°/s、板端90°/s，主机采样Iq停止阈值4 A，心跳500 ms。改变机械可动范围或更换电机后必须适配主机和板端保护，不能仅修改JSON就认为保护已更新。因此非当前台架配置只生成动作表；可在对应设备已验证的控制入口执行这些目标，再接入相同数据验收。

测试前核对电机编码器零点、实际装配与行程、停止状态、已装载HIL镜像及参数版本；关闭其他RTT消费者。当前台架NTC未装配，试验不包含热保护验收。当前schema10工作区镜像与提交的schema9镜像不同，本测试入口不负责跨版本参数迁移。

## 4. 统一采集验收

直接分析既有记录，不连接硬件：

```powershell
python tools/run_mode3_validation.py analyze --trial outputs/servo_hil_20260908/trial58_c3_range --case range
python tools/run_mode3_validation.py analyze --trial outputs/servo_hil_20260908/trial57_c3_twenty --case medium
```

输入目录须有 `trial.json` 和12通道int16的 `capture.tsv`。`--case`校验对应配置的目标序列和每点最短等待时间；分析其他历史序列时可省略，但仍核对记录的目标命令是否完整且位于配置范围内。输出 `mode3_acceptance.json`，失败返回1，配置或记录格式错误返回2。

| 验收项 | 当前基准 |
| --- | --- |
| 执行状态 | 无试验错误，目标命令被接受，镜像标识存在，最终停机已确认 |
| 运行参数 | 记录的模式3位置Kp/Kd、速度Kp/Ki及巡航速度与所选配置一致；其他参数仍需实机核对 |
| 数据完整性 | 各动作遥测均有效，完整采集等待期和末2 s；不得用无效尾段计算通过 |
| 末段最大绝对误差 | ≤0.3°，电机端；不是全过程动态误差要求 |
| 末段HOLD比例 | 100% |
| 实际Iq记录峰值 | <4 A |
| 丢帧 / 限流标志 | 0 / 0 |
| 诊断输出 | 超调、末段位置峰峰值、各动作电流、原始镜像和运行参数 |
| 结构抖动 | 单独人工/振动测量；自动结果固定标记 `NOT_EVALUATED` |

RTT时间由主机接收frame锚点插值，存在批处理延迟；不能用于证明精确控制时序。镜像标识和停机结果来自采集元数据，离线工具不会重新核验Flash或当前电机状态。通过表示采集窗口内的自动指标合格，不表示热性能、最坏实时性、整体可靠性或机械手感通过。

## 5. 需要额外执行的验收

| 用例 | 操作与记录 | 通过依据 |
| --- | --- | --- |
| 负载/摩擦变化 | 为每种装配分别记录参数、重新辨识或核对模型，运行small/medium/range | 全部自动指标及人工抖动评价，不能用一个负载结果代替其他负载 |
| HOLD外扰 | 仅在已有夹具与操作条件允许时施加可控扰动，记录偏移和恢复 | 保持退出与恢复符合定义、无持续振荡；外力大小不得由脚本猜测 |
| 运动中改目标 | 通过已验证入口在加速、巡航、减速时改变目标，记录q/v/a与Iq | 无非法跳变/超限，终点保持合格；主机已有接续测试，实机不由上述定点脚本自动覆盖 |
| 重复性 | 每个工况重复small/medium/range，保存所有记录，不只保留最好一次 | 每次均满足设定指标；建议至少3次作为本项目初始对照，不代表寿命验收 |
| 使能/停止与超时 | 使用已验证流程核对STOP、心跳和驱动关闭；无保护旁路 | 模式/输出状态正确，失败时保留现场；当前脚本每次验证正常退出停机 |
| 实时性 | 正常/HIL工程构建，DWT记录及需要时示波器检查 | 无编译错误；中断总成本及PWM时序单独验收 |
