# FOC输出角度按1.5Ts补偿 v1

用户要求按1.5Ts进行角度补偿，并在完成后提交一次。本项只改变原有输出角度预测系数。

## 实现范围

- 共用Foc_Prepare逆Park角度改为`phase + phase_vel * (1.5f * FOC_TS_S)`。
- 当前20kHz对应75μs预测；这是用户选定的补偿时间，不是新的硬件延迟实测结果。
- 电流Park变换仍使用本拍phase；PI增益、采样/PWM频率、限幅、保护和记录布局不变。
- 编码器、无感、纯电压及开环输出复用共用入口；不另建接口或可调参数。
- 开环状态每拍仍推进1Ts，避免把输出预测系数误用于速度积分。
- 之前1Ts镜像的扫频及短脉冲结果保留，不能作为本版硬件验收。

## 验证与提交

1. 保存改动前源码；冻结历史对照只投影这次1Ts→1.5Ts的明确行为差异。
2. 原生FOC对照覆盖正负电角速度、三种入口、PI/限幅和PWM顺序；反向修改预测系数应使测试失败。
3. 全仓PR与AT32普通、AT32台架、STM32普通目标构建；不自动下载或启相。
4. 仅暂存本项生产改动、对应测试和说明；保留工作区其他重构与测试改动。

证据目录：`outputs/foc-phase-advance-1p5ts-20261102/`。
回退方式：共用逆Park预测恢复1Ts，同时恢复对应测试期望；不改参数Flash。
