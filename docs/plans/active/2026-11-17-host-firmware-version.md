# 本批固件版本自动读取

## 目标与基线

上位机 v2.1.6 的首次烧录页写死 APP/Loader 版本，导致随包固件更新后仍显示旧值。
本次改为从当前选择的 HEX 描述符读取 APP 版本，并读取与该 HEX 哈希匹配的批次
清单中的 Loader 版本；不从文件名猜测，也不把目标配置中的计划版本当作镜像版本。
文件不存在、损坏或不属于当前批次时清除旧版本，显示未确认及原因。

## 不变行为与实施

保留固件 v1.8.25、Loader v2.3.4 的加载字节、参数、烧录准入与硬件行为。
复用 five_axis_jlink 的 HEX 范围和哈希校验，界面初始化、选择 HEX 后刷新版本。
上位机递增为 v2.1.7，打包入口可显式指定冻结批次清单。
不新增后台轮询、硬件访问、设备命令或通用解析框架。

## 验收与回退

离线覆盖版本与文件名不同、版本切换、缺失/损坏、哈希或版本元数据不匹配。
执行现有 Qt 页面和软件回归，重新构建 EXE；打包后运行五页离线自检并核对版本文案。
比对内外置 CAN、FULL、目标清单与冻结固件，生成新 ZIP 和 SHA-256。
回退使用原 v2.1.6 整包；不执行实机下载或运动。
