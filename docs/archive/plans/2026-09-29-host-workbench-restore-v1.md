# YG_MC_HOST 基础工作区恢复 v1

日期：2026-09-29；分支 codex/system-refactor；基线 4dac4196。

上一批把新增维护页面作为完整程序入口，遗漏原设计的连接与调试工作区。
本批恢复连接页、首页、调试工作台、参数、标定、辨识、记录诊断和设备维护导航；
维护页继续使用已经交付的真实镜像校验、冻结任务导出及三种升级模式。

依据用户引用的《电机驱动上位机设计》v0.3 和既有主机工程的工作台实现核对：

## 范围与分层

- GUI 负责页面组合、绘图及文件选择，不产生报文或设备句柄。
- 演示会话服务持有连接、运动、遥测、记录和任务状态；参数仍由现有参数服务持有。
- 复用既有 ScopeWidget 绘图方式，移除历史协议/profile 依赖；不复制旧 RAW11/YI 协议。
- 本批恢复明确标记的演示交互。CAN/SWD 仍待当前公司协议的设备适配，RS-485 无真实入口。
- 首页未提供的硬件/软件/Loader 版本、SN 等保持未知；不把节点号填作电机 ID。
- 标定/辨识演示进度与候选结果明确标记来源；取消不得变成完成，导出不代表设备保存。
