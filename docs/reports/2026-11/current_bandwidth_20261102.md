# 电流阶跃等效带宽实测 2026-11-02

本文为较早的大阶跃折算记录。后续实际频响见[D轴正弦扫频](d_axis_sweep_20261102.md)，不能把两种测量定义混用。

保持原1kHz整定参数，对当前固件补测Id阶跃和Iq短脉冲。结果说明：1kHz是整定值，
不能直接作为实际闭环带宽；本次得到的是幅值相关的大信号阶跃等效值，真实−3dB频响未扫频验证。
未提高PI增益、未改固件、未烧录或写Flash。

## 测量与结果

AT32F456＋YQ-5708（8:1），节点1，采样20kHz、每点50μs，32点预触发、96点后触发。
当前Kp=0.895354、Ki=3455.752，电零位18681；母线与原标定保持原状态。
阶跃通过原台架RUN施加，实际关相后读取冻结数据，不用主机CAN间隔估算上升时间。

| 工况 | 正常完成的次数 | 网格10%–90%上升时间 | 插值上升时间 | 一阶阶跃等效带宽 |
| --- | ---: | ---: | ---: | ---: |
| Id 0→0.3A，Iq=0 | 3 | 0.85～0.95ms | 0.865～0.939ms | 372～404Hz |
| Id 0→0.75A，Iq=0 | 3 | 0.55～0.60ms | 0.546～0.595ms | 587～640Hz |
| Iq 0→0.3A，5ms | 2 | 0.80～1.00ms | 0.780～0.983ms | 356～448Hz |

计算为`f_eq = ln(9)/(2π·t10–90)`，只在一阶近似下成立。插值没有把真实时间分辨率提高到50μs以上。
使用原始电流、阶跃前均值和实际参考变化计算；没有平滑曲线或以最终峰值归一化来提高结果。
Id小幅与较大幅阶跃结果明显不同，提示需要检查小信号非线性、实际R/L与采样/PWM延迟，不能直接套用单一带宽。

## Iq限制与停止

第二次Iq脉冲稳定时间为3.2ms，超过原建议3ms。第三次触发本轮额外收紧的5rad/s速度监护，
结束原因为2；该次即使已经采到128点，也没有纳入等效带宽统计。
故障码保持0，测试结束已确认数字关相，LUT与电零位未变，未继续更高电流或更高增益测试。
空载Iq脉冲伴随转动，不能代替固定转子条件下的q轴频响。

## 能否提高

可以开展受限的提升试验，但现阶段没有证据保证更高带宽稳定。建议顺序为：

1. 核对实际电机R/L及小信号非线性，明确ADC到PWM生效的延迟。
2. 修复电压观测后确认调制/电压余量，排查Iq脉冲的速度异常，再进行固定工况的小信号扫频。
3. 以1.2kHz作为首个候选整定点，Kp约1.0744、Ki约4146.9，复测阶跃、噪声和稳定裕度；
   通过后再评估1.5kHz。候选参数本轮没有应用，不能保证实测等效带宽按比例提高。

提高电流环带宽需要同时控制超调、噪声和稳定性；采样到输出的延迟在高带宽时不可忽略。
[Microchip电流环调参说明](https://microchiptech.github.io/mcaf-doc/9.0.2/algorithms/foc/tuning.html)
给出了这些约束和阶跃评估方法；其典型频率范围不是本板的实测能力保证。

### 新发现的电压观测缺口

本次代码复核发现`FocState.voltage_dq_v`在当前生产路径没有更新，采集的Vd/Vq一直为0。
该值不能用于证明“无饱和”或计算电压余量。真实电流反馈和参考路径不受这一显示缺口影响，
本次只用它们估算阶跃响应。原108/124接口的电压有效位不能据此当成有效实测电压，待修复。
