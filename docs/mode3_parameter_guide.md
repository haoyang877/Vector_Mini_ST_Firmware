# Mode 3 参数与工况适配

roll/pitch名称、角度范围与最大巡航速度现可通过AXS1参数扩展持久化，见 [轴配置与Flash读回](motor_axis_profiles.md)。JSON仍是测试/准备输入，本身不写入固件。

本说明对应 `Position_Mode=3` 的串级位置/速度反馈、连续加速度轨迹、摩擦前馈和HOLD保持。参数表中的数值是2026-09-08直驱台架整定值，不是不同电机的通用默认值。优化历史见 [过程报告](mode3_optimization_20260908.md)，执行验证见 [测试用例与入口](mode3_test_plan.md)。

## 参数存放与修改位置

| 类别 | 位置 | 生效方式 |
| --- | --- | --- |
| 电机、运行限制、速度PI及模式3位置增益 | `MotorControl`，保存/恢复见 [foc_param.c](../Foc/foc_param.c) | 通过现有参数接口设置；RAM生效不等于已保存Flash |
| 模式3轨迹、捕获、滤波、摩擦整形 | [position_cascade_config.h](../Foc/position_cascade_config.h) | 修改后重新编译；当前没有覆盖全部宏的运行时参数协议 |
| 实际装配机构摩擦模型 | `friction_model_valid` 和正反向库仑/粘性参数 | 有效模型优先；以读回值确认，不能仅根据存在保存文件判断有效 |
| 编码器、电流采样、电机极对数等 | 既有电机/硬件配置与标定 | 换电机先确认；不是位置环整定参数 |
| 台架动作范围和验收标准 | [bench_20260908.json](../tests/mode3/bench_20260908.json) | 供测试计划及数据验收使用，**不会自动写入固件参数** |

现有架构例外：模式3在摩擦模型无效时仍引用 `position_impedance_config.h` 的备用摩擦电流，并由 `hw_conf.h` 的阻尼环选项选择。这使修改备用值可能同时影响mode18。本次没有增加此依赖，也未改动控制器；为不同电机适配时优先使用有效辨识模型，后续拆分备用配置应单独评审。不要把新增PID参数继续放入BSP。

## 优先核对的运行参数

固件控制接口使用rad、rad/s、rad/s²，参数预设部分使用rev/s、rev/s²。换算：`rad = deg × π/180`，`rad/s = rev/s × 2π`，`巡航deg/s = 360 / 每圈秒数`。

| 参数 | 单位 / 台架值 | 作用与调整关联 |
| --- | --- | --- |
| `current_limit` | A / 6 | 总Iq限幅与抗饱和约束；来自电机、驱动和热能力，不能为消除误差任意增大 |
| `speed_limit` | rad/s / 按实际读回 | 电机运行速度上限；必须不小于轨迹巡航速度，不能与巡航速度混为一谈 |
| `pos_maxspeed` | rad/s / 0.785398，即45°/s | 最大巡航速度；短行程会自动降低峰值，8 s/rev不是每次动作都跑满速度 |
| `posAcc` | rad/s² / 0.785398，即45°/s² | 轨迹加速度上限；高惯量或启动抖动时先结合可用力矩和数据核对 |
| `posDec` | rad/s² / 保存值0.785398 | 模式3有效值还受30°/s²编译上限限制。只把posDec从45改到60不会增加实际减速度 |
| `cascade_pos_Kp` | 1/s / 8 | 位置误差到速度修正；固件校验0～50，合法范围不代表稳定范围 |
| `cascade_pos_Kd` | 无量纲 / 2 | 参考速度与实际速度差的修正；固件校验0～10；加大也会放大测速噪声影响 |
| `speed_Kp` | 既有归一化参数 / 0.5 | 内层速度比例增益，实际电流域系数为 `speed_Kp × current_limit` |
| `speed_Ki` | 既有归一化参数 / 1 | 内层速度积分增益，实际电流域系数为 `speed_Ki × current_limit` |
| `pos_error_window` | rad / 0.001，约0.0573° | 在 `foc_task.c` 初始化；原在线轨迹的结束容差，不等于定位精度或HOLD窗口，也不在当前Flash参数结构中 |

模式3使用的是 `cascade_pos_Kp/Kd`。`pos_Kp/pos_Kd/pos_Ki/pos_integral_limit` 属于另一位置控制路径，不能拿它们当作模式3的三环PID调节项。模式3静止纠偏复用速度PI积分，没有独立的位置Ki。

**换电流上限会同时改变速度PI增益。** 例如原限流6 A、速度参数0.5/1，对应电流域比例3、积分6；改成3 A并保留参数时，两项系数都减半。若目的是只改变限流，应先评估是否需要保持电流域增益，再根据新电机重新整定，不能机械照搬历史参数。

速度修正指令上限为 `min(speed_limit, 1.5 × pos_maxspeed)`，台架轨迹巡航45°/s时，可有至67.5°/s的有限追赶指令。它不是提高轨迹巡航速度，也不是机械超速保护阈值。

## 轨迹与到位保持参数

以下宏均位于 `position_cascade_config.h`，前缀为 `POSITION_SERVO_`。

| 宏后缀 | 当前值 | 含义与适配注意点 |
| --- | --- | --- |
| `DECELERATION_MAX_RAD_S2` | 0.523598776，30°/s² | 模式3减速上限；与更小的posDec取小值 |
| `JERK_RAMP_TIME_S` | 0.20 s | `J=max(A,D)/T`，台架225°/s³；增大T降低jerk。改变加速度也会改变jerk上限，即使减速上限未变 |
| `ACCEL_RAMP_TIME_S` | 0.10 s | 原在线轨迹的速度误差响应时间；不是新五次速度曲线的固定加速时长 |
| `ACCEL_FF_GAIN_A_PER_RAD_S2` | 0 | 加速度电流前馈Ka；完整负载J/Kt未确定时保持0 |
| `VELOCITY_FILTER_HZ` | 40 Hz | 模式3连续测速后的低通；滤波越低，反馈延迟通常越大，不能只看噪声下降 |
| `SPEED_CORRECTION_HEADROOM_RATIO` | 1.5 | 有限追赶速度空间，仍受speed_limit约束 |
| `FOLLOWING_ERROR_LIMIT_RAD` | 0，关闭 | 软参考治理范围，不是跟随误差故障上限；开启后使用在线规划路径 |
| `HOLD_ENTER_POSITION_RAD` | 0.003141593，0.18° | 到位捕获距离 |
| `HOLD_EXIT_POSITION_RAD` | 0.004537856，0.26° | 保持退出距离；应大于进入距离，并给±0.3°验收留余量 |
| `HOLD_ENTER_SPEED_RAD_S` / `HOLD_EXIT_SPEED_RAD_S` | 0.03 / 0.08 | 保持进入/退出速度门槛 |
| `HOLD_CONFIRM_TIME_S` | 0.05 s | 捕获后的保持确认时间 |

静止点到点路径使用五次速度曲线，q/v/a/jerk在段间连续。运动中改目标或改变限值时转原在线限jerk路径，保留q/v/a，但不承诺切换处jerk连续。详细公式见 [连续加速度轨迹](mode3_acceleration_continuity_20260908.md)。

小行程不是大行程的简单缩放：目标变化小于保持窗口时允许继续HOLD，不应验收“每次必然运动”。如果应用要求0.05°指令也必须分辨执行，则需要重新定义精度、噪声、保持窗口及编码器能力，不能沿用±0.3°验收。扩大行程则应增加动作等待时间，并检查正反向负载是否随角度变化。

## 摩擦与负载参数

| 参数 | 当前来源 / 数值 | 作用 |
| --- | --- | --- |
| `friction_coulomb_pos_a/neg_a` | 辨识/读回，A | 正反向库仑摩擦电流，均存非负幅值，方向由控制器选择 |
| `friction_viscous_pos_a_per_rad_s/neg_a_per_rad_s` | 辨识/读回，A/(rad/s) | 随参考速度增加的摩擦电流；不要把阻力随角度变化误认为粘性摩擦 |
| 备用正/反向电流 | 有阻尼环配置1.55/1.50 A，无阻尼环配置0/0 A | 只在模型无效时使用；是旧台架值，不是新电机的已知摩擦 |
| `FRICTION_BREAKAWAY_RATIO` | 1.20 | 静止启动增强比例，非新的总电流上限 |
| `FRICTION_STUCK_TIME_S` | 0.05 s | 静止确认时间 |
| `FRICTION_BREAKAWAY_DISTANCE_RAD` | 0.003 rad，约0.172° | 确认已实际启动的位移门槛 |
| `FRICTION_REFERENCE_SPEED_RAD_S` | 0.03 | 参考运动方向判断门槛 |
| `FRICTION_STOP_SPEED_RAD_S` / `FRICTION_MOVE_SPEED_RAD_S` | 0.02 / 0.05 | 静止/移动判断，需与连续测速噪声相容 |
| `FRICTION_ATTACK_SLEW_A_PER_S` | 200 A/s | 前馈建立斜率 |
| `FRICTION_FAST_RELEASE_SLEW_A_PER_S` | 200 A/s | 越过目标和换向等快速卸载 |
| `FRICTION_CAPTURE_RELEASE_SLEW_A_PER_S` | 30 A/s | 捕获及目标前窗口内卸载上限；过慢可能增加超调 |
| `FRICTION_RELEASE_SLEW_A_PER_S` | 15 A/s | 普通摩擦卸载斜率；不是所有情况下都用此值 |
| `FRICTION_LANDING_ZERO_RATIO` | 0.5 | 未锁存捕获时，从进入窗口到其一半距离衰减；台架对应0.18°～0.09° |
| `STICTION_INTEGRAL_RATE_A_PER_S` | 0.30 A/s | 确认残余静止误差后的额外速度PI积累；0可关闭，仍受总Iq约束 |
| `INTEGRAL_OPPOSING_DECAY_RATE_PER_S` / `INTEGRAL_OPPOSING_MAX_SLEW_A_PER_S` | 10 / 5 | 目标切换时，与位置和速度纠偏均相反的积分卸载 |
| `INTEGRAL_ZERO_THRESHOLD_A` | 0.001 A | 积分接近零判据 |

摩擦模型 `Ic + B × |速度|` 不能完整表达齿槽转矩、偏心、重力负载或结构共振。HOLD保留支撑电流；不要为了让停机电流看起来小而无条件清空它。

## 针对工况的整定顺序

以下顺序基于本项目已实现的控制器及历史试验，用于组织验证；每次只改变一个参数组，并记录前后数据。

| 工况/现象 | 先核对 | 再验证的参数组 | 主要观察量 |
| --- | --- | --- | --- |
| 更换电机 | 极对数、编码器方向/标定、电流采样、电流环、额定限制 | 电流域速度PI、位置Kp/Kd，最后摩擦与轨迹 | 实际Iq跟踪、速度、饱和、故障 |
| 大惯量，启动/停止带动结构 | 力矩余量、实际Iq与参考、机械响应 | A/D、jerk过渡，再检查前馈卸载 | 到位时间、超调、Iq变化、结构体感 |
| 高静摩擦，停在目标外 | 模型是否有效、正反向Ic、积分或总Iq是否饱和 | 启动确认/增强、静止纠偏，再核对着陆窗口 | FF、速度PI、残余误差、脱困时刻 |
| 低摩擦，来回抖动 | 旧1.55/1.50 A备用值是否被误用 | 正确摩擦模型、速度PI、位置增益/测速噪声 | 正反向Iq、HOLD退出次数 |
| 小角度/频繁改目标 | 指令幅度相对保持窗口、动态目标是否触发在线路径 | 窗口与实际精度要求、动态改目标测试 | 微动能否分辨、q/v/a切换连续性 |
| 扩大角度/长行程 | 软件及实际行程边界、各角度负载、足够等待时间 | 速度、A/D、长行程摩擦模型适用性 | 两方向保持误差、超调、限流、末段低速收敛 |

本轮实测说明：减速度45→30°/s²及捕获卸载200→30 A/s均有改善，但未消除抖动；Kd降到1.5、jerk过渡缩到0.15 s未保留。五次速度轨迹改善手感，同时增加运动时间。这些结果不能推导出“所有电机都应继续减慢减速”。

## 新工况记录方式

复制 [新电机模板](../tests/mode3/new_motor.template.json)，填写电机标识、实际可用角度、目标留量、运行参数和验收电流阈值。未知J/Kt及摩擦值保留null；测试计划需要的运动与增益字段必须有依据地填全。`core`是待核对的编译配置快照，修改JSON不会修改头文件。实际 `speed_limit`、编译宏、有效摩擦模型和固件schema仍需读回/构建核验。

每份实机记录还应注明负载装配、方向、温度/NTC状态、固件镜像哈希、Flash参数版本及是否保存参数。当前板卡的schema10工作区固件与已提交schema9固件不同；不要直接把旧参数区当成新固件参数结构使用。
