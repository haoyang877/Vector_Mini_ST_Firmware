# 统一正余弦查表验证（2026-09-28）

本轮按用户要求，将 APP 的正弦和余弦统一到 `Math_SinCos`；没有烧录、访问探针
或发送电机命令。基准 ce31fc60，执行计划见
[统一查表 v1](../../archive/plans/2026-09-28-unified-trig-v1.md)。

## 实现及数值变化

- 257 点四分之一周期表，Flash 1028 B（原半表 2048 B）；象限对称共享一张表。
- 正弦、余弦及 Hermite 端点导数都来自这张表；一次归一化和一组插值权重得到一对值。
  三次插值避免线性插值的弦长误差在反复坐标旋转时累积；无独立三角函数展开或回退。
- Park/逆 Park、启动交接电流参考、PI 积分状态旋转全部调用统一入口；删除
  fast_sin/fast_cos、LUT_MULT、Sensorless_SmallAngleSinCos 及固件 sinf/cosf 调用。
- 取绝对值后插值、最后恢复正弦符号，避免负小角归一化加 2π 后丢失精度。
  非有限输入输出 NaN；有限多圈输入使用 fmodf，控制输入仍应保持单圈。
- 标准库 sinf.o、cosf.o、rredf.o 已退出最终普通和诊断链接；增加 fmodf 及其依赖，
  净收益按整包测量。平方根和反正切没有改变。
- 原表 1023 采样间隔与索引 1024 间隔不一致，本轮重建为匹配的等分表。
  因而这是明确的数值算法变更，并非保持原输出位模式的重构；协议、参数、保护
  及状态转换规则不变。
