# 输出轴关系与 1024 点 Hall LUT 记录 OEN3

核对日期：2026-11-06。OEN3 替代写入 OEN2；保留读取 [OEN2](output_encoder_v2.md)
及 [OEN1](output_encoder_v1.md)。schema14 基础记录仍为 2288 字节，整轴为 4372 字节。
字段为小端，float 为 IEEE-754 binary32。

| 绝对偏移 | 字节数 | 含义 |
| --- | --- | --- |
| 2288 | 4 | magic = 0x334e454f，字节 OEN3 |
| 2292 | 4 | 同次基础记录 record_crc32 |
| 2296 | 20 | 减速比、相位、机械零位、方向、状态，沿用 OEN1 |
| 2316 | 4 | hall_lut_status：0 未标定，0x80 成功，1 覆盖不足，2 映射不一致 |
| 2320 | 2048 | int16 hall_lut_q15[1024]，65536 counts/输出圈，正值加到原角 |
| 4368 | 4 | CRC32，覆盖 2288..4367，种子 0 |

第 i 点位于 LUT 前 Hall 角 `i * 2π / 1024`，周期线性插值包含末点到首点。
成功表须每段 `64 + lut[next] - lut[i] > 0`。运行不增加表遍历，仍只读取相邻两项。
原 Hall 幅值/偏置成功状态、基础 CRC 绑定及输出相位必须匹配，不单独替换误差表。

OEN2 验证其原长度和 CRC 后，将 128 点表按周期线性插值展开为 1024 点，整数取整误差
小于 1 count，保留原输出相位及零位。旧表每段校正后增量须至少 8 count，
确保展开后的八个子段仍严格递增，否则不恢复输出关系，须重新标定。OEN1 使用零 Hall 表。未知版本或损坏记录不恢复
输出关系，保持初始化行为。旧固件忽略 OEN3 扩展；回退须同时恢复对应参数备份。

AT32 写入覆盖参数区前 3 个 2 KiB 扇区，其余区域保持；STM32 按既有双字写入尾部填 FF。
独立 struct/zlib 黄金向量见 [OEN3 测试向量](../../tests/fixtures/protocol/output_encoder_v3.json)。
