# AT32 板级标识符重命名

- 目标：统一板级 C 标识符的 AT32 前缀，并同步调用、编译定义及测试引用。
- 行为边界：硬件参数、控制逻辑、Flash 布局及通信数据保持不变；历史文件名、工程选择器和协议中的历史标记保持原样。
- 基线：当前工作树，包括已有未提交修改；当前配置选择 AT32F456 / YQ-5708。
- 验收：检查旧标识符引用，执行格式、静态检查、PR 验证及正式工程构建；记录已有问题和未完成的硬件验证。
- 回退：只反向恢复本次标识符替换及相关引用，保留原有工作树修改。

## 验证记录

- 当前工作树的 AT32 正式工程编译失败：先前删减的 13 个 `PARAM_APP_JOINT_V1_*` 定义仍被 `motor_axis_profile.c` 使用。
- 在隔离源码副本中仅为验证补回这些历史默认值，并分别选择 AT32/YQ-5708 和 STM32/HT8115-4：两个正式工程均以 0 错误、0 警告通过编译；未改动工作树配置，未进行硬件验证。
