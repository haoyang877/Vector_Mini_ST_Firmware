# 目标与实时状态 v1.9

2026-10-31恢复116同模式目标提交和108/124实时状态，沿用原CAN FD帧及45字节反馈布局，参数存储不变。
本版取代v1.7中“116不支持、测量全部无效”的行为；120/121/122仍不支持。

## 目标提交

117以零目标启动，确认RUNNING后才能发116；116不能启动或切换模式。
模式1/2/3/6使用原20字节载荷，模式9/10使用原32字节载荷。
位置/速度单位为电机轴mrad、mrad/s；电流mA、电压mV、电角频率mHz。8:1减速比不隐式应用。
模式1为Iq，2为速度，3为位置，6为Vq，9为Vd/Vq/电角频率，10为Id/Iq/电角频率；未使用字段为0。

运行所有者核对模式、故障、停止请求及现有电流/电压/速度/位置包络后，短临界区直接提交。
返回0表示目标已写入易失运行对象，并不表示电机达到目标；不再建立目标邮箱或延迟完成事务。
124在该请求之后返回当时快照和相同结果码，correlated_seq对应116请求；其帧头序号独立递增。
同序号同内容返回原提交结果，同序号冲突返回4，旧序号返回5；16位序号按半区比较，跨回绕有效。
只保留最后一次成功请求，STOP后旧请求返回5，不重启电机。主机重连先停止、使用继续递增的序号。
故障返回17、范围错误11、模式/状态不符5、格式错误3/4、未实现模式2。

GET_CAPS为features=0x1D00、supported_modes=0x064E，载荷
`00 1d 00 00 4e 06 40 00 2e 00 00 00 00 00 00 00`。能力位不代表全工况已经实测。

## 实时反馈

108按请求返回快照，correlated_seq=0；124由116触发，不额外建立周期广播器。
同一前台快照在短临界区读取，缩放和发送在临界区外执行；valid_bits继续逐字段表示有效性。
超范围、非有限或无来源数据使用INT16_MIN/INT32_MIN，数值舍入采用半值远离零。

| 有效位 | 来源与语义 |
| --- | --- |
| 0 | 位置模式的电机轴目标位置 |
| 1 | 编码器电机轴连续机械位置 |
| 2 | 速度模式目标速度，或位置模式外环速度参考 |
| 3 | 编码器电机轴连续速度估计 |
| 4/5 | 母线电压/实测母线电流；不存在的电流通道不以FOC估算替代 |
| 6/7 | 电流控制模式Iq参考/运行时FOC实测Iq；其他模式的无意义参考保持无效 |
| 8 | 有效MCU温度 |
| 9 | 无电机温度传感器，保持无效 |
| 10/11 | 运行时FOC估算Vq/Vd，非独立电压采样 |

停止时电流环和FOC电压字段无效；母线和在线编码器仍可有效。采样失去新鲜度时全部测量无效。
现有温度、保护、控制增益和波形算法不变。

2026-11-02前一镜像的`voltage_dq_v`没有生产写入点，Vd/Vq显示0但仍可能标有效，见
[原阶跃记录](../reports/2026-11/current_bandwidth_20261102.md)。本次修复在FOC完成阶段发布限幅后命令电压，
并在复位时清零；线路格式不变。新镜像与1.2kHz整定策略见[电流环整定v1](../guides/current_loop_tuning_v1.md)。
