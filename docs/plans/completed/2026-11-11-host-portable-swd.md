# 上位机独立 SWD 发布包

v3.1.0 解压后依赖工作站虚拟环境和源码。新包从 EXE 所在目录定位隔离的 Python、维护脚本、目标契约和 J-Link 组件。整机页枚举 USB 探针，保留目标 UID、停机确认、包校验和保护区回读。

验收从独立目录解压，用真实发布组件验证探针枚举、双板支持和整机包模拟写入。区分软件回读和实板烧录。回退可使用原版本包。

v3.1.2 随包提供 Windows x64 Python、双板契约、SDK 和 AT32 器件算法。打开添加设备时开始只读 CAN 扫描，选择节点后连接。中控提供断开状态下的整机安装入口。

独立目录实测识别一支 USB J-Link，双板 SDK 索引均有效。软件测试驱动实际界面控件，验证 CAN 扫描启动、J-Link 单支选中、多支选择、拔出后身份失效及随包 Python 整机安装。模拟探针全片 256 KiB 回读匹配，参数区保持原值。本轮未写实板或验证实机启动。
