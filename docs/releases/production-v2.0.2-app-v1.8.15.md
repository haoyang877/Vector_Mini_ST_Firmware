# 电机生产测试上位机 v2.0.2 、Loader v2.3.4 与 AT32F456 APP v1.8.15

本 Windows x64 调试包配套 Loader v2.3.4。完整解压 `电机生产测试上位机-v2.0.2-LOADER-v2.3.4-APP-v1.8.15-win64-20261116.zip`，保留 EXE 旁的 `_internal` 目录，运行 `电机生产测试上位机-v2.0.2.exe`。

在“设备维护”识别节点并读取当前版本。已配板可在“CAN 固件升级”使用内置 APP 升级包，完成后回读 APP v1.8.15。手动 CAN 升级包在 `firmware/can-app/`，J-Link 整包在 `firmware/` 下文件名带 FULL 的 HEX 中。

在“生产检测”选择“关相静态”可单独检查静态电压。APP v1.8.15 每 50 µs 检查一阶低通后的母线电压，滤波系数 0.05。允许范围是 28 ±1 V，含 27 V 和 29 V。任一拍滤波值越界即判异常。最低值、最高值和越界次数均来自同一测试窗口。完整检测的相电阻与双向驱动阶段也使用该电压判据。

上位机根据实际读取的 APP 版本显示判据，界面和导出报告共用板端结果。RTT1 保留 20 kHz 六槽原始采样，依次为母线电压、母线电流、Ia、Ib、Ic、自增序号。该版本的 RTT1 没有 Hall 原码通道。

本包经过离线验证。实机烧录和母线测量留待现场执行。
