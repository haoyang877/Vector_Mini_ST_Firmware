# 无当前入口的旧电机模式退役契约 v1

日期：2026-09-28。范围：APP 容量适配中的旧实现删除，不修改 CAN 线格式。

## 删除范围

删除内部 ModeNow 的 12（电压开环）、16（无感速度）、18（旧电流域位置阻抗）
命名及实现，不提供别名或旧头文件。删除旧阻抗控制器、专用梯形轨迹、任务包装、
对应状态投影/复位、开环专用 RAM 字段和默认值。内部准入拒绝这些数值和未知值，
拒绝时不改变当前模式、目标或故障。剩余模式保持原编号；空位不复用。

这些数字是内部模式号，不能与协议中的控制模式编号混用。CAN 生产控制入口仍为
电流、速度、位置和 Vq；已有协议中未实现的命令继续按现有规则拒绝。本次不增加
旧报文转换或兼容模式，也不修改 GET_CAPS 与现有控制报文的编码。

## 保持的功能和参数

- 当前级联位置、速度、电流、Vq 控制，以及有效标定和齿槽功能保留。
- 编码器观测器标定依赖的无感启动序列和观测器保留，只删除旧独立运行入口及其
  专用默认配置。
- 当前位置控制依赖的备用摩擦值移到 `position_cascade_config.h`，值保持
  1.55 A/1.50 A（启用）或 0 A/0 A（关闭），已辨识模型的优先级不变。
- 参数装载边界移到 `foc_param.c` 私有常量，schema11 的 4304 B 布局及黄金字节
  保持。保留现有记录字段是本轮不变更当前参数契约，不意味着恢复旧模式功能。
- 内部 MotorControl RAM 结构不是持久化或 CAN ABI；调试必须依据本次 ELF
  重新解析符号，不沿用历史字段偏移或旧监视面板中的已删除字段。

## 验证边界

母线保护用例检查已删除/未知编号拒绝且无状态副作用，并固定当前模式编号；
运行所有者用例覆盖 STOP/FAULT/取消和维护保存身份。参数用例核对 schema11
黄金布局和标定往返，位置适配用冻结基线作逐拍对照，外环用例验证写者与调度。
旧历史参考中的摩擦常量名只在测试生成器里映射到等值新名，不进入固件。

主状态机编译改为 O3/Ospace；本批离线测试与尺寸结果不能代替实机耗时验证。
APP 链接描述符和代码区同时固定加载地址，保持声明的描述符偏移，不扩展真实
Flash 区域。容量结果与剩余缺口记录在
[容量适配计划](../../plans/completed/2026-09-28-capacity-fit-v1.md)。
