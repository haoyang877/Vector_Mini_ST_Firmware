## 目标与实际调用链

Board_Init → MotorAxis_Init 装载参数/初始化 PI/撤销旧电流零点资格 →
board_hw_start(false) 启动 CH4 与注入采样 → ADC2 JEOS 派发 → MotorAxis_FastTick
在三相关闭状态下逐帧累加 → 发布有效均值 → 原 BOOT/SELF_TEST → READY。
原平台 JEOS 派发负责帧新鲜性；JEOC、禁用的事件和其它 ADC 事件不推进校正。

样本窗口来源：3fc1c2a6 父提交的 Task_Calib_CurrentOffset 为 20 kHz、20000帧、1秒。
复用该时间窗口及四次求和到12位counts的0.25因子，不猜新的增益、稳定性阈值。
偏置仍用当前1948..2148 counts范围校验；原始四次和不可超过4*4095。
原启动自检500ms不足以容纳历史1秒采样，仅首次上电待校正的总监督期限改为1500ms。
CLEAR后不重新校正，普通自检期限仍为500ms；初始化已具有效偏置的测试调用也仍为500ms。
这只约束监督仍在运行的情况；不声称能够处理 CPU/监督停摆。

## 不变项与失败语义

- 使用已装载的活动增益，不用默认值覆盖有效存储值；电流环动态电压限幅保持。
- 不改变协议编号、参数schema/CRC/持久布局、采样阻值、功率门限或控制时基。
- 不恢复已删除的其它标定模式，不自动启相、自动保存、清错或重试。
- 开始校正时三相offset与电流标记为NAN，复用原自检/inputs_valid有限性门禁。
- 校正完成前不运行控制、维护或磁链观测器；偏置成功后恢复既有换算/保护。
- 校正中发现启相、非NONE模式、原始和越界或最终偏置无效，锁存CURRENT_OFFSET。
  保持无效电流与零点，快车道停机；不自动再次校正，排除原因后重新上电。
- ADC不再推进时不能凑够样本或进入READY，原监督机制在1500ms内锁存自检超时。
