# 手工调试 RTT 配置 v1

目标：为 pitch 定位噪声与电流跟踪提供精简 RTT 通道。
用户要求先配置观测通道，随后明确无需很多路；最终采用 10 路，不下载或启动运动。

基线：普通目标为 11 路 int16/22 字节、2 kHz。
已检查 RTT_Sampling、hw_conf.h、MotorStatus_Sampling、外环遥测接口、
电压圆算法、旧 Scope 与实际编码器测试。复用原编码器和外环只读接口。

变更：普通目标默认 profile 2，10 路/20 字节/2 kHz。
观测位置目标/反馈、PLL/控制速度、Iq指令/反馈、Id、Vq/Vd、摩擦补偿电流。
同步 JScope 描述符、Scope、文档与黄金向量；保留 profile 1 的旧 11 路布局。
累计丢帧在静态 RAM 变量中记录，不增加波形通道。

不变项：控制增益、滤波配置、限流、标定、机械零点、运动范围、参数 ABI/存储、
模式及故障处理。保留用户已有修改。

验收：实际 C 编码器检查 20 字节布局、刻度、外环无效/停机语义、分频与 SKIP；
Scope 索引/单位匹配黄金向量；旧帧回归；可用离线测试和普通 Keil 构建通过。
历史 checkout 无新版 verify/format/lint harness，不能声明新版验证通过。

回退：编译指定 profile 1 并使用旧 Scope，仅撤销本次增量。
风险：新增快照读取及打包开销尚未板上测量；当前不声称实机 RTT 或时序已验证。
本阶段仅配置，后续下载必须使用本次固件对应的 AXF。
