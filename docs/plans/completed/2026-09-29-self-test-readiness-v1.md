# 基础自检与模式就绪 v1

日期：2026-09-29；基准：4a6c202a，目标分支 codex/system-refactor。

## 目标与决策

- 主状态保持九态；基础健康后进入 READY，未确认配置、部分/未标定不作为故障。
- 配置确认与标定资格独立于生命周期；只有明确 ENABLE 才能 STARTING。
- 复用参数值服务、采样保护、维护准入和唯一生命周期所有者，删除准入拒绝锁存故障的路径。
- 默认值可用于通信和配置；产生转矩的维护必须先明确确认配置，且满足任务自己的标定前置条件。
- SELF_TEST 连续健康窗口与总期限有界；使用平台单调时基，不新增忙等或运动诊断。
- 参数 schema12 复用两个退役槽保存配置确认和整条记录 CRC32，保持 4304 B、schema/magic 偏移及 Flash 分区。
- 旧 schema 不迁移、不自动回写；使用未确认默认值。PC 通过新增参数 ID 查询资格，108/124 布局不变。

## 子任务

1. 固定基准并运行真实状态所有者、参数与电压原生测试。
2. 配置确认、来源、记录完整性与启动诊断；同步 APP/Loader 参数契约和黄金向量。
3. 基础自检：关断、样本、温度、参数、必需编码器、资源、硬过压、连续窗口与超时。
4. 统一启动资格；维护缺少前置条件时拒绝而不锁故障；恢复默认值和标定完成不自动启动。
5. 补齐首次启动/部分标定/掉电重载/损坏记录/准入拒绝/超时/关断失败测试。
6. PR 验证及三个 Keil 目标构建、容量核对，合回主线后归档临时 worktree。

## 边界与验收

这是安全策略功能调整，不声明行为等价。保持控制算法、周期、控制目标单位、状态编号、
维护票据、取消和保存身份、通信帧结构及参数分区不变。确认标志不是标定证明。
新增状态只读诊断与配置确认命令必须有文档、黄金字节和真实调用方测试。

不加入尚不存在的驱动器故障引脚、输出轴传感器、RAM 扫描或施加电压的自检；
静止电流残差与电气功率管诊断缺少实测判据，本轮不伪造验收。
总期限/稳定窗口为软件默认值，离线可验证调度语义，硬件启动时间需后续只读测量。
禁止烧录、设备参数写入和运动；本轮证据仅为离线测试与构建。
