# 大惯量屏幕轴：摩擦变化、制动与位置噪声预算 v1

2026-10-10，设计分析。用户确认噪声指位置角度，幅值例为±0.05°/±0.01°；
屏幕装配转动惯量未知。用户随后补充当前位置峰值噪声约±0.025°，对应下表中间一行建议。本轮不改代码/参数、不下载、不执行运动测试。

## 问题边界

现有前馈退出只改变摩擦模型电流，速度PI的Ui仍可能同向出力。
代码在Ui同时反对位置和速度纠偏时才专门卸载；单独进入制动不会自动清Ui。
Ui中可能混有重力支撑、残余摩擦和运动积累，不能无条件清零，也不能都当成应保留载荷。
当前位置串级采用规划减速度，而非已验证的大屏幕净制动能力。
SETTLE近区0.18°退出锁存用于减少模型前馈重复介入，不是制动距离保证。

## 物理模型与摩擦老化

```text
J * angular_acceleration = Kt * Iq - friction_torque - gravity/load_torque
```

相同电流下，阻尼下降改变净力矩；若依靠摩擦停车，会减小净减速度、延长停止距离。
主动制动有足够力矩余量时，闭环可以抵消这种变化，但需要验证实际净减速度。
正向运动不代表必须使用正向电流；制动可需要反向电流。

固定摩擦前馈应作为可修正的负载估计，而非停车能力参数。正反向匀速辨识、温度/磨损
条件下验证可用于缓慢更新模型；不能把加速中的惯性电流或静止保持电流直接当作摩擦。
静止摩擦可以在一个力矩范围内平衡，静止电流本身不能唯一辨识摩擦。

最坏制动计算取J上界、可保证电机反向力矩下界、最大助推负载，摩擦助力下界未知时取0：

```text
alpha_min = (guaranteed_motor_braking_torque + friction_min - assisting_load_max) / J_max
```

实际可用力矩要包含电流跟踪、母线/电压饱和和回馈能力的约束；若alpha_min≤0，
就没有这组假设下的有限停车距离保证。当前J/负载未知，不能算出实机可靠的alpha_min。

J未知时可以辨识装配后响应，不必先求J的精确值：在相近角度/速度和方向下，用不同
实际Iq对应的角加速度差估计Kt/J；或直接验证主动制动响应。单次有强阻尼的减速数据
不能自动覆盖未来低阻尼情形，仍须分开摩擦助力和电机主动制动能力。

## 停止距离预算

速度上界 `v_u=abs(filtered_velocity)+velocity_uncertainty`，
位置可用距离应减去位置测量不确定性和机械限位裕量。
位置噪声的单位是度，不能直接当作速度不确定性的度每秒；测速不确定性另需实测。

初始加速度接近0、延迟期间不再加速的简化预算：

```text
stop_angle >= v_u * total_delay + jerk_limited_stop_distance(v_u, alpha_min, jerk)
              + position_uncertainty + mechanical_margin
```

若仍在加速，需要加上延迟期间的额外推进距离、增加后的制动初速度及初始加速度影响。
不能只用v²/(2*规划减速度)或把5Hz的31.8ms时间常数当作整个系统已证明的最坏延迟。
总延迟还包括执行、测速、输出变化、积分/前馈过渡等实际动态。

近区应先通过速度/加速度与剩余距离判定制动包络，控制总电流保证净减速，再卸载
过时的运动摩擦补偿。位置精修阶段由有界反馈承担剩余误差，HOLD保持必要载荷电流。
建议用实际速度/减速度和总Iq监测制动是否实现，避免将前馈为0当成已经制动。

## 位置噪声与窗口

令N为实际到位判定通道的剩余峰值位置噪声，E_bias为标定、结构/传动等误差预算：

```text
abs(true_position_error) <= abs(measured_position_error) + N + E_bias
HOLD退出窗 - 进入窗 > 2*N + dynamic_margin
```

第二式用于排除同一静止位置仅靠有界噪声跨越进入和退出窗，不保证排除真实运动。
低通只能降低部分随机噪声；不能假设常量偏差/缓慢漂移同样下降。
如果用户给的是原始噪声，需测到位资格滤波后的N；下面保守按剩余N计算，
并暂忽略E_bias，窗口只是初始整定候选，不是实机精度验收结论。

| 剩余峰值噪声 | 建议进入窗 | 建议退出窗 | 进入时真实误差上界 | HOLD内真实误差上界 |
| --- | --- | --- | --- | --- |
| ±0.01° | ±0.04° | ±0.08° | ±0.05° | ±0.09° |
| **±0.025°（当前补充值）** | **±0.06°** | **±0.12°** | **±0.085°** | **±0.145°** |
| ±0.05° | ±0.10° | ±0.22° | ±0.15° | ±0.27° |

当前0.0573°/0.0828°滞环宽约0.0255°，若判定通道N=0.05°，小于2N=0.10°，
不足以在最坏噪声假设下排除重复切换；N=0.01°时则超过2N，但动态裕量仍很小。
若希望真实保持精度±0.05°，N=0.05°已用完误差预算；放大窗口不能解决该精度要求。
需降低噪声、验证标定及结构误差，并在大屏幕装配后验证控制误差。

确认时间初始建议150～250ms，具体配合资格滤波及实际动态验证。不要单靠延长时间
隐藏稳定偏差。到位还需独立速度条件，按允许漂移角度/确认时长分配，例如0.05°
漂移预算与0.20s对应真实速度上界0.25°/s；测得速度阈值须再扣除速度测量不确定性。
该漂移关系假设期间不加速，仍需检查剩余制动距离和实际力矩。

三个参数组应各有明确契约：摩擦模型退出/恢复、到位精度/保持滞环、机械限位制动包络。
当前代码复用部分窗口常量，新整定不宜只改一个误差窗口而忽略其比例及其他用途。
按当前±0.025°噪声建议，进入0.06°=0.0010472 rad，退出0.12°=0.0020944 rad。
只改`pos_error_window`为0.06°时，原0.26/0.18比例会生成约0.0867°退出窗，不能实现本建议；
需要明确独立的保持退出阈值，不顺带放大模型前馈0.18°/0.26°退出/恢复区域。
电机编码器精度不自动等于屏幕姿态精度，还需考虑结构弹性、装配间隙等。

## 后续验证需求（本轮未执行）

1. 测屏幕安装后的静止角度噪声、低频漂移、资格滤波残余噪声及独立速度噪声。
2. 获取正反向、不同位置/电压及代表性摩擦状态的主动制动响应，建立保守能力下界。
3. 检查Ui在制动时是否残留同向驱动，区分负载支撑与运动补偿，验证无扰输出跟踪。
4. 用最坏制动能力建立速度相关减速点及限位裕量，再调到位窗/速度阈值/确认时间。
