# 上位机波特率与指定电机型号

日期：2026-11-10。基线：YG_MC_HOST v2.6.0 候选。

当前补充：本页保留前期候选的离线实现记录，不代表产品需求评审或实机验收完成。
后续先按[功能需求清单](../../guides/yg_mc_host_requirements_v1.md)明确范围，再择期实现，不继续据本记录推进开发或硬件操作。

## 目标与约束

- CAN 仲裁段、数据段分别配置，默认 1 Mbit/s / 5 Mbit/s；扫描和连接共用设置。
- 设置只在断开且未扫描/维护时修改；改变速率后撤销旧扫描结果和设备选择。
- 不自动修改板端波特率，不在未知速率间自动发命令探测。
- 电机类型须实际切换型号与配套参数，不修改生产身份 motor_type 冒充切换。
  用户选择新增 CAN 在线配置协议并同步固件；型号仍由合法轴角色/节点绑定。
- 新增 Type123 读取活动/已保存配置、Type125 准备候选、Type126携完整UID和票据提交保存、Type127携完整UID和修订应用并重启；
  GET_CAPS bit13 表示支持，旧固件只读且禁用写入，不猜测兼容性。
- 写入要求主站2、匹配当前配置修订、IDLE/实际关相、无故障且近零速；
  使用生产 Param_CreateAxis 构造配套参数，清除旧标定、锁定本次启动并校验 Flash 回读。
  保存不等于当前活动配置已改变；重启后按相同 UID、新节点重新识别，等待重新标定。
- 保留四模式控制、使能/失能、UID、STOP、固件升级及独占访问约束。
- 开发和验证不访问硬件；实际写入、清除旧标定、复位须按明确台架场景执行。

## 边界与验收

CAN SDK 负责实际配置，UI/扫描/会话传递同一份不可变速率。
型号切换须区分所选型号、当前已生效型号、待重启/待标定状态；不能只改显示名。
离线测试覆盖速率验证与传递、型号/节点匹配、参数生成及无效输入，
完成 Rust 测试、Clippy、发布构建、原生界面预览和相应仓库检查。

回退本次主机/配置工具变更即可；不更改已有板卡数据或固件通信默认值。
