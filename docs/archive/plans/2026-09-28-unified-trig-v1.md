# 统一正余弦查表 v1

## 目标和范围

用户要求全部统一查表。将 APP 中正弦、余弦统一为 `Math_SinCos`，使用一张
257 点四分之一周期 float 表及三次 Hermite 插值；端点导数也来自同一张表。
删除旧粗表入口、交接专用小角度展开、标准库 sinf/cosf 回退。
反正切 fast_atan2、平方根不属于本次正余弦替换范围。
这是数值算法变更，不能宣称逐位等价的结构重构；原表 1023 间隔与索引 1024
间隔不一致也随本次替换消除。无需兼容旧数学入口。

## 不变项与边界

不改协议/参数 ABI、状态机、保护、输出使能、标定策略、全局编译选项及硬件。
运算无可变全局、无堆分配；表在 Flash。正常单圈输入固定工作量，非有限值输出
NaN，不执行浮点到整数转换。多圈输入使用 fmodf 按 float 周期折算；大角度的
精度受 float 周期和输入精度限制，控制调用者应保持单圈角度。
工作区已有 angle_feedback.c 尾空格及 Keil GUI 修改，保持不动，不纳入提交。

## 基准、验收与回退

基准 ce31fc60，改动前现场重建：普通 APP ROM 98608 B / RAM 31896 B；
Loader APP 诊断 ROM 106424 B / 跨度 106464 B / RAM 32128 B。
原始 78 KiB Loader APP 仍链接失败，诊断扩大区间只用于测量、不可部署。
基准证据 outputs/capacity-fit/batch1/unified-trig-baseline/。

1. 对独立 double 数学参考扫描完整单圈、表格边界两侧、正负微小角、周期接缝；
   单圈最大绝对误差 <= 1e-6，单位圆平方模误差 <= 1e-6；多圈 ±8π <= 3e-6。
2. 正负零、NaN/Inf、极大有限数不得越界；微小角不能丢失符号或被量化成零。
3. 连续 10000 次代表性交接角步旋转，幅值相对漂移 <= 0.001，向量误差 <= 0.002；
   Park/逆 Park 往返误差 <= 1e-5。保留无感交接电流连续性、积分旋转与制动测试。
4. 执行 PR 验证和 format/lint，普通 APP 重建，Loader APP 容量诊断；检查最终
   map 中不再链接 sinf/cosf/rredf；记录 ROM/RAM 和源文件/产物哈希。
5. 离线不证明 MCU 快环耗时、栈水位及实机过渡电流；本轮不烧录，未完成实机验收。

回退本次文件修改即可恢复 ce31fc60 的数学实现和调用点；不回退无关工作区文件。
本计划不改变容量预算，不把诊断链接成功称为 Loader APP 发布通过。
