# 速度模式与位置级联速度 PI 分离

版本：v1，2026-10-09；适用 `codex/ovp-36v` 的现有 mode 2/3 固件。

目标：纯速度模式保留 `speed_Kp/speed_Ki`，mode 3 使用新增的
`position_speed_Kp/position_speed_Ki`。两组可独立调参、保存和复位恢复。
不改控制周期、电流限幅、滤波、轨迹、模式18或电机个体标定。

实现边界：复用现有位置级联控制器、参数服务和 CAN 参数分派。
新增 PSP1/v1 独立 CRC 尾记录，保留 schema10 的已有字段偏移；旧记录缺省时
复制原来的实际运行增益，完成校验后由已有启动迁移流程保存。坏记录拒绝使能，
不自动用另一组增益代替。CAN 新参数仅扩展本分支旧式参数协议。

验收：两种模式使用不同增益时互不影响；修改位置 PI 能刷新缓存；切换模式或
修改非活动组不串用积分状态；保存/恢复两组及 AXS2 启动配置不覆盖用户设置。
覆盖旧记录迁移、NaN/负数/损坏 CRC、黄金向量和既有标定偏移；运行原生回归、
离线 Python 测试及 Keil 普通构建，记录代码体积和 RAM。

回退：恢复本变更的源码并使用旧固件；旧固件忽略 PSP1，继续使用原 speed 字段。
旧固件保存会擦除新尾记录，下次升级时重新迁移为两组相同值。
本次只改代码与构建，不连接设备、烧录或执行运动。

环境限制：此历史工作树没有现代 `verify/format/lint` harness、uv 锁文件或 STYLE 文件。
沿用该树的离线测试和 Keil 构建，不把这些结果描述为现代 release profile 通过。
