# YG_MC_HOST 四模式 GUI 实机验证

日期：2026-11-10。用户明确要求打开新版并实测使能、失能及四种控制模式。
基线为 v2.6.0 本地包，exe SHA-256 记录在本轮 outputs 摘要中。

## 台架与边界

沿用已确认的 AT32F456 PITCH 架空台架；先自动发现并复核原会话 UID、
APP/Loader、能力、零故障、新鲜反馈和母线，再发送运动命令。
其他硬件任务已交接且当前无运行任务；不操作 J-Link、不复位、不下载或写参数。
只通过真实 GUI 请求使能、目标和失能；脚本独立回读只能作为补充证据。

## 场景与验收

1. 启动默认断开；发现、选择原 PITCH 并连接。失能确认 STOP 最终 0/0、IDLE。
2. 开始观察并核对新鲜记录；未使能时目标禁止下发，运行时禁止切模式。
3. Vq 先零输出使能，再用 0.05 V 小幅目标；Iq 用 0.02 A 小幅目标。
   每档只保持短时，观察速度/电流与故障，随后立即失能。
4. 速度从零使能，验证 1、2、0 rad/s，随后失能。
5. 位置使能保持当前值，设置相对当前位置 +0.02 rad，再返回当前位置，随后失能。
6. 每次失能均需新鲜 IDLE、模式 0、近零速和零故障；未确认时停止后续运动。
   任一控制失败或反馈异常先 STOP，不自动复位或重试；需要物理干预时向用户说明。

主机既有母线 ≤33 V / 3 A、运行 Iq ≤6 A、实测速度 ≤300 rpm 包络保留；
本次目标显著低于界面最大范围，设备保护仍然生效。

实施中；失败和未测项目按实际结果记录，不改写为成功。
