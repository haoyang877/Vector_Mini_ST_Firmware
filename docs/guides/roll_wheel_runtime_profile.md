# Roll / wheel 共用固件与快速切换 v1

适用：本分支 schema10 + DMP1 扩展、6 mΩ 驱动板、同一电机及编码器装配。
代码、镜像、R/L/磁链、电流 PI 和编码器标定共用；仅阻尼环配置可切换。
这不是板上 core-machine-test/schema11 的升级包，不能直接混刷两条分支。

## 配置值

| 值 | 工况 | 摩擦前馈 |
| --- | --- | --- |
| 0 | wheel，无阻尼环 | 关闭 |
| 1 | roll，带阻尼环，约 2 N·m | 关闭，建议先验证此档 |
| 3 | roll，带阻尼环 | 显式开启 |

位 0 是阻尼环，位 1 是前馈。2、负数、非整数、NaN、Inf 和未知位都被拒绝。
配置与 roll/pitch/左右轮轴身份、CAN 节点号、位置范围相互独立。选 1 不会改变地址或允许超出机械范围运行。

切换只改变标定/无感启动配置和前馈开关，保留采样比例、ADC 零偏、R/L/磁链、
全部 PI、已有电流/速度限制、编码器方向/LUT/电零位/机械零位。
阻尼状态变化会失效旧摩擦辨识模型及未应用候选；只开关前馈不会失效同一装配的模型。
电机快环复位电流/速度积分、位置轨迹、无感启动/观测器、未完成的编码器标定状态。
中止标定不会把未完成的结果置为有效；已经有效的结果不会因单纯切换而被清除。

## 操作顺序

1. 查询扩展版本 0x6A，必须明确收到 1；旧固件无回复时停止，不猜测支持。
2. 发送 mode0 停机，并等到 mode0 回读；机械拆装须在断电状态完成。
3. 向 0x68 写入 0、1 或 3。请求仅在 mode0、上一模式也为 0、无故障且六路输出关断时受理。
4. 查询 0x69，等到目标值。-1 表示请求尚未生效、请求被拒绝或配置无效；不得据此启动。
   提交后由快环再次核对停机/关相；若其间来了 START，该切换取消。
5. 需要断电记忆时使用现有 mode9 保存流程，待其回到 mode0，再读回 0x69。
6. 后续显式使能。切换和查询本身不会启动电机，也不会自动提高限流。

既有 Python 客户端 `Client.write(channel, node, 0x68, value)` 可写入；
`Client.read(channel, node, 0x68)` 查询 0x69。写入与保存分开，由调用方显式执行以上停机流程。
已有有效标定且编码器/磁铁/相线安装未变时，不必因增减阻尼环重新标定。

## 标定初始整定

| 项目 | wheel | roll |
| --- | --- | --- |
| mode13 对齐电流 | 2 A | 5 A |
| mode13 启动 Iq | 0.15 → 0.5 A | 5 → 6.5 A |
| mode13 启动 Id | 0.5 A | 0.5 A |
| mode13 机械目标速度 | 15 rad/s | 20 rad/s |
| 扫描圈数（另有 1 圈验证及启动/停止转动） | 10 | 5 |
| mode13 最低限流条件 | 满足 2 A 对齐及启动向量 | 至少 6.52 A |
| mode15 对齐电流 | calib_current，受限流约束 | max(calib_current, 8 A)，受限流约束 |

roll 限流低于 8 A 时 mode15 直接报参数错误，不再静默降到较低电流并标记成功。
无感速度模式的 roll 启动使用相同阻尼启动配置；wheel 保留原无感速度模式启动整定。
这些数字来自本实验分支既有整定，不是本次新电机的台架验收结果。
mode13 需要连续多圈旋转，轴位置限位不会约束它，必须使用对应裸轴台架场景。
软件电流指令限值不等同于相电流瞬时硬件钳位。

前馈默认关闭。mode3 优先使用已应用的摩擦辨识模型，否则沿用历史常量；mode18 使用历史常量。
历史正/反运行补偿为 3.6/3.5 A、mode18 起动补偿为 4.3/4.2 A，来自之前约 2.5 N·m 装配的试验。
它们尚未在当前约 2 N·m 装配上复验，因此配置 3 是明确的调试选择，不是配置 1 的自动行为。
速度/位置 PI 不按阻尼状态自动覆盖；当前没有足够实测证据提供两套最优增益。

## 持久化与兼容性

schema10 原有偏移不变：magic_word=2164、axis_profile=2208；DMP1 位于 2240，长度 16 字节。
记录依次为 little-endian uint32：magic=0x31504D44（DMP1）、version=1、flags、CRC32。
CRC 使用反射多项式 0xEDB88320、初值/最终异或 0xFFFFFFFF，覆盖前 12 字节。
全零或全 FF 尾部视为旧数据，选择 0；不会根据 node_id 或轴名称暗中启用大电流档。
其他损坏、未知版本、非法配置阻止使能，不自动覆盖 Flash，也不清除已读到的编码器标定。

保存仍使用现有 Flash 写入机制，本扩展提供损坏检测，不宣称整个参数区掉电原子更新。
旧固件会忽略该尾部，回退后以旧固件编译选项为准；旧版重新保存可能擦除扩展。
此扩展属于本分支 schema10，不能当作另一分支 schema11 的抗齿槽字段读取或移植。

## CAN 增量协议与黄金字节

仍用标准 ID `(node << 8) | parameter`，4 字节 big-endian IEEE754 float32。
既有 SI 线路版本 0x67=2 不变；新增能力单独以 0x6A=1 识别。

| 参数 | 含义 | 载荷例子 |
| --- | --- | --- |
| 0x68 | 设置装配配置 | 0=`00000000`，1=`3f800000`，3=`40400000` |
| 0x69 | 查询生效配置 | 请求 `00000000`，回复同上；未就绪/拒绝=`bf800000` |
| 0x6A | 查询扩展版本 | 请求 `00000000`，回复 `3f800000` |

SET 受理不立即回复成功；非法/忙/未关相返回 0x69=-1。必须查询快环实际生效值。
本协议没有事务序号，客户端应串行查询并丢弃历史回复。所有黄金字节见
`tests/vectors/motor_load_profile_v1.json`。
