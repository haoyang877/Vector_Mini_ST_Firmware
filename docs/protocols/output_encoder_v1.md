# 输出轴标定记录 OEN1

OEN1 是 Flash 参数区的可选扩展，位于 schema14 基础记录之后。基础记录仍为 2288 字节，原 CRC 算法和偏移不变，整轴写入长度为 2320 字节。所有字段小端，浮点为 IEEE-754 binary32。

| 绝对偏移 | 长度 | 字段 |
| --- | --- | --- |
| 2288 | 4 | magic = 0x314e454f，字节 OEN1 |
| 2292 | 4 | 同次 schema14 record_crc32 |
| 2296 | 4 | gear_ratio，当前配置的正整数减速比 |
| 2300 | 4 | phase_rad，电机单圈相位偏移，[-π, π] |
| 2304 | 4 | zero_rad，输出轴机械零位偏移，[0, 2π) |
| 2308 | 4 | direction，int32，+1 或 -1 |
| 2312 | 4 | status，bit7 对应关系成功，bit8 工装零位已设置，低 7 位故障 |
| 2316 | 4 | 扩展 CRC32，覆盖 2288..2315，种子 0 |

故障编号 0 为无故障，1 为配对样本不足，2 为 Hall 幅值/偏置标定失败，3 为位置对应关系不一致。成功位和非零故障不能同时存在。Hall 具体超幅和幅值不足故障仍位于 schema14 的 Hall 状态槽。

减速轴采用 motor = direction × gear_ratio × hall + phase (mod 2π)。输出零位独立于该传感器关系。直驱 ratio=1、phase=0、direction 默认 +1，可不安装 Hall。

恢复同时校验基础记录、扩展版本与 CRC、绑定 CRC、当前减速比及字段范围。旧记录的尾部为零/擦除值时忽略扩展，保留电机和 Hall 参数。减速比改变必须重新标定对应关系。缺少对应关系时减速轴 IsReady 为 false，不伪造绝对位置。

旧版 APP 继续读取 schema14 前缀。旧工具或旧 APP 保存时可能删除扩展，或者改变基础 CRC，重新升级后需恢复匹配备份或重新标定。新固件统一保存基础记录与扩展，避免半条新关系配旧参数。独立黄金字节见 [测试向量](../../tests/fixtures/protocol/output_encoder_v1.json)。

AT32 与 STM32 的底层整记录写入容量均为 2320 字节，仍只擦除参数区前两个 2 KiB 页。上电首次定位等待现有电流偏置采样窗口完成（约 103 ms），再采用当前编码器与 Hall 数据；传感器启动初值不参与辨圈。
