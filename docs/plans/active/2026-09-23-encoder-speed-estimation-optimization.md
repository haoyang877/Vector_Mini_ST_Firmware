# 编码器测速估计优化：低延迟估计器替换 8 ms 滑窗 v1.0

日期：2026-09-23。状态：**Phase 0 只读采集 + Phase 2（20 kHz PLL）已实施并经 J-Link 实机验证；
PR 档全绿；转速环 PI 重新整定与最终带宽验收待办**。
关联：`docs/reports/2026-09/fast_loop_timing_20260909.md`、

## 1. 目标（Objective）

在**保持或改善速度噪声抑制**的前提下，降低编码器测速估计延迟、改善低速可分辨性：

- **估计延迟**：现状群延迟 ≈ 4.0 ms，占 2 kHz 速度环相位滞后的主要部分；
  目标 Phase 1 ≤ 2 ms、Phase 2 ≤ 1.5 ms。
- **低速可分辨性**：现状硬死区 8 Q15 ≈ 0.915 rpm、阶梯 0.229 rpm；目标缩小死区、平滑过零。
- **约束**：不改协议/参数 ABI，不触碰安全路径与快环角度路径，不增加静态 RAM
  （改造前 HIL 静态 RW+ZI 距 32 KiB 边界仅约 40 B，见 fast_loop 报告 §4/§10）。

### 2.1 量化问题

- 群延迟：`(N-1)/2 × Ts = 7.5 × 0.5 ms = 3.75 ms`，加半拍 0.25 ms ≈ **4.0 ms**。
- 速度分辨率：每 Q15 count = `2π/(65536×0.008)` = 0.01198 rad/s ≈ **0.114 rpm**；
  真实 LSB = 2 Q15 → **0.229 rpm/档**。
- 死区：8 Q15 ≈ **0.0959 rad/s ≈ 0.915 rpm**（低于此强制归零）。
- 带宽估算（假设：纯积分开环、相位裕度 60°、含速度环半拍 0.25 ms）：
  T_e = 4 ms → ω_c ≈ 123 rad/s ≈ **20 Hz**；T_e = 1 ms → ω_c ≈ 419 rad/s ≈ **67 Hz**。
  即延迟 4 ms → 1 ms 约带来 **3 倍**可用带宽（受电流环限制，量级 2~4×）。
  但注意：**"降延迟"能否成立取决于估计器结构，见 §2.3**——单纯换成 2 阶 IIR 并不降延迟。

### 2.2 与方法论的关系

TLE5012B 每次读回的是完整**绝对角度**，不是稀疏增量边沿，故经典 M/T 法（数边沿）
不适用；正确范式是**相位跟踪观测器（PLL / 角度跟踪器）**。绝对式不存在"低速无脉冲"
问题，低速限制仅为量化/磁噪声，正是 PLL 的优势区。

### 2.3 现状估计器的本质：长基线割线，噪声 ∝ 1/N（关键修正）

滑窗对增量求和会**望远镜式相消**：`Σ_{k=0}^{15} delta[n-k] = shadow[n] − shadow[n−16]`，
故 `Encoder_UpdateVelocity` 实际是 **16 拍基线的割线（secant）**：
`v̂ = (shadow[n] − shadow[n−16]) / (16·Ts)`。

- 噪声：`var(v̂) = 2σ_θ² / (N·Ts)²`，即标准差 **∝ 1/N**（不是 1/√N）——它已是低噪声估计器。
- 延迟：`(N−1)/2·Ts = 3.75 ms`。

**由此否决"2 阶 IIR 替换"方案**：把 2 阶 Butterworth 作用于"逐拍瞬时速度"，
在 fc=150 Hz 时输出噪声约为现状的 **6.5×**；要降到与现状相同噪声需 fc≈3.5 Hz，
延迟反而升到 **~64 ms**。等噪声下 2 阶 IIR 并不比割线快（二者"噪声×延迟"同量级），
等延迟下 IIR 更差。**"用 2 阶 IIR 换更低延迟"不成立。**

**真正杠杆（按优先级）**：

1. **用高采样率样本**：现估计器每 8 ms 只用 16 个样本；20 kHz 角度每 8 ms 有 160 个样本。
   最小二乘斜率在相同窗口下噪声 ∝ 1/N^1.5，样本数 ×10 可显著降噪；或等噪声下大幅缩短
   窗口（降延迟）。**前提是相邻样本近似独立**——取决于 TLE5012B 内部更新率（§4 第 1 条），
   故 Phase 0 是**前提而非并行项**。
2. **模型式观测器（α-β / 卡尔曼 / PLL）**：按"匀速/常加速"模型最优加权，给定延迟下噪声更优；
   即 Phase 2。
3. **纯线性替代的上限**：仅把 16 拍求和换成同窗最小二乘斜率，噪声 ↓≈1.6×、延迟不变——
   无台架也能落地的低风险小步。

### Phase 1：高采样率低延迟估计器（利用 20 kHz 角度，取代 2 kHz 割线）

> 原"2 阶 IIR 替换 boxcar"方案已按 §2.3 否决，不再实施。

- 目标：在相同窗口噪声不劣化下，把估计延迟从 3.75~4 ms 降到 ≤2 ms；**数据来源改为 20 kHz
  角度样本**（`linearized_q15` 等高速率量），而非 2 kHz 的 `shadow` 增量。
- 结构（按 Phase 0 结果择一）：
  a) **线性最小二乘斜率**：在 20 kHz 上取 M 个样本做斜率拟合，实现简单、可离线完全验证；
  b) **α-β / 卡尔曼（匀速模型）**：给定延迟下噪声最优，是 PLL 的等价稳态形式。
- **实现要点（RAM 已确认可行，2026-09-23）**：20 kHz 固定窗口 LS 需 ~M 样本缓冲
  （如 T=4 ms → M=80 → **160 B**，余量够）；快路径入环形缓冲并发布写指针，2 kHz tick 读
  最近 M 点算斜率。**该写入是快路径的新职责 → 所有权变更须走决策记录。** O(1) 递推的
  α-β/RLS 不需要缓冲，但归属 Phase 2（观测器）。
- 保留：多圈 `shadow`（位置仍走原链）、`vel_mech`/`vel_mech_continuous`/`vel_elec` 的单位
  与语义；死区保留（阈值按新噪声重算）或改软死区。
- 移除 16×int32 ring buffer（64 B）→ RAM 下降或持平。
- 所有权：若估计器需读 20 kHz 角度，按 AGENTS.md 决定"快环只置标志 + 慢拍消费最新样本"
  还是允许快环内运行；**所有权变化走决策记录**。
- 不变：`Encoder_GetMecVel*` 契约、速度环/位置环消费方式、参数与协议 ABI、标定参数。
- **验收**：离线 native 估计器测试（阶跃/稳态/死区/换向/重启）通过；PR 档全绿；
  台架 A/B：恒速噪声不劣于基线且延迟下降；低速/零速/换向行为不劣化。
- **行为变化（须记录）**：速度估计动态更快；死区数值可能变化；RAM/Code 尺寸变化。

> 若 Phase 0 显示传感器内部更新远慢于 2 kHz、样本高度相关，则"用 20 kHz 样本"无增益，
> 退回 §2.3 第 3 条的"同窗最小二乘"小步（噪声 ↓≈1.6×、延迟不变），并转 Phase 2 观测器。

#### Phase 1 设计参考（参数化；M/T 待 Phase 0 定档）

设角度噪声标准差 σ（rad），估计器方差（未标单位处已按 σ² 归一）：

- **现状**：2 kHz 割线 N=16（T=8 ms）→ `var = 2σ²/(N·Ts)² = 31250 σ²`，延迟 3.75 ms。
- **最小二乘斜率**：N 个等间隔样本、步长 Ts → `var ≈ 12σ²/(Ts²·N·(N²−1)) ≈ 12σ²·Ts/T³`，
  延迟 `≈ (N−1)/2·Ts`（T = N·Ts）。

**场景 A：20 kHz 采样（Ts=50 µs，相邻样本近似独立）**

| 窗口 T | N | 延迟 | var/σ² | 相对现状 |
|---|---|---|---|---|
| 8 ms | 160 | ~4 ms | 1,172 | **0.037×（27× 更好）** |
| 4 ms | 80 | ~2 ms | 9,375 | **0.30×（3.3× 更好）** |
| 2.6 ms | 52 | ~1.3 ms | ~34,100 | ~1.1×（持平） |
| 2 ms | 40 | ~1 ms | 75,000 | 2.4×（更差） |

**场景 B：按默认 85.3 µs 更新率去相关（≈11.7 kHz，Ts=85.3 µs，T=4 ms → N≈47）**

| 窗口 T | 延迟 | var/σ² | 相对现状 |
|---|---|---|---|
| 4 ms | ~2 ms | ~15,900 | **0.51×（2× 更好）** |

**结论（写死 Phase 1 目标）**：现实目标应定为 **延迟 ~1.3–2 ms 且噪声不劣化**
（20 kHz 下 T≈4 ms 可把噪声降到 ~1/3；T≈2.6 ms 与现状持平）；**不要追求 1 ms**
（T≈2 ms 时噪声反而明显更差）。场景 B 收益更小但仍有 ~2×，与 §4 的寄存器结论一致。

### Phase 2：20 kHz 角度跟踪观测器 PLL（可选，按 Phase 0 结论决定）

- 实现 2 阶角度跟踪观测器：
  `err = wrap(θ_meas − θ_est)`；`θ_est += Ts·(ω_est + Kp·err)`；`ω_est += Ts·Ki·err`。
  带宽初值 ω_n = 2π·(100~200) Hz，ζ = 0.707。
- 运行位置（**按 AGENTS.md 所有权规则**）：观测器可放在 20 kHz 快环内消费最新角度，
  2 kHz tick 消费/发布速度；**若坚持"快环只置标志"的现有模型，则在 2 kHz tick 用最新
  样本运行**（收益略降）。所有权变化须走决策记录。
- **设计约束（关键，不得违反）**：估计器**只产出速度**，不替换换相用电角度，也不参与
  位置闭环。换相电角度继续由原始 LUT 校正角派生（`Encoder_UpdateElecAngle`，
  `angle_feedback.c:134-142`）；位置继续用 `theta_mech`（`shadow_q15` 累积，
  `angle_feedback.c:478`）。估计器只消费 `shadow_q15` 增量，位于标定路径**下游**；
  不得把 `linearization_lut_q15`/`electrical_zero_q15`/`mechanical_zero_q15` 等标定量
  纳入自身状态，也不得把估计角回灌到换相/位置路径。若确需用估计角做相位补偿，只能取
  预测角 `θ_est + ω_est·Δt`，且须单独评估，本计划不做。
- 处理：启动/换向/零速、抗饱和与输出限幅、**坏点门限**（相邻 20 kHz 样本 |Δθ| 超限跳过
  或 3 点中值）；死区取消或大幅缩小。
- RAM：状态仅几个 float；若替换 Phase 1 的估计器，净增很小（甚至净减）。
- **验收**：ISR 峰值重测（当前均值 29.3 µs / 峰值 42.3 µs，预算 50 µs）；台架低速/零速/
  换向行为；噪声与延迟优于 Phase 1。
- **前置**：若 Phase 0 显示传感器内部延迟主导，则 Phase 2 收益有限，可**不做**。

## 12. 风险

- **传感器内部延迟未知**：可能主导总延迟，使 Phase 2 收益缩水 → 先做 Phase 0。
- **RAM（已更正）**：normal 构建余 **2832 B**（含 3 KB 栈 + 512 B 堆，2026-09-23 实测）；
  此前"~40 B"是**已退役的 HIL 变体**。→ Phase 1 的 20 kHz 速率环（如 80 样本 × 2 B = **160 B**）
  与 Phase 2 观测器状态均可负担；实施后仍须复测 map。
- **ISR 预算紧张**：峰值 42.3 µs / 50 µs，新增计算须重测峰值与 PWM 截止余量。
- **测速消费方**：摩擦辨识/位置环/齿槽标定可能依赖现有速度动态，须逐一核对。
- **磁编码器坏点**：PLL 对单点跳变更敏感，必须补坏点门限。
