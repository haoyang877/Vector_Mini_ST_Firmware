### CAN 时钟约束

输入 SDK 的 `wk_can.c` 使用 PCLK 和整数分频/整数段长，厂商公式为
`bitrate = can_clock / (divider * (segment1 + segment2))`。
192MHz PCLK 配合当前144+48和36+12配置，分别得到1Mbit/s和4Mbit/s。
192MHz/5MHz=38.4，不能只改整数位时间段就得到精确5Mbit/s。

适配时需重新核定 AT32 的 CAN 时钟源、PLL/PCLK及位时序，必要时调整平台内部时钟树，
同时保持20kHz快环和2kHz监督等对外时序契约。不得使用近似5M或退回4M作为通过条件。
准确时钟方案、采样点与收发时序将在平台实现阶段验证；本页不将候选分频标为已实现。

### 电机温度输入更新

用户补充传感器规格为B3950、10K，记录为25°C标称阻值10000Ω、标称B值3950K。
这组参数属于外部电机NTC，不是MCU内部温度传感器的校准数据。
完整厂商料号、阻值/B值误差及B值对应温区尚未提供，后续精度验收时补齐。

后续适配已独立打开`R40_MOTOR_NTC_ENABLED=1`，
继续维持MCU内部温度开关`R40_TEMPERATURE_SENSING_ENABLED=0`。
不修改中间层、公共BSP接口、温度保护阈值或旧板行为；
电机温度只在底层验证镜像中显示独立诊断结果，不写入原有MCU结温字段。
原理图中NTC为3V3侧上臂，R92=1kΩ为下臂，R91=22Ω在ADC滤波支路。
25°C标称约0.300V/372计数，温升时计数上升。
详细换算与状态边界见[AT32平台说明](../../firmware/platform/at32f456/README.md)。
实测校核应包括常温阻值、ADC与电压对应关系、升温方向，以及断线/短路判定。

| 短时电流（幅值） | **约10.607A，持续30s** | 从此前确认的原始7.5Arms折算；30s不是热模型时间常数 |
| 最大电机轴转速 | **2500rpm** | 电机轴机械速度约**261.799rad/s**，不是电气转速或输出轴转速 |
| 减速比 | **8:1** | 按电机角/输出角=8记录；理想输出轴对应312.5rpm，不作为当前测试指令 |
| 电流环目标带宽 | **1kHz** | 所有适配电机统一要求；实际代码与存储参数分别核对 |

当前FOC的Clarke/Park为等幅值变换：平衡正弦相电流条件下，
`sqrt(id²+iq²) = sqrt(2) * I_phase_rms`。
新电机数据进入既有幅值A配置时需要明确转换，不能将2.5/7.5这两个RMS数直接当幅值。
这两个额度不自动确定首次调试限流、校准电流或板级过流阈值。

若按对称、非凸极的初始等效模型估算，线间电感的一半为142.5µH。
目前没有独立d/q测量证据，不能把该估算描述为已确认的Ld=Lq；定版模型时单独处理。

在当前等幅值dq变换下，Id=0时电磁转矩为`Te=1.5×p×ψ×Iq`，
因此按电机轴总转矩/Iq定义的`Kt=1.5×p×ψ`。
公式依据：[MathWorks PMSM Torque Estimator](https://www.mathworks.com/help/mcb/ref/pmsmtorqueestimator.html)。
YQ-5740仅改变减速比，磁链和电机转子惯量与5708相同；不在此折算输出轴等效惯量。
惯量目前只保存在独立型号配置中，不改变运行模型、通信字段或Flash布局。

## 10A幅值、10秒的功率级初步核算

用户进一步确认：本次10A指FOC的Iq/相电流幅值，不是10Arms，也不是母线电流。
以下按Id=0、三相平衡、正弦电流、不含PWM纹波估算；若Id不为零，应使用
`sqrt(Id²+Iq²)`核算。运动时每相有效值约7.071A，对应电机7.5Arms/30s的
短时额度以内，但不据此保证堵转、热启动或重复冲击工况。

### 器件与手册条件

原理图第2页为WSD6035DN33双N沟道DFN3x3封装，驱动FD6288Q，驱动电源标称12V，
各栅极串联2.2Ω；相线分流电阻为4mΩ/1W。
制造商手册采用[WSD6035DN33 Rev3.0 Jan.2024](https://datasheet.lcsc.com/datasheet/pdf/5aed9251c733122a21b073654e92d64e.pdf?productCode=C5185325)，
实际检查型号和第1至4页。网络搜索另有标题误指此型号但正文为WSD6042DN33的PDF，未采用。

手册列VDS=60V、VGS绝对最大±20V、结温上限150°C。
VGS=10V、25°C下Rds(on)典型20mΩ、最大32mΩ；100°C的典型归一化系数约1.6。
40A连续漏极电流标在Tc=25°C条件下，Tc=100°C对应18A；脚注另要求1平方英寸、
2oz铜的FR-4测试板及不超过10秒。114A脉冲值对应不超过300µs、占空比不超过2%，
不能用来证明10秒能力。

手册RθJA最大80°C/W、RθJC最大3.6°C/W；第4页瞬态曲线是结到壳，
10秒处已接近稳态，不能当作实际PCB的结到环境瞬态模型。
手册同时给出Ta=25°C的2.5W耗散，但它与80°C/W及150°C上限不能直接组成一致的
稳态热预算，因此不选取较乐观数字作整板额定依据。

### 计算结果与限制

同步导通的简化模型中，三相MOS总导通损耗为`1.5 * I_vector² * Rds(on)`。
计算未包含开关、体二极管、死区、纹波及PCB铜损。

| 项目 | 25°C典型20mΩ | 25°C最大32mΩ |
| --- | --- | --- |
| 三相六管总导通损耗 | 3.0W | 4.8W |
| 转动时每相上下管合计的周期平均损耗 | 1.0W | 1.6W |
| 堵转、某相保持10A时该相上下管合计损耗 | 2.0W | 3.2W |

以100°C典型温度系数1.6作敏感性估算，总损耗约4.8W或7.68W；
将最大室温电阻乘典型系数不是制造商保证的高温最大值。
零速Id=0仍可能出现某相10A、另两相各-5A，三相总损耗不变，器件间分配却更集中。

原理图U相为Q6.1/Q6.2，同属一个双管封装，需合计考虑热耦合；
V相标为Q9.2/Q7.1、W相为Q8.2/Q10.1，不能只凭此图假定三相各占一个相同封装。
需要PCB/BOM确认实装编号和散热铜皮，不按六个完全独立散热器计算。

相线4mΩ电阻在转动时每只平均约0.2W，堵转最大相约0.4W，
低于1W铭牌，仍需考虑实际焊盘温升和器件降额。
10A瞬时相电流对应放大器相对零点±0.8V，理想输出约0.85至2.45V；
采样范围有余量，不代表功率级热安全。按每相0.55Ω，绕组铜损约82.5W，
10秒约825J，未计电阻温升变化。

结论：器件电压/电流级别未直接排除10A幅值、10秒；可以作为后续验证目标，
不能仅凭40A或114A规格宣称本板已支持。需补PCB铜厚、铺铜/过孔及散热接触条件、
实装BOM，定义冷启动/热启动、转动/堵转及重复间隔，并在后续授权的台架测量中
核实Vgs、Vds尖峰、实际电流和温升。当前不改电流限值或热保护参数。
