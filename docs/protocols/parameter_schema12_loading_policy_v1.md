# 参数 schema12 装载与完整性契约 v1

> 兼容格式：当前写入schema14；本文及原向量保留用于仍受支持的旧版读取和兼容校验。当前装载规则优先见[schema14](parameter_schema14_storage_v1.md)。

日期：2026-09-29。schema12 新增持久配置确认与整条记录 CRC32；不转换旧记录，不自动回写。

## 存储布局与黄金字节

| 项目 | 值 |
| --- | --- |
| InterfaceParam | 4304 B，总长度不变 |
| configuration_flags | 偏移 2136 B，u32 小端；bit0 为明确配置确认，其余位必须为零 |
| record_crc32 | 偏移 2140 B，u32 小端；替代退役位置增益槽 |
| schema_version | 偏移 2160 B；黄金字节 0c 00 00 00 |
| magic_word | 偏移 2164 B；黄金字节 32 43 4e 45 |
| 参数分区 | 16 KiB，不移动 |
| TARGET_PARAM_ABI | 0x000C10D0，APP/Loader/打包工具统一 |

CRC32/ISO-HDLC，反射多项式 0xEDB88320，与 zlib.crc32 一致。首块 seed=0；
依次处理记录字节 0..2139 和 2144..4303，跳过 CRC 槽四字节。包含识别字、schema、
配置确认、保留槽、编码器 LUT 和齿槽记录的完整字节；保存时 Param_Upload 完成识别字和 CRC，
调用方不再补写会影响 CRC 的字段。计算仅在启动或停机前台进行，禁止在快慢环扫描记录。

[黄金向量](parameter_schema12_vectors.json)以独立 zlib 生成零填充记录的 CRC；
原生参数测试同时覆盖长度、偏移、配置确认、标定、输入不变和损坏记录拒绝。

## 装载与回退

- 仅接受 magic=0x454E4332、schema=12、CRC 正确、确认标志无未知位且内容有效的记录。
- 空白区使用未确认编译默认值；旧版/未来版/不支持识别字回退默认值，来源明确报告。
- CRC 或关键内容损坏回退未确认默认值，清除编码器标定和补偿，不报告“已配置”。
- 已装载当前完整记录时，configuration_flags=0 保持未确认；SAVE 本身不能赋予启动资格。
- 已确认但仅部分编码器标定的记录，重载后保持已确认/待标定；不能启动普通控制。
- 采样电阻不匹配会取消配置确认并保留既有电流域失效处理，需要重新核对板卡参数。
- DEFAULTS 清除配置确认和标定；随后自动保存仍持久化未确认状态，不会复活运行资格。

配置未确认与标定不足是正常准备状态，基础健康后留在 READY；启动与维护资格见
[基础自检与模式就绪 v1](../architecture/motor_readiness_v1.md)。启动只借用既有记录工作区，
不增加常驻记录副本，不擦写参数区。CRC 用于完整性检测，不提供真实性认证。

## 兼容和回退

schema11 的两个退役槽在 schema12 改为有意义字段，因此必须升级 schema/参数 ABI。
schema0..11、13 及未来版本均不迁移；旧标定不会自动成为新版本有效配置。现场现有参数
需要后续在匹配 APP/Loader 下重新配置、标定并保存；本次代码工作没有写设备。
回退到 schema11 APP 时不能读取 schema12 参数；需匹配镜像和单独恢复原参数备份。
线路 120/121/122 外层格式不变，新增 ID 为增量契约，旧主机可继续查询原有 ID。

剩余退役槽 reserved_pos_ki（2168 B）、reserved_pos_integral_limit（2176 B）和 can_hb
（2156 B）继续装载忽略、导出清零；没有旧功能包装或自动整定迁移。
编码器、退役齿槽占位和轴 profile 偏移不变。核心删减v3撤销齿槽/摩擦运行功能：
旧记录中的这些字段装载忽略，新导出清零；完整schema12记录CRC仍覆盖所有占位字节。
参数ID 0x47..0x4B退役且不复用，返回不支持；不自动重写现场记录。
Loader 只识别布局、schema/ABI 与节点，参数完整性/标定/确认资格由 APP 拥有。
