# MotorAxis 仅保留三个核心入口 v3

## 目标与范围

用户明确要求仅保留核心接口。Axis只公开Init、FastTick、SupervisorTick；
删除NodeId、ReadStatus、ServiceBackground和ServiceFastDiagnostics及其声明。
配置查询、状态快照和前台维护直接由现有参数、状态机、维护模块承接；运行诊断调度删除。
不新增生产文件，不公开Watch对象指针，不保留旧接口包装。

## 基线与约束

基线为本轮工作区，已包含2048拍校零和其他未提交修改；备份在
`outputs/motor-axis-three-api-20261030/before/`。回退仅撤销本轮补丁。
保留正常控制、命令/故障/STOP、状态反馈、参数与标定保存。状态机复用已有快慢环计数
核对状态快照，删除Axis重复计数。维护Init显式绑定配置和编码器终身对象。
只更改AT32链接脚本中的后台函数选择器，保持该函数原执行区不变。

## 验收

确认生产源码不再引用四个旧Axis接口；头文件只声明三个核心函数。
运行快环/校零、快慢抢占快照、参数保存及启动接线测试，进行两板离线编译、
格式/架构检查和release检查（链接输入有变动）；不烧录、不操作电机。
线上和存储ABI不变，删除的运行诊断不再出帧；未实测时序和目标资源不作等价承诺。
