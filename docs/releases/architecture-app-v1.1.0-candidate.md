# APP v1.1.0 架构发布候选

状态：准备中，尚未正式发布。类别为 debug，适用 STM32G431CB 的 normal 独立 APP。
正式产物的提交、资源、版本与哈希以同包 manifest.json 和当前 release summary.json 为准。

## 变更与实际范围

- 位置控制的 PI/Iq 核心与摩擦状态分开，组合层保留轨迹、HOLD 与积分协调。
- 编码器标定抽出标准值类型的 LUT/零位计算核心，任务保留采样与应用顺序。
- 齿槽采集任务与活动表/运行补偿分开，复用已有归约和表计算。
- 参数事务独占请求缓存、修订及保存票据，MotorAxis 保留单轴对象与调度。
- 已接入用户批准的八状态和出口；状态映射及 CLEAR/STOP 按[恢复契约 v1.2](../protocols/yg_protocol_motor_state_v1_2.md)登记。

保持控制数学、保护阈值、schema12 参数及 16 KiB 参数/身份区。
保留现用 Watch 观测符号；对外写入仍经过受控请求和对象接口。
采样/反馈模块直接使用明确平台能力属于真实硬件边界，不为形成更多层而增加空接口。
主机 GUI 真实设备接入、输出轴编码器以及位置扭矩域迁移不在本候选范围。

## 验证与部署边界

最终候选需要干净源码的 release profile 和匹配 normal 工件。离线通过仅证明该构建
及记录范围内的行为检查；新组合的实机运动、物理输出、动态栈与时序仍须实际验证。
当前另有台架会话占用设备，ROOT 不抢占、不下载、不复位、不更改参数或启动电机。

本包从 0x08000000 链接，不能由 Loader 当作配套 APP 升级。
配套 LoaderApp 从 0x08005000 链接并包含描述符，必须另外满足 94208 B 槽、容器/CRC、
试运行与恢复规则；未闭合不得把 normal 文件转换后声称可以 CAN 升级。
当前方案没有迁移 Flash 布局、放大芯片容量或删除电机功能。

首次新镜像验证前确认现场停机、真实关相、当前测试会话释放设备、原固件及参数备份，
并固定唯一源码与产物。STOP 或真实输出关断未确认时必须现场处置，不能自动继续。
原校准有效位/保存成功不代表转子实际对齐，不把原镜像成绩转写为新镜像 PASS。

回退使用明确备份及其匹配参数，由实际台架所有者执行；不能将 debug 候选作为默认量产镜像。
正式发布需补齐匹配候选的基本功能、保护与所发布升级链路的真实证据。
