## 目标、状态与计算边界

已有 `cogging_calibration` 只接收显式位置 rad、连续速度 rad/s、块平均 iq A、饱和事实，
在调用方状态对象内做双向 Q15 采样；已有 `cogging_map` 负责去均值、签名/CRC、有效性。
本轮不复制或修改这些算法及浮点求值顺序。

任务保留 20 kHz 安全观察/电流积分、2 kHz 更新与定点保持、暂存表和前台认领/保存通知。
新运行适配独占活动表、补偿请求/应用、力矩 guard 与同拍遥测，不读采样状态或任务阶段。
任务发布候选时通过既有 ImportMap 值复制接口交给运行所有者，再置保存挂起。
现有公开入口/类型/布局保持；旧头文件作为包含运行声明的兼容入口。
APP 继续拥有准入/功率、关相、epoch、工作区和真实 Flash 提交。

## 删除与接线

- 删除补偿准入在 CRC 之前读取、随后无条件覆盖的 mode/error 赋值，保留临界区复核。
- 删除私有 signature 包装，两处生产使用和既有成表夹具直接调用已有签名纯核心。
- 任务移除 string/critical/compensation 直接 include；补偿头只依赖 map，不依赖采样状态机。
- 新 runtime 源文件需要 Motor 组登记；提供 ROOT 可应用的条目补丁，不改用户 Keil 配置。
- 既有齿槽/成表夹具包含两份生产适配源；增加一个运行模块独立链接检查，不能借用任务符号。
