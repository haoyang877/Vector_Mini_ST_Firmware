### 0.2 全局复用组件（实现一次，全项目统一）

| 组件 | 用途 | 出现位置 |
|---|---|---|
| `NodeSelector` | 当前节点选择（绑定 AppState） | 工具栏 / 升级页 / 参数页 |

### 0.3 术语统一（全 UI 一致，禁止混用）

| 术语 | 含义 |
|---|---|
| 连接 / 断开 | 打开或关闭 CAN 适配器 |
| 扫描 | 探测 0–7 节点在线情况 |
| 读取 / 写入 | 参数 GET / SET（写后校验） |
| **保存到设备** | 发 `0x68` 写入 Flash（区别于"导出"到文件） |
| 升级 | 固件升级全流程（进入 Boot → 下载 → 激活） |
| 录制 | 曲线数据写 CSV |
| 诊断包 | 一键导出 zip（帧日志 + 参数快照 + 配置 + 版本） |

### 0.4 导航流

```
启动 → 连接页（未连接则引导打开设备）→ 扫描 → 选择节点
     → 参数 / 曲线 / 升级任意页
升级完成 → 提示"可回参数页验证"          曲线录制中 → 状态栏常显 ●REC
```

## 1. 设计原则

1. **设备优先**：先连接/扫描，全局维护"当前节点"，后续所有页面绑定该节点。
2. **全异步**：所有总线操作经 CanWorker 线程；UI 永不阻塞，点击立即反馈（忙碌态/进度/可取消）。
3. **安全默认**：危险操作二次确认（擦除升级、影响电机的写入、保存 Flash）；
   只读参数不可编辑；写入前按 schema 校验范围。
4. **一眼可见**：状态栏常驻连接/节点/遥测摘要/错误计数；任何失败可导出日志。
5. **单位统一 SI**（A、rad、rad/s、rad/s²、Ω、H、Wb、°C），数值 3 位小数。

│ [导出日志]                                                               │
└────────────────────────────────────────────────────────────────────────┘
```

**UI 状态机**（与服务层 1:1）：

```
IDLE → CHECK_IMAGE → ENTER_BOOT(0x66) → WAIT_LOADER(GET_INFO,≤5s)
     → BEGIN → ERASE → PROGRAM(进度) → VERIFY → ACTIVATE → WAIT_APP(≤5s) → DONE
                                                              ↘ FAILED(结果码+日志)
     任意阶段 [取消]：编辑态发 ABORT；擦除后提示"需重新下载完整升级"
```

- ERASE 前弹窗确认（"将擦除 APP 区，不影响参数"）。
- 升级前先读 `GET_STATUS` 展示当前记录（size/version）供对比。

## 5. 参数页（ParamsPage）

```
┌ 分组 ─────────────┐ ┌ 参数表 ────────────────────────────────────────────────────┐
│ 🔍[搜索名称/ID]    │ │ ID  │ 参数名           │ 当前值 │ 单位 │ 新值    │ 范围      │ 权限 │ 状态 │
│ ▸ 模式 (2)         │ │ 0x00│ SET_MODE         │ 0      │ –    │ [0    ] │ 枚举      │ R/W  │ ✓    │
│ ▸ 电流 (8)         │ │ 0x02│ SET_CURRENT      │ 0.000  │ A    │ [      ]│ ±6.0      │ R/W  │      │
│ ▸ 速度 (10)        │ │ 0x04│ SET_SPEED        │ 0.000  │rad/s │ [      ]│ ±30       │ R/W  │      │
│ ▸ 位置 (12)        │ │ 0x2D│ GET_VBUS         │ 25.10  │ V    │  —      │ —         │ R    │ ●    │
│ ▸ 位置阻抗 (10)    │ │ …                                                              │
│ ▸ 摩擦 (10)        │ └────────────────────────────────────────────────────────────────┘
│ ▸ 电机模型 (4)     │ ┌ 详情 ───────────────────────────────────────────────────────┐
│ ▸ CAN (4)          │ │ 0x04 SET_SPEED：固定点 crad32（×100），单位 rad/s，范围 0<x≤30 │
│ ▸ 遥测 (20)        │ │ 线格式: 4B BE int32；写后校验：读 0x05 比对（容差 0.01）        │
│                    │ └────────────────────────────────────────────────────────────────┘
└────────────────────┘
┌ 操作栏 ─────────────────────────────────────────────────────────────────────┐
│ [读取选中] [读取全部⏳] [写入选中] [写入并保存到设备💾] [导入] [导出]           │
│ 只读项 20 │ 未保存更改 3 │ 上次保存: 03:22:10 ✓                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

- **模型**：`ParamTableModel(QAbstractTableModel)` 按 schema 驱动；编辑 delegate 按编码分派
  （`mA16/mrad32/crad32` → 数值框，`F32` → 浮点框），提交即校验（红底+提示）。
- **变更态**：未保存行黄色高亮；单行"恢复"；[导出] 只导变更项（JSON）。
- **批量读取**：串行、带进度、可取消；无响应项标 ✗。
- **写入并保存**：写入选中项 → 逐项回读校验 → 发 `0x68 SAVE_PARAM` →
  轮询 `GET_MODE` 直到从 `Save_Param` 回到 `Motor_Disable`（判保存完成）→ 提示"已保存（Flash 写入约 N 次寿命）"。
- **安全提示**：写 `0x00/0x02/0x04/0x06` 类命令前二次确认"会切换电机模式"；
  `0x4E` 仅电机 Disable 时可写（不满足则禁用该行）。
- **兼容**：`0x29` 读走兼容路径（固件 bug）；GET-only 遥测用直接 GET 通道。

**子页切换**（参数页顶部）：`[ 在线参数 ] [ Flash 参数 ] [ 角度误差曲线 ]`

```

│ [读取 Flash 参数] [导出 JSON] [导出 CSV] [原始 blob] [与在线参数对比]            │
│ 记录: magic ✓ 0x454E4332 │ schema v10 │ 大小 2,240 B │ CRC32 0xA1B2C3D4 ✓ │ 03:30:12 │
├ 分组树 ──────┬ 字段表 ─────────────────────────────────────────────────────────┤
│ ▸ 基础/标识   │ 字段             │ 偏移  │ 类型      │ 原始值     │ 工程值 │ 单位 │
│ ▸ 电流标定    │ node_id          │ 0x00  │ f32       │ 0x3F800000 │ 1.0    │ –    │
│ ▸ 电机参数    │ currentoffset_a  │ 0x04  │ f32       │ 0x3A9D70A4 │ 0.0012 │ A    │
│ ▸ 电流环      │ …（共 40+ 字段）                                              │
│ ▸ 速度环      ├ 原始字节 (hex，选中字段高亮) ──────────────────────────────────┤

│ ▸ 摩擦        │                                                              │

- 读取：`0x69 INFO` → `0x6A` 分块（偏移 4 B + 数据 ≤56 B/块，≈40 次），带进度/取消；
  读完后整体 CRC32 与 INFO 返回值比对，不一致自动重读一次。
- 解析：`flash_schema.json`（由 `Foc/foc_param.h` 生成，字段名/偏移/类型/缩放/单位/分组），
  magic+schema 校验后逐字段提取；未知版本仅提供原始 blob 与 hex 浏览。
- 导出：JSON（全字段+原始值）、CSV（字段级）、blob.bin（可存档/对比）。

- **采样路径**：CanWorker 收帧 → `can_motor_status.decode()` → 20ms 批量 Signal →
  StreamService（每通道 numpy 环形缓冲）→ QTimer(60 FPS) 刷新 pyqtgraph（**渲染与采样解耦**）。
- 无效哨兵（`0x80000000/0x8000`）→ `NaN` 断线；统计 invalid 计数。
- 游标：双光标 + ΔX/ΔY 读数；暂停冻结视图（后台仍采样或可停采，二选一）。
- 录制：`time_s,node,fault,mode,position_target_rad,…` 与现有 `feedback.csv` 完全兼容；
  后台线程写盘，1k 行 flush，避免卡 UI。
- RTT 源（可选）：pylink 采集 12ch@2kHz → `rtt_control_frame.decode()`；曲线窗口与 CAN 共用渲染层。

## 8. 页面-服务数据流总览

```
                 ┌──────────────── CanWorker(QThread) ────────────────┐
UI 事件 ─请求─▶  │ 请求队列: scan/read/write/batch/update/streamCfg    │
                 │ 单循环: receive() → 分发                            │
                 │   0x7F0+  → decode → 20ms 批 → streamSamples Signal │
                 │   其他    → 匹配挂起请求 → requestDone Signal        │
                 │   错误帧  → CanRecovery → errorRaised               │
                 └────────────────────────────────────────────────────┘
ConnectPage ← connection/nodes      ParamsPage ← requestDone/tableModel
UpgradePage ← upgradeProgress       PlotsPage ← streamSamples (+Recorder)
LogPage     ← frameLogged/all
```

- 单请求并发度 = 1（无事务序号，必须串行）；批量任务内部串行并上报进度。
- 升级期间暂停状态流（带宽与确定性优先），结束后恢复原速率。

## 9. 固件配合改动（决策 A）

| 项 | 内容 |
|---|---|
| 命令 | `Communication/interface_can.h`: `CAN_SAVE_PARAM = 0x68` |
| 处理 | `interface_can.c`: 电机 Disable 才受理 → `Set_ModeNow(Save_Param)` → 回 OK；主循环执行 `flash_write_param()` 后回到 `Motor_Disable` |
| 上位机判定 | 发 `0x68` → 轮询 `GET_MODE(0x01)`，观察 `Save_Param`→`Motor_Disable` 迁移即保存完成（超时 3s）|
| **新增** | `CAN_GET_FLASH_PARAM_INFO = 0x69`：回复 magic/schema/size/record_crc32（16 B FD 帧）|
| **新增** | `CAN_GET_FLASH_PARAM_CHUNK = 0x6A`：请求 float32 offset（整数值）→ 回复 `[offset u32][len u8][data ≤56B]` |
| **前置改动** | 现协议回复仅 4 字节：需扩展 CAN-FD 回复缓冲（≤64 B）与发送路径（0x69/0x6A 专用路径）|
| 注意 | 确认 `Save_Param` 是否落在 `0x00 SET_MODE` 的可达枚举内（若可达，上位机将其从模式下拉中排除并备注）|
| 校验 | 写后保存前先逐项回读；保存需二次确认（Flash 擦写寿命提示）|

## 10. 样式与资源
