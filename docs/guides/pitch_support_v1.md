# Pitch 小电流支撑候选（V5位置优先修订）

本功能基于 v0.6.0，用于 mode 3 带阻尼 Pitch。本次修订已通过离线回归和普通 APP
构建，尚未完成该修订的实机验收；此前候选的台架记录不能代替本次验收。
目标是在静摩擦能承担负载时输出零电流，只在真实漂移后补足剩余负载。
没有卷簧曲线或静摩擦实测，不能直接算出最小支撑，也不能保证小电流上限足够。

## 控制过程

1. 首次捕获要求轨迹结束、滤波后的资格位置误差不超过 0.25°、原始位置误差不超过
   0.28°、速度不超过约 0.172°/s，并持续满足停靠条件 50 ms。原始位置多出的 0.03°
   只用于容忍量化噪声，不能替代滤波位置的 0.25°门限。若测速含噪声，连续300 ms资格
   位置跨度不超过0.04°也可提供独立静止证据；轨迹结束和位置误差门限仍须满足。近目标禁新增积分使用 0.25°进入、0.35°退出
   的滞环；进入停靠时清除速度 PI 和运动前馈。精确到位标志仍使用独立的位置误差窗口。
2. 支撑从零开始，原运动电流按卸载斜率平滑转移。静止且没有漂移证据时，不能直接
   把原运动积分记为永久支撑。首次卸流期间若确认向外漂移，且当前实际电流指令方向
   与漂移相反，则将该电流限幅后继承为支撑，停止继续向零卸载；超出支撑上限的剩余量
   仍平滑卸除。与漂移同向的推力不得继承。
3. 以进入停靠时的实测位置为锚点，使用独立初始化的位置滤波检测漂移。
   相对锚点移动至少 0.06°，且同向漂移持续 20 ms 后，向反漂移方向调整支撑。
   零支撑时朝目标内移不触发补力；固定目标残差不参与积分。
4. 连续 200 ms 未新增 0.025° 位移，或检测到向支撑方向回移，即冻结当前支撑。
   后续又出现持续的 0.06° 漂移时可以重新调整；已有非零支撑时，反向漂移可减小原支撑。
5. 支撑启用时，实际与资格位置误差均超过 0.4°并持续 50 ms，就进入普通受控回位，
   为 ±0.5°目标预留响应余量；非支撑轴保留原 1°、50 ms 外扰回位条件。
   非零支撑不阻止回位。支撑已饱和、正在调整且仍向目标外漂移时，门限提前到0.35°；
   同样连续确认50 ms。仅静止残差或仅触及电流上限不触发提前回位。
   回位和新目标从实测状态接回普通轨迹控制，旧支撑学习状态清除，实际电流交接给 PI。
6. 超出0.25°停靠误差死区时，附加有界比例纠偏：200 A/rad，最多1 A。它不累计到
   速度Ui或学习支撑中；与学习支撑合计仍受支撑/运行/热上限限制，并按现有斜率交接。
   固定残差在死区内不会新增电流；进入死区后比例项退到零。它不是重力模型或实测最优增益。
7. 粗支撑稳定且未饱和后允许执行一次有界的细减流，过程和停止条件见下节。
8. STOP/模式重置清除控制器状态。关闭支撑回到原零电流停靠路径。

这是一种局部、受限的“漂移后补力”，不是全局最小化算法。
每个目标的细减流结束后不周期性重试，避免反复下滑/回调；稳定后的电流可能高于实际最低值。
极慢漂移、静摩擦突变和支撑不足仍需要台架评价。0.25°捕获与 0.4°回位护栏用于减少
捕获残差和后续漂移的叠加，但不能单凭软件门限保证所有负载的动态误差始终小于 ±0.5°。
支撑上限不足时不擅自放大，保留正常回位及热保护接管。

## 单次细减流

粗调未在增补、卸流已结束、支撑未饱和、目标误差不超过 0.25°，并且位置稳定、总电流指令已跟上
支撑目标时，持续确认 300 ms 后启动。每次将支撑电流的绝对值减小 0.15 A，不反转符号，
最低减到零。最多执行 10 档，不额外提高已配置的支撑上限。

每档先等待总电流指令与新支撑目标的差不超过 0.001 A，再开始 500 ms 的观察期；
指令尚在斜率交接时不能提前消耗这 500 ms。这个跟随条件针对控制器输出的电流指令，
不等同于实测相电流已经稳定，后者仍需由台架曲线验证。

整次细调使用启动时的固定位置锚点，不能逐档重置以掩盖累计回退。出现以下任一条件，
结束本次细调：

- 相对整次锚点位移达到 0.06°，或目标误差达到 0.25°，且持续 20 ms。
- 一档的 500 ms 观察期结束时，相对该档起点的位移超过 0.025°。

若位移与上一稳定档的支撑方向相反，恢复上一稳定档；若位移与支撑同向，则保留已减小
的电流目标，不重新增大推力，并交回原漂移补力及回位判断。整次护栏使用整次固定锚点
判断方向，单档护栏使用该档起点判断方向。

500 ms 观察期通过后，当前档才成为新的稳定档。减到零或用完 10 档后保持最终档，
同一目标不自动重新开始细调。回滚的电流目标也受当前运行、支撑及热上限约束，并按
电流斜率交接。热降额取消本次细调，不把之前保存的较大电流重新恢复；新目标、STOP
和模式重置清除旧细调状态。

这是有限分辨率的局部搜索；缓慢漂移、传感器噪声和静摩擦迟滞可能使某档看似稳定，
也可能让搜索提早结束。冻结之后仍保留漂移补力和受控回位。不能把固定位置输入下减到
零的离线结果，当作真实屏幕负载能够零电流保持的证明。

## RAM 调参

| 变量 | 缺省候选 | 单位/用途 |
| --- | ---: | --- |
| `MotorControl.position_support_limit_a` | 3.0 | A，独立支撑上限；0 关闭 |
| `MotorControl.position_support_adjust_a_per_s` | 2.0 | A/s，漂移时调整速度 |
| `MotorControl.position_support_release_a_per_s` | 2.0 | A/s，从运动电流卸载/交接速度 |

当前默认采用本轮台架使用的 **3 A / 2 A/s / 2 A/s**，依次对应支撑上限、调整斜率、
卸载斜率，替代此前的 **1 A / 0.5 A/s / 2 A/s**，避免重启后退回旧候选值。
默认值与测试设置一致不表示本次修订已完成实机验收，也不代表 3 A 已获持续热额定验证。

实际学习斜率不超过上述两斜率较小值，防止内部估计跑在施加电流前面。
实际支撑上限为本表、运行限流、热可用电流三者最小值；热限幅允许立即收紧。
当上限大于零时，两斜率须有限且在 (0, 1000] A/s 内。仅已验证 Pitch 身份且启用阻尼
时接入此功能。其它轴即使 RAM 中有这些默认值也保持原控制策略。

这是独立候选上限，不是已验证的连续热额定值；不提高现有运动限流。
修改请先停机。三个变量仅在 RAM 中，复位或重新加载 Flash 参数时恢复默认。
`mode=9` 不保存这些候选参数，现有 Flash schema/记录长度及 CRC 范围保持不变。
后续若决定持久化，应新增版本化尾记录及兼容测试，不能挪用已有参数字段。

## 观测

通过现有 `MotorOuterLoop_GetTelemetry()` 获取发布快照：

- `support_current_a`：有符号支撑估计，A。
- `support_adjusting`：本次漂移后正在调整。
- `support_refining`：本次单次细减流正在交接电流或观察档位稳定性。
- `support_limited`：本拍学习支撑触及上限，或学习支撑加比例纠偏受上限截断。
- `passive_confirm_ticks`：连续满足被动捕获资格的控制更新拍数；2 kHz时50 ms对应100拍。
- `qualification_position_rad`：用于资格判断的滤波位置，rad；结合目标计算资格误差，
  不要把原始位置的单次量化跳变当作滤波位置已越界。
- `hold_current`：仍表示速度 PI 的 Ui；不是支撑电流，停靠时应为零。
- `feedback_current`：停靠时表示总指令减学习支撑，包含有界比例纠偏及尚未结束的交接量，不等于速度积分。

总 Iq 包含交接剩余量，所以刚停靠时可高于独立支撑上限，但不超过运行/热上限。
已有 CAN 与 RTT 帧格式未改；本次新增观测字段只在内部 RAM 快照。

## 离线验收

`tests/unit/pitch_support_test.c` 验证噪声、双向漂移、冻结、限幅、热收紧、外扰回位、
新目标交接、重置、无效配置和 1/2 kHz 一致性，以及收紧捕获、已有捕获残差时的回位护栏、
卸流中保留有效反漂移电流、拒绝继承同向推力；原控制器及参数兼容测试继续运行。
细减流回归还覆盖每档 500 ms 的起算条件、静止输入下减到零、漂移回滚前一稳定档且不重启、
两个退出入口均不向同向运动追加推力、热限幅不恢复旧电流，以及新目标清理并允许新的单次尝试。
边界量化回归覆盖均值约0.2393°、原始码间歇达到0.2502504°时仍能捕获，并确认真实固定
误差0.27°不能借原始位置余量被误捕获。
这些是注入反馈的确定性测试，不是屏幕/卷簧/阻尼机构的实机性能证明。


## V5验证范围

新增回归覆盖：1/2kHz下测速偏置但位置静止时能够捕获、真实移动不能借该资格提前捕获、
双向有界比例纠偏且速度积分保持零、饱和外漂在0.4°之前回位。
新增逻辑尚未进行实机测试；V4的局部通过点和失败点不能视为V5通过证据。
3A不足以抵抗负载时，比例项和学习支撑都不能突破上限，软件不能承诺所有角度可持续保持。
重复性测试还必须覆盖不同进近方向、卸流回弹和足够的热裕量。
