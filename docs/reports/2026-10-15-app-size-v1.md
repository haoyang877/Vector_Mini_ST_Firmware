## 改动及兼容性

- mode 18 的运行适配和复位引用已移除；map 确认阻抗控制模块被链接器完全裁剪。
  源码保留供后续恢复，不再进入 APP 镜像。编号 18 及参数字段不删除、不复用。
- CAN 请求在既有保护准入后拒绝 mode 18，不切换当前模式；直接写入 ModeNow=18
  则清零 Id/Iq 指令、报现有参数错误 12，并进入既有 STOP 关相路径。
- 正弦表由 1024 点缩为 512 点，原采样网格和合法索引输出保持逐位一致；浮点
  归一化舍入到周期末端以外时环回零索引，避免越界。显式处理正零，避免 ARMCC
  快速浮点优化将原表正零变成负零。
- mode 3、速度环、角度与电零位标定、备用摩擦常量、参数布局、分区和 CAN
  编码保留。未修改任何电机参数、限流、RTT 缓冲、堆或栈。
- `tests/vectors/app_size_v1.json` 固定旧表 IEEE754 哈希及 mode 18 拒绝行为；
  现有参数和版本协议向量保持不变。软件版本已递增为 v0.5.3，软件版本查询向量同步更新。

## 验证及限制

- 55 项 Python 单元测试、36 项集成测试、22 组原生检查通过；初次缺少 NumPy，
  已使用现有完整环境补跑 Python 测试通过。
- 新增 1,004,102 点角度扫查、全部 1024 个旧表值逐位比较、多周期/负角和周期
  舍入边界检查；实际 ARM 镜像内的半波表也与基线前半表逐字节一致。
- mode 18 的通信准入拒绝、运行模式保持、既有错误保持、直接调试写入转 STOP
  均通过离线检查。实际硬件关相和电机运行未在本轮测试。
- 正常和 HIL 两目标重新构建均 0 错误、0 警告；Keil 路径检查两目标均 0 错误；
  `git diff --check` 通过。
- ARM 反汇编确认新增查表路径有界，无循环、分配或库正弦调用；增加了镜像索引
  和符号处理指令。没有使用主机耗时推断 MCU 的 20 kHz ISR 时间，实机 WCET
  及电机表现待授权台架验证。
- 本历史节点没有统一 verify、format、lint 命令，采用已有离线测试、工程检查
  与 Keil 构建，不能宣称新架构的 release profile 已通过。
