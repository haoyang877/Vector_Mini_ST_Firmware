# 按 PWM 扇区重构相电流 v1

## 目标和边界

按用户要求优先增加两相测量、第三相重构，减少高占空比相的低侧无效采样对 Id/Iq 的影响。只修改代码、运行离线检查和普通固件构建，不烧录、不进行台架测试；不处理 HIL 既有问题。

基线：当前 `codex/ovp-36v` 工作区，保留用户已有改动。原始分析见 `outputs/speed_step_02_analysis/report.md`；本轮源码备份、测试和构建证据位于 `outputs/current_reconstruction_20260924/`。现有电压圆半径 0.95 Vbus/√3、20 kHz 电流环、2 kHz 速度环、5 kHz RTT、ADC 顺序和 4× 过采样保持原配置。

## 实现

- 平台接口在 ADC2 完整注入序列结束后、当拍任何 PWM 写入之前，读取上一拍的 PWM 比较值，按当前 SVM 占空比顺序推导采样扇区。当前 CCR 预装载在上一个计数谷值已生效；该接口依赖 PWM 仅由快中断写入的现有调度，不声称寄存器能直接读出硬件影子值。
- 扇区 1/2：保留 Ia、Ib，Ic=−Ia−Ib；3/4：保留 Ib、Ic，Ia=−Ib−Ic；5/6：保留 Ia、Ic，Ib=−Ia−Ic。并列最大优先舍弃采样更晚的相。
- 三相 PWM 未完整使能、无主输出、非法比较值或等占空比零矢量时不重构。零偏校准继续使用原始 ADC。
- 在 `Current_Cal` 内完成重构，电流控制、观测器及诊断共享结果。过流判定同时检查原始三相和重构结果，确认周期和阈值保持原值，不用重构掩盖原始过流。
- 无通信/参数 ABI 变更，不新增 FOC 状态字段，不修改 PWM 启停顺序或控制 PI。

## 验收与限制

执行实际平台函数、重构函数和 `Current_Cal` 的主机 C 检查：六个扇区、正反方向、边界/并列值、停机与重新使能、零矢量、模拟故障相、原始与重构过流、零偏异常；遍历实际 SVM 输出验证被丢弃相确为最大占空比。运行现有 ADC 配置检查、可用离线回归和普通 Keil 全量构建。

当前分支是旧工具结构，没有根目录 uv 项目或新 `verify --profile pr/release`、`format`、`lint` 命令；使用本分支实际提供的入口并记录结果，不宣称新验证 profile 通过。

两相重构要求保留的两相采样有效；高调制度扇区边界可能两相同时窗口不足。该增量不保证全调制范围，也不消除三相顺序采样的时间偏差。是否降低 Id 尖峰及最坏执行时间仍须后续明确授权的实机验证。
