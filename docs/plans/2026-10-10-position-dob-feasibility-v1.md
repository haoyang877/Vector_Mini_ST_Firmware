## 结论与当前实现对照

推荐保留现有电流环、平滑轨迹、速度阻尼、总限流及保护，先验证低带宽残差 DOB。不能直接删除速度反馈，也不能将完整 DOB、固定摩擦前馈及旧速度积分直接叠加。

| 环节 | 当前工作树 | 候选方案 |
| --- | --- | --- |
| 轨迹 | 静止到静止使用 PositionSmooth；运动中改目标用在线限 jerk 路径 | 复用，先不同时改规划器 |

| 惯量前馈 | 已有 J/Kt 乘参考加速度的 RAM 参数，默认 0 | 复用，核实实际 Kt 与 J；默认 0 不代表已启用 |
| 摩擦 | 正反向模型、斜率限制、接近卸载及恢复逻辑 | 标称摩擦补偿加残差 DOB，逐步替换经验证冗余的恢复逻辑 |

`position_cascade.c` 是控制状态的所有者，`foc_run.c` 组装参数。当前纯位置模块没有实测 Iq 输入，不能简单拿未限幅 IqRef 代替真实作用力矩。接入需要通过一致时刻的控制快照传递实测 Iq，不能在位置模块直接访问 ADC/HAL 或可变 FOC 全局量。

历史 `2026-10-10-near-target-stop-bench.md` 记录小角度一组通过末段误差，但扩展 +30°失败；不应将现状作为全范围已通过基线。

## 扭矩与停止距离

模型为 `J*a = Kt*Iq - d`，d 是有符号的合并负载，包括摩擦、重力等。

动摩擦范围 1.6～2.4 Nm。忽略其他负载、扭矩降额与电流跟踪误差时：

| 加速度 | 惯性扭矩 J*a | 加最大动摩擦后的需求 |
| --- | ---: | ---: |
| 30°/s² | 0.298 Nm | 2.698 Nm |
| 45°/s² | 0.448 Nm | 2.848 Nm |
| 90°/s² | 0.895 Nm | 3.295 Nm |

最坏动摩擦下理论加速度上限 `(4-2.4)/0.57` 约 160.8°/s²，这不是建议整定值。静摩擦若接近或超过 4 Nm，任何控制器都不能保证启动；若脱黏后摩擦骤降，仍可能顿挫。峰值扭矩不能等同长期可用扭矩。

以 90°/s 运行，若仅撤掉输出并靠摩擦停止，理想距离 `J*v²/(2*Tf)` 在 1.6/2.0/2.4 Nm 时分别约 25.18°/20.15°/16.79°。只撤掉摩擦前馈、却保留同向 Ui 时，不满足此假设，距离可更长。这解释了固定卸载位置不鲁棒。

现有轨迹减速度封顶 30°/s²；90°/s 对应理想匀减速距离 135°，还未计 jerk 与延迟。因此大范围运动也未必达到 90°/s，不应把最大速度设定值当成实测峰值。

DOB 不替代停止距离规划。应使用保证可用的主动净制动力矩、速度上界、初始加速度、jerk、延迟及限位余量；未知未来最小摩擦时，不把摩擦作为安全制动能力保证。

## 最小候选 DOB

先统一 Nm、rad、s，末端除 Kt 转成 A。名义惯量为 Jn，实际电流对应电磁扭矩 `tau_m=Kt_n*Iq_measured`。

总扰动估计：`d_hat = Q(s) * [tau_m - Jn*s*omega]`。

若保留标称摩擦 `tau_f0`，使用残差：

`d_res_hat = Q(s) * [tau_m - tau_f0 - Jn*s*omega]`

`tau_cmd = tau_feedback + Jn*a_ref + tau_f0 + d_res_hat`。

两者只能选择一致的一种定义。总扰动已经包含摩擦，不能再额外叠加完整摩擦补偿。饱和、扭矩与测速不同步、Kt/J 偏差都会进入估计残差。

避免裸微分。候选使用 `Q(s)=g²/(s+g)²`，两级一阶滤波实现。令速度滤波状态 `z1=L(omega), z2=L(z1)`，`L=g/(s+g)`，则惯性项可写为 `Jn*g*(z1-z2)`；力矩残差通过相同两级滤波。该式是连续模型，实现时需一致离散化、启动初始化及延迟对齐测试。

5 Hz 速度低通时间常数约 31.8 ms；若只给速度加延迟而不给力矩通道匹配，DOB 会把真实加速度误认为负载变化。±0.025°幅值不能确定速度噪声频谱，也不能直接据此选观测器带宽。候选从低于现有速度滤波带宽的 1～2 Hz 做离线扫描，再比较 3 Hz；这些只是试验起点，不是最佳值或稳定性证明。

先 shadow 模式只记录估计，不出补偿。闭环接入时必须规定：旧 Ui 与 DOB 的承载交接、补偿限幅和变化率、饱和恢复、反向过零、故障重置与目标切换。不能在非零 Ui 时直接清零并启用尚未收敛的 DOB，也不能双重补偿。

静止时静摩擦是一个可取区间的约束力，DOB 不能据静止数据辨识唯一的脱黏阈值。要求零电流被动保持时，确认停靠后受控卸掉所有主动补偿；只有最低静摩擦能承托外载，才可能同时满足零保持电流与定位要求。存在重力或弹性回弹时，应允许主动保持或明确机械条件，不能依赖 DOB 无条件保证。

## 精度预算与验证

目标真实误差 ±0.2°、位置噪声峰值 ±0.025°时，仅考虑噪声，测量误差验收界最多为 ±0.175°；还需扣除零位/标定偏差、结构弹性、判定延迟和退出后的漂移。原 ±0.18°软退出加噪声已达 ±0.205°，不能保证严格的真实 ±0.2°。

候选 ±0.06°进入、±0.12°退出可作为初始判定窗口，二者间隔大于已知噪声峰峰值 0.05°。连续 200 ms 是抗抖候选，不能阻挡真实外移的快速保护；还须独立限制速度和角度漂移。该窗口不等于屏幕真实精度，也不能解决制动。

测试顺序与验收：

1. 固化当前源码/参数/编译产物基线。候选关闭时真实 C 输出、状态、故障及 ABI 与基线一致。
2. 实际 C 控制器闭环仿真：J 标称及 ±30% 假设偏差、动摩擦 1.6/2/2.4 Nm、未知静摩擦参数扫描、±0.025°多频噪声、偏置、反馈延迟、电流滞后、重力/弹性扰动、饱和、双向及途中改目标。偏差范围是应力场景，不伪称实测。
3. 保留同轨迹比较：现状、仅惯量前馈、加入残差 DOB。固定旧传感器回放只能检查算法，不能当成新闭环仿真。
4. shadow 记录实际 Iq、参考/实际 q 和 w、参考加速度、Ui、模型 FF、估计扰动、总 Iq、饱和及状态。不能仅凭现有十通道图判定 DOB 是否正确。
5. 实机由小角度、低速到大角度与最高速度；分别评价启动、制动、末段 2 s 误差、10 s 保持漂移、电流波动、过冲和反复纠偏次数。独立角度测量才可验证真实屏幕精度。顺滑还需现场感受及带宽定义清楚的加速度/jerk 指标。
6. 最坏执行时间必须满足现有 2 kHz 调度；不允许额外漏拍、ControlOverrun 或削弱 STOP/关相。STOP 或输出关闭无法验证即停止，不能自动重试。

第一阶段参数放 RAM，不改持久化 ABI；若遥测/参数协议需要变更，独立版本、黄金向量和兼容测试。回退以默认关闭候选为第一步，完整镜像回退必须匹配符号并保留个体标定。
