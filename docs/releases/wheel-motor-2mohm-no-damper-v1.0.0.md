## 已执行的实物验证

2026-09-17，同一块 2 mΩ 驱动板、8S 电池约 28.1 V、无阻尼器电机、架空空载条件：

- 完成 mode 13 编码器 LUT 标定，再完成 mode 15 电零位标定；重启回读保存有效。
- 本台左轮 node=1，电零位 24973、标定标志 3、reverse=0。这是单台电机参数，未写入通用固件默认值。
- mode 13 交接采样峰值 375.595 rpm；本次经授权使用主机 400 rpm 监测停机阈值。该阈值仅属于测试脚本，未新增 MCU 400 rpm 硬实时保护，也未提高正常轮速上限。
- 速度环 Kp=0.02、Ki=0.5；测试临时限流 2 A，数值上升/下降斜坡分别为 20/10 rpm/s。
- 执行 `0 → +10 → 0 → -10 → 0 rad/s`，各运动/减速阶段 15 秒，最后 3 秒统计；位置积分平均速度分别为 +9.989、-9.991 rad/s，满足本次平均误差 5% 判据。
- 对应采样速度 RMS 误差为 0.206、0.299 rad/s；全程 Iq 采样峰值 0.243 A，无故障。
- 结束后相位 PWM 关闭、mode=0、fault=0，运行限流恢复 6 A，Flash 参数区保持不变。

完整原始记录在交付包 `validation/` 中：标定报告及 `speed_203852` 报告/CSV。
构建、原生 C 测试、RTT 接口测试、Flash 范围及镜像一致性结果由交付清单记录。

## 部署与已知限制

- 本包为直接启动 APP，HEX 自带地址，APP 区为 `[0x08000000, 0x0801C000)`；参数/保留区为 `[0x0801C000, 0x08020000)`。仅烧写 APP HEX，保留参数区，不能整片擦除或把此镜像作为偏移 Loader APP 使用。
- 本轮交付验证基于 J-Link/SWD。未在本轮验证 CAN 升级、Loader 兼容性、断电升级恢复或负载全速运行，不将其列为已通过项。
- 空白参数板默认 node=0、未标定，速度 Kp=0.05、Ki=0.5；已有有效 NVM 参数优先。烧录通用 APP 不会自动将其他电机变成本台已标定左轮。
- 新电机须配置正确节点并独立完成标定；本台的 24973 电零位和 LUT 不作为通用参数交付。当前 ±10 rad/s 实物结果来自 Kp=0.02 的已配置电机，不代表空白板默认参数已经实测。
- 3 rpm 测试曾出现约 20.14 rpm 超调并触发主机停机，低速问题尚未修复。±10 rad/s 通过不能替代低速、负载、温升、最高转速及全部保护测试。
- 直接 SWD 写 ModeNow=0 曾出现相位输出未关闭的情况；本次测试停机使用直接关断相位输出后复位，并验证输出关闭。该观察不等同于 CAN 正常停机路径验证，根因未在此版本修复。
- mode 3 中观测器更新策略沿用原代码，虽然 RTT 持续发帧，观测器字段可能不更新。
- 本机 Keil `.uvoptx` 会话改动不属于构建配置，保留于原工作区，不纳入交付提交。交付镜像从提交导出的干净源码重新构建。
