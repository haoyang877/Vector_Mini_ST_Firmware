# 10 rad/s 运行中 q 轴响应与低延迟测速验证

台架使用 AT32F456、YQ-5708（8:1）和已持久化的新标定表。测试中电流环保持 20 kHz，速度环保持 2 kHz，速度为电机侧 rad/s。原参数为速度 PLL 90 Hz、Kp=0.015、Ki=0.3、限流 3 A。各项测试在原配置之外只使用 RAM 试验设置。

## 测量方法

独立诊断镜像在 20 kHz 快拍上产生有限时长的正弦。测 q 轴时，电机在速度模式保持 10 rad/s，在速度 PI 输出之后给 q 轴增加 0.060 A 峰值的扰动。同时解调送入电流环的总给定、实测 Iq、速度 PI 输出和测速。每点先丢弃 8192 拍，再独立积累两个 32768 拍窗口。电流响应以实测 Iq 除以实际总给定；同一注入得到速度环返回比，即速度 PI 输出相量取反后除以总给定相量。开环增益交越与相位裕量按实测返回比插值。

测速度闭环时，给 2 kHz 速度目标增加 0.20 rad/s 峰值的扰动，在速度斜坡之前记录实际保持的速度指令；输出为当次被速度 PI 使用的反馈。两个同步窗口各 65536 个快拍。频率响应报告正弦单边幅值之比。恒速波动使用独立 7 秒无注入段，并始终保留 90 Hz 观测和补偿机械角差分作共同参照。测速器之外的换相、速度预测和新表保持原路径。

诊断程序的电流、速度、心跳及注入时长均有限制。每组结束关相、恢复速度包络和 PI、回读 RAM。镜像切换前备份 Flash，确认只改写应用区，并校验参数及身份区逐字节一致。

## q 轴

原 PLL 和原 PI 下，两个独立运行的实测 Iq 对总给定在 1.20 kHz 分别为 −9.37 dB、−9.44 dB，相位约 −96° 至 −97°。相对单位跟踪增益的 −3.01 dB 交点约为 400、421 Hz。在第二次运行，9.8、14.6 Hz 的增益为 −0.85、−0.81 dB；若以这个低频实测增益作基准，则再下降 3 dB 的频率约为 0.56 kHz。因此本工况应按数百 Hz 的运行中 q 轴响应设计。120 Hz 附近的相位滞后约 16°。此前的 1.19 kHz 是另一次 d 轴试验。

## 32 kHz 更新率

用户给出的电流环更新率上限是 32 kHz。本轮采用 20 kHz。若改用 32 kHz，半拍保持延迟可由 25 µs 降到 15.625 µs，在 120 Hz 约减少 0.4° 相位滞后。这只计算保持环节。若以后验证 32 kHz，还应单独核对中心对齐 PWM 的计数周期、ADC 触发位置、31.25 µs 快环执行预算，以及监督、速度和位置环的分频；保留 2 kHz 外环时分频应从 10 改为 16。32 kHz 的板上效果本轮未测。

当前 AT32 定时器 180 MHz，中心对齐精确 32 kHz 需要半周期 2812.5 个计数。现有 BSP 对整数分频作编译期检查，单改 FOC_FREQ 会触发该检查。若安排独立升频试验，30 kHz 可在当前时钟下精确分频（半周期 3000、外环分频 15）；使用 2813 计数则需按约 31.994 kHz 的实际频率明确处理时基。

## 测速器对照

按当前离散 PLL 更新式，在 120 Hz 处，90、300、600 Hz 三种设置的测速增益分别为 0.502、0.999、1.005，相位分别为 −111°、−31°、−13°。把同一段电角度回放给三者，24 阶速度峰值分别为 1.763、1.793、1.794 rad/s。回放数据来自 2 kHz 导出，插值到 20 kHz 只用于核对低阶差异。理想独立 16 bit 量化白噪声下，三者的速度输出噪声约为 0.0016、0.0102、0.0309 rad/s RMS。此值是模型估算。

实际闭环中，保持原 PI 仅切换反馈，90 Hz 下选中反馈的 24 阶约 1.76 rad/s，300 Hz 下约 1.16 rad/s，600 Hz 下约 1.09 rad/s。恒速反馈 RMS 占目标的比例相应为约 13.0%、9.1%、8.7%。提高测速自然频率后，旧 PI 的闭环峰变平，指令到速度的 −3 dB 截止也改变。测速自然频率与速度闭环带宽是两个独立指标。

## 正常 CAN 入口与结论

正常 CAN 目标的峰值为 0.24 rad/s，记录每次发送、受理回复、2 kHz 同帧的实际目标、斜坡输出及反馈速度。试验使用同一协议和硬件，分别比较主机串行收发/采集，以及 CAN 和探针各用一个线程。下表以板上实际收到的目标到实测反馈为口径，按相邻可信频点对首次 −3 dB 交点插值。

| 600 Hz PLL、Kp=0.0335、Ki=0.67 | +10 rad/s | −10 rad/s |
| --- | ---: | ---: |
| 独立收发/采集的实际 CAN 指令速率 | 420–561 次/s | 492–554 次/s |
| 120.0 Hz 的增益 | −2.37 dB | −2.43 dB |
| 120.0 Hz 的前、后半段增益 | −2.60 / −2.52 dB | −2.62 / −2.55 dB |
| 首次下降到阈值的估计 | 126.6 Hz | 136.0 Hz |
| 相邻实测频点包围 | 124.3–129.3 Hz | 134.7–140.2 Hz |
| 板内同步注入截止 | 141.1 Hz | 138.6 Hz |
| 7 秒恒速反馈标准差 | 0.567 rad/s | 0.574 rad/s |

正转 129.3 Hz 的增益为 −3.43 dB，134.7 Hz 回到 −2.57 dB，140.2 Hz 为 −3.60 dB。应将 126.6 Hz 理解为首次交点；整段并非严格单调。负转 129.3 Hz 的 −2.95 dB 接近阈值。两方向在 120 Hz 处参考斜坡本身分别衰减 0.35、0.28 dB。板上目标与根据收发时刻重建的输入给出相近的幅值结果。

在旧式串行调试程序中，指令速率约 235–318 次/s，高频指令有效幅值较小。综合重复试验，首次交点估计约为正转 117 Hz、反转 116 Hz；不同频点的半段波动较大。主机发送节奏和信号幅值属于 CAN 入口测量条件。因此 120 Hz 的验收针对上述独立收发条件和 ±10 rad/s，不能外推到任意主站更新率或全部速度域。

20 kHz 电流更新率下已达到本运行点的 120 Hz 目标。最终候选的速度环相位裕量约 62°，在已测板内频点峰值分别约 +0.40、+0.32 dB。转速标准差约为 5.7% RMS，仍大于 3%；24 阶单边峰值约 0.63 rad/s。即使从正转记录中扣除拟合的 24 阶，剩余标准差仍约 0.35 rad/s。轴速和编码器误差的分离仍需独立测量。
