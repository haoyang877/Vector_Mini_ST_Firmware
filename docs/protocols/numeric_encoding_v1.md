# 数值编码等价实现 v1

日期：2026-09-28。适用：CAN 电机反馈及活动参数读回的 Flash 优化。

## 保持的契约

线路字段长度、单位、消息版本、有效位和错误码均不变；不增加旧格式兼容入口。
状态转换仍按 `round((double)value * scale)` 的半值远离零规则取整，然后检查
允许区间；i16/i32 最小值保留为无效哨兵。

参数转换保留原算法先加正负 0.5、检查 i32 边界、再截断的顺序。它和状态转换
在端点的接受语义不同，因此分别保持私有实现，不能用一个近似的 float 强转代替。
参数转换失败时不修改原始值输出。

| 输入 | 缩放 | 状态结果 | 参数结果 |
| --- | ---: | ---: | ---: |
| 0.0625 | 1000 | 63 | 63 |
| -0.0625 | 1000 | -63 | -63 |
| 1.25 | 1000 | 1250 | 1250 |
| +0 或 -0 | 1000 | 0 | 0 |
| NaN 或正负无穷 | 1000 | 无效哨兵、有效位不置位 | OUT_OF_RANGE |
| 400 V 母线电压 | 100，i16 | 无效哨兵、有效位不置位 | 不适用 |

## 实现边界

输入为本工程使用的 IEEE-754 binary32。通过 memcpy 取得位模式，拆出符号、
指数、24 位有效数，以 u64 乘正整数缩放；当前缩放只有 100、1000、10^6、10^9。
这些乘积不会溢出 u64，且与原 double 乘法的值一致：例如 10^9 含 2^9 因子，
去除该因子后的有效乘积最多 45 位，小于 double 的 53 位精度。

有界移位获得整数部分与最高丢弃位，实现半值远离零；非有限值直接拒绝。参数
端点额外区分精确半值，保留加半后检查的语义。新缩放不得未经验证接入此实现。
参数描述表的 scale 改为 u32，当前所有值转换回 float 都精确，写参数的 SI 换算
和产品范围检查不变。代码不分配内存、不调用硬件，不修改全局浮点设置。

## 验证与资源

- `tests/unit/native/test_numeric_encoding.py` 直接编译生产私有转换，对照冻结的
  `f0c2517` double 算法：49358928 次结果/拒绝/失败输出比较通过。
- 覆盖随机位模式、全部指数段和双符号、subnormal、NaN/无穷、整数上限附近的
  相邻 float，以及正负半整数附近的相邻 float；通过真实参数目录读取所有标量。
- 现有协议核心测试继续核对完整 45 B 反馈黄金向量和无效值有效位。
- ARMCC5 重新链接后双精度相关库对象移除；普通 APP 和 Loader APP 各净减少
  2096 B，RAM 不变。该数值已包含替代实现和整数运行库开销，不是库对象的简单求和。

本次为离线数值与构建验证，没有设备烧录或实机时序验收。
