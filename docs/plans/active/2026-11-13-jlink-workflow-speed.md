# J-Link 初装流程与擦除耗时

## 目标与基线

简化 CAN-Link-Test 的初装入口，消除擦除遗漏 SWD 提速的性能问题。
基线为 ca36b9cf；历史整片擦除记录耗时24.256秒，其中擦除阶段约2.39秒，
擦除流程未调用已有的速度试读，全部备份/回读停留在1000 kHz。

## 不变行为与范围

不改变固件、参数ABI、型号预设、备份范围、双读校验、UID绑定及关相保护。
保留同镜像重复烧录、中断恢复、已有参数保护和烧录后版本查询。
仅调整主机流程：已配板可直接烧录；空白板首次点击只识别并显示明确的初装选择，
明确选择后再执行初装。整片擦除仍要求确认，不自动执行硬件擦除。

## 设计与验收

- 复用现有识别、速度试读和写入函数，不新增平行烧录路径。
- 在擦除备份前以已有低速参考试读选择8/4/1 MHz，失败保留降速行为。
- 比较只读实机速度及原日志；没有实机完整擦除测量时不声称总耗时已实测。
- 离线覆盖直接烧录、空板等待选择、错板/错型号拒绝、擦除提速/降速及原保护。
- 运行PR及发布构建所需Release，记录新工具产物，原用户工程设置原样保留。

## 回退与当前状态

回退本次主机提交即可，板端固件和数据未改变。正在分析及实现。
