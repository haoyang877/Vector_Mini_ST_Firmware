# PLL 与 2 ms 短窗测速比较

日期：2026-09-24。结论等级：实际 C 离线比较完成；短窗部分台架扫频完成；PLL 同工况台架验收未完成。实验分支，不构成发布或最高带宽认证。

## 结论

以尽可能提高速度环闭环带宽为目标，**优先选择 PLL 作为后续台架候选**。当前 3 rad/s 工作点对应 PLL 自然频率 600 Hz，其相位滞后显著小于 40 快拍 / 2 ms 短窗。不能据此声称已完成两种方案的实机最优选择：临时台架镜像出现启动电流读数尖峰，触发停止门限，本轮停止进一步运动测试。

未更改正常固件算法、默认参数或 Flash 参数。结束恢复运动测试前的短窗镜像、原 RAM 增益及限值，确认模式 0、故障 0、三相通道关闭、六路驱动引脚高阻。

## 当前真实调用路径

- 编码器采样与两种估计器均在 20 kHz 快路径执行；速度 PI 为 2 kHz。
- `ENCODER_VELOCITY_SOURCE` 选择 PLL 或 WINDOW4。WINDOW4 实际是 **40 × 50 µs**，不是 4 × 50 µs。
- 普通模式 2 走 `MotorOuterLoop_FastTick → MotorOuterLoop_Service → SpeedMode_UpdateControl`，反馈读取 `Encoder_GetMecVel()`。`SPEED_LOOP_USE_FAST_VELOCITY` 没有控制这条异步外环路径。
- RTT `encoder_speed` 在 fast 开关开启时记录 `vel_mech_fast`。因此低速下，遥测与实际控制反馈并不完全相同。
- 短窗的 `vel_mech` / `vel_mech_fast` 分别在窗口位移不超过 8 / 1 Q15 计数时归零，对应约 **0.3835 / 0.04794 rad/s**。PLL 的 `vel_mech` 门限为 0.05 rad/s，fast 输出无此门限。
- 两种算法在本轮 3 rad/s ± 小幅正弦工况远离死区；不能将该工况结论直接外推到接近零速。

旧的 `test_speed_loop_bandwidth.py` 比较的是 8 ms 长窗与固定 300 Hz PLL，且其延迟预算将 PLL 快拍半周期用于速度环。保留用户原文件，本轮新增独立比较工具，统一计入 2 kHz 速度环保持，并区分估计器频响、开环穿越和闭环 -3 dB 带宽。

## 实际 C 离线测试

复现命令（`--cc` 指向本机 C99 编译器或 Zig）：

```powershell
python tools/analysis/compare_speed_estimators.py --cc <compiler> --out outputs/speed_estimator_ab_20260924/offline_final
python tests/run.py --out outputs/speed_estimator_ab_20260924/final_regression
```

工具从当前 `encoder.c/.h` 抽取真实结构、宏及 C 函数，编译宿主程序，输入相同的线性化 Q15 角度序列。覆盖静止、正反转、跨圈、低速死区、600/450/300 Hz 调度工作点；64 个算法/频率/工作点响应通过与离散解析式的复数误差检查。它未模拟 SPI、坏帧恢复、MCU 指令耗时或真实机械负载。

| 指标，3 rad/s 工作点 | PLL，600 Hz | 40 快拍短窗，2 ms |
| --- | ---: | ---: |
| 5 Hz 相位折算延迟 | 约 0.30 ms | 约 1.00 ms |
| 50 Hz 幅值 / 相位 | +0.01 dB / −5.42° | −0.14 dB / −18.01° |
| 100 Hz 幅值 / 相位 | +0.03 dB / −10.93° | −0.58 dB / −36.00° |
| 200 Hz 幅值 / 相位 | +0.09 dB / −22.56° | −2.42 dB / −72.01° |
| 同源角度白噪声引起的速度差值标准差 | 0.1165 rad/s | 0.07665 rad/s |

噪声测试采用 20 kHz、每样本 σ=0.0001 rad 的同一随机输入，以有噪/无噪输出之差计量，包含 Q15 量化影响。600 Hz PLL 此项约为短窗的 1.52 倍；15 rad/s 下 PLL 调度到 300 Hz，此项为 0.03804 rad/s，短窗为 0.07395 rad/s。白噪声模型不能代替实际磁编码器的相关噪声、角度周期误差或齿槽扰动。

### 带宽预算：仅为模型

假设刚性惯量、电流环一阶 750 Hz、Ki/Kp=10 s⁻¹、附加延迟 150 µs，纳入离散 PI 和速度环零阶保持；在高频下降段寻找 60° 相位裕度候选穿越点：

| 估计器 | 2 kHz 速度任务 | 假设改为 4 kHz |
| --- | ---: | ---: |
| 2 ms 短窗 | 48.5 Hz | 52.9 Hz |
| PLL 300 Hz | 61.1 Hz | 67.8 Hz |
| PLL 450 Hz | 76.9 Hz | 87.7 Hz |
| PLL 600 Hz | 88.1 Hz | 102.5 Hz |

这些是**假设模型中的开环穿越频率，不是实测闭环带宽**。600 Hz PLL 的候选值约为短窗的 1.82 倍。将速度任务升至 4 kHz 在这组预算中只增加约 16%，不能预设带宽翻倍。当前台架还出现高频非单调响应，刚性惯量模型不够解释全频段，故不采用其机械速度 -3 dB 数值作为验收结果。

## 本轮台架证据

用户确认：HT8115-4，无阻尼环，轮子架空空载，6 mΩ，母线约 32.9 V；最高 5 rad/s，电流指令不超过 2 A，现场可断电。读取标定有效、21 极对、CAN 接收关闭后才启动测试。

### 采集方法

1. 原镜像 SWD 正弦注入只有约 165 次/秒，高频参考失真；`window_kp010` 仅作方法诊断，不能据其高频数据选带宽。
2. 临时镜像在 MCU 内以 2 kHz 产生 3 rad/s 基值的正弦，增加 250 ms 主机心跳超时、60 s 总时限、5 rad/s / 2 A 实测 Iq / 母线边界检查。实际 C 宿主测试覆盖波形边界及各停止条件。测试源码、镜像及哈希仅归档在 outputs，未留在正常固件源文件内。
3. RTT 同时记录实际 `speedShadow`、测速反馈、Iq 指令/反馈及编码器电角 sin/cos。通过相位展开及正弦拟合求角度导出的机械速度响应，不以不同估计器自己的平滑程度评价机械运动。
4. 序号检查丢帧；最小二乘包含直流和线性趋势。角度仍来自同一编码器，并非独立测速真值。采集存在快拍级调度抖动，序号不提供每帧精确硬件时间戳。

### 短窗有效运行

运行 `window_mcu_kp040_05a`：电流指令上限 **0.5 A**，启动加速度 **1 rad/s²**，Kp=0.4、Ki=4，正弦幅度 0.25 rad/s。有效比例增益为 **0.2 A/(rad/s)**，等价于 2 A 限流时 Kp=0.1，不能直接与 6 A 下同数值 Kp 比较。

| 频率 | 反馈响应幅值 / 相位 | 角度导出速度幅值 / 相位 |
| --- | --- | --- |
| 20 Hz | +0.02 dB / −30.00° | +0.54 dB / −23.18° |
| 35 Hz | +0.00 dB / −44.59° | −0.18 dB / −31.46° |
| 50 Hz | −1.22 dB / −64.38° | −0.41 dB / −46.20° |
| 70 Hz | −1.95 dB / −91.96° | −1.38 dB / −64.40° |
| 90 Hz | −4.66 dB / −116.89° | −4.81 dB / −81.78° |

本轮有效运行各频点无序号丢帧，记录的 Iq 反馈峰值不超过 0.31 A、指令峰值不超过 0.33 A。35–50 Hz 之间由 `L=T/(1−T)` 得到首个穿越约 **44 Hz**、该处相位余量约 **65°**；分半拟合相位相差约 2.2°/0.4°，支持这一局部估计。

这不是“最大可用带宽”：未完成增益扫描；120 Hz 分段响应一致性差，160 Hz 又出现明显响应回升，无法用单一低通曲线或单一穿越点概括整条环路。70–90 Hz 的首次 -3 dB 下降不能当作全频域带宽认证。应先排查高频响应来源，再进行完整稳定裕度和重复性验证。

### 启动停止事件与未完成项

两次临时镜像启动触发本轮快速 Iq 门限。第二次锁存：使能后的第 4 个 20 kHz 快拍，上一拍 Iq 为 **9.928 A**、Iq 指令为 **0.0001005 A**；当前拍 Ia/Ib/Ic 为 0.134/0.121/0.134 A。Iq 与此处三相值不在同一采样时刻，不能用它们证明尖峰一定为真实电流，也不能断言只是测量错误。

该异常是在临时台架镜像下观察到，尚不能归因于原固件、估计器、采样或测试插桩中的某一项。第一次事件后经用户确认，降低启动电流至 0.5 A、加速度至 1 rad/s²，完成一次低增益诊断和上述扫频；后续重复启动仍触发，遂停止进一步运动。每次均通过 STOP、通道和高阻引脚回读。未放宽停止门限，未绕过保护。

**PLL 本轮仅完成离线与构建，未取得同工况台架扫频。**下一步应先用同步启动采集定位 Iq 尖峰；解决后按相同限流、电流环和有效增益重复短窗/PLL，并检查高频响应回升。届时才能选定最大可用闭环带宽与推荐 PI。
