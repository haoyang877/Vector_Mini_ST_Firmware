# 核心功能删减 v3

日期：2026-10-08。用户要求每个模块删到最简单，仅保留核心功能。
本决定覆盖收口 v2 中扩展功能与保留全部辅助模式的要求。

## 输入与边界

源码基点 0ec1aa900e13cbb4d1bb92891e12a34c9a3fd14f，文档基点 524b66a4。
只在隔离的 codex/architecture-closeout 修改，旧 v1.1/v1.2 包、用户现场不动。
本次明确删功能，不要求被删除功能与旧版本等价。

保留：FOC 电流/速度/位置控制及必要 VQ 调试；编码器 LUT、电气/机械零位标定；
必要电流偏置初始化；参数默认值、schema12 读写和真实保存；启停、原阈值的故障保护；
CAN 基本控制、反馈和参数；Loader 镜像校验、升级与失败恢复。
保留 LUT 所需无感启动与观测器，不把标定依赖误删。

删除：新增运行租约、持久启动计数、新会话/泛化标定计划线路；复杂自动模式切换；
摩擦/相电阻辨识、齿槽标定及补偿；复杂轨迹/前馈/HOLD 编排；自动 RTT 遥测。
运行模式变更采用 STOP → IDLE → 新 START；CLEAR 不启动，STOP 撤销旧目标。
历史参数字段保留布局，仅退役其执行/加载作用，不迁存储或擦现场数据。
撤回的 CMD 保留编号、不复用，不以能力位为零或编译宏伪装删除。

各任务从确切源码基点取本范围文件，不能回灌各自旧树快照。
公共接口变化由 ROOT 转递，最终采用窄文件清单集成。
