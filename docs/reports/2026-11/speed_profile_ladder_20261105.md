# YQ-5708 正式速度参数与电机侧 0～200 rad/s 阶梯实测

2026-11-05，AT32F456 驱动 YQ-5708，减速比 8:1，电机固定、输出轴空载。所有转速均为电机侧机械角速度。速度 PI 采用 Kp=0.0335、Ki=0.67；速度模式的反馈 PLL 自然频率为 600 Hz，换相及位置速度反馈使用 90 Hz 主观测器。电流更新率为 20 kHz，速度环更新率为 2 kHz。

## 固件与测量口径

以板上原应用为基线，在隔离源码目录中重建并核验原 HEX 与板上应用一致，再加入速度反馈和默认 PI。正式 HEX 的 SHA-256 为 `d7399bb98726d61f8c2219eca3d1722a9fdbd0817d860ec4f8aec1db0786ddca`。更新板上已有参数记录中的两项 PI 与 CRC，重启回读。整个标定区与写入前逐字节一致。

每档通过普通 CAN 设置目标并维持约 6.2 s。取后约 3.1 s，对 SWD 单次 32 位读取的 600 Hz PLL 机械速度求平均值和标准差，使用软零速死区前的值，采样时刻不等间隔。相对波动为标准差除以给定绝对值。2 kHz RTT 同步记录三相电流、换相电角、90 Hz 速度和实测 Iq；另以展开电角的净位移和 14 极对数核对平均速度。电流峰值取整档，包含切换过程。均速和波动均来自板载编码器，轴端未安装独立转速计。

首轮在 130 rad/s 档因探针速度读数触发截止，当时 RTT 连续反馈最高 130.62 rad/s；原探针分字节读取运行中的浮点量，无法核实该次瞬时值。采用单次 32 位对齐读取后，从低速重新测量。结果表仅使用单次 32 位读取记录。全程限流 3 A；追加上端测量时按已确认的 200 rad/s 给定上限、210 rad/s 瞬时反馈截止执行。

升至 197 rad/s 时有一次 CAN 状态应答超时，程序执行停机；另一次在 10 rad/s 起步时因主机轮询数不足结束。两次均核验关相，增加空闲状态的采集速率检查后重新逐级升速。各档只采用完成全时长并通过采集校验的记录，同一档有多条完整记录时取最后一条。

在通信边界，`200000 mrad/s × 0.001f` 的单精度结果为 200.00001526 rad/s。当 RAM 限值恰为 200.0 时，普通 CAN 目标返回越界。端点复测将临时限值设为协议换算后的同一浮点值，主站给定仍为 200000 mrad/s。该处理仅用于本次台架运行。

这些结果用于评价恒速跟踪。此前在相同 PLL 和 PI 下，正常 CAN 入口于 +10、−10 rad/s 测得的首次 −3 dB 交点分别为 126.6、136.0 Hz。各速度点的带宽须通过小信号频响测量。[±10 rad/s 带宽试验](speed_pll_120hz_20261105.md)

## 各档结果

详见[逐档数据](speed_profile_ladder_20261105.csv)，包含反馈区间、角位移均速、90 Hz 反馈标准差、全段速度与电流峰值以及母线电压范围。

1 rad/s 能跟踪均值（0.990 rad/s），但速度反馈标准差达到 0.749 rad/s，同段 90 Hz 反馈标准差也达到 0.747 rad/s。10 rad/s 的两个方向相对波动约 5.7%；正向 20 rad/s 为 2.41%。20～200 rad/s 的每个已测档位均低于 3%。30 档记录包含 29 个非负给定和一个反向复核档，平均反馈与给定的最大绝对偏差为 0.143 rad/s 以内。

200 rad/s 档的稳态快速反馈范围为 195.413～205.099 rad/s，2 kHz 电角净位移对应均速为 199.798 rad/s，Iq 全段峰值 0.849 A。所有完整档位中，实测 Iq 峰值最高 0.917 A，三相电流绝对峰值最高 1.047 A。

结束后独立重连核对完整 256 KiB Flash 和应用参数，PI 为 0.0335、0.67，电流限值 3 A，日常速度限值和上限分别恢复为 3.142 和 20 rad/s；设备空闲、零故障、PWM 为 0。原始波形、完整 Flash 备份及末次回读位于 `outputs/speed-profile-production-20261105/`。

隔离 AT32 工程重建为 0 错误、0 警告，HEX 哈希与台架一致。双板编码器回归和 7 项测速离线检查通过。工作区 release 检查 `20261105T101921107009Z-25f64c7b` 整体失败，失败项包括工作区存在未提交修改、AT32 主入口格式与中断路由测试、工程分组与 RTT 文件校验、历史文档链接和发布构建清单。
