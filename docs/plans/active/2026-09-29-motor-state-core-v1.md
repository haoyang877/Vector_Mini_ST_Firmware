# 主状态机冗余删减 v1

日期：2026-09-29。行为基线：0c97aea8，分支 codex/system-refactor。

## 目标与范围

用户明确选择保留现有电机功能，只精简状态机。删除重复的数据、判断、初始化和
无生产调用的查询接口；不以新增文件、接口层或功能开关代替删除。

保留编码器 FOC、电流/速度/位置/VQ、全部现有标定与辨识、齿槽补偿、参数保存、
CAN 与 Loader。无感算法仍被编码器 LUT 标定实际使用，不作为闲置功能删除。
九个主状态、STOP 关闭输出、故障恢复、自检期限、任务代际、资源归还和最终启相复核不变。

## 子任务

1. 冻结实际所有者与规则基线、构建输入及 APP/LoaderApp 容量证据。
2. 删除只在本地请求提交前同步赋值的 request_epoch 影子字段；原始 worker、后台、
   控制邮箱和取消身份继续保存。远程请求缓存有效性由非零受理票据表示，不重复保存布尔位。
3. 删除无生产调用的 IsMaintenanceActive 查询，测试使用已有 GetMaintenanceKind；
   保留必要的 RequestEnable 功能入口。统一上下文初始化，配置查询复用已有事实。
4. 同一临界区内复用恢复事实；启动资格分为共同原因与位置附加条件，资格快照只计算一次
   共同原因。只复用期间没有动作和配置变化的结果，动作后与最终提交的复核保持原位置。
5. 检查其他重复的布尔判断及未用依赖，删除能够证明与已有条件等价的内容。
6. 运行基线/最终真实所有者差分、规则黄金摘要、PR 和 release；编译两种 APP，核对
   ABI、故障/状态/输出行为、静态资源、构建产物及未知时序范围。
7. 分阶段提交并合入 codex/system-refactor；保存忽略目录中的证据后归档临时 worktree。

## 验收与回退

- 电机功能代码、持久化 schema、CAN 黄金向量、共享契约和链接布局不变。
- 实际所有者的受理、目标提交、维护结果、取消、后台迟到结果、故障和升级交接测试通过。
- 新增资格矩阵覆盖未确认、部分标定、编码器离线、母线异常和位置边界；对照基线运行。
- 纯转换规则不修改，262144 组黄金摘要继续为 f98662bc6ed8b902。
- 状态机源文件、接口和上下文减少；不增加状态副本或 goto。记录实际 Flash/RAM 变化。
- 同一临界区内减少重复读取，不修改快慢拍调度、输出动作顺序或输出确认条件；静态证据
  不能证明实机中断时延、抖动、栈峰值或物理关断。
- 每批可单独 revert；不接触设备，不烧录或修改参数。

证据保存在 outputs/state-core 与 outputs/runs；最终 summary.json 记录提交和产物哈希。

接口契约集中在头文件，删除实现中重复的 Doxygen 块；保留实现中的并发、输出与资源约束
说明。报告同时统计总行数与去除注释/空行后的代码行数，不能把说明删减等同于逻辑删减。
