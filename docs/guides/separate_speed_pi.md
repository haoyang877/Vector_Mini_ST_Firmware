# 速度模式与位置级联的独立速度 PI

版本：v1，2026-10-09。适用 `codex/ovp-36v` 旧式 CAN 参数协议。
不适用于其他分支的公司协议/APP 1.3.0。

| 场景 | RAM 参数 | 使用路径 |
| --- | --- | --- |
| 纯速度模式 mode 2 | `speed_Kp`、`speed_Ki` | 速度 PI；mode 16、摩擦辨识也沿用这组 |
| 位置模式 mode 3 | `position_speed_Kp`、`position_speed_Ki` | 位置级联内部的速度 PI |

两组都是既有归一化增益，Kp 单位 s/rad，Ki 单位 1/rad；位置控制器内部乘以
运行电流上限换算为电流域增益。没有改变增益定义、控制周期、滤波或电流限制。
mode 18 的电流域位置阻抗参数保持原样，不使用新速度 PI。
更改位置组会刷新配置缓存；修改另一组不影响当前模式的计算和有效性校验。
既有模式切换重置规则继续隔离两种控制器的积分状态。

五台电机的纯速度模式目标统一为 Kp=0.06、Ki=0.6，与共同固件默认值一致。
Roll/Pitch/Yaw 的位置内速度 PI 目标仍为0.5/1.0。目标配置不等于各板当前保存值；
旧参数迁移仍保留原值，下载后需独立写入纯速度组目标并保存，不能把兼容升级解释为
已完成五台实机统一整定或 Flash 同步。

## CAN 与保存

| 参数 | 写入参数 ID | 查询参数 ID |
| --- | --- | --- |
| 速度模式 Kp | 0x18 | 0x19 |
| 速度模式 Ki | 0x1A | 0x1B |
| 位置内部速度 Kp | 0x6B | 0x6C |
| 位置内部速度 Ki | 0x6D | 0x6E |

新参数的载荷仍为 4 字节大端 IEEE-754 float，帧 ID 仍按旧式节点/参数规则组合。
新写入接受有限且非负的增益；Ki=0 可关闭积分。原速度写入范围保持不变。
例如 Pitch 节点 4 写入位置内速度 Kp=0.5：标准帧 ID `0x46B`，数据
`3F 00 00 00`。随后查询 0x6C 核对。停机调参，通过 mode 9 保存，
复位后分别读取两组参数。J-Link 使用匹配新 AXF 的符号，不能沿用旧 RAM 地址。

旧上位机的 0x18/0x1A 现在只改速度模式；位置调参需改用 0x6B/0x6D。
现有 mode 3 HIL 操作码 5/6 改写位置组，CLI `--speed-kp/--speed-ki` 语义仍是
位置内速度 PI。测试配置旧键 `runtime.speed_Kp/speed_Ki` 保留，但实际回读字段
为 `position_speed_Kp/position_speed_Ki`。

## Flash 兼容

schema10 及现有字段偏移保留，新增 PSP1/v1 尾记录：

| 记录字段 | 相对参数区偏移 | 大小 |
| --- | ---: | ---: |
| magic=`PSP1`（0x31505350） | 2272 | 4 |
| version=1 | 2276 | 4 |
| 位置内速度 Kp | 2280 | 4 |
| 位置内速度 Ki | 2284 | 4 |
| CRC32 | 2288 | 4 |

CRC 使用标准反射 CRC32，覆盖记录前16字节；记录小端存储，与 CAN 载荷字节序不同。
参数结构由2272扩为2292字节，仍占原参数区的两页；Flash 写入函数为最后不足8字节
的部分填充0xFF。原速度字段仍在2116/2120，电零位、LUT、机械零位均不移动。
黄金向量见 `tests/vectors/position_speed_pi_v1.json`。

旧参数尾部全零/全0xFF：复制旧实际运行增益到两组，校验其他记录后由现有启动
迁移机制保存。AXS2 旧配置曾覆盖速度 PI 的，迁移保留覆盖后的实际值；已有 PSP1
时分别恢复两组保存值，AXS2 不再次覆盖用户 PI。非空尾记录 CRC、版本或数值损坏
则拒绝参数准入，不自动复制另一组或保存成默认值。

旧固件忽略 PSP1，继续使用原速度组，不会移动或重解释标定。旧固件执行保存会
擦除该尾记录，再次升级时两组将重新从旧实际值初始化，因此降级前需导出新位置组。
该旧式扩展不用于其他工作树的 schema12。

总体目标值见[五台电机参数表](five_motor_parameter_table.md)。本次只完成代码、
离线验证和构建，没有下载新固件到五台电机。
