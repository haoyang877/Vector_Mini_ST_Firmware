# 启动连贯性与静止卸流 v2

v1的5 A/s建立斜率消除了原+90°到−90°启动后的约0.64 s静止段，但仍超前参考4.59°，
速度先增后减，不能据此宣称连贯性通过。用户进一步指出过冲。按实测继续减小摩擦建立
斜率到2 A/s；保持模型、释放斜率和静止重启起点修复，运动中参考q/v/a连续。

Kp8/16未让±90°进入0.25°入口；Kp32/Kd3在+90°仍停在约0.33°且Ui为0，
说明单纯禁积分不能消除保持前馈。+30°已能卸流，但实际回弹靠近0.45°软唤醒边界。
据用户±0.5°容差，停靠入口调到0.35°，软唤醒0.475°持续50 ms，原始0.5°硬唤醒不变。
不放宽硬边界，不把精确到位标志改成0.5°。改后仍须实测回弹是否超界，不能预先认定通过。

使用相同6 A、低速全范围流程，候选增益只在RAM中试验Kp32/Kd3，不保存Flash。
记录启动超前、起动后低速段、最终目标过冲、末段误差、总Iq/Ui/前馈及STOP。
离线回归、构建和哈希核验通过才下载。任何故障立即停止；未验证停机不得重试。
回退至v1归档镜像，参数区和个体标定保持不变；其他阻尼轴未实测。
