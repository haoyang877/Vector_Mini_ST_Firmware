# 输出轴采样分块差值验证

基线：`e02e82ec`，`codex/at32-ram-64k`，工作区干净；AT32 配套 APP 总 RAM 48944 B。

目标：优先验证分块基准加16位差值能否减少14376 B输出轴采样区，同时保持2048组样本、
完整32位电机计数、两路12位Hall、标定数学及失败/取消行为不变。

先验证再采用。16点块的名义布局为每块32位基准、每点16位差值，电机数据4608 B，
比现有8192 B少3584 B。必须检查完整采样链，不把目标转速当作原始计数差值硬上限。

调用方为MotorAxis外环采集、OutputEncoder前台多遍结算和原生测试；不修改协议及Flash ABI。
优先在outputs中保留候选编码和对照夹具，不新增生产通用压缩框架。

验收：正常正反转/减速比、跨零、整数边界、慢速/回退/长区间平均、分块溢出及最坏回退容量；
逐点还原和原标定结果对照。只有能证明不丢数据且静态RAM下降才进入生产实现。
若候选失败，记录反例及范围，不缩小原输入域、不新增标定失败条件以换取通过。
文档调查运行quick；若修改固件则运行PR及匹配的精度对照和ARM构建。

不连接硬件或烧录。回退为保留基线固件，仅移除本轮候选修改。

## 验证结果

两板各62次编码还原/结算逐字节相同。正常16点块最大跨度19429 counts，
实际采样函数的回退、停留、再前进反例产生659154 counts块跨度。
全32位接口的128块均可要求原值回退；当前未证明可用更小异常池覆盖完整生产输入域。
候选名义节省3584 B，未满足最坏固定RAM下降门槛，不并入固件，实际节省0 B。
