# 编码器标定

`encoder_calibration.c/.h` 集中实现 LUT 标定和电零位标定，包含阶段推进、运动控制和私有计算。
机械零位由 `MotorAxis` 调用编码器反馈接口设置。完整入口与结果说明见
[编码器标定流程](../../../docs/guides/calibration_process.md)。

## 调用与所有权

```c
EncoderCalibration_StepLut(&control, &workspace);
EncoderCalibration_StepElecZero(&control);
```

`MotorAxis` 在调用时通过 `control` 绑定配置、FOC、电机、编码器、观测器和
无感启动对象。电零位使用配置、FOC、电机和编码器。调用方保证绑定有效、编码器就绪，
标定速度 PI 由 LUT 会话独立持有。电零位入口另需有效 LUT。这些条件由生命周期准入和监督层检查。

工作区由 Axis 独占，固定 6144 字节，采样计数与候选 LUT 共用存储。
调用方传入非空且地址固定的工作区，待发布或取消完成后才能再次使用。
计时与数据按启动、采样、构表和停止阶段组织，会话持有工作区、阶段、阶段状态联合体和独立速度 PI。
采样阶段的观测器位置代际传递给构表阶段，两阶段都检查参考连续性。
电零位的样本锚点、和与计数由角度均值状态集中管理，固定保持窗口完成后计算非空均值。

## LUT 流程

1. 首拍建立会话，随后运行无感启动并每拍清理 4 个 bin。闭环转速连续稳定 0.5 s 后，
   记录观测器位置和方向校正角作为相对采样参考。清表、启动和稳速共用 8 s 超时。
   原始观测器速度低于可用下限或速度偏离目标时，连续稳速计数归零。
2. 按内部编码器净位移正向采集 100 个机械圈，稳速帧用于每个 bin 累加校正量和样本数。
3. 分两遍构表，每拍最多处理 8 个 bin。第一遍检查非空、求均值、展开环形校正量并求和，
   第二遍按整圈平移到 `int16_t` 范围并写入候选表。
4. 减速、卸流，返回 `MOTOR_TASK_FINALIZE`。生命周期关相，主循环发布候选 LUT。

PITCH、YAW 在步骤 2 同时由 Axis 的 4 kHz 外环采集 Hall 原码极值，不再单独旋转磁场扫圈。
关相停稳并发布 LUT 后继续电零位对齐，结束后统一计算 Hall 偏置、幅值并保存结果到 Flash。
中止不自动保存，重新开始编码器标定会清空上次 Hall 极值。

`step_measure()` 组织启动、采样、构表的控制输出和阶段推进。
`step_stop()` 组织减速与卸流，根据实际闭环、观测器相位和速度、编码器低速条件截止制动。
共用无感启动入口完成 FOC 与 PI 初始化。

相对参考中的整体常量由后续电零位标定吸收。本轮删去对齐原点均值、寻找原点、
额外一圈残差验证和 RMS/峰值门槛，每 bin 仅要求有样本。
模型参数检查由生命周期和共用无感启动负责，任务保留参考跟踪、采样覆盖及超时边界。

## 六个任务接口

| 接口后缀 | 职责 |
| --- | --- |
| `StepLut` | 20 kHz 推进 LUT 标定，完成时保留候选并请求前台发布 |
| `StepElecZero` | d 轴对齐、计算线性化角均值并写入电零位 |
| `GetPhase` | 读取当前 LUT 阶段 |
| `IsIdle` | 通过 LUT 阶段和电零位计时查询两个任务是否空闲 |
| `Cancel` | 清理两个会话，结束工作区借用 |
| `PublishLut` | 在关相前台发布候选，清除旧零位资格并请求反馈重建 |

以上接口统一使用 `EncoderCalibration_` 前缀。功率许可、STOP、故障和状态迁移
归生命周期所有。Axis 持有全中断临界区，复核会话和输出状态后调用发布函数。
发布函数检查待发布阶段、复制 LUT 并将有效位置为 `ENC_CALIB_LINEARIZED`，
完成后释放工作区，随后由 Axis 恢复中断。

标定结果写入 RAM。带 Hall 的轴由 `MotorAxis_ProcessCalibrationPublication()` 统一保存，
未使用的手动保存入口已删除。写前保留会话、STOP/故障和关相检查。
对外六个接口、6 KiB 工作区和 schema14 存储布局沿用既有契约。
