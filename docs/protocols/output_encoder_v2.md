# 输出轴关系与 Hall LUT 记录 OEN2

此页保留 128 点历史格式。当前写入使用 [1024 点 OEN3](output_encoder_v3.md)，仍兼容读取本格式。

核对日期：2026-11-06。OEN2 替代写入 OEN1，兼容读取仍见 [OEN1](output_encoder_v1.md)。
schema14 基础记录保持 2288 字节及原 CRC，OEN2 扩展为 292 字节，整轴共 2580 字节。
字段均为小端，float 为 IEEE-754 binary32。

| 绝对偏移 | 字节数 | 含义 |
| --- | --- | --- |
| 2288 | 4 | magic = 0x324e454f，字节 OEN2 |
| 2292 | 4 | 同次基础记录 record_crc32 |
| 2296 | 20 | 原 OutputEncoderParams：减速比、相位、机械零位、方向、状态，布局沿用 OEN1 |
| 2316 | 4 | hall_lut_status：0 未标定，0x80 成功，1 覆盖不足，2 映射不一致 |
| 2320 | 256 | int16 hall_lut_q15[128]，65536 counts/输出圈，正值加到 Hall 原角 |
| 2576 | 4 | CRC32，覆盖 2288..2575，种子 0 |

第 i 个表项对应幅值/偏置校正后、LUT 校正前的 Hall 角 `i * 2π / 128`。
运行使用相邻节点线性插值，最后节点接第一节点；未标定或失败时 RAM 表清零，继续输出原角。
成功表必须满足每段 `512 + lut[next] - lut[i] > 0`，包括首尾段。
Flash 装载只在前台执行版本、CRC、基础参数绑定、幅值成功状态和表单调性检查。
表状态 1/2 记录 LUT 故障；原幅值/偏置的故障位仍保存在 schema14 的 Hall 槽中。

本次新电机 LUT、Hall 幅值/偏置、Hall LUT 与依赖校正后 Hall 的输出相位必须作为同一组
参数保存。不能只更换表而沿用旧相位。LUT 重标定后沿用既有规则清除输出工装零位。

OEN1 读取时恢复原输出相位，并使用零 Hall 表。无扩展时保留初始化行为；旧固件只认识
OEN1，遇 OEN2 时忽略整个扩展，不会把新相位搭配未校正 Hall。旧固件仍可读取 schema14。
旧工具改写基础记录导致 CRC 绑定变化时，扩展不再恢复，须重标定或恢复匹配的整轴备份。
