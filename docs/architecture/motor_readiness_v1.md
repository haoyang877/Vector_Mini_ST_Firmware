# 基础自检与模式就绪 v1

日期：2026-09-29；2026-10-08 按当前上电零点路径更新。配合[主状态机](motor_state_machine_v1.md)使用。

## 主状态与准备资格

READY 表示基础健康、可接收命令，不等于所有模式允许启动。没有增加 UNCONFIGURED、
UNCALIBRATED 主状态；配置确认、编码器标定、模式启动资格均为独立事实。

| 情况 | 主状态 | 行为 |
| --- | --- | --- |
| 未装载当前参数或默认参数尚未确认 | READY | 输出关闭，允许通信、参数修改、SAVE、DEFAULTS；拒绝转矩维护和 ENABLE |
| 参数已确认、编码器未标定或部分标定 | READY | 输出关闭；允许符合前置条件的标定，拒绝正常控制启动 |
| 标定任务已受理 | MAINTENANCE | 仅执行该任务；完成或取消后经关断/归还回 READY |
| 配置和标定完整，母线满足启动要求 | READY | 等待明确 ENABLE；不因配置、标定或保存完成自动启动 |
| 无功率母线但板级供电正常 | READY | 允许通信、配置与保存；拒绝启相与转矩维护 |
| 必需采样、编码器或基础参数长期未准备好 | FAULT | 自检超时，保持关闭输出；恢复后需明确 CLEAR 并重新自检 |
| 自检中关断无法确认 | FATAL | 普通 CLEAR 不可恢复，需人工排查及外部复位 |

默认电机 profile 只是待确认的数值来源。用户必须确认 profile/活动参数与实际电机匹配，
再写配置确认；确认不代表执行过电机辨识或编码器标定。当前已登记电机模型参数仍只读，
更换模型使用现有编译 profile/完整参数记录，不能把确认命令当作模型写入功能。

## 自检事实与期限

所有者汇总以下事实；不施加电压、不运动、不自动标定或保存：

实现按感测、配置、停机确认三组组织，仍返回以下八位诊断。参数有效性来自本次
`read_state_conditions` 的唯一数值校验结果，输出与资源位复用同一事实快照。
`rules.tested` 保存唯一的完成资格；诊断位始终是当前条件，不是资格缓存。

| bit | 通过事实 |
| --- | --- |
| 0 | 六路数字输出关闭回读成立 |
| 1 | 自上一监督拍以来完成过快速感测周期 |
| 2 | 母线原始/滤波值有限且非负，原始值低于硬过压阈值 |
| 3 | 本次上电电流零点采样完成，偏置在原范围内，三相电流有限；不以旧保存值代替本次完成资格 |
| 4 | MCU 温度换算有效、100 ms 内有有效来源且未过温 |
| 5 | 电机模型、轴配置、控制增益和限值通过现有确定性数值检查 |
| 6 | 当前产品必需的转子编码器在线且最近坏帧连续计数为零；不要求标定 |
| 7 | 控制邮箱、维护/后台任务、参数借用与功能资源已释放 |

以上事实连续满足 4 个 2 kHz 监督拍后提交 SELF_TEST_DONE，READY 保持关闭输出。
普通自检期限为 500 ms；当前初始化先清空电流零点资格，在关相状态累计 1 秒新鲜
采样，所以本次上电的初始自检期限增加到 1.5 秒。CLEAR 后恢复普通 500 ms 期限。
BOOT 等待与 SELF_TEST 使用所有者当前计时；BOOT_DONE 进入自检时重新记录起点。
期限先于完成判断，过期的成功不能放行；毫秒时基使用无符号差值处理回绕。
期限和稳定窗口是软件默认值，不代表所有板卡冷启动等待时间已经验收。
监督任务若完全停止，本任务自身不能执行超时判断；不能把它当成独立看门狗证明。

硬过压在关闭输出时也由快速检查上报，不必等待启动；正常欠压/启动电压窗口仍是准入条件。
未配置、部分标定、低电压导致的请求拒绝不会锁故障；采样模块报告的真实故障仍按原路径锁存。
所报位是当前事实，不是一次通过后永久有效；运行时输出已开，bit0 自然为零。

数字回读不能证明功率管未短路。当前板没有独立驱动器故障输入，本轮未增加假检查。
静止电流残差、ADC 饱和电气诊断需冻结板级判据；相序、辨识、标定及转矩试验仍为维护任务。
没有启用输出轴传感器，因此没有对应自检项；CAN 主机在线不影响基础自检。

## 配置确认与启动受限原因

新增 120/121 参数 ID；线路结果、序号、revision 和停机独占遵循
[参数线路 v1](../protocols/yg_protocol_parameter_wire_v1.md)。108/124 的 45 B payload 不变，
READY 仍映射为既有线上状态 5；PC 用新序号查询资格，重试原身份重放原快照。

| ID | 类型/权限 | 含义 |
| --- | --- | --- |
| 0x4D | u32，R/W-IDLE | 0 未确认，1 用户确认；其他值拒绝。写 1 前必须通过配置数值校验 |
| 0x4E | u32，R | 来源：0 默认/空白，1 当前存储记录，2 版本/识别字不支持，3 CRC/内容损坏回退，4 活动确认操作 |
| 0x4F | u32，R | 电流模式当前启动受限原因，按下表组合；不是故障码 |
| 0x50 | u32，R | 当前八项自检事实位，全部满足为 0xFF |
| 0x51 | u32，R | 各模式当前可启动位：bit0 电流、bit1 速度、bit2 位置、bit3 VQ |

| 0x4F bit | 受限原因 |
| --- | --- |
| 0 | 配置未确认或基础配置数值无效 |
| 1 | 编码器标定未完整 |
| 2 | 编码器离线 |
| 3 | 母线不满足启动窗口或数据无效 |
| 4 | 基础健康或自检未通过 |
| 5 | 模式不支持；当前产品不允许无感启动 |
| 6 | 位置准入不满足；仅逐模式计算，电流模式查询不置此位 |
| 7 | 非 READY 或升级维护锁定 |
| 8 | 资源、待受理请求或升级停机票据占用 |

位置模式可能因轴边界独立受限，应检查 0x51 对应位。资格查询不保留使能许可证；
ENABLE 在同一临界区重新核对，监督拍及运行守卫继续复核。确认、标定、保存都不自动 ENABLE。
SAVE 可以持久化未确认/部分标定记录，重载后保持同样限制；DEFAULTS 清除确认和标定资格。

配置确认持久化与整条 CRC 见[schema12 契约](../protocols/parameter_schema12_loading_policy_v1.md)。
黄金字节见[参数线路向量](../protocols/yg_protocol_parameter_wire_v1_vectors.json)。

未配置设备使用节点 1，与 Loader 救援节点一致；完整电机状态的节点合法范围为 1～254。
默认速度保持原 0.5 rev/s，不因节点 1 的轮子硬上限自动提高。批量配置仍需使用各板既有
编译 profile/完整记录指定节点；本轮未增加运行时节点重配接口。

## 所有权与验证

Param 服务应用默认/装载/确认，状态存于 APP 私有电机对象；没有新增可写全局导出。
参数值服务拥有确定性数值校验，motor_state_machine 拥有真实资格、自检和状态迁移；
功能任务仍只返回结果。ReadReadiness 复制值对象，通信通过参数请求读取，不持有内部指针。

原生用例覆盖未确认/四种标定组合、允许标定的前置条件、无母线 READY、拒绝无故障、
健康窗口中断、时钟回绕、总期限、关断失败 FATAL、CRC 黄金与掉电重载。
这属于离线验证；未烧录、未修改设备参数、未控制电机。
