# 核心接口语义 v1.7

2026-10-30：APP接口跟随生命周期收敛，仅保留核心状态值与真实关相确认。
三类标定通信启动继续遵守[标定通信v1.6](yg_protocol_calibration_v1_6.md)。

- 117零目标启动、110停止及显式清错不变，STOP只有确认关相才报告OK。
- 116不再进入控制提交、进度或重试历史。合法请求始终返回UNSUPPORTED；
  长度错误、字段错误和非主站请求仍分别拒绝。相同或旧序号不执行任何控制动作。
- 108与124只返回主状态、控制模式、故障及请求关联信息，帧布局仍为45字节。
  十二个测量位全部清零，各测量字段使用原有INT16_MIN/INT32_MIN哨兵；
  不再把不存在的零目标、参考电流等字段标记为有效。
- GET_CAPS仍为features=0x1C00、supported_modes=0。参数与Flash布局没有变化。

旧主机须检查结果码及测量有效位，不能等待116应用进度或将哨兵解释为实际测量。
停止受理编号仍为非零；重复请求复用编号，旧关相确认失效后重新分配，回绕跳过零。
见[黄金向量](yg_protocol_motor_state_v1_7_vectors.json)。
