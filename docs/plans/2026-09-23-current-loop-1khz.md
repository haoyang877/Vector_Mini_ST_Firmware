# 决策记录：电流环重整定（无超调优先，闭环带宽仍达标）

- 日期：2026-09-23；分支：`codex/ovp-36v`（实验分支，不发布）。
- 需求：① 电流环**超调 < 1%**（用户硬性要求，不可接受 33%/6.6%）；② 保留可用的电流环带宽。
- 测量方式：用户指定**扫频**（d 轴正弦，20 kHz 片内生成/记录，10 Hz–1800 Hz 12 点），
  并用 20 kHz 片内 d 轴阶跃复核超调（幅值 3 A，使 1% = 2.2 个计数，可分辨）。

## 定量权衡（为什么不能同时取满）

用 L = G/(1−G) 从扫频数据反演开环：

| 设置 | 穿越频率 | 相位裕度 PM | 阶跃超调 |
| --- | ---: | ---: | ---: |
| Kp=10.273（原始设计，L 参数偏大 1.8 倍） | 1165 Hz | 57.4° | 33% |
| Kp=5.6549（按实测 Ld=0.9 mH 重算） | 780 Hz | 61.5° | 6.6%（0.5 A 阶跃） |
| **Kp=4.2412 / Ki=10103.3（最终）** | **~620 Hz** | **~71°** | **0.39%（3 A 阶跃）** |

环路有效延时 T≈100 µs，PM≈90°−ω_c·T。要 <1% 超调需 PM≥76°（ζ≥0.83）→ 纯 PI 下穿越频率
需降到约 390–620 Hz。实测 620 Hz 时超调 0.39%，已满足要求，且闭环 −3 dB 为 **1400 Hz**（≥1 kHz）。

**注意**：增益再往上（scale 1.0，Kp=5.65）时 P 冲击达 17 V 接近电压上限，
出现**电压饱和非线性**，阶跃超调反而恶化到 40.8% —— 因此最终点取 scale 0.75。

## 若后续需要更高穿越频率（例如回到 1 kHz 穿越且仍 <1% 超调）

必须降低环路延时 T：当前 T≈100 µs（≈2 个 20 kHz 周期）主要来自"每周期一次采样 + 占空比下一周期生效"。
可通过**双边（峰值+谷值）采样与更新**把 T 降到 ≈50 µs，则同样 PM 下穿越频率可翻倍（~1.2 kHz）。
这属于定时器/ADC 触发与 ISR 结构改动，需单独实施与验证；本级保持现有单边方案。
