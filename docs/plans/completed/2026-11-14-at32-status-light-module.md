# AT32 状态灯模块化与 2 kHz 调度

基线 c495b040 的灯语由应用前台每 50 ms 轮询。两款 AT32 APP 改在 TMR6 监督拍更新，
保持五种灯语和 PC13/PC14 的低有效接线。应用模块计算逻辑亮灭，MCU 驱动负责引脚。
验收覆盖完整灯效周期、跨状态优先级、两板中断路由、Keil 两目标和 PR 检查。
[前台版本的 28 V 验证](2026-11-13-at32-status-lights.md)保留作基线。回退本次模块和调度改动可恢复原入口。

两个固件目标均经 Keil 编译和链接，APP 与 Standalone 各 0 错误、0 警告。
原生测试逐拍覆盖空闲心跳、硬件检查快闪、标定双闪及状态切换，检查了故障优先级和 GPIO 电平。
中断路由测试验证状态灯在轴监督更新后执行。
全仓 PR 检查通过，记录见 `outputs/runs/at32-module-2khz-final/summary.json`。

## 2026-11-14　28 V 关相实板验证

右轮节点 4 烧录配套 Loader 的 2 kHz APP，镜像 CRC32 为 `ca47b7e2`。烧录后全片回读一致，Loader 和参数区与烧录前相同。
下表灯效取自 J-Link 对 PC14 蓝灯和 PC13 红灯的 GPIO 回读，时间按主机采样边沿计算。

| 阶段 | 实测结果 |
| --- | --- |
| 启动后空闲 | 母线 28.25～28.30 V。三个蓝灯脉冲分别亮 103.5、108.9、99.0 ms，连续周期为 2.0015、2.0116 s。 |
| 关相硬件检查 | 第二轮在 0.101 s 进入等待驱动，3.111 s 等待超时。蓝灯连续快闪约 3.1 s，29 个相邻亮灭边沿间隔为 93.2～106.0 ms。红灯始终熄灭，两路 GPIO 输入与输出回读一致。 |
| 返回空闲 | 未发驱动命令。检查按等待超时中止，轴回到无故障 IDLE，三相输出关闭。随后两个蓝灯亮起边沿相隔 2.007 s。 |

第一轮静态检查通过，CAN 轮询中断了灯脚采样。第二轮由 J-Link 独立记录边沿，结束后通过 CAN 读回同轮报告。
第二轮 62,003 个母线样本均在 27～29 V 窗口内，实测 28.20～28.35 V，已安装的静态项目全部通过。
本次覆盖空闲心跳和关相检查快闪，未测动态驱动项目及 2 kHz 中断执行耗时。

原始记录位于本机 `outputs/at32-2khz-led-board-1794668525459/` 下的 `idle.json` 和 `retry-28v-1794668899779355400.json`。
