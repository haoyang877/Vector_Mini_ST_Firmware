# 输出轴采样分块16位差值验证

核对日期：2026-11-13。固件基线为 `e02e82ec`，本调查未修改固件。

## 结论

16点分块、32位基准和每点16位差值，在现有正常曲线上可以无损表示电机计数，
名义节省3584 B。但当前接口和采样逻辑没有保证块内跨度不超过65535 counts。
实际采样函数的回退、停留、再前进输入可以超过这个范围。
没有证明异常块数量上界前，不能限制原值回退空间。因此未将候选并入生产代码，
也未改变原始数据、采样数量、失败条件、标定运算或48 KiB链接预算。

本结果否定的是当前固定块编码的无条件容量保证，不证明所有无损压缩都不可行，
也不把离线采样反例当作整机所有状态和物理运动均可达的证明。

## 当前数据与候选

[采样类型](../../firmware/motor/feedback/output_encoder.h)的电机数据为8192 B，
两路12位Hall打包为6144 B，状态和对齐40 B，合计14376 B。

候选对每16点取最小值作为32位基准，保存无符号16位差值。使用最小值比固定首点的
有符号差值更宽容：只要最大值减最小值不超过65535，整个块均能无损表示。
差值与还原在64位中计算，避免INT32边界的中间溢出。

| 布局 | 电机数据 | 含Hall和原状态的名义总量 | 名义节省 |
| --- | ---: | ---: | ---: |
| 现有int32数组 | 8192 B | 14376 B | 0 B |
| 8点块 | 5120 B | 11304 B | 3072 B |
| 16点块 | 4608 B | 10792 B | 3584 B |
| 32点块 | 4352 B | 10536 B | 3840 B |

以上候选容量未加入原值回退区，也不是已构建固件的RAM实测结果。
生产采样为4 kHz，块内重定基准还需有界更新已有差值；离线编码成功不等于该实时写入已验收。

## 等价与边界实验

候选及驱动保留在 `outputs/block-delta/probe.inc`、`run.py`；执行命令：

```text
uv run python outputs/block-delta/run.py
```

驱动复用两板原生输出轴夹具和真实生产采样/结算/参数代码。每次结算先编码，再还原到
独立的原布局；逐字节比较全部采样区，并分别运行原始与还原数据的CalibEnd，比较返回值、
完整OutputEncoder及LinearHall（包括1024点LUT）。没有替换滤波或拟合算法。

- 两种板型各62次结算对照全部相同，包含成功和失败路径。
- 每板38次完整2048点结算的最大块跨度：8点9100、16点19429、32点40132 counts。
- INT32_MIN/INT32_MAX附近、负数、跨零及跨度65535均可精确还原。
- 跨度65536和完整INT32两端被候选明确拒绝，禁止截断。
- 既有全部12位Hall组合和完整32位电机原值存取检查继续通过。

## 区间均值反例

[实际采样函数](../../firmware/motor/feedback/output_encoder.c)按绝对行程阈值提交区间均值。
未达到下一阈值期间的回退和停留都会参与累计，均值不等于提交时刻的位置。
因此相邻保存值的差不能直接用相邻ADC拍的位移上限替代。

离线输入使用40:1、每拍位置改变60 counts、4 kHz。先前进到1001个存储点，
回退到相对起点100000 counts，停留4000拍，再前进直至收满2048点。
所有传给采样函数的单拍增量均为0或正负60；总计87883拍（21.97075 s）。
触发问题的是第1001号点（从零编号）：前值1292400，新区间均值642306，
相邻差为-650094 counts。8/16点块最大跨度659154，32点块679854，均超过65535。

原CalibEnd对此输入返回false，output status为3，Hall status为2；实验没有把失败改为成功。
这是实际采样函数的反例，不是台架运动，也没有证明整机观测器会一直保持锁定。
反过来，目前整机边界也没有形成可用于此编码的块跨度定理，不能据此省略回退。

## 回退容量与后续门槛

现有存取接口保留完整int32位模式。接口级边界实验可使128个块全部不能编码，
这些块保存原值至少仍需8192 B，另有标志/索引开销。
这不代表随机全范围数据是实际机械曲线；它说明若要缩小异常池，必须先证明生产输入域
更窄，而不能把已通过的正常曲线当作容量上界。

下一候选必须满足以下任一条件，才可继续实施：

1. 从现有完整状态机、计数、时限和故障语义证明块跨度或异常总量的严格上界；
   不能为编码方便额外拒绝原本可处理的输入。
2. 提供另一种最坏容量仍小于现有存储的无损编码，覆盖原输入域并保持有界采样开销。
3. 找到确实互斥的其他内存阶段，证明回退借用不会破坏同时活动的电机LUT工作区。

没有采用简单int16截断、减少2048点、减少LUT点数、上位机代替标定或Flash采样暂存。
本轮无固件修改，不声称新的RAM缩减或实机时序通过；原版本仍为48944 B总RAM。
