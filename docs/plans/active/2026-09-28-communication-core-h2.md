## 实际交付与所有权

| 删除或替换 | 替代与调用迁移 |
| --- | --- |
| 独立 STOP/ENABLE 两份处理器 | 一份 handle_motor_power；路由、权限、特殊长度拒绝顺序及回复码保持 |
| GET_INFO/GET_CAPS 本地编号副本 | 使用 protocol 已有常量，避免两份编号来源 |
| IRQ 重复帧格式过滤 | link 的 OnRxFrame 唯一验证，ISR 仍最多采集 3 次 |
| 查询时 nullable 快照分支 | 初始化/解绑时绑定 link 的空快照，保留缺失样本的结果与哨兵 |
| 多处局部清零及零值设置 | link_context 一次 memset，显式建立默认绑定和非零常量 |
| applied_sequence 误导命名 | response_sequence，router 和全部 C 测试引用已迁移；结构布局未变 |

本基线已删除旧 111/旧 108 线路兼容路径，本轮没有残存兼容路由可再次删除。
endpoint_process_one、只读提供者和参数桥有现有接口/测试调用，未因生产调用少而删除。

link 独占静态端点、队列、重组、控制历史和待发状态；快照只借用 app 的 const 指针。
RX 仅 ISR 入队、前台在短临界区出队；TX、路由、CRC、反馈编码仍由前台串行拥有。
runtime 独占配置桥值、一次启动标记和 bus-off 调度；link 冻结启动地址。参数桥 Get/Set
保留真实参数装载/保存调用，不在线重配端点，不新建看门狗。两种 ready/initialized 分别表示
链路资源与运行时启动完成，不合并为一个含混状态；不新增跨模块 extern 可写对象。
