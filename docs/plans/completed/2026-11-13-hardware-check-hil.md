# AT32F456 硬件功能检测实测

2026-11-13。当前基线 `ac661bed`，分支 `codex/hardware-function-check`。

目标：在本轮连接的单板上验证通信、关相静态采样和具备明确现场条件后的双向检测。
先通过 SWD 与 CAN 核对同一 UID、节点及 APP 能力；本轮识别节点为 6。
原板停在 Loader，已有 APP 描述符为 1.6.2，尚不能作为本分支检测结果。

不变项：保留完整参数、标定、生产身份及镜像范围以外的数据；不修改保护阈值、
协议 ABI 或生产默认参数。不继承其他历史台架的电流和机械行程授权。

步骤与验收：

1. 已完成关相核验、整片 Flash 双读备份及 schema14 参数 CRC 验证。
2. 构建本分支匹配的 Loader/APP，记录构建日志与哈希；部署后逐字节回读镜像及保护区。
3. 执行 release 级离线检查，单独记录既有文档断链失败，不据此宣称 release 通过。
4. 核对 APP 身份与硬件检测能力，运行关相静态窗口，保存 CAN 原帧和实际数值。
5. 双向驱动须先取得现场供电、限流、可用行程及固定/负载条件；结束核对 STOP 与实际关相。
   未取得实物方向参照的动态项保留未测。

证据统一保存在 `outputs/hardware-check-hil-20261113/`，离线验证在 `outputs/runs/`。
回退使用本轮写入前完整 Flash 备份，恢复后核对参数及身份；任何回读不符立即中止并保留现场。

## 本轮结果

现场条件由用户确认：空载，供电 28 V、电源限流 5 A、相电流上限 7 A，
正反向行程不限，环境约 20 °C。动态候选使用 1.6 A、3 Hz 电频、去回各 1000 ms；
实际被准入拦截，没有下发运动启动或目标。

先前镜像停在 Loader。已构建并部署当前分支 APP v0.7.3 / Loader v2.3.3，
两个目标均为 0 错误、0 警告。合并包逐段回读、段外保护区及重启后的完整参数比较通过。
构建前通过原生成入口修正配套工程末尾换行差异；XML 元素、属性和源码清单不变。
