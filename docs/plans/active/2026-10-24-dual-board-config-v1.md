# 双板共用配置收敛 v1

日期：2026-10-24。仅修改配置、构建入口、定向离线测试及文档，不连接硬件。

## 目标与不变边界

旧板/HT8115-4与新板/YQ-5708共用APP、FOC、状态机、标定、保护和协议实现。
板级差异由平台配置及端口实现，电机差异由型号配置，测试例外由目标配置拥有。
BSP API全部文件、算法及APP的C实现、控制时基、CAN 1M/5M、参数布局保持不变。
保留当前默认值，不把PLL 500Hz或临时热参数升级为正式产品默认值。

## 当前问题与实施

- 两个AT32完整APP的Keil Define重复散列身份、保护模式、外设及电机整定。
  改为每个工程预包含一个目标配置头，公共设置只写一份。
- 共享电机默认入口判断AT32台架宏。移除硬件判断，临时热数据由目标配置提供，
  通用入口只检查完整性；没有明确测试配置的未确认电机仍编译拒绝。
- 公共启动配置判断YQ型号。型号相关标定转速移入电机profile，保持现有数值。
- 速度估计头内保存默认PLL数值。移入共用反馈配置头，默认90Hz不变；
  500Hz覆盖只存在于限时目标，离线带宽测试改读新配置位置。
- 已集中在boards中的ADC尺度、母线电流能力、温度策略、电流上限继续沿用，
  外设寄存器、引脚、Flash布局仍由各平台拥有，不制造通用寄存器抽象。
