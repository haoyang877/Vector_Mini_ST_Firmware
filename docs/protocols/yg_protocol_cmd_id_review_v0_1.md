# yg_protocol CMD ID 核对表 v0.1

日期：2026-09-23。状态：**待公司消息类型表登记及项目评审；此表不授权修改控制固件**。本文用于在实现[简化电调协议](yg_protocol_simplified_motor_v0_1.md)前冻结业务 `type:u16`。CMD ID 是公司应用帧头偏移 6～7 的 `type`，不是 29 位 CAN ID、`mode`、参数 ID、标定子类型或结果码。所有 Type 十六进制按小端序发送，例如 `116 / 0x0074` 在线上为 `74 00`。**124 的反馈字段与触发时机已更新，见[逐命令反馈契约 v0.2](yg_protocol_motor_feedback_v0_2.md)。**

## 1. 三份证据及其权限

1. [公司《消息类型定义》](https://wcnxj7iyqdkp.feishu.cn/wiki/DXV4wohO0ioGbskmFAFct8wFngd)在 2026-09-23 核对时，仅 `0x0000` 测试指令填有名称和 ACK=Y。表将 `0～99` 留给通用消息、`100～199` 留给电机、`200～299` 留给感知；`0x0001`、`0x0064`、`0x0065` 等只是空编号格，**没有为本项目批准具体含义**。该表最近修改仍显示 9 月 2 日 21:43。
2. [飞书《电调通信协议》](https://wcnxj7iyqdkp.feishu.cn/wiki/M5KJwCZApilqfjk251XcktAPnxa)定义使能/失能、模式和控制目标及 0～5 模式值，但没有填写任何 CMD ID、单位或完整反馈字段。升级条目标注“由 AI 补充”，不能作为正式编号批准。
3. 当前仓库已注册业务路由 `1 GET_INFO`、`2 GET_CAPS`、`108 GET_MOTOR_STATE`、`110 MOTOR_STOP`、`111 MOTOR_DISABLE`；其中 110/111 执行服务尚未绑定。`124 MOTOR_FEEDBACK` 有描述符/编码器，尚无周期发送。仓库编号与公司表登记状态不能混同。

因此，**公司已确认的具体 CMD ID 只有 0 TEST**；下表其他编号都是待登记的项目分配建议。仓库已有路由可用于本项目内部读取/联调，但不能据此宣称公司其他设备会按相同含义解释。

## 3. 明确退役、不重复占号

| 旧编号/含义 | 处理 | 原因 |
| --- | --- | --- |
| 111 MOTOR_DISABLE（当前路由） | 在 101 SET_ENABLE 实现时删除路由并同步主机；正式版不保留同义入口 | 一个使能/失能命令即可，且 111 执行目前未绑定 |
| 4/5 控制会话、106 SET_MODE、109 SET_REPORT、112 GET_CONTROL_STATE、113 KEEPALIVE、114 ARM | 不登记本轮简化业务 | 正常控制只需 101+116；反馈 124 回显实际应用序号 |
| 100/102～105 历史独立控制命令 | 保留空号，不恢复旧含义 | 避免重新分拆模式和目标 |
| 126 MOTOR_EVENT、130～159 轨迹/回零族、164～169 扩展任务族、181～192 多个同步管理命令 | 不在本轮占号；将来证明有独立业务再申请 | 飞书新页未定义这些业务，避免先登记一批无实现命令 |
| 历史 50～59 十条升级候选 | 由本表 50～56 简化候选整体替代 | “传输中”“校验完成”是状态；镜像清单并入 BEGIN，不需要同义多步入口 |

111 虽然退役，但在真正改固件前仍是**当前有效路由**；主机不能提前把 111 当成新语义。108/110/124 等保留同一编号但 payload 或回复将变更，因为用户已明确不要求旧协议兼容，仍需版本化文档、黄金向量和主机/固件同时切换。

## 4. 核对结论与冻结门槛

- **无重号**：建议清单内部 28 个数值互异；通用编号均在 0～99，电机编号均在 100～199，不碰公司感知段 200～299。CAN ID 的 PF=0xEF 与这里的 `type:u16` 属于不同层，不构成冲突。
- **有语义替换**：101、116、50～56、160～163 改写了历史未实现提案；111 当前路由需要删除；108/124 是实际格式迁移。这些必须按新协议版本一起切换，不允许主机和固件各用一张表。
- **尚未得到公司正式编号确认**：须将本表的名称、方向、ACK、payload/回复和说明填入公司《消息类型定义》并取得负责人的确认；在此之前文档保持“候选”，不能开始 101/116 的控制业务接线或宣称升级 Type 定版。
- **分批冻结**：先确认首批 1/2/101/108/110/116/124，随后参数/标定、五轴同步和 Loader 升级各在动代码前冻结对应条目。0 已在公司表定义。模式 5 的物理动作和 mode 6 电压单位另按[简化版协议](yg_protocol_simplified_motor_v0_1.md)评审。

逐项功能、准入条件、回复和失败状态见[CMD 功能契约 v0.1](yg_protocol_cmd_function_contract_v0_1.md)。本轮只完成编号与功能设计，不修改固件、主机或飞书公司表。
