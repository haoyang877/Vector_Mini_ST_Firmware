日期：2026-10-08。开发候选，未正式发布、未实机验收；源码与产物以当前清单为准。

## 实际接入

- 编码器 v3/v4、齿槽任务 v3、MotorAxis v3 合并到同一程序，模式/数学/开发观察保持。
- 主流程保留八状态执行边界，六类视图只读推导；已有标定步骤串联最后独立 SAVE，
  实际回读提交后才完成。运行切换先关相、确认真实快环中性预载后重新准备。
- 项目内0x0076运行会话及0x00A6标定计划接入真实所有者；线值和内部枚举明确映射，
  新START核对本次epoch，完整payload去重，续租重放不延长租约。
- 已修复拒绝启动残留来源绑定，以及不同来源拒绝记录污染序号；主站STOP/失能/
  成功CLEAR撤销新命令缓存，非主站STOP不推进主站水位，旧命令字节保持。
- 启动计数provider位于现有参数区域61/62页，最后双字提交并完整读回才发布。
  RAW只写56..58页，59/60保留，63身份页不动；未知、撕裂、ECC和耗尽不伪造身份。
- Qt 通过用户显式打开的 Python/ControlCANFD GET-only 端口查询身份、能力和反馈；
  不同UID/启动身份清旧快照，SN显示ASCII；功率、参数写入和升级发送仍关闭。

## 发布与维修限制

新命令已注册在开发程序中；能力声明仍保守为0，不能把代码存在当产品安全验收。
公司外部CMD表同步尚未确认。旧117/旧单项维护为调试兼容路径，不宣称已防跨复位重放。
未实现电感/磁链辨识、Nm力矩、类型选择profile、电阻结果应用政策；不能声称全参数已辨识。

本固件每次程序启动会在专属计数页追加或轮换记录，读取GUI本身不写计数。
参数保留验收要分RAW、身份、计数和保留页；正常启动计数增长不算标定损坏。
不可将历史整片/16KiB备份不加区分恢复，或擦计数回到1；硬件抗回滚和安全维修工具未实现。
双位ECC可能停在已关相初始化，不能在线诊断或自动续试。

normal从0x08000000链接，是独立APP，不能用于CAN升级；将其写到有Loader的设备会
覆盖Loader所在区域，部署前须由实际台架所有者明确备份和方案。
LoaderApp从0x08005000链接，须独立满足94208B槽及真实镜像容器/升级/恢复规则。
本轮完整接线源码0ec1aa90：normal为98616B，静态RAM为27080B。
LoaderApp同对象诊断重链接为101016B，超正式槽6808B；Loader本体15100B。
诊断仅用于测量，不可部署；未改变正式分区，不能相加对象收益或使用放宽诊断包。
目前没有探针/USB-CAN连接、下载、复位、参数写入、运动或实机PASS。
只读GUI已打包Qt运行库，离线八页面预览通过；真实读取仍需用户选择Python运行时与厂家DLL。
该包是可查看候选，不是安装器或实机验收版本，不自动重连或恢复运动。

实际离线验证、组合资源及未完成项登记在本候选输出清单；正式release仍须匹配实机证据。
