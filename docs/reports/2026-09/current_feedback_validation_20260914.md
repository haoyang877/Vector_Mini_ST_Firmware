# 电流反馈扩展与双轴烧录验证

日期：2026-09-14。协议定义见 [CAN 状态流](../../guides/can_motor_status_stream.md)。

## 版本与行为

在固件基线 `8d16ba4` 上增加周期母线电流反馈：48 字节帧中偏移 36 为有符号毫安 Ibus，偏移 38 为扩展版本 1。原 Iq 参考和实测字段保持偏移 20、22。Ibus 来源为 `FOC.Ibus_filt`，属于估算滤波值。旧/未知扩展版本及无效哨兵必须表示不可用，不能当作 0 A。

配套 motor_ctrl_app 提交 `1209f2c`（v0.20.0、UDS 11）分别提供 `ibus_a`、`iq_reference_a`、`iq_feedback_a`，修正此前将周期 Iq 映射到 Ibus 的错误。Iq 输出应用产品方向（roll +1、pitch −1）；Ibus 不翻转。CAN 参数格式修订号仍为 2，Flash 参数 schema 仍为 10。
