# AT32 ADC2 四路等长采样

## 目标与基线

基线 febb2d87。按最终需求将 ADC2 抢占组调整为母线电压、母线电流、Hall A、Hall B，
四路采用相同采样时间，总时长接近且不晚于 ADC1 三相电流序列。
已有 v1.8.19 ADC1 普通组隔离方案仅作为台架回退包，不保留第二套运行路径。

## 实现与不变行为

- APP v1.8.20：ADC2 四路各 47.5 周期采样保持，含转换各 1 us，合计 4 us。
- 结果槽依次为 PDT1、PDT2、PDT3、PDT4，调用方的电流、Hall 和电压映射同步。
- ADC1 三相四次累加、22.5 us 触发、27.5 us 完成、20 kHz 快环及 4 kHz 外环不变。
- NTC 继续使用 ADC2 普通组、640.5 周期及 TMR6 2 kHz 触发；ADC1 普通组不使用。
- 保留有效电压样本恢复后重建 NaN 滤波状态的修复，不改单位换算、阈值、参数或 CAN ABI。
- 使用现有 ADC 私有实现和资源映射，无需新函数、文件、结构体或公共接口。

## 验收与回退

原生测试覆盖四路顺序、采样时间、结果槽、两组完成门禁及停采恢复；运行 PR 和 release。
用户授权的节点 7 场景为机身固定、输出轴整圈自由转动，升级后连续三次标定，
采集固件发布到 RAM 的电压、Hall 和快环计数，不读取有清标志副作用的 ADC 数据寄存器。
检查升级参数保留、结束关相、故障和温度，量化电压与 Hall 的关系。
若位置相关电压漂移复现，恢复 v1.8.19，不将数字时序合格视为模拟精度合格。

代码、文档与验证流程的改动在此归档；台架结果、原始数据和候选包保存在忽略的 outputs，
不纳入源码提交。当前发布资格必须以本次 summary.json、产物哈希及台架验收为准。
