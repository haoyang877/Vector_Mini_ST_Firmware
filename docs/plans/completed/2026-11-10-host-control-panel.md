# 调试页右侧控制区

日期：2026-11-10。用户要求模式、使能/失能、STOP、目标集中在右侧，模式使用下拉框，
取消运动控制的台架确认勾选，使能/失能和 STOP 更醒目。

## 基线、约束与验收

基线为 v2.7.0 工作区；保留波特率、型号与参数配置等已有更改。
新增独立控制面板模块，页面只组合面板与曲线；设备线程继续独占控制和停机判断。
取消 START/目标命令中的人工勾选字段，不取消 UID/目标、能力、配置、标定、
新鲜反馈、故障、限值或 STOP/IDLE 检查。升级和参数写入的确认各自保留。
使能、失能与本地 STOP 都由用户点击触发，禁止自动使能；失能和 STOP 共用 Type110。

右侧面板在趋势工具栏之前取得完整高度，1024 窗口也能直接看到模式、
两种使能操作、红色 STOP 和目标下发。下拉菜单需覆盖深浅主题、禁用状态和窄窗口。
离线测试覆盖去掉勾选后的运动准入、原有故障/过期保护与预览无硬件访问；
执行 Rust 测试、Clippy、发布构建、原生预览及仓库 quick。

## 回退与未测

回退本次面板、运动确认字段与对应文档即可；无固件、协议或参数 ABI 变化。
本轮不操作设备，Type108 超时及四种模式实机仍属于原实测计划的未完成项。

离线实现完成，候选 v2.7.1。右侧面板在观察工具栏前取得完整高度，模式使用下拉框，
绿色使能/橙色失能同排，红色 STOP 独占一行，目标与实测及下发紧邻。
START/目标命令已移除人工勾选字段，设备快照准入与线程发送前复核保留；
升级和配置写入的确认各自保留。
