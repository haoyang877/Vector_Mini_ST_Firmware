## 2. 开始前的强制条件

以下条件全部满足才进入上电测试：

- 电机空载且轴周围没有人员、线缆或松动物体；需要堵转的项目使用专用固定夹具；
- 有可立即操作的母线断电开关或急停，操作者手不离断电装置；
- 台式电源启用电流限制，首轮建议从 13–15 V、0.5–1 A 输入限流开始；
- 示波器探头地线、电流探头和调试器不存在错误接地回路；
- 首次烧写前断开电机母线，并确认功率级硬件处于禁止状态；
- 记录电机型号、极对数、编码器安装方向、电源设定、环境温度和固件版本；
- 每一步出现异常声音、抖动、反向加速、母线电流突增或温升时立即断电。

## 3. 分阶段门禁

任何阶段失败都停止，不跨阶段继续。

### Gate 0：工具链和固件基线

操作：

1. 电机母线断电，保留满足烧写需要的逻辑电源。
2. 用 J-Link 连接 `STM32G431CBUx`，接口 SWD，初始速度不高于 4 MHz。
3. 烧写 `MDK-ARM/Vector_Mini_ST/Vector_Mini_ST.hex`，执行下载校验。
4. 断开调试会话；不要在母线带电时留下断点或停核条件。
5. 保存固件 Git revision、构建时间和 HEX 哈希。

通过条件：下载、校验均成功，MCU 能独立复位运行。

### Gate 1：上电安全与自动零偏标定

操作：

1. 接好板载 USB CDC 或 CAN；先不要发任何写命令。
2. 打开母线电源，观察输入电流和电机是否保持静止。
3. 固件应自动进入模式 11 完成电流 ADC 零偏标定，然后回到模式 0。
4. 连续读取模式、故障、编码器、母线电压、温度和三相电流至少 10 s。

USB 只读命令：

```text
\r_mod
\r_err
\r_e_s
\r_vbs
\r_tmp
\r_i_a
\r_i_b
\r_i_c
\r_i_d
\r_i_q
\r_s2f
\r_p2f
```

也可运行仓库内的只读冒烟测试：

```powershell
python tools/usb_position_test.py COMx --verbose
```

通过条件：

- 最终 `mode=0`、`error=0`；
- 编码器返回 `TLE5012B-Online`；
- 母线读数与电源表差异在 5% 以内，且位于 10–30 V；
- 静止时三相电流、Id、Iq 建议均在 ±0.10 A 内；
- 温度接近环境温度，建议首轮偏差不超过 ±15 °C；
- 电机无出力、无抖动，输入电流稳定。

### Gate 2：编码器静态检查

保持 `mode=0`，手动缓慢转动电机轴一圈，记录 `p2f` 和 `s2f`。

通过条件：位置连续变化，跨零点只有正常的角度环绕；正反转符号一致；静止后速度
回到接近零；无 Offline、跳变、CRC/编码器故障。此阶段只确认反馈链路，不修改
`erv`，也不保存参数。

### Gate 3：协议边界与功率级零指令

先在 Standby 写入临时安全限制，不保存：

```text
\w_mod=0
\w_ilm=0.5
\w_slm=0.1
\w_sac=0.125
\w_sde=0.125
```

读取并确认回读值。随后写 `\w_i_s=0` 进入电流模式，保持 2 s，连续观察相电流、
Id/Iq 和输入电流，然后立即 `\w_mod=0`。

通过条件：零电流指令不产生可感知转矩，电流仍处于 ±0.10 A 附近；模式 0 能立即
关闭输出；越界值和 NaN/非法文本被协议拒绝且不改变原参数。

### Gate 4：低电流方向与相序

仅在轴已固定、固定机构允许小转矩时执行。保持 0.5 A 限流，分别给出 +0.10 A、
0 A、-0.10 A 的短时 Iq 指令，每个非零指令不超过 1 s，指令间回到模式 0。

通过条件：正负转矩方向相反且符合定义；三相电流平衡，无单相异常；撤销命令后输出
立即关闭。若方向错误，先核对相序与编码器定义，不直接用软件反向掩盖接线问题。

### Gate 5：低速首次运动

电机必须空载、可以自由旋转并置于防护范围内。优先使用带参数恢复和自动停机保护的
脚本：

```powershell
python tools/usb_position_test.py COMx --run-motion `
  --delta-rev 0.02 --current-limit 0.5 --max-speed 0.05 `
  --acceleration 0.125 --deceleration 0.125 --duration 5 --verbose
```

先正向 0.02 圈，通过后再反向 -0.02 圈。脚本退出时必须确认 `mode=0`，并恢复原
参数；如果通信中断，立即人工切断母线。

通过条件：无失控、抖动和异常噪声；位置误差进入 0.02 rad；峰值电流不超过 0.5 A；
正反向均能停在目标附近。

### Gate 6：标定流程

按以下顺序执行，每项完成后都必须回到模式 0 且故障为 0：

1. 模式 11：再次验证电流零偏标定重复性；
2. 模式 15：先把标定电流降到 0.5 A，再做电角度零位标定；
3. 模式 17：相电阻辨识；需要双电流点，必须单独评估并逐步提高允许测试电流；
4. 新电机优先执行模式 5 的受限电流闭环旋转矢量 LUT 标定；观察器已独立验证后，
   才可选择模式 13 的编码器/观测器 LUT 标定。模式 13 目标约为
   +20 mechanical rad/s（约 191 rpm），只能在自由旋转和完整防护条件下执行；
5. 核对标定结果和方向后，模式 9 保存参数。

模式 5 与模式 13 二选一，不重复执行。

通过条件：每项均自动结束；电流、速度和时间没有越限；编码器保持在线；相电阻三相
差异低于 Profile 故障阈值；保存过程不产生故障。

### Gate 7：控制模式逐级验证

每一级从 0.5 A 限流开始，先正方向、后反方向：

1. 电流模式 1：±0.10、±0.25、±0.50 A；
2. 编码器速度模式 2：±0.02、±0.05、±0.10 rev/s；
3. 位置阻抗模式 18：±0.02、±0.05 圈；
4. 位置级联模式 3：相同小角度阶跃；
5. Vq/开环/无感模式 14/12/16 最后验证，并建立单独的电压、速度和失锁保护记录。

每次模式切换前先写模式 0；监视母线电流、相电流、速度、位置、温度和错误码。

### Gate 8：故障与恢复

在低能量条件下验证：

- 通信超时后输出关闭；
- 编码器故障在需要编码器的模式下触发关断；
- 缓慢降低母线触发欠压，禁止直接短接或制造过流；
- 故障清除前不能重新使能；
- 清故障只回到 Standby，不能自动恢复原运动命令；
- 复位、看门狗复位和异常状态均保持 PWM 关闭。

过压、硬件过流和堵转测试需要专用工装、保险丝/电子负载和示波器，不纳入桌面首轮
验证。

本次台架因温度 ADC 异常，允许使用显式定义
`HARDWARE_VALIDATION_SKIP_TEMPERATURE_PROTECTION` 的临时验证镜像继续其他项目。
Production 默认值始终启用温度保护。验证镜像必须有人值守、低压限流运行，且不得
用于量产、无人值守或额定功率测试；测试结束必须恢复 Production 镜像。

## 4. 中止条件

出现以下任一情况立即写模式 0；通信不可用时直接切断母线：

- 电机意外连续转动、方向与指令相反或速度继续上升；
- 电源进入限流、母线电流突增或相电流超过当前软件限流；
- 编码器 Offline、位置跳变或速度在静止时持续非零；
- 温度快速上升、功率器件或电机出现异常声音/气味；
- MCU 被 J-Link 停核、程序跑飞、通信丢失或错误码非零；
- 模式 0 后输出仍未关闭。
