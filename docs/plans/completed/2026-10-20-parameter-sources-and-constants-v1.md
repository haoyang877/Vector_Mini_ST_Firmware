# 参数来源与编译期派生收口 v1

## 目标与基线

基线为 `codex/system-refactor@b5c5a36d8ef6c961b8f1e3204d887a4b1a02696c`。
按硬件、电机、应用、设备归属以及输入、派生、标定、运行来源整理现有参数。
固定板型和型号的派生表达式由宏形成编译期常量；依赖已装载配置或测量的量保留运行时来源，
可提前计算的动态系数仅在初始化或停机配置提交处生成，不用宏伪装成常量。

本批复用现有 profile、值对象、参数事务和标定所有者，不新建配置注册器或重复参数表。
保留用户修改、其他会话工作及当前已下载镜像，不连接硬件或改动实际测试候选。

## 不变项

- schema13 的字段、大小、偏移、CRC、Type121/122 权限及设备身份保持。
- 默认数值、浮点运算顺序、四次 ADC 累加、20kHz/2kHz 时基和保护阈值保持。
- 有效 Flash 中已保存的电流 PI 继续装载，不因重新计算默认值覆盖手动整定。
- 标定资格、配置确认、STOP/FAULT、热历史和真实保存的时序保持。
- 不把运行状态改成宏，不扩展电机型号、不自动辨识，也不改 CubeMX 生成区或链接布局。

## 实施范围

1. 板级 profile 区分原始设计输入和编译期换算量，合并 ADC 参考、电流/电压换算与时基的重复来源。
2. 电机 profile 声明默认电流 PI 的派生公式，参数默认装载引用相同宏；应用/设备默认值注明来源。
3. 持久记录仅加来源说明，不改变布局。文档逐类说明填入、计算、标定、运行和失效规则。
4. 对仍在周期中计算的量做窄审；只有不增加隐式状态、不改变既有配置语义的优化才纳入本批。

## 验收与回滚

复用并按需扩展现有默认参数/装载、采样换算原生测试，核对固定派生值与基线，
明确加载已保存 PI 不被默认公式覆盖。完成一次 PR profile（含格式、lint、架构及原生检查）。
对编译期常量可核对编译输出，不以宏数量宣称运行速度提升；不启动全套实机或多工程构建。
若改动引入额外动态除法、改变二进制值/ABI、保护行为或新增隐藏状态，应缩回该项。

各项独立于固件功能改动，回滚本批提交即可恢复；不修改旧存储或烧录镜像。
本批离线通过不等于新固件已实机通过。
