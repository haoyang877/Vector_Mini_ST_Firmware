# 新标定表的速度闭环带宽

2026-11-05，在 AT32F456、YQ-5708（8:1）、输出轴自由的同一台架上，实测从 CAN 速度目标到编码器 PLL 速度反馈的频响。转速均为电机侧 rad/s。

## 测量条件

- 板上为已修正参考角的镜像，HEX SHA256 为 `b91a1bb8b3466bca42204b3430dd4518848bc718f4acd0f19b97e486041ae083`。每次起动前核对 UID、应用、两项零位、方向、标志及完整 LUT；本次使用的 1024 点 LUT 的 SHA256 为 `75b170ed5e5e10f93eef3f9a51c36317e22e9fc0f560e42f0984bd263b49cd7c`。
- 速度环 2 kHz，测速 PLL 自然频率 90 Hz，速度 PI 维持 Kp=0.015、Ki=0.3。电流限制 3 A，每个工作点仅在 RAM 临时放开速度包络，关相后恢复并回读。
- 先测 0、正反向 1、3、5、10、20、30、40、45、48 共 19 个工作点。每点五组三频激励覆盖 2.6 至 90.3 Hz，共 15 个独立频点。50 rad/s 是反馈截止值，两侧 48 rad/s 给小信号和背景波动留出余量。
- 再做独立单频试验，重点加密 ±10 rad/s 的截止附近，并避开明显转角阶次。每次 CAN 命令核对受理回复，按发送与应答中点做零阶保持重建。输出取 2 kHz RTT 速度反馈，故测得的闭环包含参考斜坡、速度 PI、电流环和 PLL。
- 各频率以 Hann 加权的正余弦拟合求输出与实际输入幅值之比，同时检查前后半段及加入机械角阶次后的估计。禁止直接将转角谱线的高度当成受迫响应。
- 在 |速度|≥10 rad/s，另施加两个相邻恒速台阶，剔除过渡段，按整数机械转计算两侧平均速度；台阶输出差与目标差之比给出局部直流增益。带宽取截止附近增益比该直流值下降 3.01 dB 的频率。窄带峰值和截止频率分别判断。

## 截止的判读

每个速度点都另做了单频试验。10 rad/s、转角谱影响较大的点以及边界点还用较长记录复测。中高速估计用 60–77 Hz 内的独立单频结果在截止附近作局部直线拟合。前后半段不一致，或加入转角阶次后增益变化较大的点，权重较低。表中的包围区间是实际测过的两个单频，两端的前后半段都在阈值的相应一侧，完整记录和转角校验至少距阈值 0.3 dB。包围区间用于说明测量分辨率。

在 +10 rad/s，直流增益为 −0.073 dB；67.85、68.45、70.80 Hz 的独立单频增益分别为 −2.76、−3.04、−3.96 dB。在 −10 rad/s，直流增益为 +0.013 dB；66.05、68.45、70.15 Hz 分别为 −1.75、−3.18、−3.50 dB。两方向的实际截止都在约 69 Hz 附近。正转另一次在 70.15 Hz 得到 −3.03 dB，因此按 Hz 量级使用结果更合适。

## 高速峰值、采样及收尾

±48 rad/s 在首轮三频激励的 42.7–48.7 Hz 区域出现约 +3 至 +4 dB 的表观峰值。独立单频复测同一频率，+48 rad/s 在 42.7、48.7 Hz 分别为 +2.81、+2.08 dB；反向分别为 +2.84、+2.31 dB。正转 47.9 Hz 为 +2.97 dB。因此单频复测未复现首轮约 +4 dB 的峰，正转在已测频点上接近 +3 dB 判据。这些是离散频点结果。

共记录 426 个频率响应值，采用 425 个。−48 rad/s 首次长记录的 73 Hz 点出现 19.2 ms 的采样时钟拟合抖动，已标注排除；在相同转速、相同频率补测，结果为 −4.09 dB。其余采用的记录采样率为 1997.84–1997.98 Hz。扫频记录中电机侧速度范围为 −49.41 至 +49.57 rad/s，实测 Iq 的绝对峰值为 0.55 A。

52 组试验均完成 STOP、关相、恢复包络并回读。最终独立核对镜像、新表、Kp=0.015、Ki=0.3、3 A 限流，速度配置恢复到原值。设备为空闲、无故障、相输出关闭。本轮没有烧录或改写持久参数。
