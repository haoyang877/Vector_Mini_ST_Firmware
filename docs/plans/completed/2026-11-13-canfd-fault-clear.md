# CAN FD 故障解析与显式清除

目标：v1.10.0共享电机栏显示协议故障位名称，增加全页共用“清除故障”按钮；
Type107只显式点击时发送一次，随后读Type108确认零故障、IDLE、NONE。保留原始码、
应答、清除前后状态和超时；不得用受理代替完成，不得自动启相或重启。
基线`4844ac58`，APP1.8.4/Loader2.3.4及协议不变。0x20映射为编码器故障。
沿用can_motor_operations的单节点Link和TraceBus，GUI只负责共享身份、入口和显示。
运动/标定/烧录/其他任务进行中禁用；发送前核对当前UID及非运行状态。
协议多个内部原因共用一位时显示对应类别，不推断唯一内部根因。未知位原样保留。
验收：位组合/未知位；成功、拒绝、应答丢失、原因未消失、UID不符、运行中拒绝等
离线用例；界面回归、Release、打包和实际窗口。未获当前清错操作指令前不自动清故障。
回退新版上位机即可，不改变板端参数或故障规则。
