## 4. 统一组织、采集和停止规则

### 4.1 批次顺序

1. 登记硬件、仪器、参数、固件哈希及限值，确认机械安装和停止方式。
2. 仅逻辑供电/关相完成TC07只读通信、TC01静态、TC02静态；核对电流零偏、方向和量程。
3. 完成TC06线性化、电零位及关相结果确认；失败则停止依赖该标定的带电测试。
4. 在已确认的空载安装条件下完成TC03的零参考/Id部分，再按评审批准范围执行TC04；锁轴项目延期。
5. 检查机械状态，完成TC05空载运行、TC03动态dq以及TC01/TC02动态部分；加载扰动延期。
6. 完成TC06运行验证和TC07生命周期/异常帧验证；统一STOP、确认关相、保存全部结果。

这是一个统一空载批次，保留安装、防护、通电和方向切换的人工检查点，不要求中途临时锁轴。
每个子项建议重复3次；按最差值判定，并展示各次结果。失败后保留原始记录，不自动重试到成功。

### 4.2 板载采集与导出

| 通道 | 建议采集方式 | 能证明什么 |
| --- | --- | --- |
| 快环突发 | 20kHz、连续序号、同拍采集；4KiB以内固定缓冲，按通道数确定128～256点，含25%预触发 | ADC采样噪声、dq纹波和毫秒级阶跃；是否足够覆盖稳定时间由实际窗口确认 |
| 长时记录 | sin/cos按实际辅助采样率（预期2kHz），速度/状态按2kHz或已核验的较低速率；每点保留采样时间/序号 | 完整低速波形、速度稳定性、角度误差和长期漂移 |
| CAN FD导出 | 快环只写定长缓冲；停止后分包读回并校验样本数/序号。慢速流经带宽和丢包验证后方可连续采集 | 传输板载测量数据，不增加原始ADC采样率或物理带宽 |
| 外部示波器，延期 | 当前没有设备；以后补齐设备再独立评审物理PWM纹波子项 | 本批不提供这类测量结论 |

4KiB是建议的新增缓冲预算，不代表当前已具备缓冲或剩余RAM足够；实施前核对MAP、栈余量和IRQ耗时。
短窗覆盖不足时降低通道数、采用经验证的更长采集或多次独立窗口，不拼接成伪连续波形。
稳态可用多个短窗分布覆盖至少1秒；同时保留长时趋势。FFT只分析足够长的连续窗口。
快环里只做有界拷贝/统计，不打印、不等待主机；采集溢出、丢帧、时间戳异常须计数并使该次测量无效。
采集开/关都要核对控制时序；采集造成超时则BLOCKED，不能提高原保护门限。
报文到达主机的时间不是ADC采样时间。图形横轴使用板端时间/采样序号，不能按CAN包间隔重建电流阶跃。
CAN FD导出失败可在关相后重读已冻结数据，不得因此自动重复激励或标定动作。

## 5. 指标口径及建议门限

建议门限只适用于已确认的低电流、低速台架范围，不是全温、全电压、全负载产品指标。

| 项目 | 建议门限 |
| --- | --- |
| TC01关相静态 | 各相原码标准差≤2 counts，峰峰值≤12 counts；偏置校正后均值绝对值≤3 counts对应电流 |
| TC01旋转采样残差 | 各相残差RMS≤2%`I_test_max`，峰峰值≤10%`I_test_max`；物理PWM纹波当前不可测，不填估计值 |
| TC02静止 | sin/cos各自标准差≤2 counts，峰峰值≤12 counts；不得削顶 |
| TC02动态 | 拟合残差RMS≤0.5% ADC满量程，双通道幅值不平衡≤5%，相位差偏离90°≤5°；偏置和XY轨迹一并展示 |
| TC03稳态dq | 零参考/Id及空载速度稳定段内：各轴平均跟踪误差≤2%`I_test_max`，去均值纹波RMS≤2%，峰峰值≤10%`I_test_max`；不外推锁轴/负载工况 |
| TC04阶跃 | 10%～90%上升时间≤1ms，稳定时间≤3ms，超调≤10%阶跃幅值；另一轴最大偏移≤5%`I_test_max`。短脉冲未覆盖稳定时只报告已覆盖指标 |
| TC05速度稳态 | 偏差≤max(1%给定幅值, 0.02rad/s)，误差RMS≤max(2%, 0.03rad/s)，误差峰峰值≤max(10%, 0.10rad/s)；无持续增幅振荡 |
| TC05速度切换 | 空载条件下记录稳定时间及超调，建议≤1s及≤15%；存在给定斜坡时分别相对实际斜坡与最终目标计算 |
| TC06 LUT | 先按冻结源码的内部阈值判定；当前RMS≤256 Q15 counts、峰值≤1024 counts，分别约1.40625°、5.625°机械角；另报告独立参考误差 |
| TC07通信 | 1000次只读请求无错误/丢失/重复业务执行；超时建议100ms，P99应答延迟≤20ms，正反例行为符合冻结协议 |

计算定义：

- 对窗口`x[k]`，偏置/均值为`mean(x)`，纹波RMS为`sqrt(mean((x-mean(x))²))`，峰峰值为`max(x)-min(x)`。
- 电流/速度跟踪误差为反馈减实际给定；同时报告平均误差与含偏差的RMSE，不能只给去均值纹波。
- 旋转三相电流拟合`a·sin(θe)+b·cos(θe)+c`，以原始值减拟合值求残差；完整正弦的峰峰值不叫纹波。
- sin/cos动态同理去除基波；静止噪声和动态拟合残差分开，不把幅值变化当作采样噪声。
- 阶跃以**实际被控制器接受的参考改变时刻**为零点；稳定带为±max(2%阶跃幅值, 1%`I_test_max`)，进入后须保持到窗口结束。
- 下降/负向阶跃按归一化阶跃方向计算；零给定指标用`I_test_max`或绝对速度下限归一化，不能除以零。
- 角度误差用环形差，避免0/360°跳变制造假尖峰；长时趋势同时展示解卷绕角度。

## 6. 七项详细用例

### TC01　三相电流采样纹波

**条件与信号**：零偏校正完成；采集三相等效12位原码、三相A值、母线电压、PWM状态、θe及采样序号。
物理纹波子项须有校准后的外部电流测量；没有设备时该子项BLOCKED，不用ADC结果替代。
当前仅测板载ADC，换算电流值不作独立电流准确度结论。

**步骤**：

1. TC01.1：功率关闭、无外加相电流，稳定后采集1秒统计及不少于5个连续短窗。
2. TC01.2：评审允许后，零给定启相，分别观察PWM开关前后噪声及偏置变化。
3. TC01.3：标定合格后，在TC05的各空载稳定转速点重复采集，记录实际电流幅值。
   无负载时不能保证获得两个不同稳态电流档位，不为凑档位增加持续Iq给定。
   动态拟合需覆盖至少3个电周期；显示各相残差及`Ia+Ib+Ic`，标注顺序采样带来的限制。
4. TC01.4：当前BLOCKED（无示波器/电流探头）。以后补设备后再记录至少100个PWM周期，区分开关尖峰和真实电流纹波。

**结果展示**：`TC01_currents.png`、`TC01_residuals.png`、`TC01_pwm_scope.png`及三相指标表。
表中分列PWM关闭/开启、工况、零偏、均值、RMS、峰峰值、最大尖峰、带宽与丢帧数。

### TC02　输出轴sin/cos采样纹波

**条件与信号**：确认AT32目标实际启用两路辅助采样；记录PA5/PA6原码、电压、采样率、通道顺序和时间差。
需识别DMA已完成半缓冲，禁止读到正在更新的半帧；本轮仅规定要求，不编写采集实现。
电压由板载原码与参考电压换算，须标注为换算值；没有外部仪器时不作模拟端电压准确度结论。

**步骤**：

1. TC02.1：关相，在机械允许范围内选择覆盖两路峰值与过零附近的4个静止位置，各记录2秒。
   采用自然停稳位置，不带电手持或临时卡住输出轴；无法稳定停留的位置标为BLOCKED。
2. TC02.2：在评审确认的零给定PWM状态重复静止采样，比较开关前后的噪声增量。
3. TC02.3：通过允许的驱动/机械方式低速正反转，每方向覆盖至少3个输出轴周期；不强行反拖机构。
   确认每个信号周期至少20点，优先100点以上；不足时降低速度或重新设计采集。
4. 计算两路偏置、幅值、幅值不平衡、相位差、基波残差；展示原始XY椭圆。
   另绘去偏置/归一化XY图，处理方式必须标注。两路顺序采样引入的相差单独记录。

**结果展示**：`TC02_static.png`、`TC02_waveforms.png`、`TC02_xy.png`、`TC02_residuals.png`及四位置/双向指标表。
**判定**：按第5节；原始信号合格不等于输出轴角度解算/标定已通过。

### TC03　Id/Iq闭环纹波

**条件与信号**：TC01静态和TC06标定合格；电机本体可靠安装、输出轴自由空载；测试入口已验证并受原保护约束。
同拍采集Id/Iq实际给定、Id/Iq反馈、Vd/Vq、母线电压、θe及限幅/故障信息。

**步骤**：

1. TC03.1：`Id=0, Iq=0`测零参考附近噪声和偏差。
2. TC03.2：`Iq=0`，Id先测`+0.10 × I_test_max`，评审允许且低档通过后再到`+0.25`档；检查d轴稳态和q轴耦合。
3. TC03.3：在TC05各空载稳定段记录Id/Iq实际给定与反馈，评价该工况下的跟踪误差和纹波。
   Iq由速度环产生，不能把它当作固定矩形给定；该结果不证明非零Iq锁轴稳态能力。
4. 每点稳定后记录至少1秒的趋势/统计及5个快环短窗；按热/通电时间边界分段，冷却后再测。
5. TC03.4：非零Iq固定转子/已知负载稳态项目当前BLOCKED；无固定装置时不持续施加该测试给定。

**结果展示**：`TC03_dq_tracking.png`、`TC03_dq_error.png`，逐轴、逐幅值、逐方向列均值偏差、RMSE、纹波RMS和峰峰值。
**判定**：第5节门限仅用于已批准的空载范围；Vd/Vq长期饱和、参考被限幅时该工况无效。
空载运行波形与锁轴测试分别列结果，不互相替代。

### TC04　Id/Iq阶跃响应

**条件与信号**：TC03最低幅值合格；输出轴自由空载，增加“实际参考更新”触发标记及速度/角位移记录。
本轮Id阶跃和Iq短脉冲均须单独确认幅值、脉宽、速度及角位移截止，未经确认不执行。

**步骤**：

1. TC04.1：固定`Iq=0`，Id先做`0→0.10→0 × I_test_max`；低档通过且评审允许后再加`0.25`档。
2. TC04.2：建议以`Id=0`、`Iq=0→I_pulse→0`短脉冲测上升/下降沿；`I_pulse`不高于已批准最低档，脉宽建议≤5ms，最终值由评审确认。
   脉冲由板端定时截止，同时执行速度/角位移边界；不依赖CAN/USB往返来结束脉冲。
   脉冲期间明确使用电流模式，不允许速度环同时改写Iq给定；模式切换与收尾仍受原生命周期控制。
3. 每次Iq脉冲后先STOP并确认轴已静止，再决定是否进行同幅负向脉冲；不连续施加正反向方波。
4. 每个已批准的方向/幅值重复3次，保存25%预触发数据；Id步骤间隔建议≥200ms，Iq重复间隔还须满足轴静止条件。
   采集窗口若未覆盖稳定，则报告“稳定时间大于窗口”，不得将窗口末值当作稳定值。
5. TC04.3：固定转子Iq阶跃矩阵当前BLOCKED。空载短脉冲结果只代表本次速度/位移范围内的电流瞬态响应。

**结果展示**：`TC04_id_step.png`、`TC04_iq_step.png`、`TC04_cross_axis.png`。
每个阶跃标出零时刻、10%/90%、稳定带、超调点；表中列上升时间、稳定时间、超调、稳态误差、交叉轴峰值和饱和状态。
**判定**：第5节；时间指标精度不得优于实际采样周期。

### TC05　速度闭环稳定性

**条件与信号**：关相时确认电机本体安装、输出轴自由空载、转动区域及线缆行程；核对机械角速度单位和正方向。
采集请求速度、斜坡后的实际参考、反馈速度、速度误差、Iq给定/反馈、母线及状态。

**步骤**：

1. TC05.1：先在最低可稳定运行速度核对电机轴角位移/时间与速度反馈，检查极对数、减速比及正方向。
2. TC05.2：按正负`0.10、0.25、0.50 × ω_test_max`逐级测试；每点稳定后记录至少20秒，超出热/行程限制则分段并说明。
3. TC05.3：最低幅值通过后测试`0→低速→中速→低速→0`；正反向之间先停止并确认，不直接高速反转。
4. TC05.4加载扰动当前BLOCKED（无加载装置），不安排人工手压、手刹或临时夹轴来产生负载。
5. 检查持续振荡、幅值增长、低速爬行/停转、零点漂移和速度误差与Iq的关联；不可用长时平均掩盖失稳。

**结果展示**：`TC05_speed_tracking.png`、`TC05_speed_error_iq.png`、`TC05_drift.png`。
表中列方向、速度/负载、平均误差、RMSE、峰峰值、稳定时间、超调和温升；换算输出轴速度另列。
**判定**：第5节；失稳、异常反向、异常倍率或触发过速立即FAIL并停止。

### TC06　角度标定之后的波形

**范围**：默认是电机端编码器LUT和电零位；输出轴sin/cos标定尚无实现。
若评审要求的是输出轴角度标定，必须将该部分列为BLOCKED，先补设计和实现，不能由TC02替代。

**步骤**：

1. TC06.1：备份当前标定数据/标志；在同一供电、转速、方向下保存标定前可获得的原始角度与误差基线。
   禁止为制造“标定前”曲线直接擦Flash；若无安全可比基线，只报告标定后，不虚构改善比例。
2. TC06.2：通过现有`0x00A0, kind=1`启动线性化，记录阶段、原始/方向修正角、观测器参考、速度、Id/Iq和故障。
   完成后确认实际关相、候选发布及线性化标志，而不只看ACCEPTED或回到IDLE。
3. TC06.3：通过`kind=2`做电零位；记录固定电角参考、编码器电角、Id/Iq给定与反馈、零位结果及完成/故障。
4. TC06.4：在同一次启动会话中，以匹配工况低速正反转，采集至少3机械圈。
   绘制原始角、线性化角、解卷绕角、LUT修正量、标定前后环形误差；两个方向分别统计。
5. 有独立参考编码器时测量绝对误差；没有时，观测器比较只能报告内部一致性，不能据此宣称绝对角度精度。
6. 机械零位`kind=6`只在已确认的物理基准位置执行并记录；完成后不自动保存/重启验证，除非另行评审该范围。

**必须实际显示的图**：

| 文件 | 图中内容 |
| --- | --- |
| `TC06_calibration_process.png` | 阶段与时间、参考速度/反馈速度、Id/Iq及故障标记 |
| `TC06_angle_before_after.png` | 同坐标尺度的原始角/线性化角/参考角，含0/360°接缝放大图 |
| `TC06_error_before_after.png` | 标定前后误差随角度曲线、正反向分色、RMS和峰值标注 |
| `TC06_lut.png` | 完整1024点LUT修正曲线，角度坐标和Q15/机械度双单位 |
| `TC06_electrical_zero.png` | 电零位后的电角误差、Id/Iq叠图及对齐/采样时段 |

以上图须在统一报告中直接嵌入，不接受只提供文件路径、日志或“标定成功”文字。
**判定**：算法阈值按冻结源码核对，完整覆盖、无故障、发布/标志正确；绝对精度采用另行批准的独立参考指标。

### TC07　通信协议跑通

**条件**：同一固件与主机版本；主站0x02、设备实际Node ID；CAN FD扩展帧、BRS、1Mbit/s仲裁和5Mbit/s数据。
先关相运行只读/异常帧子项；涉及启相的合法请求与前述用例共用限值和停止条件。

| 子项 | 请求/场景 | 预期结果 |
| --- | --- | --- |
| TC07.1 | `0x0001 GET_INFO`、`0x0002 GET_CAPS`、`0x0003 GET_DEVICE_STATUS` | 长度、CRC、源/目的、页号和身份字段符合当前向量；能力页与实际支持范围一致 |
| TC07.2 | `0x006C`状态、`0x007C`反馈，10Hz共1000次只读请求 | 应答正确、无丢失；延迟分布达标。测量有效位为零时必须解释为无效，不能当作0A/0速度 |
| TC07.3 | `0x0075`零目标启动、`0x006E`停止、`0x006B`清错 | 准入符合状态；STOP最终确认关相；清错不自行恢复运动。无安全可恢复故障时清错只验证幂等/拒绝场景 |
| TC07.4 | `0x00A0`的kind 1/2/6，与TC06共用一次实际执行 | 受理回复、非零关联号、状态变化及实际标定结果一致；ACCEPTED不等于完成 |
| TC07.5 | `0x0074`普通目标、在线参数读写/保存、`0x00A1/0x00A2` | 按现行协议返回UNSUPPORTED；不得产生目标变化、写Flash或额外标定 |
| TC07.6 | 错CRC、错长度/保留字段、错目的地址/主站、未知kind | 按协议丢弃或拒绝；无启相、无配置变化，记录收发帧及错误计数 |
| TC07.7 | 忙时重复标定、超时、应答丢失、主机断开、STOP重复 | 无额外业务执行；按实际协议区分BUSY/拒绝/无应答。断开后的关相策略先评审确认，不能假定存在通信看门狗 |

kind 1/2/6载荷分别为`01 00 00 00`、`02 00 00 00`、`06 00 00 00`。
标定START只发一次；应答丢失不自动重发。先读取状态，再人工判断恢复；旧关联号不能用于当前未实现的历史查询。
异常帧与重复执行测试优先在关相或原生模拟边界验证；不得用未知报文在带功率运行中盲目探测。

**结果展示**：`TC07_transactions.csv`逐帧记录请求时间、应答时间、ID、CMD、payload、CRC结论、期望/实际状态；
`TC07_latency.png`显示延迟分布和时间趋势，另列错误/超时/重复计数及状态迁移表。
**判定**：按第5节及当前协议；TC07通过只表示当前声明范围贯通，不能宣称普通目标控制已接入。

## 7. 统一结果交付格式

执行后每批生成一个目录：`outputs/unified-motor-test/<run_id>/`，建议包含：

```text
manifest.json            硬件/固件/参数哈希、仪器、采集率、限值、操作者和评审版本
report.html              七项结果总览，全部必要波形直接嵌入，失败/阻塞项同样展示
results.json             主项/子项状态、实测值、阈值、最差重复、证据路径
raw/                     原始ADC/反馈采样、CAN帧和故障末段记录
plots/                   TC01～TC07图像；每图带批次/工况/单位/采样率/滤波说明
logs/                    执行顺序、人工检查点、STOP与关相确认
```

每个结果卡固定展示：测试编号、工况、状态、关键数值、门限、波形、原始数据链接、失败原因。
每张波形标明坐标单位、实际采样率、窗口起止、给定/反馈图例、丢帧和滤波状态。
当前未执行，不填任何实测数字、不生成伪实测波形。
