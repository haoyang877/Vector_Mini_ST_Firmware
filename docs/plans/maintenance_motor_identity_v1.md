# 维护工具电机身份显示 v1

日期：2026-10-15；基线：v1.1.0 / `2add54e1`。

目标：初装页在只读识别目标时显示用户约定的电机名称及真实板内节点ID。
按0默认电机、1左轮、2右轮、3 roll、4 pitch、5 yaw、6 lift 映射；无效/空白值不显示为0。
读取参数区首个float32两次核对一致，不使用独立USB-CAN选择值推断J-Link目标。
CAN身份和状态/标定表复用同一映射，切换连接清除旧身份。

保持：不写参数、不改控制/协议/ABI/固件，UID/关相/备份准入及CPU状态保留逻辑保持。
维护软件版本递增至v1.1.1，配套APP仍v0.5.2，Loader仍v1.0.0。

验收：离线ID0～6映射、未知/空白ID、模拟SWD真实ID优先于CAN下拉框、清除过期身份、
940×740界面及现有Loader/GUI回归、格式/lint、冻结EXE版本/内置DLL/HEX检查。
构建、截图和清单保存于本轮outputs，不接触正在由用户和其他任务操作的真实电机。
回退：使用上一版EXE，不需要回退板端固件。

集成时目标分支已由其他任务推进至`a11a8d94`，APP源码为v0.6.0。
仅合入本轮维护工具改动，保留该固件推进；交付ZIP仍沿用此前核验的v0.5.2镜像，
不把本轮离线工具验证解释为v0.6.0的实机验收。
