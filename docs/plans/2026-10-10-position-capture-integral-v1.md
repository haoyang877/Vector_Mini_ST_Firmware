# 位置捕获精度和静摩擦积分修复 v1

用户提供两份位置环 RTT 采集并要求通过 J-Link 排查。只读匹配板上 HEX/AXF 后
确认 Roll 节点 3，位置 Kp/Kd=8/2，位置内速度 PI=0.5/1，8 A 限流，5 Hz 速度
滤波，摩擦前馈 2.946/3.259 A。现场读到 mode 0、无故障、三相关断。

第二份按手工 RTT v2 分析：前馈为 0 后，约 0.24° 偏差缓慢减至 0.18°，
Iq 由约 −2.1 A 增至 −3.9 A；记录没有独立积分通道，积分归因由电流合成关系、
源代码及 J-Link Ui≈−4.0 A 交叉支持。停止后数据不计入闭环到位结果。

## 根因与实现

原 `position_error_window` 为 0.001 rad（0.0573°），只用于轨迹结束；HOLD/前馈
捕获独立使用 0.18°，退出为 0.26°。一次进入宽捕获窗口会撤除前馈并冻结积分；
从未捕获但停在进入/退出窗口之间时，原恢复分支也不重新施加前馈。
本轮按用户要求收紧实际定位精度，改变误差窗口的行为契约，不是单纯改名。

- 将有效捕获阈值统一为 `position_error_window`，保持退出/进入滞环比例：
  有效退出 = hold_exit × position_error_window / hold_enter，本台约 0.0828°。
  在参数校验时缓存两个内部阈值，不改变公共结构布局、CAN 或 Flash ABI。
- 确认 HOLD 前要求连续满足实际精度，只有确认 HOLD 后才允许退出滞环。
  连续位置/速度资格达到 50 ms 后才撤除前馈，前馈退出后再确认 HOLD；
  瞬时进入窗口只暂停位置内速度积分，不立即切掉接近补偿。
  摩擦减载、静摩擦恢复及反向积分卸载都使用同一有效捕获阈值；未捕获时
  不用退出窗口阻止恢复。
  SETTLE 未捕获时保留接近方向的摩擦补偿，PLL 噪声越过静止判据只影响
  脱黏资格，不把尚未到位的前馈直接置零。
  到位资格的位置使用同一速度滤波截止频率的独立低通状态，实际位置控制
  仍使用原始位置；raw 偏差超过基准退出窗口（本台0.26°）立即退出 HOLD，
  不能因资格滤波掩盖真实大扰动。滤波为0时资格也直接使用原始反馈。
- 静摩擦积分正在按 0.30 A/s 向同一 Ui 增长时，暂停普通速度 Ki，避免两条
  积分叠加。保留原电流限幅、总电流抗饱和和运动恢复后的 PI，并保留负载支撑积分。

兼容性：原 0.18° 平台不再被默认配置判为到位；要求原噪声容差的调用者需显式
设置其 `position_error_window`。无需迁移 Flash，PI/限流/滤波/标定数值不改。
保留其他任务的温度、RTT、PI 分离、版本及用户配置变更；不扩大电流或速度边界。
旧测试中依赖宽窗口的到位输入改为满足实际精度；需要较宽噪声容差的测试
显式配置其误差窗口，不通过放宽断言掩盖新精度要求。

## 验收与证据

原生实际控制器回归覆盖正反向、0.24° 未到位平台、精确捕获、确认前误差离窗、
确认后滞环、静摩擦积分限速/无重复累积、运动恢复、总限流和负载支撑保留。
新回归在原位置控制器上必须失败，在修复后通过。固定传感器注入不是机械仿真，
不能据此宣称实机收敛或无超调。

Python 回归、原生外环/缓存/PI 分离检查及普通固件构建，证据保存
`outputs/position_approach_20261010/`。旧 worktree 不提供现代 verify/format/lint
profile，不声明这些 profile 通过；HIL 按用户此前范围不处理。

硬件阶段先固定匹配镜像和参数备份；任何运动需满足已确认 Roll 台架条件及控制
独占、现场可断电。本轮只读不会当作通电测试通过，不盲目恢复未知运行状态。
回滚本轮位置控制器及对应测试即可恢复宽捕获逻辑，其他任务改动不撤销。
