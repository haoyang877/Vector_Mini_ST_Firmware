# 运行中 q 轴与低延迟测速验证 v1

在已确认的 AT32F456 + YQ-5708 台架、10 rad/s、新标定表、3 A 和 50 rad/s 边界内，先测运行中的 q 轴动态，再验证速度反馈的相位和可用带宽。独立诊断镜像在速度模式的 20 kHz 快拍加有限时长的小电流扰动；速度扫频则在 2 kHz 将小信号加入目标。同期记录实际参考与输出。对照同时计算 90 Hz 与 300 Hz 估计，只在关相时选择速度 PI 的输入，换相继续使用原路径。

核对原镜像和整片备份，只写应用区，校验标定/参数/身份区。先以原配置建立对照，再逐级试验。以 −3 dB 截止、共振峰不超过 +3 dB、稳态波动低于 3% RMS 分别验收；记录 q 轴幅相、速度返环裕量和 24 阶峰值。试验完毕恢复原应用、原参数和空闲关相状态，不将诊断镜像作为发布固件。

增加 600 Hz 速度反馈对照。20 kHz 不变，按相同 PI 先比较 300/600 Hz；32 kHz 是台架允许的电流更新率上限。本轮先判断 20 kHz 是否已足够，若未来单独升频，需要同步核对 PWM/ADC 时序、快环执行预算及 2 kHz 外环分频。

实测已完成。20 kHz 下，正常 CAN 独立收发条件的 ±10 rad/s 均通过 120 Hz 验收，3% RMS 未通过。整片原 Flash 已恢复并核对。见[实测报告](../../reports/2026-11/speed_pll_120hz_20261105.md)。
