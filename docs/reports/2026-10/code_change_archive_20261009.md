## 4. 兼容和归档注意点

1. 外层参数保持 schema10，既有字段偏移不移动。PVF1 位于参数区偏移 2256，长度 16 B，结构总长 2272 B；旧固件忽略新尾部，旧固件重新保存可能清除该记录。
2. RTT 新档是 20 B/帧，与旧 22 B 标定档不同，必须匹配描述符和 Scope；位置/速度量程约 ±327.67°/±327.67°/s，不能用该速度通道证明左右轮全速域数值。
3. AXS2 的通用 yaw ±180° 候选包络与总体表中 yaw 的 ±90° 目标不是同一个配置层。Roll 表中 ±150°/90°/s 也不能直接套入现有 AXS2 roll 的 ±90°/45°/s 模板；配置时必须核对记录版本和最终回读。
4. Flash 节点号优先是临时联调策略，必须保证多机 ID 唯一；运行时只改 `node_id` 不会自动重建已经初始化的硬件接收过滤器。
5. 单点 mode 15 完成位不证明克服阻尼并获得可靠电零位。同一 LUT 下的不同起点收敛、受限双向控制以及实际原始角度记录才提供进一步证据。
6. `Vector_Mini_ST.uvoptx` 包含本机调试窗口/变量设置；本次原样保留用于恢复，但不计为产品功能。`main.c`、`stm32g4xx_it.c`、`can_motor_status.c` 当前差异仅为空白；不要把它们描述为 CAN 或中断算法修复。
