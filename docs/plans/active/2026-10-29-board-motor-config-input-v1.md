# 板卡与电机配置单一输入 v1

## 目标

两套完整 APP 统一显式选择板卡与电机，去除可证明相同的物理输入重复，集中计算可确定的派生值；新增型号应能以型号文件和目标选择完成，不要求按型号修改控制算法。

## 不变边界

保留当前两工程的电机/板卡组合、所有默认值、参数schema14与已存参数优先级、保护和故障行为、调度与PWM许可，AT32继续永久关相并限制临时热值。用户确认保留Flash已有模型、手动PI及标定，新编译默认值用于未配置设备，换电机后由配置流程核对更新。独立的电角与机械标定设定点及未确认热模型不可猜测或静默统一。新MCU的BSP、项目和硬件适配不属于配置公式自动生成范围。保留工作区其他改动。

用户确认保留并行变更：STM32的非当前目标2 mΩ配置使用10 A命令/标定上限与18 A过流阈值，不再使用30 A/40 A；当前正式6 mΩ目标保持原值。

## 实施与验证

记录两工程改动前构建、HEX和资源；完成后重建并比较HEX、ABI、资源、状态和输出。扩展定向离线测试，覆盖替换电机/板卡、公式变化、不完整型号及非法组合拒绝、schema14已存参数语义。运行PR检查；不连接硬件。发生差异须定位原因，不能以旧实验输出替代当前证据。

## 回退

只撤销本计划涉及的配置、目标接线、测试和文档；不覆盖其他未提交工作或生成数据。
