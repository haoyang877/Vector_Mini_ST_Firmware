# 四类参数所有权解耦 v1

## 目标与边界

基点 `83f5aae0c6e40aac581db41cb4234d6ee03f4975`。目录归属已完成，
本批拆开硬件默认值、电机模型、应用配置、设备个体配置与易失运行目标。
活动参数仍由 `MotorAxis` 独占，不增加完整记录或 LUT 的常驻副本。

- 硬件配置：平台只读编译配置，不允许参数写入改变采样尺度或保护阈值。
- 电机配置：独立模型默认值和活动模型子对象。
- 应用配置：速度/电流限制、轨迹、控制整定和轴范围子对象。
- 设备配置：节点地址、采样零偏、摩擦标定；编码器/LUT 与齿槽表继续由各实际所有者持有。
- 易失状态：命令目标、模式、故障与测量留在运行对象，不进入参数配置对象。

删除参数服务到通信的 `Protocol_NodeId_Get/Set` 桥；地址由参数所有者值传递给启动组合层。
schema12 旧地址到应用限速的映射只在装载边界解析一次，运行写参数不再查询通信地址。
本批不新增制造序列号/批次协议或多个尚无实际数据的电机型号。

## 不变行为

保持控制公式、默认数值、保护阈值、调度频率、STOP/FAULT/CLEAR 语义、
schema12 的 4304 字节记录、CRC 与 16 KiB 区域、参数 ID/缩放/权限及异步保存语义。
现存轴类型到地址映射保留为兼容装载行为；不在本批修改已发布存储 ABI。
内部 RAM 成员偏移会改变，诊断必须使用对应 ELF；不可复用旧偏移脚本。
