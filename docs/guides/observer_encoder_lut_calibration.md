# 模式 13：基于观测器的编码器 LUT 线性化标定

## 目的

`ModeNow = 13`（`Calib_EncoderObserver`）用于标定 MT6701 编码器的 1024 点机械角线性化 LUT。标定过程复用现有无感启动；只有无感启动完成并已进入“观测器角度 + 转速闭环”后，才使用磁链观测器的位置作为机械角参考。

LUT 的输入为 `Encoder.directed_q15`，即经过编码器安装方向统一后的原始角度；这与运行时 `Encoder_Update()` 中的 LUT 查表输入完全一致。

`ModeNow = 5`（`Calib_EncoderOffset`）保留原有的电压开环单向扫角流程，不会进入模式 13 的无感闭环标定流程。

## 本次上电的参考坐标

观测器位置只在本次上电、且观测器连续有效的期间内连续累积；它不是断电后仍保持的绝对多圈位置。机械参考原点按以下方式建立：

1. 无感启动的静态对齐阶段固定 `phase = 0`。
2. 在静态对齐末尾 `0.1 s` 内，对 `Encoder.directed_q15` 做圆周平均；平均值定义为本次标定中第 0 极对的机械原点。
3. 进入观测器闭环且转速稳定后，等待 `directed_q15` 正向再次经过该机械原点。
4. 对这次编码器过零事件进行插值，得到该时刻的连续观测器电角位置 `observer_position_origin`。

设连续观测器电角位置为 `theta_obs`、极对数为 `p`，则对应的参考机械角为：

```text
reference_q15 = uint16((theta_obs - observer_position_origin) * 65536 / (2*pi*p))
```

若观测器被复位，其 `position_epoch` 会改变，标定立即中止且不替换旧 LUT。

## 模式 13 流程

模式 13 强制将无感转速参考设置为 `+20 mechanical rad/s`，然后按以下步骤运行：

1. 执行现有无感静态对齐、开环拖动、观测器切换和观测器角度速度闭环。
2. 连续 `0.5 s` 检查闭环稳定性：观测器速度和转速参考误差不大于 `20%`。`Vd` 补偿和电压利用率不作为采样阶段的失锁条件，因为它们会随电机参数误差和负载变化而出现正常偏置。
3. 捕获上述静态对齐原点的下一次编码器正向过零，并建立观测器参考原点。
4. 按观测器参考连续采集 5 个机械圈；每个采样点将 `directed_q15` 与参考机械角的圆周误差累加到对应的 1024 个 LUT 桶内。
5. 要求每个桶至少有 16 个样本，生成候选 LUT；候选 LUT 仅保存在 RAM 中，尚不影响当前运行 LUT。
6. 使用候选 LUT 再验证 1 个机械圈。
7. 仅在 RMS 残差不大于 256 Q15 counts、峰值残差不大于 1024 Q15 counts 时，将候选 LUT 替换为运行 LUT。
8. 标定结束后先在 `1 s` 内将观测器闭环转速从 `20 rad/s` 平滑降至无感安全速度，再在 `0.5 s` 内将当前转矩电流平滑降至零，最后切换到 `Save_Param` 写入 Flash。

该流程为误差和、桶样本数及候选 LUT 共分配约 8 KiB 堆空间；工程堆大小为 16 KiB。

## 标定结果与后续步骤

标定成功后只设置 `ENC_CALIB_LINEARIZED`，并明确清除电角零位和机械零位标志；本流程不会写入电角零位。

因此，完成模式 13 后，需要单独执行 `ModeNow = 15`（`Task_Calib_EleAngelOffset()`）以基于已线性化的编码器角度标定电角零位。将这两个步骤分开，便于后续扩展独立的电角度标定功能。
