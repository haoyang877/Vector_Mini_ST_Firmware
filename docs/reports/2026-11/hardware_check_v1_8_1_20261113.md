# APP v1.8.1 趋势、命令方向与 CAN FD 上位机实测

日期：2026-11-13。用户确认接受原角度曲线的整体趋势，并明确要求：正向三相开环
命令对应编码器角度增加，反向命令对应角度减少；无需现场旋向参照，霍尔安装方向
关系不作为验收门槛。此轮已按该契约完成全部十项检测及打包 GUI 验证。

电机命令与编码器方向关系通过。** 类别保持 debug，不作完整量产验收声明。

## 判据及界面变更

旋转在至少 500 ms 预转、连续两个 50 ms 平均速度窗符合条件后，按原码展开角的
50 ms 窗口均值观察整段趋势。每向至少三个窗口、净位移可辨，至少 2/3 可辨窗口
增量与该段方向一致；电机方向还须与该段开环命令符号一致。单拍角增量与局部
波动幅度不再判失败。停滞仍检测，趋势失败锁存该项后继续收集其他项结果。
霍尔独立验证自身趋势，取消其与电机安装方向的关联门禁。

CRC/状态、霍尔原码 [95,4000]、电压/温度、故障、行程、运动租约、采样丢失、
超时和 STOP 保护保留。八项静态阈值不变：母线 RMS <50 cnt，三相/霍尔 <10 cnt。
电流 PI 没有修改，常规测试使用模式10、3 A。零频保持 500 ms，电机角均值确认
停稳后反向。Type127 v2 的线路载荷及黄金向量不变。

检测页内置 3 A、3 Hz、1500 ms 默认值，自动核对命令/编码器方向，不弹人工旋向
窗口。界面及 JSON 独立显示通信超时：只读快照最多重读一次，状态 BUSY 最多读
三次，同一运动会话的续租丢应答时仅用递增计数再试一次，不重新使能；再次失败
仍 STOP。每次超时仍按 50 ms 计入可靠性失败，CLI 返回失败，不因恢复而掩盖。
