# 交付功能参数扩展 v1：schema13

2026-10-17。随APP v1.4.0提供绕组热保护和可选速度整形/惯量前馈；公司协议帧头及120/121/122 payload格式保持不变。

本文保留 schema13 的已发布契约；当前紧凑格式见[schema14存储与迁移](parameter_schema14_storage_v1.md)。

## 存储和兼容

参数记录由4304增至4352字节，仍位于RAW参数专属页；身份页独立，不参与擦写。前4304字节的全部字段偏移保持：schema在2160，magic在2164，配置确认在2136，整记录CRC在2140。schema13的CRC32/ISO-HDLC依次覆盖`[0,2140)`及`[2144,4352)`，CRC槽本身跳过，初始种子为0。字节序为小端；浮点为IEEE754 binary32。

| 偏移 | 字段 | 存储 |
| ---: | --- | --- |
| 4304 | 持续向量电流、峰值、升温时间常数、降额进入/退出、跳闸、清除门限 | 7个float，A、A、s、比例×4 |
| 4332 | 前馈使能 | u32，0/1 |
| 4336 | 前馈增益、加速度上限、jerk上限、前馈电流上限 | 4个float，A/(rad/s²)、rad/s²、rad/s³、A |

新增默认值取自已提交交付代码：热配置`3A,7A,65.98486785s,0.8,0.7,1,0.5`；前馈默认关闭，其余为`0.028,20,200,2`。这些不是替换应用电流上限的命令：有效上限始终取应用限流与热上限的较小值，前馈仅使用同一预算且不超过总限流50%。热模型估计预算，不宣称测量绝对绕组温度。

APP只读兼容有效schema12：按原4304字节长度核CRC，原配置及标定保持，新字段用默认值，不读其后的垃圾字节。显式保存才写schema13。schema10不在启动时自动转换；交付分支10的基础记录无整CRC，只可在离线工具核对完整快照SHA和确切版本后显式转换。旧APP不能直接加载schema13；回滚必须配套原参数记录。

共享目标`TARGET_PARAM_ABI=0x000D1100`，声明当前输出schema13。Loader可从schema12/13共同前缀解析节点；这不替代APP对整CRC、配置及标定的判断。旧主机若只接受schema12必须更新配套契约，不能绕过身份/schema拒绝。

## 新增在线参数

所有项R/W-IDLE，仍受关相、单台身份、完整类型/耦合校验、revision和去重规则约束。写入不自动保存；122真实提交后才OK。拒绝不改变活动配置或revision。

| ID | 字段 | 线路类型与缩放 |
| --- | --- | --- |
| 0x60 | 持续向量电流 | i32，A×1000 |
| 0x61 | 峰值电流 | i32，A×1000 |
| 0x62 | 升温时间常数 | i32，s×1000 |
| 0x63 | 降额进入热量 | i32，比例×1000000 |
| 0x64 | 降额退出热量 | i32，比例×1000000 |
| 0x65 | 热跳闸门限 | i32，比例×1000000 |
| 0x66 | 热故障清除门限 | i32，比例×1000000 |
| 0x68 | 速度整形/前馈使能 | u32，0/1 |
| 0x69 | 惯量前馈增益 | i32，A/(rad/s²)×1000000 |
| 0x6A | 前馈规划加速度上限 | i32，rad/s²×1000 |
| 0x6B | 前馈规划jerk上限 | i32，rad/s³×1000 |
| 0x6C | 前馈电流上限 | i32，A×1000 |

0x67未登记。完整热门限必须满足`0≤clear<exit<enter<trip≤1`；持续电流≥0.01A，持续≤峰值≤100A；升温常数0.1..86400s，冷却常数为max(120s,升温常数)。前馈增益0..0.2，加速度0.1..100，jerk1..2000，前馈上限0..10A。物理应用/硬件限流始终独立生效，不能用以上编码上界扩大整机范围。

热参数在停机关相临界区同步重配，保留热历史、窗口和锁存；降低持续电流会保守换算已有热量。STOP、模式切换、DEFAULTS和CLEAR都不清热量。CLEAR仍不启动，模型采样失效不能靠CLEAR重新伪造有效。

## 清标定与测试

`tools/build/prepare_calibration_reset.py`只离线生成新页镜像。要求完整16KiB原快照及匹配SHA256，接受已盘点schema10/12/13，校验可用的整记录/尾记录CRC；清角度LUT、电角/机械零位和标定资格，保留编码器方向、设备节点、模型和应用包络。配置确认置0，需测试前核对后显式确认；上电电流零偏仍由真实新鲜ADC采样重新建立资格。

源schema10的复杂位置/摩擦扩展不带入新RAW字段。身份页及新记录范围之外的原字节原样保留；工具不连接硬件、不下载、不清设备。T需按页写入并核对，不能mass erase。新固件、主机及清标定镜像必须在同一冻结清单中记录hash，离线通过不等于实机通过。

固定布局/CRC向量见[黄金向量](parameter_schema13_vectors.json)；schema12兼容向量继续保留[原向量](parameter_schema12_vectors.json)。测试合同包含原记录不变、旧前缀装载、新字段保存回读和损坏拒绝。
