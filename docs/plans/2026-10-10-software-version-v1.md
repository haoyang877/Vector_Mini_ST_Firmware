# 当前 APP 软件版本号

版本：v1，2026-10-10；适用 `codex/ovp-36v` 的普通 APP。

目标：为当前五电机统一固件增加 v0.2.0 软件标识，复用启动 RTT 和旧式 CAN
参数回复。历史 `roll-pitch-v0.1` 是旧节点标签，不回填或改写历史固件。

实现：一个头文件维护主/次/修订/构建号；启动组装文件保存只读数字和字符串，
启动时 RTT 通道0打印。新增只读参数0x6F，四字节大端回复版本值；旧参数编码、
协议版本2、Flash 参数及标定 ABI 均保持原样。主机已有解码函数支持这一新回复。

验收：黄金向量验证0x6F请求、数字/字符串及回复一致；查询不修改模式或参数，
非法帧仍被拒绝，原有 CAN 回复回归通过；运行离线测试及普通 Keil 构建，确认
AXF/map 中保留只读版本符号、HEX 内实际版本内容，归档当前输入和工件哈希。

回退：恢复本次头文件、启动打印、新查询和主机解码改动；旧固件不支持0x6F，
查询超时不得视为版本0或标定无效。本轮不连接硬件、烧录或执行运动。

本工作树没有现代 uv 锁文件及 verify/format/lint 命令，使用现有离线测试和
Keil 构建；不把这些结果当作现代 release profile 或正式发布认证。
