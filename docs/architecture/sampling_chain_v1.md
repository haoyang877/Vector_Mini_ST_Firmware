# 双板采样链路与职责 v1

更新：2026-11-09。当前接口以[bsp_adc.h](../../firmware/platform/bsp/include/bsp_adc.h)为准。

## 所有权

两板的mcu/adc.c管理初始化、原码读取、触发启停、DMA、中断及内部量校准读取。
零偏、通用单位换算和NTC公式也位于各MCU的adc.c，不保留独立的公共实现文件。
原码接口在各MCU文件直接实现；初始化声明统一位于bsp_internal.h。
没有BspResult、valid_mask、帧结构、就绪标志、序号、时间戳或采样软件缓存。
两板使用同一公开头；工程选择对应MCU的完整ADC实现，应用不按板型选择调用。

应用中断入口显式定义于各板`projects/<board>/application/main.c`：
AT32：`MCU ADC IRQ → BspAdc_CompleteFast → MotorAxis_SampleFast → MotorAxis_ControlFast → ++g_app_fast_samples`。
BSP公开接口负责主/辅ADC配对和清标志；main依次调用采样、控制并递增计数。
SampleFast包含三相/母线电流、电压、零偏校正及编码器反馈，ControlFast只消费本拍结果。
STM32保留`BspAdc_HandleInterrupt → HAL完成回调 → BspApp_OnFastSample → MotorAxis_SampleFast → MotorAxis_ControlFast`，
仍先执行快环再清JEOS。两板共用g_app_fast_samples供前台看门狗读取，不增加计数转发函数。
AT32链接脚本将整个main ADC入口保留在快速SRAM区。

| 项目 | AT32F456 | STM32G4 |
| --- | --- | --- |
| 生命周期 | Bsp_Init配置，Bsp_Start启动 | 同一入口，内部调用原CubeMX/HAL |
| 快触发 | TMR1 CH1 同时触发 ADC1 三相电流和 ADC2 四个抢占通道 | TIM1 CH4触发原注入序列 |
| 完成 | ADC1 IRQ 确认 ADC1、ADC2 的抢占转换均完成后通知应用 | ADC2 JEOS确认快帧后通知应用 |
| 独立母线电流 | ADC2 PA4注入rank，92.5采样周期 | 无传感器，不置有效位 |
| 辅助量 | NTC 由 TMR6 触发普通转换，Hall 由 TMR1 触发抢占转换 | 无这些板上输入 |
| 内部量 | 无 MCU 温度采集 | 原校准温度及VDDA |
| Flash协调 | Adc_Stop关闭触发/转换；Adc_Start恢复，不等待首帧 | Adc_Stop/Start直接停止/启动转换，无采样状态包装 |

## AT32采样时序配置

ADC1 和 ADC2 独立工作，时钟均为 60 MHz。TMR1 在每个 50 µs PWM 周期上数至 4050（22.50 µs）时，同时触发两组抢占序列。下表以 TMR1 谷底为零点，每次 12 位转换按 `(采样周期 + 12.5) / 60 MHz` 计算，区间包含采样保持与转换，未计触发同步和中断延迟。[PWM 载波、边沿与装载](at32f456_pwm_adc_driver.md#一个载波周期)

| ADC | 输入 | 采样周期 | 从 PWM 周期开始算起的转换区间 |
| --- | --- | ---: | --- |
| ADC1 | PA0，相 A 电流 | 12.5 × 4 次 | 22.50～24.17 µs |
| ADC1 | PA1，相 B 电流 | 12.5 × 4 次 | 24.17～25.83 µs |
| ADC1 | PA2，相 C 电流 | 12.5 × 4 次 | 25.83～27.50 µs |
| ADC2 | PA4，母线电流 | 92.5 | 22.50～24.25 µs |
| ADC2 | PA5，Hall sin | 24.5 | 24.25～24.87 µs |
| ADC2 | PA6，Hall cos | 24.5 | 24.87～25.48 µs |
| ADC2 | PA3，母线电压 | 24.5 | 25.48～26.10 µs |

ADC1 对每相连续转换四次，硬件累加且不右移，读取时乘 0.25 还原为等效 12 位计数。
单次采样保持约 0.208 µs，每相四次转换共约 1.67 µs。三相依次采集，相邻相的转换区间中心相差约 1.67 µs。
ADC2 每路各取一次，标称比 ADC1 提前 1.40 µs 完成。母线电压排在两路 Hall 之后，电压原码直接取 ADC2 最后一个结果槽。

**与开关沿的距离随占空比而变。** CH1 的触发位置固定。若一相占空比为 D，其上桥的两个理想比较边沿位于 `25D` 和 `50 − 25D` µs。
在 50% 时，22.5～27.5 µs 的转换区间位于两边沿之间；在 90% 时，两边沿正好落在区间两端。
更高占空比下，比较边沿会进入三相转换区间。判断某一路是否受干扰还要对照其具体采样保持时刻、驱动死区和电流放大器建立时间。

**从完成标志到控制输出。** 只有 ADC1 开启抢占序列完成中断（优先级 0）。
入口检查两只 ADC 的 PCCE；两者均置位才清两组标志，执行 `MotorAxis_SampleFast → MotorAxis_ControlFast → ++g_app_fast_samples`。
只有 ADC1 完成时清其标志，跳过本拍，不等待 ADC2。标志没有拍号；异常迟到时仅凭这两个标志不能验证同拍。
采样函数先发起编码器 SPI 传输，与母线和相电流处理重叠，再更新编码器反馈。运行态 FOC 计算 SVPWM 后写三相比较缓冲。
每五个成功快拍派发一次 PendSV 外环（标称 4 kHz）。独立的 TMR6 每 500 µs 触发 2 kHz 监督中断，两者优先级均为 2，均可被 ADC 抢占。

TMR6 的同一溢出事件还触发 ADC2 普通组的 PA7 电机 NTC。单次采样保持 640.5 周期，含转换标称约 10.88 µs，
结果在完成后才进入普通数据寄存器。监督中断入口没有等待本次 NTC 转换完成。NTC 为 B3950、R25=10 kΩ，下臂 1 kΩ。
实现见 [ADC 初始化及完成判定](../../firmware/platform/bsp/mcu/at32f456/adc.c)、
[正式 APP 中断入口](../../projects/at32f456/application/main.c)和[轴快环](../../firmware/app/runtime/motor_axis.c)。

## 数据与职责

两板都只有两个数值读取入口：ReadRawChannel返回等效12位原码，ReadChannel返回A、V或摄氏度。
零偏设置直接写入，返回void；未设置零偏时电流为NAN。未启用、缺参数或公式无定义返回NAN。
ADC完成中断只确认/清标志并通知快环；读取不等待首帧，不判断健康/年龄，不保证多通道同拍。
快慢通道都没有软件缓存；AT32直接读取 ADC 结果寄存器，STM32直接取ADC1的TS/VREF寄存器。
STM32 system.c中的监督回调在应用读完当前TS/VREF之后触发下一组，保持2kHz软件采样。
Flash停止后旧寄存器/缓冲区值仍可被直接读取；AT32 恢复时清标志并开放触发。

应用的电压/电流搬运函数直接接收数值，不再依赖BSP帧类型。
`FocState`直接持有母线电压、硬件母线电流及各自滤波值和低通系数；
Axis初始化两系数为0.05，20kHz快环直接读取BSP母线通道并更新。
母线电流通道未提供或未校零时为NAN，恢复有效后以首个有效值重建滤波基准；
FOC内部的估算母线电流继续独立存在；协议反馈来源不由测量搬运函数更换。
电流校零与母线滤波保持各自的应用所有权；母线Watch序号改为监督读数次数，
不再根据ADC序号去重或验证硬件触发连续性。AT32 电机温度读取 ADC2 普通组结果。
本轮没有往其它层新增ADC保护，原应用看门狗和校零策略继续存在。

电流偏置校正固定累计2048个快拍，20kHz下理论102.4ms；AT32 正式 APP 在 IDLE 快拍中调用。
三相和已启用的母线电流共用窗口；第2048拍计算各自均值，确认处于
1948～2148 counts且仍关相、控制禁用后，一次发布给BSP，三相值同时写入活动配置。
无母线传感器的板卡跳过该通道；启用通道任一失效都会阻止全部偏置发布。
正常采样只读取物理量，监督任务不再处理偏置。失败锁存原故障，不自动重试、保存或启相；
自检额外等待按毫秒向上取整为103ms。

2026-11-09 在停机的 PITCH 0x06 上回读到 ADC1 通道顺序 0、1、2，ADC2 顺序 4、5、6、3。
母线电压单次原码约 1190 counts，软件上报约 30.02 V，快采样计数约 19.96 kHz。
