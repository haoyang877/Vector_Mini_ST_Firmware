# 速度闭环稳定性实测 v1

用户要求测试速度闭环稳定性。沿用已回读验证的当前Commissioning镜像、117启动、116目标与108实时状态，
不修改固件、控制增益或标定。硬件为AT32F456＋YQ-5708（8:1），电机固定、输出轴自由、无加载装置。
用户批准相电流3A、速度50rad/s上限；本轮先测最低速度，使用更窄的速度和行程截止。

## 步骤与判据

1. 核对身份、镜像、关相、故障与RAM标定；只读记录当前实际速度上限和PI参数。
2. 先执行+1rad/s，3秒启动观察后继续采集，目标为末段20秒评价窗口，总时限28秒。
   该点额外使用5rad/s速度截止、40rad累计行程、500ms租约；相电流截止3A。
3. 只在前一项通过且静止确认后反向测试−1rad/s。低速通过后再按配置允许范围决定扩档。
   任一控制指标失败不继续反向或升档；保留本次全部数据，不调参重测。
4. 评价窗口未达到目标稳定带时，明确记为未进入稳态，不能把静止速度纹波小写成通过。
   建议值沿用v1.1：偏差≤max(1%目标,0.02rad/s)，误差RMS≤max(2%,0.03rad/s)，
   峰峰值≤max(10%,0.10rad/s)，切换稳定时间≤1秒、超调≤15%，无持续增幅振荡。
5. 目标为100Hz主机采样，记录实际往返时刻、帧序号、目标/反馈速度、位置、Iq给定/反馈、母线及状态。
   另用既有台架快照读取斜坡参考；所有取样分别保留时刻，不冒充同一快拍。
6. 板端原监护保护持续生效；若转速连续低于目标10%且|Iq|>0.8A达2秒，主机结束该次测试，
   记录堵转迹象，不维持大电流等待。故障、采样失效、通信失败、异常反向或越限均停止。
7. 结束确认关相、故障、零位、标定标志及LUT，保存图表、原始CSV和逐项结论。

## 适用范围与证据

实测速度来自现有编码器估计，位置差分用于交叉检查；无独立转速仪，不能给出外部绝对精度结论。
加载扰动测试仍因无装置未执行。原v1.1完整高档矩阵不因一个低速点通过而自动判为通过。
本轮证据位于`outputs/speed-stability-20261031/`，历史结果不覆盖。
仅输出批次脚本和报告；文档检查与quick验证用于本轮变更，不重新烧录。
