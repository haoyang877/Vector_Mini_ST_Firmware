# 硬件测试实测值展示

基线 b43c34c5，包含 ROLL 标定 PI 和现有实时曲线上位机。当前 Type127 仅返回十项枚举结果，板端统计不对主控公开。
目标是在测试结果表展示项目、实测值、判定标准和结果，并在 JSON 保存同轮数值。保留现有阈值、采样、运动、STOP、故障和参数布局。

方案：Type127 v2 增加只读操作2，按项目读取32字节数值页；CAPS bit20 声明支持。旧查询和启动字节不变，新主控在旧固件显示未提供。轮号必须匹配且已停止采集，避免跨轮或半更新统计；无有效数据用位图表达，不以零冒充。
板级检测拥有统计，协议仅序列化，界面只负责显示。读取在结束/中止且关相确认后执行，不加入运动续租循环。

验收：覆盖原码均值/RMS、电压极值、温度、电机静态峰峰角、霍尔双通道、去回净角度及趋势一致率；覆盖旧固件、缺测/未装、部分中止、轮号不匹配和非法页；原判据回归不变。运行PR及Release，构建配套固件/上位机；不自动接触硬件。
回退：恢复旧主控和固件；无Flash迁移。

用户追加要求：ROLL正常运行PI同左右轮改为0.05/0.5；旧ROLL默认0.5/1.0在RAM恢复时迁移，保留其他人工整定、标定5 A和全部编码器数据。随APP1.8.8验证。

结果：协议端到端黄金帧、均值/RMS、提前中止、代际和旧固件、Tk结果表及ROLL旧默认迁移回归通过。发布验证见outputs/runs/hardware-values-roll-pi-release-final-20261113。配套版本APP1.8.8/工具1.15.0；真实硬件和最终视觉检查未执行，用户已停止界面自动化。
