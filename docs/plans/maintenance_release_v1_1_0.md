# 维护软件 v1.1.0 版本计划

日期：2026-10-14。基线：Loader 合并节点 `339a7590`。

目标：将当前四页维护工具、Loader v1.0.0、APP v0.5.2 整理成一个可追溯版本包，
验证升级是否保留电机标定。维护软件版本独立于板端版本。

范围：新增单一软件版本源，窗口标题、侧栏、离线版本查询、Windows EXE 属性及
构建清单共同使用 v1.1.0；继续内置两个厂商 DLL。合包包含合并 HEX、CAN APP 包、
说明和校验清单，不引入新依赖。

保持不变：CAN 协议、Flash 布局、参数 ABI、控制算法、UID 绑定、STOP/关相准入、
备份和写保护路径。APP 仅递增修订版本，独立重建 APP/HIL/Loader 并核对哈希。

验收：现有 Loader/native/GUI 检查、格式及静态检查通过；冻结 EXE 验证版本资源、
四页界面、内置 DLL、有效/非法 HEX；所有下载文件清单 SHA256 匹配。
实机测试先只读探针/适配器/板卡身份；指定探针变化必须明确绑定后才写入。
模拟历史 v0.4.1 的独立 APP 位于 0x08000000、无 Loader 的停机 Flash 状态，
原始参数保持独立；随后安装 v0.5.1 合并包，再经 CAN 升级到 v0.5.2。
升级前后完整 16 KiB 参数逐字节比较，复位后再次比较，并记录 LUT、标志、零位；
CAN 全参数 CRC 作为独立旁证。空白参数或硬件不可用时明确限制，不能宣称标定通过。

回退：维护软件退回基线 EXE；板端失败使用同板 J-Link 恢复兼容合并镜像。
不能使用全片擦除，不能将其他电机的参数写到当前板。
证据保存在本轮 `outputs/maintenance_v1_1_0_20261014*`，不将历史日志作为本轮实测。
