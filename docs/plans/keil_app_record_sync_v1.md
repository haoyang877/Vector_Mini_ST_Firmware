# Keil APP 与有效记录同步 v1

日期：2026-10-15。分支：`codex/ovp-36v`。

问题：Keil 原 AXF 只有 APP，下载后仍保留旧记录，正常复位时 Loader 因 CRC 不符拒绝跳转。

## 实施与不变项

- 增加独立只读记录段，位于 `0x08003000`，长度 48 B，不占 APP 或 RAM。
- 链接后复用现有有效记录编码，根据 AXF 内实际 APP 和版本符号填写记录；同步导出 HEX、APP BIN。
- APP 填充到其分区末尾，使用 `0xFF`，保证 CRC 包含的字节均在下载镜像中，消除旧尾部残留。
- Keil After Build 自动执行；不使用调试脚本补写 Flash，不关闭 Loader 校验。
- 不改电机控制代码、参数 ABI、Loader 代码、标定参数或内存分区；仅改变构建/下载产物。
- 记录页 6 允许擦写；Loader 页 0～5、保留页 7 和参数页 56～63 必须原样保留。

## 基线、验收与回退

修改前备份工程与链接脚本，记录用户已有改动，禁止整文件恢复或覆盖其他任务的优化。
离线测试覆盖真实共享 C 解码、CRC、版本来自镜像、幂等、坏 ELF/越界拒绝及构建挂钩。
普通 APP/HIL/Loader 分别编译、检查产物范围与哈希；所有证据放在
`outputs/keil_app_record_sync_20261015/`。

用户已授权当前 J-Link 板实测且不启动电机：先确认关相并双读备份全 Flash，
通过 Keil 下载；随后不使用调试入口脚本，从 Loader 复位入口执行并以硬件断点停在 APP main，
在任何 APP 外设/电机初始化前暂停。核对有效记录、Loader/保留页/16 KiB 参数逐字节一致。
测试结束 MCU 保持暂停；关相验证失败立即停止，按仓库规定要求物理介入。

回退只撤销本次记录段、构建挂钩及工具；保留参数与已备份现场 Flash。
本分支无统一 verify/format/lint profile，使用现有构建、目录检查和 Loader 离线套件。
