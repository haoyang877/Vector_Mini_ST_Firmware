# 底盘轮子速度上限

> 当前固件已移除 MCU USB CDC 服务。本文中 USB/VOFA 指令及采集流程仅作历史参考；当前 CAN 能力与未迁移功能见 [USB 移除说明](usb_removal.md)。


节点 1 为左轮，节点 2 为右轮。按电机与车轮直连、轮径 0.10 m、最大轮缘线速度 1.0 m/s 配置：

```
omega_max = 2 * v_max / diameter = 20 rad/s
n_max = v_max / (pi * diameter) = 3.183098862 r/s
rpm_max = 60 * n_max = 190.9859317 rpm
```

正反向速度目标范围为 `[-20, +20] rad/s`。这是速度目标上限，实际闭环瞬态可能有跟踪误差。不要向上取整为 191 rpm；200 rpm 对应约 1.0472 m/s，超出此配置。

`firmware/services/parameters/foc_param_profile.h` 中的 `PARAM_WHEEL_DIAMETER_M` 和
`PARAM_WHEEL_MAX_LINEAR_SPEED_M_S` 定义几何与线速度；`Param_SpeedLimitRadS(node_id)`
统一返回节点上限。节点 1、2 返回 20 rad/s，其他节点仍使用原电机档位的 0.5 r/s（30 rpm）。

参数加载先解析最终 CAN 节点，再限制 Flash 中的 `speed_limit`。已保存的较低限速保留；
非正值或非有限值回退到该节点上限。CAN 与 USB 均通过 `Param_SetSpeedLimit()` 检查。
修改节点会向下限制当前限速；降低限速也会限制已有速度目标，由现有加减速配置过渡。
本次不改变参数结构，schema 仍为 10，也不改变电机或编码器校准。

启用最大限速时，需要将运行参数 `speed_limit` 设置为 20 rad/s，再保存参数。
仅升级固件会保留旧的 30 rpm 运行限速。

| 接口 | 设置最大限速 |
| --- | --- |
| CAN 协议修订 2 | `CAN_SET_SPEED_LIMIT = 0x12`，节点 1 ID `0x112`，节点 2 ID `0x212`；大端有符号整数，0.01 rad/s 单位，4 字节载荷 `00 00 07 D0` |
| USB | `slm` 参数单位 r/s；可发送 `3.1830988`（略低于理论值，避免十进制向上取整被拒绝） |
| 固件内部 | `speed_limit = 20.0f`，单位 rad/s |

主机回归测试：

```
python tests/unit/native/test_wheel_speed_limits.py --cc <C99编译器或zig路径>
```

测试执行生产参数加载/保存函数和 CAN、USB 设置分支，检查节点范围、边界、较低限速保留、
校准保留、轴身份优先级及节点切换后的限速。
