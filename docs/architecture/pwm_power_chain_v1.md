# 双板PWM与功率输出链路 v1

更新：2026-10-29。公开契约见[bsp_pwm.h](../../firmware/platform/bsp/include/bsp_pwm.h)。

## 职责

公共bsp_pwm.c拥有输入检查、比较值计算、提交窗口、关相序号及输出状态。
各板pwm.c负责初始化、比较寄存器、六路输出和实际状态读回。
应用pwm_power_window.c拥有原一次性窗口；准入、超速、STOP及故障归应用/电机层。
PWM随Bsp_Init初始化，不再公开另一套初始化入口。

| 项目 | AT32F456 | STM32G4 |
| --- | --- | --- |
| 通道 | TMR1 CH2/3/4，CH1采样 | TIM1 CH1/2/3，CH4采样 |
| 时基 | 180MHz，TOP4500，原模式/死区 | 170MHz，TOP4250，原CubeMX配置 |
| 写入 | 原比较值尺度和A/B/C顺序 | 原表达式和A/B/C顺序 |
| 启停 | 原寄存器门控 | 原HAL顺序及就绪快路径 |

## 提交与失败

占空比须有限且在0..1；初始化时缓存固定换算周期，运行中不修改PWM周期。
全部校验和换算后只调用一次MCU提交：取得输出状态、检查期限、成功才写比较寄存器。
三相与单相都由MCU提交入口检查期限，公共BSP统一处理超时关相及故障锁存。
快环为最高优先级，不允许被抢占；bsp_pwm.c不再开关中断，不提供嵌套锁或快照重试。
前台启停和一致快照由调用方保证互斥，应用功率契约检查同锁读取输出及窗口。
MCU检查方向、计数位置及256计数保护窗口，安全时写原预装载寄存器。
不产生软件更新事件、不重启计数器、不改采样通道。来不及安全提交则关相并锁存失败。
此项及启相失败收尾是明确的保护增强，不是仅更名。

BSP消费目标注入的BSP_PWM_HARD_LOCK，不包含应用许可策略头。
Enable检查初始化、永久关相和故障锁；部分启用失败则关断并读回。
STM32保留原HAL停止顺序，同时直接清通道/MOE作为收尾；无法确认关断则进入不可返回故障停机。
GetStatus单次返回OFF/ON/INCOMPLETE与关相序号；一致性由调用上下文保证。
ArePhasesDisabled保留六通道全关判据。
Disable推进关相序号，应用据此消费窗口。
窗口仍为200..45000ms、5秒未用失效、20拍/ms双截止及不可续期。
应用在同一临界区开始窗口和启相；失败消费窗口并进入原故障处理。

## 验证

29968组实际STM HAL MMIO对照核对正常启停；公共测试覆盖非法输入零写入、超窗关相、部分失败、锁存和永久关相。
AT32本轮只测关相及运行，不启相，不能作为功率波形证据。
