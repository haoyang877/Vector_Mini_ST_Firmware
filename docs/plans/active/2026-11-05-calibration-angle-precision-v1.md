# 标定参考角精度修正 v1

## 证据与目标

Math_Atan2的三次近似在单位圆上最大误差约0.5815度电角。
其8次电角谐波折算为14极对电机的112阶机械角，幅值约0.0241度，
现有LUT同阶实测约0.0201度。观测器角度直接用于编码器标定，数值误差会进入表格。

用标准单精度atan2f消除这项可确定的算法近似误差，保留非有限输入的失效传播、
零向量的既有约定和公开API。此项修正与LUT中的电角基波误差分别记录。

## 验证

新增单位圆及缩放向量精度回归，先验证旧实现失败，再确认新实现通过。
运行观测器与标定路径原有回归、PR验证及ARM构建。
上板前检查实时路径代价；全速度域矩阵使用当前已核对镜像，构建与上板分阶段进行。
现有Flash LUT需要独立复核，修改角度函数不会自动重建记录。
