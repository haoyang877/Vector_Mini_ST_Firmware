# 统一台架协议v1.1：D轴正弦

2026-11-02。在[原测试协议](unified_motor_bench_v1.md)上仅扩展RUN请求，外层版本字段仍为1。
只有Commissioning启用，正常APP不注册。旧16字节RUN、原捕获/导出格式和所有保护不变。

RUN数据（不含op/version）新增24字节形式：

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| 0 | u16 | kind=8，D轴正弦 |
| 2 | u16 | 保留0 |
| 4 | f32 | 正弦峰值电流A，必须大于0 |
| 8 | u32 | 正弦持续时间μs |
| 12 | u32 | 偏置预热时间μs，最多100000 |
| 16 | f32 | 频率Hz，1至FOC_FREQ/5 |
| 20 | f32 | D轴偏置A，必须≥峰值；偏置＋峰值≤已配置电流上限 |

预热时Id=偏置、Iq=0；正弦起点为相位0，之后每个20kHz控制拍产生
`Id=偏置+峰值*sin(相位)`，Iq始终0。时限结束立即请求原STOP。
参考边沿和延时捕获的起点为正弦开始，GROUP_DQ仍记录同拍参考和原始反馈；INFO的run_kind为8。
本机租约、速度、累计行程、相电流和故障检查每拍先于参考产生；不改变FOC计算。

旧固件不支持该扩展时返回4，不可退化为循环CAN指令生成高频参考。
长度错误返回4；NaN、幅值、频率或时限越界返回11；无运行许可返回5。
有副作用的重发沿用序号缓存，不能重新触发正弦。
黄金向量见[正弦请求向量](unified_motor_bench_v1_1_vectors.json)。
