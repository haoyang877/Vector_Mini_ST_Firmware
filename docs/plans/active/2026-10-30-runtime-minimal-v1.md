# 五态 runtime 最小化 v1

## 目标与不变行为

等待五状态重写完成后，以其最终工作树为基线简化 `firmware/app/runtime`。
保留上电空闲、自检占位、启停与故障、请求去重、标定取消、后台保存、参数格式、
快慢环调度顺序和全部对外协议。删除单一实现之间的转发接口、重复声明和无用封装。

生命周期只有一个所有者：上下文、内部辅助函数和公开实现放在同一 `.c` 中，
不再为同一对象跨文件传参，不公开可写上下文。轴编排、维护叶任务、参数事务和
固定工作区保持各自职责，不把控制算法或硬件寄存器移入 runtime。

## 基线与回退

五态任务完成后冻结受影响的源码、测试、工程及文档到
`outputs/runtime-minimal-20261030/before/`，记录 SHA-256 和行数。
先运行两板五态测试、参数/保存、状态快照和母线保护测试；保存当前 PR 检查结果。
回退仅恢复本轮受影响文件，不覆盖其他未提交修改或实验数据。

## 验收

- 比较全部保留函数：只允许内部命名、上下文访问和删除转发造成的差异，
  另行记录显式简化；保持临界区、故障优先和发布顺序。
- 两板五态测试及参数/保存、协议、快照、母线专项通过；请求身份、
  迟到结果和取消资源归还不能退化。
- 更新四个 Keil 工程的实际编译文件，分别离线编译两板 runtime 并比较代码/RAM。
- 运行格式、lint 和 PR profile；明确区分已有失败与本轮引入问题。
- 不烧录、不驱动电机；对象段比较不替代完整固件镜像或实机时序验收。

## 结果

已在五态重写完成后实施。`runtime`由16个C/H文件、3942行缩为10个文件、3264行，
净减678行（约17.2%），保留全部现有业务。

- 生命周期上下文、私有辅助函数及公开实现归入`motor_lifecycle.c`。
  删除requests/maintenance/safety三个内部实现文件和internal头，去掉26个公开转发函数。
- 命令校验成为该文件内的`validate_target`，删除仅承载此函数的`motor_command.c/.h`。
- 快环由BeginFastTick统一检查并关断旧故障，再消费启相许可；PostOutcome发布结果后
  统一关断本拍故障。Axis无需安排三个额外保护调用，原先的两阶段关断顺序保持。
- 三个单次使用的测量谓词展开到输入检查；删除维护类型范围的重复判断和取消路径中
  已被外层证明的分支。LUT发布及输出预期查询收为私有，不保留无生产调用的声明。
- 单轴初始化/调度、维护叶任务、参数事务和固定工作区仍保持各自职责；未新增抽象层。
