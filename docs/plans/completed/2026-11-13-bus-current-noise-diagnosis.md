# 母线电流静态噪声定位

2026-11-13，基线 `ac661bed`，沿用本轮已连接节点 6 的关相台架。
用户明确要求区分硬件噪声与 ADC 时序问题，不放宽检测阈值。

基线：四个 2000 样本窗口的母线电流 RMS 24.29～25.11 cnt，三相和霍尔噪声正常。
本轮仅关相诊断，不执行电机运动，不写参数、标定或生产身份。

步骤：核对原理图、ADC 实际寄存器、结果槽与取数时刻；采集连续原码并核对 RMS；
通过可回退的单变量实验比较采样时间、触发相位和通道切换影响。实验修改仅在忽略的
outputs 中生成，保持 `<10 cnt`、偏置界限及其他保护不变。

验收：提供每项对照的真实数据、寄存器差异和可支持的因果范围；不能仅凭平均或滤波
把噪声改判正常。结束恢复原采样配置/镜像，核对六路关相、APP 运行及参数逐字节一致。
若必须依赖外部仪器才能区分具体模拟器件，明确已排除的原因与剩余验证步骤。

证据：`outputs/bus-current-noise-20261113/`。回退镜像与完整快照沿用前轮
`outputs/hardware-check-hil-20261113/` 并在本轮开始时再次确认。

## 实测结论与边界

噪声随 PA4 模拟输入出现，现有证据不支持 ADC2 专属时序、原采样时长不足、
原 PWM 触发相位或 NTC 普通组抢占是主要原因。定位范围为母线电流的模拟输入链路；
尚未用外部仪器直接测得 PA4 电压，不能断言 INA240 已损坏、输出振荡或某个电容故障。
用户确认现场暂无示波器，本轮保留证据，结束片上对照。

原理图依据为 [R40](../../hardware/SCH_R40_260522_2026-09-18.pdf) 第 1、2 页；
实际引脚按板卡已确认的 PA4 母线电流、PA3 母线电压，不根据图纸网名直接交换。
基线寄存器核对 ADC2 rank1=通道4、PDT1 取数、92.5 周期采样、60 MHz ADC、
20 kHz 触发、CCR1=4050；快环入口确认 ADC1/ADC2 完成后才取数。

| 单变量实验 | 三个完整 2000 样本窗口的 RMS（cnt） | 解释 |
| --- | --- | --- |
| 基线，ADC2 PA4，92.5 周期、22.5 μs | 24.685 / 24.713 / 25.114 | 前轮检测可复现 |
| ADC2 PA4 改为 12.5 周期 | 24.268 / 24.562 / 24.868 | 未显著改变噪声；不支持 92.5 周期采样时长不足 |
| 触发点改为 10 μs，采样时长保持 92.5 | 24.514 / 24.645 / 24.697 | 未显著改变噪声；不支持原 22.5 μs 相位是主要原因 |
| ADC1 第三槽改采 PA4，其他配置不变 | ADC1 PA4：22.704 / 22.934 / 22.994；同期 ADC2 PA4：24.811 / 24.700 / 24.856 | ADC1 原第三槽约 0.9，改接 PA4 后同样高噪声；ADC1 另外两路仍约 0.9，噪声跟随 PA4，非 ADC2 独有 |
| 停用 ADC2 NTC 普通组外部触发 | 24.836 / 25.204 / 24.868 | 未显著改变噪声；不支持 NTC 抢占为主因 |
| 恢复原镜像复测 | 24.899 / 25.246 / 24.530 | 恢复后重现原问题，未通过临时配置掩盖异常 |

ADC1 使用既有四次硬件过采样并折算到 12 位等效 cnt；其结果不能当作与 ADC2
单次采样完全同口径的原始噪声值，也不能作为降低检测阈值的依据。
四个诊断工程均为当前分支生产 APP 的单处 ADC 初始化改动，独立构建 0 错误、0 警告。
未新增调试协议、运行时 ADC 配置命令或产品配置。测试全过程关相，不执行运动。

ADC1 交叉组首轮 Type127 在 50 ms 内未取得匹配应答，结束快照中止于 1578 样本，
未形成完整 RMS；该轮保留为异常，不计入表格。随后两个完整窗口及追加一个完整窗口
均复现上述 PA4 噪声。追加窗口在前轮证据目录的 `diagnostic-adc1-extra.json` 中。
没有把不完整窗口的零统计值当作通过，也未更改通信期限或重试规则。

原始曲线使用前轮末尾 128 个连续样本，约 6.4 ms，原码 1969～2066，均值 2016.414，
去均值 RMS 25.823 cnt。横坐标使用捕获周期差/180 MHz，不冒充精确的模拟采样时刻。
所有图均未滤波，CSV 保留每点原码。128 点 RMS 不等同于完整 100 ms 窗口结果。

## 后续模拟链路核验

需要在同一关相条件下测量 U9 OUT、实际 PA4、U9 的 VS/REF 与本地地之间的波形。
检查真实分流电流纹波、共模耦合、参考/供电纹波、输出稳定性和实装 RC。
图纸中母线 U9 由 VCC3V3 供电，三相 INA240 使用 VDDA3V3；母线输出有 R125=22Ω、
C39=10nF，与三相的 100Ω/1nF 配置不同。这些是待实测的差异，不能仅凭图纸判为故障。
INA240 的供电、参考、容性负载与布局检查依据
[TI 原厂数据手册](https://www.ti.com/lit/ds/symlink/ina240.pdf)，需结合实板波形判断。
