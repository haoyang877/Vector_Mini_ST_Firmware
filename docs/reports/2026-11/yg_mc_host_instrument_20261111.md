# YG_MC_HOST v3.0.0 仪器工作台与实机回归

日期：2026-11-11。产物为测试候选，不代表整套产品与固件发布收尾。
源码基线 `ed66253f`，保留工作区原有通信续租、清错和标定修改；本轮未提交代码。

## 实现结果

- 顶部常驻电机连接状态、实际型号、轴角色、节点及 APP、Loader、硬件版本，历史身份明确标注。
- 五个顶部工作区替代宽侧栏；设备详情、辨识支持范围和原有业务入口继续可达。
- 调试采用主曲线与两张辅助曲线，右侧集中模式、使能/失能、目标与 STOP。
  全局 STOP 和故障底栏保留；通信与曲线线程的状态所有权不变。
- 参数统一设备值、编辑值、单位与属性/来源五列，分类为电机85项、控制19项、阈值30项。
  控制按电流环、速度环、位置环分组；可搜索、筛选和分页，支持1024窗口及DPI缩放。
- 48项标量使用共享协议目录的类型、缩放和权限；86项扩展/编译定义没有读取接口时明确显示未知。
- 接入 bit14 参数服务：活动值与真实Flash值分别读取；单项写入携修订号，随后读取设备实际量化值；
  显式保存须核对保存修订与flags。重连清空缓存，不跨设备/上电复用修订号。
- 保留型号配参、APP CAN升级、Loader+APP SWD维护、三项标定、清错、诊断和CSV。

未扩展固件ABI，未修改固件控制算法、参数默认值、限位策略或动态保护。

## 实机范围与结果

通过真实GUI操作USBCANFD-200U，选择并连接PITCH节点6，型号YQ-5740。
实际回读APP1.6.2、Loader2.2.0、硬件Rev2、schema14、ABI0x000E08F0。
完整UID、主机版本、命令序号、实际负载及原始诊断保存在生成证据目录。

| 场景 | 观察结果 |
| --- | --- |
| 扫描、选择、连接 | 发现一个适配器和目标节点，连接后重新绑定完整UID |
| 失能 / 本地STOP / 顶部STOP | 收到最终0/0和IDLE回读，零故障；失能后目标禁用，可重新切模式 |
| 参数只读 | 活动与Flash读取流程完成，均r1；电流环Kp0.610、Ki3226.221在两种来源一致 |
| 速度 | 零目标使能，1、2 rad/s均受理；取样区间均值约1.001、1.974 rad/s；随后本地STOP |
| Vq | 零输出使能，0.05 V目标区间回读固定0.050 V；随后失能 |
| Iq | 零输出使能，0.02 A目标区间均值约0.0207 A；随后失能 |
| 位置 | 使能保持40.894 rad；下发40.914 rad与回位40.894 rad，回位末2秒读数为40.894 rad；随后顶部STOP |
| 记录 / 导出 / 断开 | 记录13700样本，CSV、曲线更新时间和JSONL均导出；最终主动断开并显示历史/未知状态 |

19次受控命令事务包含4次START、6次目标和STOP等待最终状态所需的查询；
受理结果与最终状态分别核对，没有将START受理直接当作使能完成。
日志记录28次BUSY均恢复、6次不匹配回复丢弃后恢复，零错误级事件、零日志队列丢失。
无自动重连、复位、J-Link访问、固件下载、标定执行或持久参数写入。

## 仍需推进

本轮证明GUI流程与通信链路，不构成控制精度验收。
1 rad/s区间实际反馈约0.185…2.275 rad/s；2 rad/s区间约1.010…3.053 rad/s。
位置小步进也有超调/振荡，回位末段收敛不能代替完整精度、超调与稳定时间评估。

230.48秒交互/四模式记录中，反馈接收约59.44 Hz；采用新数据的曲线更新约51.17 Hz，
完整2秒窗口34.5…60.0 Hz。**稳定至少60 Hz未通过**；不能用接收频率或显示器刷新率替代。
该场景包含UI自动化交互，与v2.8.1静止观察不是相同负载对照。

通用参数写入/保存仅完成离线事务测试，本轮实机只读；升级、实机标定、故障注入亦未执行。
这些范围保留在[需求清单](../../guides/yg_mc_host_requirements_v1.md)中，不以本次重构宣称全部验收。
