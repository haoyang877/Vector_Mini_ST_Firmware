# AT32F456/YQ-5708 位置和速度外环 4 kHz

目标是将该机型的速度 PI、位置串级、位置估计和轨迹采样统一到 250 µs，保留 20 kHz ADC/电流环和独立的 2 kHz 维护、RTT 节拍。其他板型和电机配置沿用 500 µs 外环。

每五个完成的 ADC 样本请求一次 PendSV；ADC 优先级高于外环，外环与监督同优先级。若上一请求到下一截止仍未完成，ADC 路径锁存控制超时并关 PWM。正常速度与位置模式跳过磁链观测器，编码器及测速 PLL 持续工作。标定和无感控制仍使用磁链观测器。

核对离线中断派发、无效 ADC、超期、状态/故障抢占及编码器更新；用正式 AT32 工程构建。板上交接需测量 ADC 至 PendSV 的实际延迟、重规划最坏耗时，并分别验证速度和位置参数；2 kHz RTT 不足以验证外环的实际执行频率。参数持久化及台架操作由轨迹调试会话负责。

基线为 2 kHz、3 A、速度 PLL 600 Hz、速度 PI 0.0335/0.67。固件按原记录装载增益。4 kHz 的高增益仅是待测候选。回退本次调度时恢复原工作区对应的 2 kHz 外环代码和匹配的原板备份。
