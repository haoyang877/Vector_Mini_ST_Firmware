# 普通通信与 Loader 通信分离 v1

按要求保留两个实现文件：`yg_protocol.c` 处理 CAN 收发和普通业务，
`yg_protocol_boot.c` 处理 Loader 命令、握手状态、回复超时和发送确认，共用一个头文件。
合并原 motor/device 普通业务，移走全部 Loader 专用状态与处理。

删除内部固定队列的参数检查、发送队列中已编码帧的重复解码、分发层重复的通用请求校验。
CAN 接收入口只复制入队，格式、长度和 CRC 在前台解包时检查一次。
普通命令、权限、错误回复、STOP/目标/标定、Loader 精确发送确认及超时语义保持不变。
接收入队的返回值只表示入队成功，不表示报文有效。

开始时编码函数有一处未完成的 `message->` 字段，先恢复为 `destination_node` 以获取可编译基线。
基线副本、构建、对照和哈希记录在 `outputs/protocol-boot-split/`。
验收包括协议黄金向量、错误帧、拥塞、Loader 确认/超时、真实 APP 控制回归、完整 PR 和三 APP 构建。
不连接硬件；回退只恢复本次基线相关文件，保留其他未提交修改。
