历史文档：2026-10-09标记。v1.3.0已删除齿槽标定与补偿实现，以下描述仅适用于删减前版本。

采样任务与运行状态分开后的所有者边界见[v2 职责图](cogging_core_boundaries_v2.md)。

## 职责与数据流

| 阶段 | 输入与输出、单位 | 写入者与边界 |
| --- | --- | --- |
| 准入/启动 | 在线且 LUT/电零位齐全、速度低于 0.05 rad/s、无行程轴、有效限值；锁定方向、电零位、极对数 | APP 先准入；任务复核电压/温度/电流/电角度，复位 PI 与电流控制器并预载零矢量，返回 PREPARED；主状态机授予功率许可 |
| 每拍安全门 | 20 kHz 机械位置 rad、连续速度 rad/s、iq A、电压 V、温度 ℃与锁定身份 | 适配层校验会话身份、有限值与既有阈值；失败中止采样并报告故障 |
| 采样抽点 | 每个 20 kHz iq 反馈，10 拍算一个块平均 A | 适配层累加与分频；不改变 2 kHz 调度与浮点运算次序 |
| 定点保持 | 目标/位置 rad、速度 rad/s；输出限幅 iq A，id=0 | 适配层每 2 kHz 执行既有斜坡、迟滞速度与阻尼 PI；20 kHz 电流计算仍由 FOC_Current 执行 |
| 点资格/双向遍历 | 1024 点整圈，正/反共 2048 次；100 ms 合格定位后 100 ms 合格采样 | CoggingCalibration_Update 唯一推进点索引、窗口计数、超时/饱和与暂存 Q15 表；第二遍平均时保留第一遍量化值 |
| 采集结束 | COMPLETE 或 FAILED；控制目标清零、PI/电流控制器复位，返回 FINALIZE 或 FAILED | 适配层只清理本地控制；APP 主状态机消费结果关相并协调后续 |
| 候选成表 | 私有暂存 int16 Q15[1024]、满量程 A、编码器签名；输出 2064 B 记录 | 前台认领后借 APP 工作区；CoggingMap_Build 去均值、检查全部转换值、舍入并写 CRC，不进 ISR |
| 发布/保存 | epoch 仍有效且真实关相时复制候选为活动表；随后导出参数记录并写 Flash | 候选归 APP 工作区；活动表归适配层，发布不等于保存。SaveResult(true) 只由真实 param_store_write 成功且认领仍有效的路径通知 |
| 运行补偿 | 用户 iq A、限流 A、单圈线性化角 0..65535、身份与 CRC 快照；输出总 iq A | 前台完整校验准入；20 kHz 核心插值、±1 A 表限幅、200 ms 渐变、总电流限幅，不覆盖用户 iq 指令 |
| 台架 guard/采样 | 20 kHz 租约拍数、速度上限 rad/s；独立 36 B 同拍遥测 | 真实力矩 guard 保留：租约/速度失败清零目标并挂起跳闸，由 APP 关相。遥测有单帧握手，未消费帧不覆盖 |

暂存表由标定核心写、采集完成后前台只读；活动表只在启动导入、停机复位或认领发布时写。
签名仍包含方向、电零位、极对数和 1024 点编码器 LUT；机械零位不参与表坐标。
满量程与参数/记录布局、CQG1 magic、CRC 字节范围及全部公开签名保持不变。

首点超时 10 s，其余点 5 s，全程 30 min，连续饱和 200 ms；全部保持。
取消由主状态机停相并清理目标后调用 Abort：采集中取消立即释放本地会话；
前台已认领时只标记取消，拒绝候选构建/发布，等待 ReleaseFinalize 和 APP 归还工作区。
失败/取消不自动恢复出力；恢复由主状态机故障清除资格与新的显式请求决定。

真正核心是点资格、双向 Q15 采样、去均值/签名/CRC；抽点、位置保持、会话安全门和
前台握手是必要任务适配。只收口重复的终止清理与结果拼装，不把标定与运行补偿混合。

## 完成、取消与恢复资格

`COGGING_COMPLETE` 是采样完成事实。`GetState` 在成表挂起或保存挂起时返回 SAVING；
成表认领已取走 pending、尚未发布时可以返回 COMPLETE，因此查询该值不能证明持久化。
APP 区分 RAM 发布、派生 SAVE 与存储提交；只有 `param_store_write` 成功且原 epoch
仍有效，才向 `SaveResult(true)` 报告成功。参数存储还负责既有回读验证。

采集中 STOP/FAULT 的关相与目标清理先于功能取消。成表认领中取消保持占用到前台
FinishBackground/ReleaseFinalize 与工作区归还完成，不在取消函数中提前复用候选空间。
取消拒绝后续成表/发布；若此前已经发布 RAM 表，既有实现不回滚该表，不能称其已保存。
归还后会话不再占用工作区，主状态机仍须检查实际关相和所有维护资源释放。

故障清除与再次启动归主状态机：当前传感器/电压/温度/参数/输出关闭/资源释放事实
须满足资格，清故障后重新自检；齿槽任务不自动恢复出力，不改变 encoder 校准数据。
台架 torque guard 仅在普通电流任务执行，不替代齿槽每拍会话保护或生产通信断连保护。
