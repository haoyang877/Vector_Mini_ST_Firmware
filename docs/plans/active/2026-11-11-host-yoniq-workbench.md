# YG_MC_HOST 电机工作台重构计划（参考 YONIQ STUDIO 1.0.2）

2026-11-11。阶段一已提供 Rust/egui v3.1.0 原生 EXE。设备中心、运动调试与全参数共用正常运行及离线样机的页面实现。曲线性能和台架任务另行验收。

## 依据与差异

参考目录中，发行版使用说明、提取的 `MotorV3Settings.qml` 及其四个业务页可用于核对导航和页面职责。`offline_studio/results` 的设备中心、运动和全参数截图来自独立模拟工程。全参数浏览器是该工程扩展，截图中的参数值、控制命令和升级结果均不能作为 YG 设备依据。

| 参考中的做法 | YG 的具体落点 |
| --- | --- |
| 设备中心进入某台电机的工作区 | 首屏显示扫描入口及适配器、节点结果。显式选择一台，连接后重读 UID 和身份。工作区提供返回设备中心入口，返回浏览不隐式断开或启动。 |
| 电机内四个业务标签，独立日志入口 | 运动调试、参数配置、标定与辨识、固件维护。日志、CSV 和通信诊断从常驻入口打开。设备详情从型号打开。 |
| 运动页三幅波形垂直对齐，控制区就近提供环参数 | 三图共享秒时间轴、游标和观察窗口。右侧选择模式、使能、失能、设目标和 STOP。环参数摘要显示设备回读，点击定位唯一的参数编辑表。 |
| 状态与操作跨页可见 | 顶栏突出连接及实际型号，另列轴角色、节点和 APP/Loader/硬件版本。输出独立标明失能、待回读、已使能或未知。底栏保留故障摘要和日志入口，全局 STOP 固定可见。 |

当前应用默认进入断开的调试页，曲线为一主两辅。硬停截图中同一拒绝原因占用多个区域，历史型号也与实时状态相邻。新版把历史身份标在型号和版本旁，反馈过期时数值就地标记，硬停只保留一条常驻原因和详情入口。全局和本地 STOP 共用现有事务。

## 页面布局

| 区域 | 展示与交互 |
| --- | --- |
| 设备中心 | 按适配器分组显示候选节点。型号、轴角色、节点、身份来源分列。成功绑定后再显示“已连接”。最近使用记录与本次发现分组。 |
| 运动调试 | 左侧三幅曲线同宽并对齐刻度。首图随模式显示 Vq、Iq、速度或位置，另外两图提供关联量并避免重复。控制区在右侧，依次为模式下拉、输出状态、使能/失能和红色 STOP、带单位的目标/实测及下发。Vq 用 V，力矩用 Iq（A），速度用 rad/s，位置用 rad。开始/暂停观察、恢复视图、清空记录和导出 CSV 有独立语义。 |
| 全参数 | 左侧目录分电机、控制、阈值。控制展开电流环、速度环、位置环。右侧统一表头为名称、单位、活动值、Flash 值、待写值、权限/来源。支持全目录搜索，切换分类保留同一设备草稿，切换设备按 UID 隔离。写入需回读实际值，保存 Flash 单独执行。 |
| 标定与辨识 | 左侧任务及前置条件，右侧进度、结果及设备反馈。现有三项标定按设备能力开放，辨识缺少接口时显示原因。 |
| 固件维护 | 分列单 APP（CAN）、Loader + APP（J-Link/SWD）、单 Loader（独立入口待接入）。显示当前及目标版本、包检查、传输和最终回读。参数读取、写入及 Flash 保存可直达对应参数表，备份保留维护入口。 |
| 视觉和缩放 | 建议采用 4/8/16 逻辑点间距、正文 14、分区标题 16–18；数值等宽右对齐，名称和单位分列。宽屏控制栏约占三成，窄屏优先折叠设备列表和次要详情。深浅主题都检查下拉列表的正常、悬停和选中状态。 |

参数基线为 134 项目录，电机 85、控制 19、阈值 30。48 个标量已接入通用服务，读写按各项权限开放。其余 86 项逐项显示已有专用入口、编译来源或待接入。示例值只属于明确标识的离线预览。

## 实施与验收

| 阶段 | 交付物与通过条件 |
| --- | --- |
| 1. 原生样机 | 在现有预览入口实现设备中心、运动页和全参数页。可操作设备选择、模式下拉、三环筛选。覆盖未连接、空闲、已使能、硬停和历史身份。用 1024×700、1366×768 及高分屏的有效工作区，验证 100%、125%、150%、175% 和 200% 缩放。低高度允许滚动，STOP 常驻，单位、下拉选项和写入状态可读。 |
| 2. 接入现有会话 | 重排页面与导航，沿用设备线程的独占 CAN、UID 绑定、STOP 和续租。UI 只发既有命令。验证换页不发送控制命令，扫描后由用户选择；旧读数和未确认状态不能显示为当前在线或已使能。核对全部旧入口在新工作区有去向，清理仍称“在线标量未接入”的旧提示。 |
| 3. 完成业务页 | 全参数显示全部目录，三环定位、权限、读活动/Flash、写入回读、保存状态均可核对。标定、诊断、导出、备份与三类固件操作按现有通道接入。离线覆盖设备拒绝、断开和未支持能力，保留原因及恢复入口。 |
| 4. 单独验证曲线 60 Hz | 复用现有曲线工作线程。从反馈入队、曲线快照发布到 UI 采用新样本分别记录序号和时间；先定位瓶颈再调整采样或绘制调度。建议以有效观察段连续 60 秒、逐个完整 2 秒窗口至少 120 次采用不同新样本的更新为通过条件，同时记录最差窗口、样本缺口与丢弃。观察静置和调试交互分别测。重复绘制同一数据或同次绘制合入多个样本均只按实际新数据更新次数计。 |
| 5. 实机与版本交付 | 现场确认上次硬停后的输出状态后，先核对只读身份和参数，再验证零目标使能、续租、STOP、跨进程重连及四模式低幅目标。单独记录 GUI 新样本更新频率。维护回归区分包校验、实际刷写及最终版本回读，写参挑选可恢复项并核对原值。每次候选在标题栏、EXE 文件名、发布说明中带版本，报告列出通过、失败和未测。 |

## 基线、依赖与回退

- 既有 v3.0.0 台架记录中，PITCH 的 CAN 接收约 59.44 Hz，曲线采用新数据约 51.17 Hz。若输入速率不足，必须先验证采集链路的可持续余量；同一批样本的重复绘制不能提高有效指标。
- v3.0.1 续租防护已完成 84 项离线测试，计数回退根因和跨进程实机复测仍在[原专项计划](2026-11-11-host-lease-counter-recovery.md)追踪。离线 UI 可先推进，复测结论独立记录。
- 状态、参数权限和升级通道沿用[当前设计](../../architecture/yg_mc_host_design_v1.md)及[需求清单](../../guides/yg_mc_host_requirements_v1.md)。参考软件的 Qt/QML、MAVLink 和 MIT 模式无需引入 Rust 产品。
- 按页面分批交付，出现功能回归时撤回对应 UI 变更，保留现有版本包、设备会话逻辑、参数记录及续租高水位。原生预览、台架日志和带版本的二进制按候选分别存入 `outputs/`。

## 阶段一交付

- `--studio-preview` 打开离线样机，提供 PITCH、YAW 两个显式标记的示例节点。「视图」支持缩放、深浅主题及未连接、空闲、运行、硬停、历史五种状态。正常启动仍需显式扫描、选择、连接。
- 运动台保留四种模式及各自单位，主量与两项关联量纵向对齐。环参数按钮进入同一参数表；参数目录可搜索全部 134 行，活动值与 Flash 独立显示。
- 离线测试覆盖模拟状态切换后禁止扫描、连接、发送设备命令。Windows 候选包、截图与检查日志存放在 `outputs/host-studio-v3.1.0/`。本阶段的布局样机未连接硬件，不计入曲线性能和续租的实机验收。

## v3.1.1 界面对照修订

以指定 1.0.2 发行版实际未连接窗口为设备中心基线，以同目录离线工作区截图和页面定义核对运动与全参数。复现浅色设备侧栏、灰色全局标签栏、中控卡片、设备内四页标签、紫色三图、白色控制分组和全宽参数表。原生同尺寸预览逐页比对，大缩放时折叠侧栏。沿用既有设备线程及读写门禁，保留 v3.1.0 候选用于回退。

本次实现将原扫描选择界面移入添加设备窗口。运动页保留按模式选通道、工程单位、参考线及全局 STOP；右侧环参数直接读取同 UID 的既有参数缓存。参数页使用连续滚动浏览。对照用的三个参考图来自指定目录的离线重建，另已在桌面核对 1.0.2 发行版真实启动页。原生截图、版本包和验证日志位于 `outputs/host-studio-v3.1.1/`。
