# 自由转子相电阻测量

基线d4545f19。右轮实机APP1.8.9静态通过，测阻在第一档约6.25ms触发0.5°保护，无有效阻值；原始角轨迹也变化约0.49°。核对新测阻PWM方向与现有FOC/SVM约定相反，先修正此问题。

用户确认电机自由转动：电流爬升放慢，转子稳定后再测。过流阈值7A，减少额外检查。

实施：0.5A/1A保持两档；目标升降流1A/s；每档在目标电流附近且100ms角度窗口峰峰值不超过0.1°，连续200ms后平均采样50ms。换相先降流至零并确认消退。取消0.5°绝对位移、第三相0.15A、两相和0.2A、正反向差50%硬中止。保留每次激励4s上限、既有STOP/故障保护、有效值和两档电流差。板级25s总看护覆盖最长序列，主机等待同步。

阈值为当前台架起点，不代表实机精度已验证。既有±50%判定、协议布局、Flash参数和运行PI不变。修正PWM与现有SVM一致的方向并加入真实SVM对照测试，不用相同错误极性的仿真自证。

验收：自由转动/持续振荡/断相/低阻/高阻/7A过流/无效输入离线测试；PR与镜像构建；明确授权的当前右轮台架上仅静态和相电阻，不启动独立动态检查。复核关相、参数未变、实际两档电流及阻值。产物与原始帧归outputs。回退保留已备份APP1.8.8与1.8.9，不覆盖原数据。
