# Pitch 小电流支撑实机短测 v1

## 范围与结论

2026-10-19，在已有角度及电零位标定的 Pitch 带屏幕机构上，通过用户指定的
J-Link 执行短测。许可边界为现有零位 ±0.15 rad（约 ±8.59°）、运动最大 7 A、
支撑最大 3 A、每次通电最多 10 s。其他运动命令暂停，现场可断电。
测试速度与加减速度临时限制为 5°/s、5°/s²，未改机械零位。

初始 0.5 A/s 支撑建立速度在负向停靠时赶不上卸流后的回弹，两次偏差超过 1°，
触发正常轨迹回位。改为 RAM 中的 2 A/s 后，正负方向均在短时观察内稳定，
Ui 清零、支撑冻结，不再反复回位。

| 项目 | −2° | +2° |
| --- | ---: | ---: |
| 支撑上限 | 3 A | 3 A |
| 支撑建立/卸载斜率 | 2 / 2 A/s | 2 / 2 A/s |
| 冻结支撑电流 | −1.538 A | +1.226 A |
| 冻结后观察时间 | 约4.87 s | 约4.98 s |
| 末1秒误差范围 | −0.412°～−0.391° | +0.281°～+0.308° |
| 末1秒角度峰峰值 | 0.022° | 0.027° |
| 末端速度PI积分Ui | 0 A | 0 A |
| 末端卸流交接剩余 | 0 A | 0 A |
| 采样到的最大Iq绝对值 | 4.019 A | 4.061 A |
| 单次通电时长，含STOP | 8.530 s | 8.529 s |

当前角度定点试验还观察到：无需支撑时可以保持零电流约7 s，角度总波动约0.038°。
最终两个短测末端总电流指令等于冻结支撑，未见继续积分增长。

## 镜像与保护

板上原固件为 v0.5.3、节点4、Pitch、标定标志7。先读取完整备份，确认输出关闭后，
更新为基于 v0.6.0 的支撑候选。Loader、保留区及全部参数区逐字节回读一致。
LUT、电零位、机械零位未修改。

原候选启动出现 MCU 温度故障10，采样随后可见无效值。用户明确要求本轮忽略该保护，
故只在独立台架镜像中旁路 `Temperature_Update` 的 MCU 过温判据；正式源码保持原样。
绕组热模型、相电流保护、总电流限幅和总线电压保护保留。
试验另以板端250 ms通信保活作为主机失联的停止措施，单次采集最长8.5 s并验证STOP。

第一次启动校验把采样CH4维持的MOE也作为功率关断要求，触发了过严的停机判据；
已经执行硬件关相并检查引脚高阻。后续正常STOP以三相通道关闭、六个功率引脚高阻、
mode0和Id/Iq指令为0核验，CH4继续采样允许保持MOE。

全部实际运动试验均记录STOP成功、无运行故障和控制截止期错误。
最终回读 mode0、ErrorNow0、Id/Iq指令0，三相通道关闭且功率引脚高阻。
调试连接结束时保持空闲，不启用新运动。

## 最终配置与证据

当前RAM保留支撑上限3 A、建立2 A/s、卸载2 A/s；原位置速度上限恢复为0.2 rad/s。
三个支撑参数没有写入Flash，复位后仍按正式源码默认1 A、0.5 A/s、2 A/s加载。
当前板上为临时忽略MCU过温的台架镜像，不作为正式发布固件。

证据目录：`outputs/pitch_support_bench_20261019/`。
包含各次 `curve.csv`、`result.json`、`analysis.json`、`final_state.json`、原始Flash备份、

## 结论适用范围

通过的是这台机构的 ±2° 短时停靠，不是全行程或长期热稳定验收。
算法寻找局部够用的支撑，不周期性试探减流，不能据此证明数学上的最小电流。
主机约50 Hz读取数据；所有 `telemetry_coherent` 标志均为false，表内结论依据持续数秒
的异步趋势，不声称电流分量严格同拍。实际外力手推未执行；初始慢斜率试验观察到了
回弹越过1°后自动回位，不能代替全部外扰工况验证。

后续按用户要求已将命令扩大到±0.15 rad。该轮存在位置超差和端点未到达，
不能将本页的小角度结果外推为全范围通过；详见[扩范围实测报告](2026-10-19-pitch-support-range-v1.md)。
