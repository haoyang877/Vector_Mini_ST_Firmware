## 接线规则

1. 可变状态只有一个所有者，取消跨模块可写电机全局对象；不以万能 context 或 getter/setter 替代。
2. 通信和 Watch 传递值命令与结果，不写模式、控制对象或 PWM；未实现模式明确不支持。
3. STOP/FAULT 撤销旧目标；CLEAR 不启动；维护结果携带原始身份，资源真实归还后才能结束取消。
4. APP 升级交接顺序为撤销目标、停机、确认输出关闭与维护资源释放、确认确切回复发送完成、
   写共享交接值、受控复位。发送入队不能当作发送完成。
5. Loader 与 APP 独立链接；共享目录只存跨产品稳定数据契约和目标配置，不依赖 APP 状态或 HAL。
6. 目标容量、向量入口、邮箱、参数区来自单一配置；禁止分区重叠、假定额外 Flash 或静默改写标定。
7. 第一目标为现有板卡 CAN FD；不顺带新增 UART 产品、控制算法或低侧制动行为。
