# 模式3停止抖动优化记录（2026-09-08）

本文件记录停止柔化阶段（image26～image31）。用户反馈为到达目标且仍使能时带动结构抖动；本阶段改善了停止手感，但未消除抖动。后续已采用image33连续加速度轨迹，最终结论见 [优化过程汇总](mode3_optimization_20260908.md)。

## 本阶段保留的设置

- 轨迹减速度上限30°/s²，保留更低的posDec；加速度仍为台架设定45°/s²，巡航45°/s（8 s/rev）。
- jerk过渡时间0.20 s，对应当前台架225°/s³；轨迹速度误差响应时间保持0.10 s。
- 目标前0.18°内及捕获后的摩擦卸载限30 A/s；越过目标和换向继续快速卸载。
- 位置Kp=8、Kd=2，速度Kp=0.5、Ki=1，40 Hz速度滤波和6 A原电流上限保留。
- 取消快周期配置对象重复清零，成员逐项赋值；提前跳过不需要的过渡积分计算。未改变控制器与硬件的边界。

Flash中的posDec仍为45°/s²；30°/s²上限在模式3适配器生效。本轮没有保存新Flash参数，参数区逐字节保持不变。Kd=1.5只做RAM对比，最终复位已恢复2.0。

## 实测与取舍

1. image26：柔化轨迹后，用户反馈“有减轻，但仍明显”。±20°测试保持误差最大0.154°，无超调。
2. image27：仅捕获确认后减慢卸载，用户反馈“有一点改善，仍明显”。波形显示实际先到而参考未到时，前段衰减仍较快。
3. image28：目标前衰减也限30 A/s。trial51的±20°最大保持误差0.126°，超调0.023°，无到位前持续低速停留。后续大范围检查发现+85°末段缓慢收敛，以及29次IRQ记录超过50 μs、最大50.37 μs。
4. image29：优化等价执行路径。trial53大范围复测最大8233周期（约48.43 μs），无记录超过50 μs。保持精度合格，但首个+85°仍有约0.235 s低速收敛，未解决所有临近目标的迟缓。
5. Kd1.5对比没有改善+85°末段收敛，未保存。image30将jerk过渡改0.15 s，同样没有消除低速收敛，首个+20°超调增到0.132°，未保留。

本阶段结束时恢复image29的已测二进制，归档名image31_restored_soft；AXF/HEX哈希与image29相同。当时源代码恢复为0.20 s设置，正常/HIL工程重新编译均0错误0警告。此后轨迹实现继续演进，image31不是本轮最终版本。
