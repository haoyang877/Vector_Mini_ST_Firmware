# 同型号新电机调试流程整合

## 目标

整合电气链路健康检查、逐台角度标定、摩擦辨识、速度闭环、位置闭环和 Flash 保存复位检查，形成同型号新电机的逐阶段放行流程。

## 基线与不变项

- 复用同型号、21极对及6 mΩ驱动板的硬件基线；阻尼环和目标装配作为明确的负载变量。
- 不复制不同电机的编码器 LUT、电角/机械零位、方向或摩擦结果。
- 硬件健康步骤复用现有 `motor_electrical_health_test_v1.md`；Mode 3 指标复用 `mode3_test_plan.md`。
- 本轮可作为低速候选的模式3增益为位置8/2、速度0.5/1.0；规划速度0.1 rad/s、Iq限制5 A。机械速度STOP阈值90°/s与命令规划速度分开记录。
- pitch 机构的目标行程为 −0.3～+0.9 rad。已把当前线性化编码器位置 Q15=61352 暂设为软件零位并写入 pitch AXS1 范围；它不是安装后的真实机械零位，装入目标机构后仍须重新标零并验证物理净空。

## 接受标准

新指南逐段说明操作前提、PASS/未完成处理、停止规则、个体校准边界、持久化及证据清单；明确 pitch 的 −0.3～+0.9 rad 目标范围、临时软件零位的边界，以及实际机构零位/净空确认前不得据此开展机构运动。文档链接可从 README 到达，不引入硬件动作到默认验证。

## 回滚与证据

本工作只编辑文档。若流程内容与现有专用方法冲突，以专用硬件健康指南和 Mode 3 计划为准并修正文档。产物为跟踪的流程/计划文档，以及 `outputs/` 下的 Flash 写入与复位回读证据；不提交二进制和台架日志。
