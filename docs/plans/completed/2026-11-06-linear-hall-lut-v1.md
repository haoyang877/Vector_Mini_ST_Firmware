# 线性 Hall 128 点 LUT：方案与离线验证

核对日期：2026-11-06。先记录方案并完成离线模型检查，通过后接入固件。
本次范围为方案、离线验证、实现及编译，不下载、不转动电机。
结果不能替代实机精度或 ISR 时序验收。

## 目标与基线

- 128 点误差表，复用现有标定的采样，不增加扫圈或改变 PI、100 圈及电零位流程。
- 保留两路独立幅值/偏置、现有负号方向 `-atan2(sin_cal, cos_cal)`、4 kHz 角度更新。
- 参考基线为 `the-system-refactor` 当前工作树：已有 OutputEncoder 未提交实现，
  `OutputEncoderCalib` 在观测器采样阶段保存首个约 1.01 输出圈的 256 组原码，共 2048 字节。
  不能用 HEAD 版本覆盖这些修改。现有幅值标定继续记录整个采样阶段的极值。
- 本次不切换位置环反馈来源。OutputEncoder 仍由 Hall 初始辨圈、随后累计电机角度。

## 参考角与计算链

参考是**本次新电机 LUT 校正后的连续机械角 / 减速比**。不使用电角度、速度积分、
观测器瞬时角或已依赖 Hall 定位的 `OutputEncoder_GetPos()`。

保存的 `motor_counts` 是方向处理后、尚未查电机 LUT 的连续原码。结束时令：

```text
raw16 = uint16(motor_counts)
corrected16 = Encoder_Linearize(new_motor_lut, raw16)
continuous = motor_counts + int16(corrected16 - raw16)
reference = direction * (continuous - first_continuous) * 2π / (65536 * gear_ratio)
sin_cal = clamp((sin_raw - sin_off) / sin_amp, -1, +1)
cos_cal = clamp((cos_raw - cos_off) / cos_amp, -1, +1)
hall_raw = wrap_2pi(-atan2(sin_cal, cos_cal))
hall_final = wrap_2pi(hall_raw + interpolate(lut, hall_raw))
```

电机单圈校正量按有符号差补回连续原码，不能将校正后的单圈角直接除减速比，
否则每一电机圈都会丢圈。`direction` 从整圈 Hall 展开位移与电机位移的符号关系求出。
不减电机机械零位和电零位；固定安装相位在拟合中消除，工装输出零位继续独立设置。

## 生成 128 点表

1. 原扫圈结束、功率关闭后，发布新电机 LUT，完成原有电零位步骤和 Hall 幅值/偏置结算。
2. 在可被中断抢占的前台重放 256 对原码，使用新系数计算并展开 Hall 角，计算上述参考角。
3. 对相邻样本构成的曲线做线性插值，在 **Hall 原始角域** 的 `i * 2π / 128` 节点求误差。
   不按参考角索引，不把同一桶的均值当成桶边界值，不填补未被实际样本跨过的区间。
   1.01 圈的重叠节点取均值；256 点不意味着每个固定桶必有样本，相邻点插值解决这个问题。
4. 节点误差减去 128 点平均值，去掉任意常量相位，表只补偿周期非线性。
   这定义了零均值修正约定，不等于重新设置工装零位。
5. 量化为 `int16_t[128]`，一圈对应 65536 counts，正值表示**加到** Hall 原始角。
   节点间距 512 counts（2.8125°）；误差量化步长约 0.005493°，不宣称这是实测精度。
6. 使用新 Hall LUT 重新拟合 OutputEncoder 方向/相位并执行既有辨圈残差检查。
   不能保存旧 Hall 相位配新表。依赖 Hall 关系的工装零位按现有重标定规则清除。
7. 在现有会话代次复核和提交边界一次发布、保存，STOP/故障/新会话不能提交过期候选。

运行时只做索引、两个节点读取、一次线性插值和回绕；第 127 点与第 0 点相连。
增加 `angle_raw_rad` 供观察，现有 `angle_rad` 返回校正结果。未有表时全零表等价原角，
不新增逐拍“角度无效”状态。幅值系数更新时清除旧表，禁止新系数搭配旧表。

## 核心检查与失败行为

| 边界 | 保留的检查 | 失败行为 |
| --- | --- | --- |
| 原幅值标定 | 原码 10..4086、两路半幅至少 800、有样本 | 沿用原故障位；不生成 LUT |
| LUT 结算 | 256 对样本足够、完整覆盖 128 节点、原曲线不折返、方向/减速比关系成立 | 记录覆盖或关系故障；候选表清零 |
| LUT 表 | 误差可表示；每段 `512 + correction[next] - correction[i] > 0`，包括首尾段 | 拒绝折叠表，保留原始角计算能力 |
| 输出辨圈 | 既有相位残差小于 π/2 电机 rad | 不赋予绝对辨圈成功资格 |
| 发布/Flash | 原有代次、停机保存、版本、CRC 和基础参数绑定 | 不恢复/提交不一致的参数 |

不增加重复空指针、内部数据逐层有限值检查、每拍扫描 LUT、重试、额外转动或额外计时诊断。
没有样本覆盖的节点不得自动补零并标为成功。映射单调只保证可用性，不证明实际线性度。

## 采样配对约束

目前 Hall 从 ADC 寄存器读取，电机来自 `s_rotor_encoder.directed_q15`，两者在 4 kHz
外环合并。AT32 的 Hall ADC 与相电流同触发、Hall 不过采样；但外环可被 20 kHz 快环抢占，
BSP 契约也不承诺同拍。**同一函数调用不等于硬件同时采样**。

接入时在快环完成本拍编码器更新后锁存这一拍的电机原码和两路 Hall 原码，4 kHz 角度计算
读取一致的三元组，仅在原标定阶段追加到 256 点缓存。三次赋值不含 atan2、拟合或查全表。
ADC 优先级为 0，BASEPRI 控制临界区不能阻止快环；复制 8 字节快照使用全中断短临界区，
复制后立刻恢复，不增加第二个扫圈缓存。离线中断交错测试确认解锁后抢占不会导致混拍。
ADC 通道转换及编码器采样自身存在时间偏移，离线不能证明其实际延迟；匀速时主要表现为
固定相位，变速时误差约为输出角速度乘时间差。实机复测需核对残差随速度、方向是否变化。

## 数据归属、存储及资源

- `linear_hall`：128 点表、表结果状态、原始/校正角、4 kHz 插值；不依赖 OutputEncoder。
- `output_encoder` 标定结算：已有配对样本与电机参考，负责生成 Hall 候选表及更新相位。
  复用该工作区，不另建通用标定框架，不增加 ADC 配置。
- `motor_axis`：锁存样本、原流程调度、候选对象和原子发布。
- `parameter_record`：schema14 前 2288 字节不变；新 OEN2 扩展整体包含输出轴关系、Hall
  LUT 状态和 128 点表，绑定基础 CRC 并独立 CRC。扩展 292 字节，总记录 2580 字节。
  布局为 magic(4)、base_crc(4)、原输出参数(20)、lut_status(4)、lut(256)、crc(4)。
- 兼容读 OEN1 时使用零 Hall 表并恢复原相位；无扩展沿用初始化行为。旧固件不认识 OEN2，
  不能把经过 LUT 的相位误解释成 OEN1。同步版本文档、黄金向量及读写/损坏/旧版回归。
- 新常驻 Hall 表约 256 字节，存储镜像较 OEN1 增加 260 字节，候选表和结算工作区计入
  栈预算；不新增 256 对原码数组。准确 ROM/RAM/最大栈以双板编译产物核对。

## 离线检查和后续验收

先运行 [算法模型](../../../tools/analysis/check_hall_lut_plan.py)，覆盖 256 点采样、
128 点周期表、正反方向、反向转动、电机多次跨零、起点变化、增益/偏置、相位不正交、
谐波失真、ADC 量化/噪声、缺覆盖和折叠。用未参与拟合的密集样本报告消除常量相位后的
峰值和 RMS，验证首尾连续及查表单调。仿真误差门限仅为离线验收，不成为新的固件限制。

历史 Hall RTT 文件不是本次 256 对原码快照；列缺少明确的新电机 LUT/连续原码绑定，
角度列还有 int16 饱和值，不能拿它证明 LUT 的绝对精度。当前离线结论以合成模型明确标注。

模型通过后才接入 C；后续分别验证真实 C 算法、Flash 新旧格式、中止不提交、采样交错，
执行 PR 和 AT32F456/STM32G431 编译。最后才进入另行实机验收：独立圈残差、正反方向、
不同速度、减速器回差和 20 kHz/4 kHz 时序。电机参考带有传动误差，不能消除回差/弹性。

回退只撤销本方案新增内容，不清理用户其他修改；旧固件仍能读取 schema14 基础参数。
## 执行结果

先运行模型，再接入 C；未修改 ADC 频率、PI、圈数、位置环反馈来源或运动阶段。

模型包含 144 组：3/8/12 减速比、两个安装方向、两个旋转方向、三个起点、四种失真；
每组复用 256 对拟合样本，以独立 8192 点验证，加入 ±1 ADC count 噪声。
6 项负向检查覆盖缺样、半圈、折返、错误减速比及首尾折叠。

| 理想波形加噪声 | 0.05953° | 0.09555° |
| 二/三次角度谐波 | 4.68316° | 0.10696° |
| 两路相位相差 12° | 6.07594° | 0.10987° |

理想波形上的 LUT 会拟合部分采样噪声，不能保证每个信号都提高精度。
对照过三点平滑；它降低部分噪声峰值，但增加强失真模型的 RMS，因此第一版不加入。
