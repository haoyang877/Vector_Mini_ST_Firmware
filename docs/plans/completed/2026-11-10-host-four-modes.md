# YG_MC_HOST 四种调试模式

日期：2026-11-10。范围：Rust 上位机离线实现，不操作硬件。

## 目标与基线

v2.5.0 调试页仅接入速度。复用固件现有 Type117/116/108 和 GET_CAPS，
增加 Vq 电压、Iq 力矩、速度、绝对位置选择；力矩输入由用户确认为 Iq（A）。
模式、单位、目标编码由 control 模块维护；设备线程独占命令和门禁，
曲线线程处理快照，UI 只选择和提交操作。

## 约束与验收

- 保留 UID、身份兼容、反馈时效、故障、母线和速度保护、STOP、升级及已有页面。
- 调试页模式旁提供使能/失能；使能请求所选模式 START，失能复用 STOP。
  失能无需台架勾选，状态依据新鲜 RUNNING 或 STOP/IDLE 回读。
- 模式切换先 STOP 并确认 IDLE；目标命令不启动、不切换模式。
- Vq/Iq/速度从零启动，位置启动保持当前实测位置。
- 主机调试范围：Vq ±6 V、Iq ±6 A、速度 0…300 rpm；位置单次偏移不超过 10°。
  设备自身电压、电流、热和行程约束仍生效。
- 按 GET_CAPS 声明开放能力；缺失反馈和未实现功能明确显示。
- 真实位置参考、速度参考、Iq 参考和 Vq 实测进入记录；不生成 Vq 参考反馈。
- 离线测试验证四种编码、能力/状态门禁、单位及无效值；Rust 测试、Clippy、
  GUI 多模式和窄窗口截图、仓库 quick 检查，并生成版本化 exe 和 summary.json。

## 回退及未测

回退本次 Rust 模式接入和对应文档即可，不改变固件协议、ABI、参数或镜像。
四模式实机控制未测；曲线稳定 60 Hz 和 GUI APP 升级仍需独立实机验收。

## 结果

离线实现完成，候选版本 v2.6.0。35 项 Rust 测试、Clippy（零警告）、LLD 发布构建通过。
30 张原生预览覆盖四种模式、1024 窗口、缩放、主题与已有页面；预览硬件入口均禁用。
使能/失能位于模式选择旁；右侧仅保留目标值和下发，位置模式窄窗口可直接看到目标按钮。
最终生成证据、日志、exe 哈希及仓库 quick 结果见
`outputs/host-v2.6.0-20261110/summary.json`；此前 quick 已通过，最终结果以该摘要为准。
本阶段未连接 CAN 或 J-Link，未执行运动、失能、下载、升级或参数写入。
四模式实机及稳定 60 Hz 验收继续保留为未测边界，不因离线完成关闭实机缺口。
