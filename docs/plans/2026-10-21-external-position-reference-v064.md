# v0.6.4 外部位置参考跟随候选

目标：使用实机 0x306 序列复现 Roll 连续轨迹滞后，提供明确选择的外部参考路径。
基线：v0.6.2 实机；v0.6.3 离线默认点到点控制与其相同，CAN 准入差异单独保留。
边界：只读已有文件、源码、离线回放和构建，不连接 CAN/J-Link，不写设备。

步骤：
1. 从 CAN 日志提取带时间戳的目标及实际位置/速度；读取既有 Flash 备份确定参数。
2. 用生产控制器和真实 .52/.52 rad/s²、.78 rad/s、Kp/Kd=8/3 等回放，量化内部参考与实测误差。
3. 仅在证据支持后加入默认关闭的编译选项；协议、标定、速度/电流/位置限制保持。
4. 检查停止输入、重复点、抖动、过期点和重新进入模式；保留默认算法等价回归。
5. 提交可审查补丁、回放证据、候选构建和局限；是否上机由现场任务另行决定。

验收：无每包状态重置、无无界增益或扩大限值；实际反馈保留来源，不把模拟输出称为实机结果。
回滚：关闭候选编译选项，保留 v0.6.3 冻结构建及输出；不覆盖原参数或其他本地调试文件。
