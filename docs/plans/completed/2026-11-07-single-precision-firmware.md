# 固件单精度化

基线 `d65f3c0`。目标是从 G431 普通 APP、AT32F456 普通 APP 和 G431 LoaderApp 的生产代码与最终镜像中移除双精度运算。测试端保留独立高精度参考以检查误差。

- 位置轨迹的建表和采样改用单精度；保持速度、加速度、jerk 限值、在线重规划连续性、长行程时间进展及失败时的原计划。
- CAN 遥测保持原单位、舍入、越界判定、无效哨兵和有效位。
- 使用原生 OTG 与协议回归、Keil 三目标全量构建、链接符号扫描和 PR 验收。可通过回退本次提交恢复基线实现。

## 实现与验证

- 轨迹建表使用单精度融合乘加修正各阶段时长。段边界和采样时钟都保留单精度加法的余量，跨段时按剩余时间推进。原生回归保留原有位置、速度与加速度误差门槛，覆盖 12,000 次规划、2/4 kHz 等时采样、长巡航与大步长跨段。
- 遥测和参数编码复用 binary32 尾数与整数比例的精确乘积，各自保留原有的哨兵、有效位和端点规则。不同板型对遥测边界以及 100,000 组浮点位模式作差分，参数编码完成 16,452,976 次参考比较。
- G431 普通 APP、AT32F456 普通 APP、G431 LoaderApp 的 Keil 全量构建均为零错误零警告。检查三个镜像的 MAP 符号和 AXF 反汇编，双精度运行库符号与 F64 指令均为零。逐镜像哈希保存于本工作树的 `outputs/single-precision/precision-audit.json`。
- 对比基线，三个镜像的 Keil Code 分别减少 2244、3316、2248 字节，静态 RAM 均减少 32 字节。本次为离线验证，未测量实板控制环耗时。
