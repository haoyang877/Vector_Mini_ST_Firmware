# 基于观测器的 TLE5012B 单向线性化标定

## 1. 目的

TLE5012B 的原始单圈角度可能含有磁钢偏心、安装偏心和非线性误差。当前固件用磁链观测器给出转子参考电角度，建立 `1024` 点 Q15 线性化表。

与旧实现相比，当前流程只保留一条路径：**观测器对齐后单向扫描一圈机械角度**。不再判别编码器方向，不再正反转平均，也不再保留开环注入回退流程。

## 2. 运行条件

- TLE5012B SPI2 帧连续有效；SPI 传输状态正常。
- 极对数、相电阻、Ld、Lq、磁链和标定电流已正确配置。
- 电机应空载、可自由转动。
- 编码器方向由持久化参数 `encoder_reverse` 控制；当前硬件默认反向，确保方向与电机三相正方向约定一致。切换方向后必须重新执行线性化和电零位标定。

## 3. 状态流程

| 状态 | 动作 |
| --- | --- |
| `CS_OBS_ALIGN` / `CS_OBS_ALIGN_LOOP` | d 轴对齐，保持约 1.5 s 让观测器收敛 |
| `CS_OBS_RAMP_CW` | 在约 3 s 内将开环速度升至 `2π × 20 rad/s` 电角速度 |
| `CS_OBS_SAMPLE_CW` | 以观测器解卷绕电角度作为参考，单向采集一整圈机械角度 |
| `CS_OBS_END` | 生成 1024 点 Q15 修正表，清除旧电零位/机零位并保存 |

扫描一圈所需的参考电角度为 `2π × pole_pairs`。采样由角度进度驱动而非固定采样点，原始 `raw_q15` 直接决定写入的 LUT 扇区。

## 4. LUT 与插值

TLE5012B 原始 15 位角度左移一位后转换为：

```c
raw_q15 = raw14 << 2;
```

LUT 索引和插值分数为：

```c
index = raw_q15 >> 6;    /* 0..1023 */
fraction = raw_q15 & 0x3f;
correction = lut[index] + ((lut[index + 1] - lut[index]) * fraction >> 6);
linearized_q15 = raw_q15 - correction;
```

标定期间每个 LUT 扇区累计 `raw_q15 - reference_q15`。完成后按环形连续性展开误差，再写入 `int16_t` 修正值。无效帧不会参与误差累积。

## 5. 后续电零位标定

线性化表只修正机械单圈非线性；它不等于电零位。线性化成功后，必须执行模式 15：固定 d 轴电流对齐后平均 `linearized_q15`，将结果保存到 `electrical_zero_q15`。

闭环要求线性化和电零位两个标志都有效。机械零位（模式 7）只影响位置原点。

## 6. 故障处理

SPI 超时、CRC 不匹配、磁场异常或超速都视为坏帧。连续 `100` 帧（20 kHz 下为 5 ms）坏帧后，使用编码器反馈的运行或标定模式报 `Encoder_Error`。短暂坏帧不会修改有效角度，也不会被纳入标定平均。
