# 固件配置集中管理 v1

## 目标与范围

将产品板卡、电机、应用和测试目标配置集中到 `firmware/config`；保留协议、存储格式、设备标定和芯片私有实现的既有所有权。保留全部目标原有默认数值与预包含限制，集中管理派生计算，不引入运行时自动覆盖。

## 不变边界

按用户后续要求，APP仅装载当前 schema14；schema12/13 不再受 APP 支持，旧记录不自动迁移。验收范围为STM32G4和AT32F456两个正式APP工程，Loader及台架不纳入本次行为变更。schema14 的已存 PI 装载语义、目标输出许可、控制频率、故障阈值、公式运算顺序和硬件资源保持不变。保留现有未提交工作。测试临时热参数不得转为正式默认值。

## 基线与验收

以迁移前工作树为基线；执行 PR 离线检查及可用的目标构建，核对型号矩阵、非法组合、时基、采样、schema14记录、旧版本拒绝与保护。比较构建证据与目标输出；不可用工具或基线失败须如实记录。不得连接硬件。

## 实施与回退

迁移产品配置和其调用方、Keil 路径、离线测试及当前架构文档；对混合类型或算法常量的文件按责任拆分。按原路径与本计划回退本次变更，不能还原其他未提交工作。迁移完成后记录验证结果和未覆盖风险。
