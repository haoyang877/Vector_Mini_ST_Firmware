# 生产上位机 Qt 重构 v2.0.0

基线06bde127 / v1.23.0；保留已有Keil工程改动。用户要求用Qt重构并美化布局。
使用Python/PySide6 6.8.3，复用现有CAN/烧录/标定/检测协议和持久记录，不改变固件。
原生Qt界面与独立任务调度、参数页、曲线控件按生命周期拆分；SDK继续在子进程独占，Qt主线程只处理事件和绘制。
维护优先、通信测试保留、状态每1秒刷新、UID隔离、下一台归档、停止关相及擦除确认不变。
UI目标：浅色工业工作台，固定导航与紧凑设备状态，主区可滚动、可伸缩日志，结果与输入分层。
新Qt入口替代默认打包入口。Tk版本暂用于离线对照，2.1迁移完对照测试后删除源码；不同时运行两个界面、不在新包内提供Tk入口。
验收覆盖全部页面和操作路由、识别/初装/恢复/升级、参数编辑、停止关闭、会话互斥与刷新、失败与报告、曲线有界缓存。
使用offscreen真实Qt控件、mock设备及现有协议测试；PR全档、Windows包和内嵌资源检查；离线渲染截图核对至少1280x900及1536x960。
硬件功能不自动运行，当前任务不连接台架。发布沿用APP1.8.12/Loader2.3.4冻结包；回退既有v1.23.0完整包。
