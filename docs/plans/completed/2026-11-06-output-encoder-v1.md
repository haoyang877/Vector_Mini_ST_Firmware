# 输出轴绝对位置 v1

实现 output_encoder，直驱采用电机单圈绝对角，整数减速轴使用 Hall 辨圈。位置输出上电为 [0, 2π)，运行连续跨圈，单位 rad。断电后的输出轴历史圈数不恢复。减速比读取型号配置，当前只支持正整数，不能把非整数传动当成整数处理。

核心函数按用户要求采用 Init、Locate、Update、GetPos、IsReady、CalibBegin、CalibSample、CalibEnd；另由 SetZero 设置工装机械零位。核心计算不访问硬件，不重复做空指针和参数边界检查。运行以 int64 电机计数累计位移，避免逐拍浮点累加漂移。轴层集中检查样本及标定资格，参数层集中校验 Flash。

Hall 幅值和偏置与观测器 LUT 同步标定。4 kHz 只保留首个 1.01 输出圈的 256 对原码，使用约 2 KiB 工作区。新 LUT 发布、电零位对齐完成后，在可抢占前台使用新 Hall 系数与新 LUT 求方向和相位。依据整圈位移检查方向及减速比，残差小于 π/2 电机轴 rad，为辨圈的 π 边界保留余量。100 电机圈须足够覆盖采样窗口，否则报告样本不足。机械零位在重新线性化后清除，须在工装重设。

所有标定成功完成均先关相，再保存整轴记录。STOP、故障或会话更换时不提交旧候选。失败保存故障类型，但不赋予定位资格。旧运行位置控制和 CAN 位置仍保持电机轴单位，本轮新增只读 output_encoder 反馈供后续接入。

存储采用 schema14 之后的 32 字节 OEN1 扩展，不改变前 2288 字节布局、CRC 或协议编号。扩展含减速比、方向、相位、机械零位及状态，绑定基础记录 CRC，并独立校验。旧记录仍可启动，直驱沿用已存机械零位，减速轴需要对应关系标定。旧工具改写基础参数导致绑定不匹配时不恢复扩展；旧固件可忽略扩展。详见 [OEN1](../../protocols/output_encoder_v1.md)。

验收覆盖直驱无 Hall、多个整数减速比、反向、0/2π 跨界、新 LUT 配对校正、圈数选择、工装零位、Flash 往返、损坏/旧记录/减速比变化、中止后重开，以及 AT32F456 与 STM32G431 编译。原生验证不代表实机时序或机械精度验收。后续按用户明确授权完成 PITCH 实机标定与断电恢复。回滚时旧 APP 读取 schema14 前缀，OEN1 不再使用。

2026-11-06 范围完成：双板构建、算法与存储回归、PITCH 完整联合标定及冷启动恢复通过。修正底层 2320 字节容量与首次定位过早问题。测试、参数和已知 release 阻塞见 [实机报告](../../reports/2026-11-06-output-encoder-bench-v1.md)。直驱实机、外部绝对精度、非整数减速比及历史多圈恢复不在本轮验收范围。
