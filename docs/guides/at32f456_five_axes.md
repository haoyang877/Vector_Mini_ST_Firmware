# AT32F456 五轴单镜像配置

同一个 APP 使用 schema14 节点地址和 AXS2 配置修订 2。活动角色、型号、观测器和限额在启动装载时确定，电流零偏仍在本次上电重新采集。新装配必须使用本机生成的标定。

| 节点 | 轴 | 模型 / 减速比 | 运行 / 标定上限 A | 速度 Kp / Ki 初值 | 电机轴运行速度硬上限 rad/s |
|---|---|---|---|---|---|
| 0x03 | 左轮 | HT8115-4 / 1 | 3 / 3 | 0.05 / 0.5 | 20 |
| 0x04 | 右轮 | HT8115-4 / 1 | 3 / 3 | 0.05 / 0.5 | 20 |
| 0x05 | ROLL | HT8115-4 + 2 N·m 阻尼轴 / 1 | 3 / 3 | 0.5 / 1 | 0.7854 |
| 0x06 | PITCH | YQ5708 / 8 | 3 / 1.6 | 0.048 / 0.5 | 6.2832 |
| 0x07 | YAW | YQ5708 / 8 | 3 / 1.6 | 0.048 / 0.5 | 6.2832 |

电流采用 dq 向量幅值。HT 的 Id/Iq PI 为 12.328 / 14363.36，YQ 为 0.60996 / 3226.22。HT 使用主编码器测速，YQ 使用 600 Hz 独立 PLL。观测器均以 gamma 800000 初始化并按所选型号的 R/L/磁链工作。HT 的 LUT 目标为电机轴 15 rad/s（315 电 rad/s），PITCH 为 24 rad/s（336 电 rad/s），YAW 为 30 rad/s（420 电 rad/s）。电流上限还受记录设置和热模型持续额度约束。运行速度 PI 为归一化增益，改变限流会改变对应安培数。

轮子加/减速度起点为 1 rad/s²，ROLL 为 0.7854，PITCH/YAW 为 6.2832。位置增益 Kp/Kd 起点为 ROLL 8/2、PITCH/YAW 2/0，轮子拒绝位置模式。两个 YQ 角色可采用各自核实的速度 PI 和行程。上述关节参数仅为离线起点，ROLL 的历史整定不代表已验证带阻尼启动。LUT 需要连续旋转，ROLL 的当前参数按脱开阻尼和机构的标定工装设置；限位机构须在可连续旋转工装上标定。

编码器标定使用会话独占的速度 PI，反馈来自磁链观测器。PITCH 的标定 Kp/Ki 为 0.012/0.5，YAW 为 0.048/0.5，ROLL 为 0.5/1.0，左右轮为 0.05/0.5。型号预设集中在 `motor_axis_profile.c`。交接、稳速和减速使用同一积分状态，取消或重新开始标定时清零。运行速度环由 Flash 中的运行增益独立配置。

在允许输出轴连续转动的工装上，对 PITCH 或 YAW 发起编码器 LUT 标定。在观测器闭环下按内部编码器净位移扫满电机轴 100 圈，同时用 4 kHz 外环记录两路 Hall 原始极值。只在编码器采样阶段采集 Hall，启动、构表和减速阶段不计入极值。关相停稳后发布 LUT，再完成电零位对齐，不再额外扫 Hall 圈。任一路最低低于 10、最高高于 4086 或半峰峰值小于 800 count 时，保留原系数并记录故障。正常结束后关相保存编码器结果、Hall 四个系数、`calibration_success` 和 `calibration_faults`，完成 Flash 回读后报告结果。中止扫圈不自动写 Flash。机械零位仍须在已知工装零点单独设置。

## 离线配参

在重构工作树运行，例如生成左轮记录：

    uv run python tools/run.py make_axis_record --node 0x03 --speed 2 --output left.bin

输出为一条 2288 字节记录，工具用生产代码导出并重新装载检查。默认不确认型号；完成实际配置核对后可用 --confirm-model 生成已确认记录。两种记录的编码器标志均为零。工具不下载、不擦除 Flash。YQ 需显式提供 --thermal 七项经核对的输入，依次为持续 A、峰值 A、热时间常数 s、进入/退出/跳闸/清除比。三个关节必须提供 --travel MIN MAX，没有默认行程。默认行程和速度单位为电机轴 rad、rad/s；--output-shaft 接收输出轴单位，并通过选定减速比转换一次。现有 CAN 控制和反馈仍使用电机轴单位。左右轮安装方向、双边反馈和关节绝对原点须逐台确认，当前控制使用电机端编码器。

原记录、未知节点、CRC 损坏、节点和轴角色或电机模型冲突时，产品 APP 关相且不注册整车地址。迁移须先备份原参数区、显式选择角色并生成新记录。Hall 轴联合标定完成后关相自动保存。
