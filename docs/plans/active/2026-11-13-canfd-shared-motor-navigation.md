# CAN FD 共用电机选择与页面顺序

目标：各页共享当前轴/节点/UID，J-Link识别或烧录成功自动选定；新板初装仅在烧录页
选择一次物理类型。页序为J-Link烧录、硬件测试、通信测试、角度标定、升级压测、速度控制。
协议发送移入通信测试子页，原多轴查询和批量升级保留为显式批量选项。

基线GUI1.9.3，APP1.8.4和协议、固件控制行为不变。当前分支the-system-refactor；
保留用户七份本地配置与所有outputs。页面调度按页面身份而非数字下标，防止重排误启动。
识别/烧录/扫描结果更新共用状态；换轴或失败不得沿用旧UID，运动前核对已绑定身份。
常规操作无需重复选轴，样机序号和测试序号继续独立保存。

验收：原生Tk验证六页顺序、调度、烧录/识别后跨页联动、换轴身份失效、批量功能保留，
离线检查和打包验证。UI调整不自动烧录或启动电机；回退工具不影响固件和参数。
