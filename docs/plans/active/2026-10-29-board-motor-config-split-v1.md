# 板卡与电机配置拆分 v1

## 目标与边界

将原合并资源头拆为 `board_config.h` 和 `motor_profile_config.h`，应用配置继续在 `application_config.h`；板卡、电机可独立选择，保留自定义配置入口、四种已有型号、自动派生、软件保护、电流策略、schema14 和已保存参数优先级。STM32G431 默认 STM32G4/HT8115-4；AT32F456 默认 R40/YQ-5708 并永久关相，临时热数据不得泄漏到其他电机或无约束目标。

## 验收与回退

冻结同一源码作为基线，在副本仅应用本次文件拆分、包含路径及工程入口调整后重建两套正式工程，比较 HEX 与资源。离线覆盖型号矩阵、板卡/电机独立选择与自定义输入、派生值、非法配置拒绝、目标关相、Flash 保留及 2 mΩ/6 mΩ 电流限值。运行 PR 检查；不连接硬件。预先备份旧配置和修改文件；回退仅撤销本次拆分，不覆盖其他工作区更改。

## 用户追加：合并能力检查

将逐项重复的编译检查合并为一组，继续拒绝非布尔能力、启用未支持硬件和已移除的相电压开关；保留 ADC 使用的辅助采样派生开关。补充自定义板卡能力非法值的拒绝测试，重新构建两套正式工程并对照已有冻结基线，运行完整 PR 检查。
