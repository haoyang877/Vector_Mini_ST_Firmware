# CAN FD 参数读写与速度页面调整

## 目标与基线

基线为 the-system-refactor 的 39e47b88，工具 v1.14.1 / APP v1.8.7。
实施时发现另一任务已发布工具1.15.0/APP1.8.8；合入 b6f7967d，保留硬件实测值显示
及ROLL运行PI更新，本次工具版本使用1.16.0，固件复用其已验证的1.8.8字节。
速度动作移到页面右上方，移除首次计数输入；保留 UID 持久计数和轴限速。
新增参数页，电机、电流环、速度环、位置环四组，支持读取与写入保存。

## 不变行为与边界

参数页本身不修改固件、线路 ABI、PI 默认值、保护阈值或标定数据。
复用参数服务 v1，模型/标定字段保持只读；运行中禁止参数写入。
参数写入核对 UID、活动修订号；不隐式启相、清错或重试 Flash 写入。
保存为板端整轴记录，失败保留已修改 RAM 项和未确认持久化状态，不伪报回滚。
界面使用现行共享参数目录的类型、缩放和权限，SDK 仍由单一工作进程持有。

## 实施与验收

参数事务和参数视图因协议/界面职责分离为独立模块。
覆盖版本冲突、只读拒写、单位换算、保存回读、部分写入失败、换板及停止。
检查速度页按钮布局及四组参数显示；执行 release 离线验证，构建新上位机。
保留用户工程设置；不自动烧录或启动电机。硬件读写由用户新包验证。
