# APP 模块整理实机回归 v1

基线：`7a3eb7a2`，前序离线报告见 [模块整理报告](../reports/2026-10-16-app-optimization-v1.md)。
用户授权排除通信测试，先实机验证，再继续优化电机功能模块。

## 台架与范围

只操作与本轮只读检查 UID、完整镜像和参数匹配的既有无阻尼轮电机。
沿用该台架已确认条件：21 极对、6 mΩ、轮子架空可连续转动、其他运动命令暂停、
现场可随时断电。相电流及 dq 矢量停止边界 3 A，机械速度 30 rad/s。
实际探针、UID、参数和镜像哈希只记录在 `outputs/app_module_bench_20261016/`。

本轮不执行 CAN 收发、改号或波特率测试，不故意触发 Flash 擦写/掉电故障。

## 顺序与验收

1. 只读匹配旧固件，备份全 Flash 和个体参数；停机/关相核验后安装已通过离线验证的普通镜像。
   下载后确认 Loader、保留区和参数不变，启动仍停机，无新故障。
2. 在停机下用可逆参数验证写入、恢复、复位回读与重复保存跳过。
   读取真实保存结果，比较整个参数区，不只等待固定延时。
3. mode 13 到候选验证阶段后 STOP，核验旧 LUT/零位/标志及 Flash 未改变，工作区指针清空。
   不复位再运行完整 mode 13，验证残差、候选提交、自动保存与工作区释放。
4. 完成 mode 15，使新 LUT 配套新电零位，再做低速正反向运行/STOP 检查并记录曲线。
   临时限流不超过原配置，并留出实测 3 A 停止门限余量；不清热量或绕过保护。
5. 恢复试验前运行配置并保存、复位回读。新 LUT 未完成电零位时不得作为完整标定交付；
   必须恢复原备份标定或明确停止后续运行。

任何异常模式、故障、非有限反馈、电流/速度越界均结束本轮动作并核验 STOP 和六路输出。
STOP 或紧急关相无法确认时记录硬失败，要求现场干预，不自动恢复试验。
旧镜像可在已核验关相后恢复，个体参数仅从本轮该板备份恢复。

## 后续优化准入

实测通过后再选择一处电机模式/标定生命周期的职责整理，保留控制公式、参数 ABI、
保护与调度。独立做行为对照、全量离线验证和双目标构建，另行提交；不能把前序
硬件测试当作后续修改的实测证据。本轮不据普通镜像曲线新增完整 IRQ 耗时结论。
