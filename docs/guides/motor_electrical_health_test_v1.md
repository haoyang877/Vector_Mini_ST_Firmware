# 电机驱动电气健康检查方法 v0.1

日期：2026-09-29。状态：工程方法草案，尚未完成产线方法确认。

适用对象：同型号永磁同步电机、6 mΩ 三低侧分流驱动板，包含有/无阻尼环两种装配。
本方法检查电流采样链、逆变器与三相线通路、相序/编码器方向、三相电阻。
它是功能健康检查，不能代替温度循环、寿命、绝缘耐压或 EMC 可靠性认证。
本文不下发运动命令，不新增模式号，不自动改写标定参数。

实施与验收范围见[方法设计记录](../plans/2026-09-29-motor-electrical-health-method-v1.md)。

## 1. 结果必须按项目分别给出

| 项目 | 可以证明什么 | 单靠此项不能证明什么 |
| --- | --- | --- |
| ADC 零点、独立参考电流对比 | 各通道偏置、极性、增益、线性与动态采样质量 | 电机相线标签与编码器电角零位 |
| 六方向低压开环激励 | 三相均可导通、正负响应及通道对应关系 | 每颗 MOS 的完整开关品质、大电流性能 |
| 正反向缓慢旋转矢量与原始编码器 | 绕组激励方向相对机械正方向、编码器方向和极对数一致性 | 仅靠旋向区分 ABC/BCA/CAB 循环置换 |
| 静止双电流电阻辨识 | 电阻大小、三相对称性、明显高阻或接触异常 | 所有匝间短路、绝缘缺陷、额定负载温升 |

每项结果为 `PASS / WARN / FAIL / INCONCLUSIVE / NOT_RUN`，并携带测量范围。
`INCONCLUSIVE` 表示激励不足、转子未跟随、仪器缺失或样本无效，不能当作 PASS。
发生 STOP/关相验证失败时另记 `HARD_STOP_FAILURE`，要求现场处理，不自动重试。
完整项目验收必须全部必测项 PASS；存在 WARN 或未完成项时只报告局部通过。

## 2. 测试分级和准备

### 2.1 两种执行范围

**现场快速检查**：待机零偏、低压六方向响应、mode 17 电阻估计、允许转动时的相序检查。
使用板载采样可以筛查明显异常，但没有外部电流基准时，采样绝对增益只能记为未验证。

**首次设计/维修后的完整检查**：增加四线电阻计、独立相电流测量、MOS 栅源与相节点波形、
采样窗口及温度/母线/电流覆盖。将完整检查建立的边界固化为对应硬件版本的测试配置。

### 2.2 每台必填上下文

- 板卡版本、MCU 身份、固件及参数备份哈希、分流电阻、放大倍数、ADC 基准电压。
- 电机型号、绕组接法（Y/Δ/未知）、极对数、阻尼装配、相线端子标签及线束版本。
- 电源设定电压、实际板端电压、限流值、是否可吸收回馈；记录 CC/限流状态。
- 机械安装、允许旋转角度/速度、允许电流、绕组和板卡温度、现场断电方式。
- 测试期间唯一命令源；其他上位机只读或停止发送运动命令。
- 本次仪器型号、校准状态、量程、带宽、连接位置和测量不确定度。

最大值取电机、板卡、仪器、供电、机械条件和本次授权中最严格的边界。
有阻尼环不能默认提高电流；既有 8 A 标定指令许可也不能当作长期持续电流额定值。
温度传感器缺失或读数无效时使用外部温度测量，不能凭无温度故障判定不过热。

### 2.3 仪器和夹具

- 独立、可双向测量的相电流探头，或经校准的串联基准分流器及隔离差分测量。
  母线电流表不能直接代替相电流参考。
- 四线低阻计；电机相线与驱动器完全断开后测量。接触电阻较大时普通两线万用表只作通断筛查。
- 差分/隔离示波器探头测 MOS 的 Vgs、相节点、运放输出和采样时刻。
  高侧 Vgs 以其源极为参考，不能用接地探头地夹接高侧源极或开关相节点。
- 带额定值的固定夹具用于电阻测量；相序检查时解除固定并确认运动空间。禁止手扶锁轴。
- 电流链独立确认可使用已知三相星形电阻负载或专用受限流夹具，额定电压、脉冲能量和散热须匹配。
  不默认向 ADC 引脚或运放输入直接注入信号，除非该板已有审查过的注入接口。

## 3. 执行顺序和停止条件

```text
身份/备份/停机确认
  → T0 断电检查与线间电阻
  → T1 采样零偏、极性和独立参考增益
  → T2 低压六方向功率通路
  → T3 三相电阻辨识
  → T4 低速正反向相序/编码器方向
  → T5 采样窗口、MOS 波形与工况覆盖（完整检查）
  → STOP、确认关相、保存报告
  → 另行进入 mode 13/15 和闭环验证
```

T1 的带电参考电流可由专用负载夹具产生，或与 T2 的低压试验联合采集。
若尚未验证采样增益，保护必须依靠独立电源限流、外部电流参考及已验证的硬件保护，
不能让待测电流环自己给自己作安全背书。T3 的闭环注流仅在 T1/T2 通过后允许。

所有带电步骤都设置最大电压、实测电流、速度、位移、单点时长、总时长和温升/能量预算。
异常电流、母线跌出窗口、电源进入 CC、编码器离线、超速、非预期模式或采样超时立即停机。
主机轮询只能提供附加监测，毫秒级过流和失联停机须由经验证的 MCU/硬件保护执行。
mode 12 并不通过 `current_limit` 自动钳位输出电流；设置该变量不构成电压开环限流。

每步先电压归零再 STOP；确认模式退出、相使能全部关断、引脚进入设计停机态，才进入下一步。
MOE 的含义取决于固件：当前分支 mode 0 可保留 MOE 供 ADC 触发，不能仅凭 MOE=1 判失败。
J-Link 断开/重连可能改变 CPU 运行状态；禁止连接后无条件 GO，禁止在 PWM 活动时停核取样。

## 4. T0：断电通路和绕组基线

1. 断电、验证母线放电，断开电机与逆变器，记录接线标签 A/B/C ↔ U/V/W。
2. 检查端子压接、松动、焊接、线束破损；不要在带电时拔插或改变相序。
3. 四线测量 U–V、V–W、W–U 的线间电阻，各测三次，记录温度及重复性。
4. 有条件时分别在电机端和线束远端测量，差值用于定位线束/接插件高阻。
5. 绝缘筛查遵循电机/驱动器规定；耐压或绝缘电阻测试须将驱动板和编码器电子电路隔离。

浮置星形绕组且第三端开路时：

```text
Ruv = Ru + Rv
Rvw = Rv + Rw
Rwu = Rw + Ru
Ru = (Ruv + Rwu - Rvw) / 2
Rv = (Ruv + Rvw - Rwu) / 2
Rw = (Rvw + Rwu - Ruv) / 2
```

平衡 Y 接法中线间电阻约为单相的两倍。平衡 Δ 接法中线间电阻为单支路的 2/3；
`R线间/2` 只是等效星形相电阻，不能声称是实际 Δ 绕组支路电阻。
接法未知时保留线间结果，不臆测实际绕组值。

温度比较使用电机材料对应系数；对铜绕组可先用近似值 α20=0.00393/K：
`R20 = RT / [1 + α20 × (T − 20°C)]`。未知导体或温度不可信时不作该修正。

## 5. T1：电流采样链独立确认

### 5.1 必须同时保存原始量和控制量

保存原始 ADC A/B/C、各通道零偏、采样有效标志、重构后的 Ia/Ib/Ic、母线电压、
采样对应的 PWM 扇区/CCR、样本序号和时间戳。
重构强制得到的 `Ia+Ib+Ic=0` 不是电流采样正确的证据。

当前板换算约为：

```text
Iraw,k = −(ADCk − Offsetk) × Vref / (4095 × 0.006 Ω × 10)
Vref=3.3 V 时约 0.013431 A/count
```

比例与负号须以实物电路和本机镜像为准。三个低侧 ADC rank 并非同时采样；
只有三个窗口都有效、且电流变化足够慢或已完成时间对齐时，才评价原始三相和。

正式方法由 MCU 快环发布同一采样周期的完整快照，携带序号、有效位和丢帧数。
J-Link 原型使用对齐 32 位读取动态 float；这保证单字完整，不保证整个结构同拍。
主机 50 Hz 左右记录只能检查慢变稳态；它不能证明 20 kHz 电流环噪声或开关尖峰正常。

### 5.2 零点与噪声

依次检查母线关闭/功率级禁止、母线上电但禁止 PWM、确认等占空比零矢量 PWM。
每种状态稳定后采集至少 0.5 s，建议 MCU 原始记录率 5 kHz 或完整 20 kHz；
必须报告实际采样率、滤波、窗口和丢帧数，不能比较不同带宽下的“噪声”。

记录各相均值、标准差、峰峰值及 PWM 开启前后均值漂移。
先保存原零偏，禁止先重新校零再宣称原零偏合格。PWM 相关偏置与静态零偏分别报告。
ADC 轨到轨、异常恒码或大偏置 FAIL；完全平稳时少量恒码本身不证明 ADC 卡死，需受控激励验证。

### 5.3 极性、增益和线性

在已知电流通路上，对每相采集 0、±0.5、±1、±2 A（实际点由台架上限裁剪），
同步记录外部 `Iref` 与板上 `Iraw`，稳态窗口拟合 `Iraw = g × Iref + b`。
记录增益 g、偏置 b、最大残差、正负对称性及不确定度。
相电流参考需与低侧有效采样时刻/同一物理量匹配，不能把开关周期平均电流与瞬时低侧样本直接相减。

没有外部参考时，仅能评价通道相对一致性；三路同时错误相同比例仍可通过三相平衡检查。
PWM 共模变化可能在电流放大器输出引入毛刺和建立延迟，必须与稳定直流的增益误差分开分析。
这一分离原则也见 [TI SBOA160](https://www.ti.com/document-viewer/lit/html/SBOA160)。

## 6. T2：六方向开环检查功率级和三相线

使用现有 mode 12 电压开环，固定电角度，先零矢量，再 0.5→1→2→4 V 分级。
这些值来自本次约 2.15 Ω 电机的低压试验，不得直接套用低阻电机；
新型号从更低电压开始，以实测电流及独立保护决定下一档。
本型低压筛查建议 3 A 实测停止门限，每级约 100 ms 建立、300 ms 稳态记录、100 ms 停机间隔。
建立时间至少覆盖实际 L/R 和采样链稳定时间，固定时间到达仍不稳定则该点无效。

在每个允许电压档依次施加下表六个方向，电流比例是平衡绕组静止时的理想模式：

| 电角度 | Ia/I | Ib/I | Ic/I | 检查重点 |
| --- | ---: | ---: | ---: | --- |
| 0° | +1 | −0.5 | −0.5 | A 正向、B/C 回流 |
| 60° | +0.5 | +0.5 | −1 | C 负向 |
| 120° | −0.5 | +1 | −0.5 | B 正向 |
| 180° | −1 | +0.5 | +0.5 | A 负向 |
| 240° | −0.5 | −0.5 | +1 | C 正向 |
| 300° | +0.5 | −1 | +0.5 | B 负向 |

记录引脚复用、PWM 相使能、CCR，以及三路原始和重构电流；禁止直接手工打开单颗 MOS。
以相反方向成对消除固定偏置，例如 `AA(V)=[Ia(0°)−Ia(180°)]/2`，B/C 类推。
比较三相幅值极差/平均值、正负不对称、增量电压–电流斜率、原始 KCL 残差和响应重复性。

随后可用 2 V、2 rad/s **电角速度**缓慢扫一个以上电周期，拟合三相电流幅值、偏置与相位。
相差约 120°且随电压单调变化，支持通路和采样映射正常；电机可能因阻尼不转。
试验电压不足以克服负载时不能据此评价机械旋向或标定功能。

若要确认每颗 MOS，增加示波器波形：各相上下管 Vgs、相节点、驱动电源、开关重叠/死区。
按实际栅极驱动器和 MOS 的规格判定，不能把 TIM1 寄存器使能直接写成“MOS 已验收”。
当前六方向试验也不是每颗 MOS 完全独立的隔离测试，异常通常需要外部测量进一步定位。

## 7. T3：三相电阻检查

### 7.1 推荐复用 mode 17

当前分支已有 `PhaseResistance` 纯算法核心与 FOC 适配层，mode 17 无需编码器零位。
默认六方向、每方向两档电流 1/2 A，上限 3 A；每点 200 ms 斜坡、200 ms 稳定、
100 ms 采样、100 ms 间隔，超时配置 3000 ms。执行前仍须核对实际镜像及限流。

记录每个方向的 I1/I2、V1/V2、拟合斜率、截距、重复性，以及最终 Ra/Rb/Rc。
电压应与形成该电流样本的上一 PWM 周期匹配；当前适配层使用上一调制量和母线电压估计输出。
这是逆变器模型估算，不是相端实测电压；MOS 导通、电缆、死区和器件温漂都会影响结果。
路径补偿只能采用经夹具确认的值，不能调补偿来强行让结果“合格”。

核心原理：在转子静止、电流稳定的窗口，`U ≈ R·I + Uoffset`；
两点斜率 `(U2−U1)/(I2−I1)` 降低固定压降影响，正反向配对降低方向相关偏差。
斜率对应三个方向的等效值 SA/SB/SC；按现有算法转换：

```text
Ra = (5·SA − SB − SC)/3 − Rpath
Rb = (5·SB − SA − SC)/3 − Rpath
Rc = (5·SC − SA − SB)/3 − Rpath
```

转换依据当前三线电流矢量模型，近似恒定电流方向；明显不平衡、较大 Iq、磁饱和或转子运动时，
不要把计算结果当作精密独立相阻。使用 T0 四线电阻复核，Δ 接法报告等效星形值。
单纯 mode 12 的 `Vcmd/Ia` 不等同上述独立相阻算法，电压估计差异也必须保留。

### 7.2 有效性与比较

- 采样窗口转子应静止；移动导致反电动势或电流未稳则丢弃该点，重新稳定有明确超时。
- 达不到目标、触发电压饱和、ΔI 不足、母线限流、返回负阻或模型残差过大：无效，不保存结果。
- 同温度/同线束下至少重复三次，报告单相重复性和与四线基准的偏差。
- `不平衡率 = (max(Ra,Rb,Rc) − min(Ra,Rb,Rc)) / mean(Ra,Rb,Rc) × 100%`。
- 三相都正常且绝对值符合型号温度范围才通过；“三相一样”不能排除三相一起接错型号。
- DC 电阻正常不能排除匝间短路；怀疑时增加电感/阻抗、反电动势对称性及专业绕组测试。

线间量与相量口径需明确记录；[TI MCF8316A Tuning Guide 第 3.6 节](https://www.ti.com/lit/ug/sllu335a/sllu335a.pdf)
也要求明确电机参数的线间测量与驱动器使用口径。其芯片算法数值不能直接移植到本项目。

## 8. T4：相序、机械方向及编码器方向

### 8.1 先定义“正确”

给定观察方向、机械正方向、A/B/C 板端标签、U/V/W 电机标签和原始编码器计数增减方向。
三相对称电机的六种接线排列中，循环置换可能保持旋向，仅改变电角零位；
交换任意两相会反转旋转磁场方向。**旋向正确不等于线束标签完全对应。**
完整标签映射需由线束通断检查/已知参考装配确认，不能由一次正反转推断全部排列。

### 8.2 正反向低速试验

1. T1/T2/T3 通过，解除锁轴，确认允许运动范围。使用原始编码器单圈角展开，
   不依赖旧 LUT、旧 electrical zero 或 `reverse` 后的角度来证明当前接线正确。
2. 缓慢建立固定电压矢量，确认转子能够跟随；从小幅值增加，仅到已确认电流/热预算内。
   未克服阻尼时记 `INCONCLUSIVE_STALLED`，不通过加速掩盖静摩擦，不无限增流。
3. 电角速度从约 0.5 rad/s 开始，条件允许时至 2 rad/s；连续至少两个电周期，
   留下稳定窗口，再停机，反向重复。21 极对时场指令机械速度约为 0.024～0.095 rad/s。
4. 记录实际机械方向、展开角位移、跟随斜率与电流。同步跟随时应满足
   `dθraw/dθe ≈ s/p`，p 为极对数，s 为相序与原始编码器方向组合的符号。
5. 正反转符号均与定义相符，稳态斜率绝对值接近 1/p，且重复一致，才判方向关系通过。
   启停拉齐的固定角位移不用于斜率；原地摆动、失步或只动一次不是同步跟随。

本方法暂以斜率比值 `|p·dθraw/dθe|` 在 0.9～1.1 作筛查起点，必须结合负载、展开误差和样本长度确认。
无法安全产生实际旋转时保留未完成；完整台架可改用外部低速拖动及相间反电动势/原始编码器对比，
但这也需要已定义的物理方向和线束基准。

发现反向先记录证据并判定不符；不要自动交换相线或翻转软件方向使测试“变绿”。
实际变更相线、方向或编码器/磁铁装配后，旧电角零位和关联标定均须重新验证/标定。
完整顺序是硬件检查后再执行 mode 13、mode 15，机械零位依据装配单独建立。

## 9. T5：采样窗口、温度及带载覆盖

低调制度通过只是第一层证据。首次方法确认至少覆盖实际工作区间内的：

- 母线低/标称/高值，冷态/热态，正负电流，小/中/最大已授权测试电流。
- 六个扇区及边界、PWM 占空比低/中/高区间，含调制上限附近；不能为覆盖而超出安全范围。
- 电流放大器输出建立时间、ADC 实际采样窗口、PWM 边沿和完整序列结束事件。
- 板载采样与独立电流参考的幅相误差、毛刺、饱和、丢帧和有效窗口占比。

当前为低侧三分流、单 ADC 顺序 4×过采样，必须确认所用每相的全部子样本处于有效窗口。
只有两相有效时按规则重构并标注来源；不足两相有效时不得靠 KCL 生成“正常”数据。
见[项目采样窗口说明](current_oversampling.md)；
[ST UM1052 的三分流电流采样章节](https://www.st.com/resource/en/user_manual/um1052-stm32f-pmsm-singledual-foc-sdk-v43-stmicroelectronics.pdf)
可作为同步 PWM/ADC 的参考，但不能照搬其双 ADC 时序到本板单 ADC。

产线阈值冻结前，用多块确认良品、已知偏置/增益误差、断路线束和串联已知电阻夹具验证检出能力。
所有故障注入在断电下连接，并限制能量；不通过实际短接 MOS、带电拔相线或破坏绕组制造故障。
用模拟数据覆盖危险故障，物理夹具只覆盖审查过的受控故障。
完整报告需给出覆盖数量、温度范围、重复性、误报和漏检情况，单台正常样本不足以冻结产线标准。

## 10. 工程初始判据（不是厂家额定/已验证产线标准）

下表适用于本型 6 mΩ、约 2.15 Ω 电机的低压方法起点。
任何跨型号/量程使用均须重新建立测量误差预算；测量不确定度接近阈值时记 INCONCLUSIVE。

| 指标 | 建议初始判据 | 说明 |
| --- | --- | --- |
| 停机零偏均值 | 每相绝对值 ≤0.05 A | 先保存原偏置；与噪声分开 |
| PWM 开启偏置变化 | ≤0.05 A 初判正常；0.05～0.10 A WARN；>0.10 A 待定位 | 不能自动重校零覆盖异常 |
| 稳态噪声 σ | ≤0.02 A，限已声明采样率/带宽 | 不用主机低速抽样声称全带宽通过 |
| 外部参考对比误差 | 每点 ≤max(0.05 A, 参考电流绝对值×3%) | 另报增益/偏置，不含参考仪器误差则不得宣称绝对精度 |
| 三相幅值极差/平均值 | ≤3% PASS；3～5% WARN；>5% FAIL | 要求有效激励、无饱和、温度可比 |
| 正反对称偏差 | 偏置消除后幅值差/均值 ≤5% | 超标需区分传感器、驱动和绕组 |
| 原始三相和 | 有效慢变窗口 RMS ≤max(0.10 A, 测试幅值×5%) | 仅作残差诊断，不作独立增益验收 |
| 电流矢量相位间隔 | 约 120°，暂取 ±5° | 相位误差须扣除采样时间差 |
| 电阻三相不平衡率 | ≤3% PASS；3～5% WARN；>5% FAIL | 与当前 mode 17 的 3%/5% 门限相符 |
| 单相电阻三次重复极差/均值 | ≤2% | 先校正温度和接触变化 |
| 电阻绝对值 | 优先型号/良品温度基准；暂无规格时 ±10% 仅筛查 | 不以本次 2.15 Ω 值替代所有电机规格 |
| 运动方向/标签 | 与装配定义一致 | 缺少方向或线束参考为未完成 |
| 输出关断 | 模式退出、相使能及停机引脚状态均验证 | 失败为 HARD_STOP_FAILURE |

这些阈值是方法设计建议，不是将单次台架结果反推成的保证值。

## 11. 故障定位表

| 观察 | 优先排查 | 独立确认方式 |
| --- | --- | --- |
| 一相原始 ADC 不随激励变，外部电流正常 | 放大器、ADC 引脚/rank、采样时刻或通道软件映射 | 运放输出与外部电流同步测量 |
| 一相内外测电流均接近零，另两相相反 | 相线开路、接触不良或该桥臂不能导通 | 断电线束测阻、Vgs 与相节点波形 |
| 三相只在某方向失真/单向导通 | 上/下管驱动、MOS、续流路径或测量极性问题 | 正反六矢量、对应上下管波形 |
| 三相幅值同倍数偏大/偏小 | 分流值、放大倍数、ADC 基准/换算错误；也可能电机型号不同 | 外部电流和四线电阻基准 |
| 原始和异常，重构后三相和完美为零 | 重构掩盖原始偏置/采样窗口故障 | 有效位与原始 ADC，对比电流探头 |
| 低压正常，高调制度尖峰 | 有效采样窗口不足、运放恢复、重构扇区错配 | PWM/ADC/运放时序同步示波器 |
| 电阻高且插接/位置变化时跳变 | 接触高阻、线束压接、焊点 | 电机端与线束端四线测量、断电夹具重复性 |
| 电阻三相一起随时间上升 | 绕组升温或电流比例漂移 | 温度和独立参考电流 |
| 三相通路正常但转子不跟随 | 阻尼/堵转、启动场加速过快、供电限流、极对数/方向定义 | 低速场试验、机械检查、板端电压/CC 状态 |
| 正转场对应机械反向 | 相序/编码器原始方向与装配约定不符 | 已知机械方向、线束映射、原始计数 |

表中是排查优先级，不是仅凭单项观测即可唯一归因。

## 12. 后续固件/工具功能如何落地

复用 mode 0、mode 12、mode 17 及现有平台采样/关相接口，不先新增一个包办所有动作的大模式。
由专用台架工具串行编排 T0～T5；默认 verify/CI 只运行纯计算或回放，不连接硬件。
需要新增的关键能力是可追溯的原始采样快照、板端超时/失联停机、阶段结果及独立有效标志，
而不是复用“标定有效”位表示硬件健康。

算法层负责拟合、阈值和状态汇总；平台层负责 PWM/ADC 时序及关相证据；应用层拥有状态机。
不得将新的 HAL 寄存器访问塞进通用电机算法层，也不得让主机零散改 ModeNow 成为量产接口。
命令/参数 ABI 如有新增，另建版本文档、黄金向量和兼容性测试；本文未分配新的 CAN 命令或模式号。

测试结束恢复临时参数，默认不写 Flash。需要保存补偿或改变方向时另行审查并重标定；
参数保存应验证完整记录和 CRC，保留修改前后备份。
