# INIT独占的统一电流偏置校正 v2

## 目标与基线

用户要求将偏置校正从正常电流采样中独立，三相和硬件母线电流一起校正，
并且仅在初始化状态执行。基线为本轮工作区，文件副本位于
`outputs/current-offset-init-20261030/before/`；不覆盖其它未提交修改。

## 实现

- 正常测量直接位于快环的校正完成分支，读取三相及母线物理量并更新测量对象，
  不累计、不执行偏置校正；按用户要求删除单调用封装`sample_currents`。
- `MotorCurrentOffsets_Calibrate`是独立、非阻塞的校正功能：共用2048个20kHz快拍，
  在最后一拍计算均值，复核关相和控制禁用后一次发布三相与母线偏置。
- APP仅在`MOTOR_STATE_INIT`调用该功能；监督任务不再计算或发布偏置。
  完成与失败均冻结本次校正，离开INIT后不采集零偏，不自动重试。
- 三相按硬件累加域统计，母线按12位单次域统计，分别换算为等效12位偏置。
  启用母线通道时缺失或非法数据会阻止全部偏置发布；无该硬件的板卡显式跳过。
- 原始值须位于ADC量程，均值保持1948～2148 counts边界；三相范围不放宽，
  母线采用相同零点范围。保留首个故障，不自动启相、保存或改变协议。

这次有意改变完成时点：由2048拍后等待监督提交，改为第2048快拍统一提交。
102.4ms采样窗口及自检103ms额外等待保持。运行校正状态由20字节增为24字节，
协议、参数记录及Flash ABI不变。
