# 编码器标定核心简化 v1

## 目标与基线

按本次需求保留核心标定功能，并通过结构体聚合业务状态。
工作位置为 `the-system-refactor` 现有工作树，起点提交为
`6c355b963c2583a01850db530124889f1a8a959e`，包含已有未提交修改。
改动前两种板卡与阻尼环开关的四组原生标定测试通过。
相关文件快照与日志保存在 `outputs/encoder-calibration-core-20261104/baseline/`。

## 核心流程与决策

1. 复用无感启动完成对齐和闭环建立，期间每拍清理四个采样 bin。
2. 稳速后记录观测器电位置与编码器角，作为相对采样参考。
3. 正向采集十圈合格行程，按编码器角累计角差。
4. 两遍构表，每拍最多处理八个 bin。第一遍求均值、环形展开并累计总和，
   第二遍统一平移到有符号范围并写候选表。
5. 完成减速与卸流，由生命周期关相，前台发布候选表。
6. 电零位任务独立执行电流斜坡、保持和环形角均值。

删除对齐原点均值、再次寻找原点、额外一圈残差验收及其 RMS/峰值阈值。
每 bin 采样要求改为非空。保留范围、参考位置连续性和分拍工作量条件。
相对参考带来的 LUT 整体常量由随后执行的电零位标定吸收。
删除无感启动已经执行的模型参数检查，以及电零位中已由入口保证的电流正值判断。
启动超时统一从会话开始累计，8 s 包含无感对齐过程。

控制对象由 `EncoderCalibrationControl` 绑定，采样参考和累计行程、构表进度、
停止状态和电零位均值各由业务结构体管理。各阶段互斥的数据继续复用联合体。

## 接口与验收

继续使用六个任务接口、6144 B 工作区和现有参数存储布局。
保留候选发布、取消、故障释放、两段停止以及标定后清除旧零位的生命周期契约。
本次属于有意缩减功能，阶段序列和标定结果的整体偏移会变化。

验证包括环形角均值、合成非线性误差、多起点与极对数、空 bin、范围边界、
两遍构表工作量、完整任务入口到发布、停止和取消重入，并运行仓库 PR 检查。
编译结果不能代替实机标定精度、快环耗时及物理关相验证。
