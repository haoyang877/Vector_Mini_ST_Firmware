# 决策 0002：编码器速度估计迁移到 20 kHz 快路径 PLL

日期：2026-09-23。状态：**已实施**（PR 档全绿；固件台架功能验证通过；转速环增益整定与带宽终验收待办）。

## 当前实现核对（2026-10-21）

20kHz PLL的速度所有权决策仍有效；当前默认ωn=90Hz、ζ=0.707，来源为
`firmware/motor/feedback/angle_feedback.h`。下文300Hz与带宽/纹波结果保留其原试验基线，
不能作为当前默认或所有轴的验收结论。当前传感器帧错误/传感器故障由平台端口映射到反馈健康，
更细的传感器诊断能力需按实际driver核对，不能从历史未决项推断已经覆盖全部STAT位。

## 背景

原速度估计为 2 kHz tick 上的 16 点割线（8 ms 窗口，群延迟 ≈4.0 ms），且速度状态由
2 kHz 慢估计独占写。量化复核（计划 §2.3）表明：16 点增量求和的割线噪声 ∝ 1/N，已是低噪声
估计器；用 2 阶 IIR 在等噪声下**不降延迟**（等延迟下更差），故被否决。改用 20 kHz 二阶
角度跟踪观测器（PLL）。

## 决定

1. 速度估计改为 **20 kHz 快路径二阶角度跟踪观测器（PLL）**；**速度状态所有权由 2 kHz tick
   迁移到 20 kHz 快路径**（`Encoder_UpdateVelocityPll`）。这是对既有“快路径只置标志”约定的
   有意变更。
2. 观测器**只产出速度**：不写 `theta_elec`/`theta_mech`，不触及 LUT/电零位/机械零位等标定量。
3. 参数：`ωn=300 Hz`（**带宽优先**生产默认；等噪声点约 90 Hz，可下调）、`ζ=0.707`、
   输出限幅 ±2000 rad/s、软死区 0.05 rad/s。
4. 快路径消费 `velocity_restart_requested`（以当前角重建观测器）；2 kHz 慢估计不再计算速度，
   只保留多圈/机械角。

## 影响（相对改造前）

| 项 | 变化 |
| --- | --- |
| 估计群延迟 | 4.00 ms → ~0.75 ms（ωn=300） |
| 估计器相位滞后 @40 Hz | −57.6° → −15.4°（ωn=300） |
| 延迟受限带宽 @PM45 | ~29 Hz → ~108 Hz（ωn=300） |
| 速度噪声 | ωn=300 约 6× 于 ωn=90 点（∝ωn^1.5）；ωn=90 约等于旧割线 |
| RAM / Code | 净减（移除 64 B 滑窗与计数） |
| 行为变化 | 速度动态更快；死区 0.096→0.05 rad/s；无窗口填充期 |

## 未决

### 2026-09-30 轮电机低纹波候选（全产品默认未定版）

角度标定后的轮电机验收中，300 Hz 候选在 60 rpm 的均值为 60.072 rpm，但瞬时速度
标准差 3.076 rpm，超过 3 rpm 门槛；120 rpm 的瞬时速度标准差 3.504 rpm。
角度位移差分较平稳，但低频非原子采样不能单独区分估计噪声与真实机械纹波。
结合此前同台架 90/150/300 Hz 对比，本轮 V4 候选自然频率改为 90 Hz，使用已有 PLL，不增加
滤波状态或参数 ABI。旧的 300 Hz 高频性能结论不沿用到此默认配置。
此变更作用于所有使用该编码器测速的模式，其他轴和带载高带宽必须另行回归。
离线验证仍要求恒速正反向跟踪、重启、限幅和低于旧割线的延迟，新增默认噪声不超过
旧割线 1.2 倍的检查。实测 90 Hz/6 A 的 30 rpm 标准差 3.486 rpm，仍失败；
仅 90 Hz/临时 3 A 的正反 30/60/120 rpm 六档通过。限流通过归一化 PI 的输出缩放同时
改变等效增益，不是只改变饱和上限。试验后活动值恢复 6 A，3 A 未落盘。
详见[本轮报告](../../reports/2026-09/angle_speed_acceptance_20260930.md)。
不得将该结果视作 6 A 配置或全产品默认定版，也不证明高频机械纹波根因已经排除。

- 转速环 PI 增益需重新整定（当前 Kp=0.5/Ki=2.0 下裸速度环欠阻尼振荡）；整定后做最终带宽验收。
- `ωn` 默认值可在测得真实（相关）噪声后上调。
- TLE5012B `STAT` 报错误/角度无效标志，固件未监控，待跟进。
