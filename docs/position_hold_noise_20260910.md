## 代码路径

原模式3在HOLD内冻结速度积分，但保持两条速度比例反馈路径：

```text
speed_command = position_kp * position_error - position_kd * speed_feedback
Iq = speed_kp * current_limit * (speed_command - speed_feedback) + integral
```

在未限幅、无前馈时，速度扰动到Iq的增益为
`-speed_kp * current_limit * (1 + position_kd)`。
例如 `speed_kp=0.5, current_limit=6 A, position_kd=2` 时，增益为
−9 A/(rad/s)，0.00428 rad/s的测速波动可贡献约38.5 mA的Iq波动。
这里的6 A仅为公式示例，不能代替当前实机限流参数确认。

`FOC_Current()`的PI使用原始 `FOC->Iq`；`Iq_filt`是另行计算的观测量。
因此单独改变 `Iq_filt` 的显示滤波不能解决上述指令波动。

架构检查：现有旧FOC适配层仍依赖硬件头文件，尚未完全达到AGENTS.md目标分层。
本次控制修改留在不依赖Vendor/BSP的 `position_cascade.c`，状态归现有模块私有state，
未新增跨模块全局变量、硬件调用、动态分配或阻塞操作。

## 候选修复与边界

`POSITION_SERVO_HOLD_VELOCITY_FILTER_HZ` 默认10 Hz，是待实机验证的软件调节值，
并非硬件辨识参数。设为0可关闭新增滤波进行A/B比较。

- 原窗口测速及40 Hz基础低通保留，HOLD进入/退出和摩擦判断继续用基础反馈。
- 仅在已进入HOLD后，额外低通同时作用于位置阻尼项和速度PI的反馈项。
- 进入HOLD的首个更新直接对齐基础速度，避免切入滤波造成额外跳变。
- 退出HOLD或收到新目标时，在下一个控制更新立即恢复基础反馈。
- 位置误差不设死区，位置比例增益不变；承载积分、原限流和抗积分饱和逻辑保留。
- 滤波系数随控制周期配置缓存，HOLD更新新增固定次数浮点运算；不在快环中计算频谱。
- `data5`输出实际控制速度，HOLD内包含新增滤波；HOLD退出判断使用滤波之前的速度。

新增低通引入阻尼反馈相位滞后。保留静态位置比例增益不等于动态刚度或稳定裕度不变。
超过原速度/位置退出阈值时可以退出HOLD，但阈值内的低幅振荡仍需要实机验证。
不通过放宽定位窗口、清零承载电流或降低保护能力换取静音。

## 实机A/B验收

±0.3°沿用当前轴验收尺度，不代表用户已认可该精度，也不是新增控制死区。

现有保持策略、摩擦及起始状态可能共同影响最终停点，尚未通过力矩测量分离其贡献。
不能仅用本轮数据把稳态误差归因于滤波器，也不能认定5 Hz提升定位精度。

### 重启首帧圈数修正

安装支持在线滤波的HIL镜像后，原地测试在ARM前被位置检查拒绝：读数约−333.97°，
相比下载前约+26°差一整圈。原因是编码器启动首帧直接以单圈读数减机械零点，
当两者跨越单圈码值边界时，未选取该有界关节的正确圈数分支。
该问题在未使能状态暴露，失败记录 `roll_AB_5rounds_3s` 无采样、正常STOP，未运动。

### Roll运动与定位验证

用户要求验证调整滤波后的运动和定位。沿用同一修复启动圈数的镜像、roll增益
8/2/0.5/1、电流上限6 A、主机停止阈值4 A及45°/s轨迹速度上限；不改Flash参数。

执行四轮：

- `roll_position_B_1`、`roll_position_C_1`：26、26.1、26、25.9、26、27、26、25、26、31、26、21、26°，每个目标6秒。
- `roll_motion_B_1`、`roll_motion_C_1`：26、27、26、0、20、−20、0°，每个目标8秒。

每轮第一个目标用作准备段，不纳入下表；末2秒统计稳态误差。
“到位时间”指进入并在本段余下时间保持±0.3°，是当前配置的验收尺度，
并不代表已经停止所有微动。时间依据主机/RTT锚点，存在批量接收误差。

| 指标 | B：10 Hz | C：5 Hz |
| --- | ---: | ---: |
| 1°小幅轮到位时间 | 0.394–0.642 s | 0.361–0.557 s |
| 5°小幅轮到位时间 | 0.785–0.832 s | 0.777–0.829 s |
| 20°跨零轮到位时间 | 1.549–1.556 s | 1.551–1.553 s |
| +20°至−20°到位时间 | 2.456 s | 2.452 s |
| 所有比较段末2秒最大绝对误差 | 0.226° | 0.220° |
| 所有比较段最大瞬时超调 | 0.363° | 0.130° |
| Iq反馈采样峰值 | 3.233 A | 3.299 A |

所有比较段的末2秒HOLD占比100%，无无效/丢帧/限幅标志。
但是±0.1°目标没有被逐次跟随：B在这些目标段基本停在26.0266°，C基本停在26.0870°。
这些目标一开始就落在±0.3°范围，统计到位时间为0，不能解释为微小定位性能优秀。

B第一轮27°→26°返回时，位置先停留在约26.24°，随后保持积分继续积累，
约3.5秒后开始缓慢靠近目标，末2秒峰峰变化达0.176°。
该数值包含缓慢位置变化，不能全部解释为高频振动。随后的26°→25°段出现0.363°瞬时超调，
最终仍稳定在当前到位范围内。B第二轮重复27°→26°时没有重复先前缓慢移动现象，
末2秒停在约26.19°、位置峰峰值0.044°。这些记录说明小幅停点受运行历史影响，
不能把一次B/C停点或超调差异简单归因于滤波截止频率。

在本次5°及跨零往返中，两种截止频率的到位时间接近，没有证据表明5 Hz提升运动性能。
结合听感结果继续推荐10 Hz基线，但0.1°指令跟随及小步一致性尚未达到精细定位要求。
下一步应针对HOLD窗口/保持积分与摩擦的交互优化，而不是仅继续下调截止频率。
本轮未修改这些控制策略，也未测试原始A的同组运动，不能声称已量化相对A的性能变化。
