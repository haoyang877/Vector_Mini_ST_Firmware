# 模式3位置伺服

`Position_Mode`（模式号3）采用 jerk 参考规划、位置/速度串级反馈、摩擦前馈与到位保持。控制器为纯 C 模块 `Foc/position_cascade.c`，只依赖标准库与项目 PI；`Foc/foc_run.c` 负责注入参数。模式号、正常命令入口和 Flash 参数结构保留。模式18算法不在本次整定范围内。

本轮台架整定、顿挫优化结果与验证边界见 [模式3验证记录](mode3_validation_20260908.md)。原始采集数据和固件快照保留于本地 `outputs/servo_hil_20260908/`，不纳入源码提交。

## 结构与单位

```text
目标 q -> jerk 轨迹 -> q_ref, w_ref, a_ref
w_cmd = w_ref + Kp_position*(q_ref-q) + Kd_position*(w_ref-w)
Iq = speed_PI(w_cmd-w) + friction_FF + Ka*a_ref
```

位置、速度和加速度分别为 rad、rad/s、rad/s²，电流为 A。控制器运行于2 kHz，电流环标称20 kHz。位置Kp单位为1/s，位置Kd无量纲。速度PI在电流域执行，实际Kp/Ki为已有 `speed_Kp`/`speed_Ki` 乘以 `current_limit`，避免改变原参数含义。没有确定负载J/Kt，因此Ka保持0，不伪造惯量补偿。

轨迹仍受加速度、减速度、最大巡航速度及jerk限制。速度修正上限为 `min(speed_limit, 1.5*pos_maxspeed)`，给落后于巡航参考的电机留出有限追赶余量；它不提高轨迹巡航上限，也不越过已有电机速度限制。上一轮实机整定使用12°/s巡航；本轮按用户要求将最大巡航速度调整为8 s/rev（45°/s、0.785398 rad/s），对应67.5°/s速度修正指令上限。巡航上限与瞬时反馈修正速度上限含义不同。

轨迹制动预留只计入沿目标方向的正加速度，避免对已用于制动的负加速度重复预留距离而造成末段二次速度抬升。

`POSITION_SERVO_FOLLOWING_ERROR_LIMIT_RAD`默认0（关闭软轨迹治理）。非零时，参考领先量增大将降低轨迹期望速度，再经过加速度/jerk限制；它不是保证不会超过的误差上限。旧1°治理范围与过小位置Kp组合会让参考长时间暂停。

## 连续低速反馈

模式3读取 `Encoder_GetMecVelContinuous()`：保留原16点测速窗口，绕过旧硬零速截断，再通过40 Hz一阶低通（此前为20 Hz）。摩擦判断、反馈控制及RTT data5使用同一滤波值。旧模式与标定仍使用原速度接口。滤波引入的延迟已纳入实机整定，不能把滤波零速当作真实静止证明。

## 摩擦与残余静止误差

优先使用有效辨识模型 `Ic_pos/neg + B_pos/neg*abs(w_ref)`；无有效模型时沿用现有正反向摩擦电流配置。静止有运动请求持续50 ms后允许1.2倍启动增强，实际沿请求方向运动0.003 rad确认启动。正反向切换先卸载到零，所有前馈变化受原斜率限制。

制动包络使用 `hold_enter_position + v_toward_target²/(2*deceleration)`，用于着陆判定。摩擦补偿不再沿整个制动距离衰减，而保留到0.18°捕获区；未被捕获时在0.18°～0.09°间缩放到零，实际与参考均进入窗口后由捕获锁存卸载。所有变化继续受电流斜率限制，越过目标和换向仍卸载。规划减速度不是已辨识的真实制动能力。参考已接近终点且参考速度很低、实际尚未到位时，继续沿目标误差方向补偿，避免MOVE到SETTLE间断力。

MOVE/SETTLE着陆后若停在保持退出窗口外，均可恢复受斜率限制的前馈，不必等待内部参考到达终点。

残余静止纠偏使用已有速度PI的Ui，不再增设负载积分器。以下条件持续50 ms才按0.30 A/s额外积累：尚未捕获保持窗口、目标和参考误差均在进入窗口外且同向、滤波速度不大于0.02 rad/s、观察位移小于0.003 rad。前馈正在增强时暂停同向额外积累。P项、前馈和总电流上限共同约束可用余量；运动、换目标、复位或到位取消资格。0.30 A/s是整定项，不是总Iq变化率或新电流上限；设为0可关闭。

## 捕获与保持

- 进入距离0.18°，退出距离0.26°，确认时间50 ms。轨迹结束精度仍为原0.001 rad。
- 实际位置及参考均进入0.18°时锁存“已进入窗口”，撤除运动前馈。前馈撤除期间位置退回迟滞区不会丢失捕获；超出0.26°立即清除此锁存。
- 轨迹完成、前馈接近零、速度满足条件后开始HOLD确认。确认使用已捕获锁存与退出边界，避免必须在前馈归零瞬间再次进入严格窗口。
- HOLD冻结Ui更新并保留支撑电流，位置/速度比例反馈持续运行；超过0.26°或0.08 rad/s立即回到SETTLE。
- 从未进入窗口而停在迟滞区时，继续静止纠偏；已捕获后在同一区域则保持安静。
- 新目标清除捕获状态；仅当过渡积分同时反对位置纠偏和速度纠偏时，按既有时间常数和斜率卸载；单独的减速速度误差不再清除已学习的负载电流。不能在保持时无条件清零支撑力。

总Iq限幅回写速度PI抗饱和通道。静止纠偏可能逐渐用到既有电流上限，持续受阻仍由原有故障保护处理。

## 实时路径

调试发现原模式3有效频率不足20 kHz。已将温度logf换算移至既有1 kHz监督任务，模式3不计算未使用的无感磁链观测器；在命令派发后选择观测器路径，避免进入模式3的首周期叠加两套计算。

控制配置仅在参数变化后完整验证；每次快调用仍检查目标与传感器有效性。缓存比较排除结构体填充字节，位置目标改变不触发整套不变参数验证。RTT帧编码避开2 kHz外环执行周期，完整配置校验的首周期也避让RTT；冲突时延后一个50 μs快周期。主工程与HIL工程的8个实时业务/算法文件及ADC中断入口、ADC HAL编译单元使用ARMCC `-O3 -Otime`；未修改Vendor SDK。

HIL的DWT计时只存在于硬件IRQ的USER CODE区域，命令服务不包含MCU对象。实测数值见报告；DWT记录区间不包括全部异常入栈/返回开销，也不能替代PWM相位与最坏中断嵌套的示波器验收。

## 构建与复现

正常工程 `MDK-ARM/Vector_Mini_ST.uvprojx` 默认不启用HIL服务。专用 `Vector_Mini_ST_HIL.uvprojx` 复用同一控制代码，增加受限调试命令、500 ms心跳和行程保护。对应Scope工程为 `pro_lks_servo_hil.lksscope`，AXF必须与下载镜像匹配。自动采集期间只允许一个RTT消费者。

`tools/run_position_servo_tests.py` 编译实际控制器、实际编码器测速函数和HIL命令服务进行主机回归。运行示例：

```text
python tools/run_position_servo_tests.py --cc /path/to/zig
python -m unittest discover -s tools -p "test_*.py"
```

HIL主机采集和参数烧录脚本依赖本地调试环境，本次未纳入提交；以上命令不控制硬件。专用HIL工程及邮箱接口可用于后续接入台架工具。台架所用参数及Flash版本与本提交的区别见验证记录。

当前台架NTC未安装（用户确认），ADC温度原始值0及显示−273.15°C均不代表有效温度；本轮未验收热保护能力。

本轮HIL允许运动范围为±90°：自动目标限制±85°，主机位置停止阈值±88°，板端位置停止阈值±90°；主机/板端速度停止阈值分别85°/s、90°/s。角度以现有电机编码器零点为准。位置保护触发后关闭驱动，不代表具有机械制动能力。500 ms心跳、4 A主机采样电流停止和原有驱动保护继续生效。

最新保存参数已通过复位后±85°/170°换向及±5°混合复测，主复测末段最大误差0.164°，±20°补查最大0.232°；Kd已保存为2.0。过程中发生过一次命令与停止确认超时，根因未查明，后续复测通过不能替代可靠性验收。主机已增加计数停滞检测与停止失败记录；SWD可用时可先关闭输出再暂停CPU保存现场。
