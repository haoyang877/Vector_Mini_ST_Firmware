# 双板采样链路与职责 v1

更新：2026-10-30。当前接口以[bsp_adc.h](../../firmware/platform/bsp/include/bsp_adc.h)为准。

## 所有权

两板的mcu/adc.c管理初始化、原码读取、触发启停、DMA、中断及内部量校准读取。
零偏、通用单位换算和NTC公式也位于各MCU的adc.c，不保留独立的公共实现文件。
原码接口在各MCU文件直接实现；初始化声明统一位于bsp_internal.h。
没有BspResult、valid_mask、帧结构、就绪标志、序号、时间戳或采样软件缓存。
两板使用同一公开头；工程选择对应MCU的完整ADC实现，应用不按板型选择调用。

应用中断入口显式定义于各板`projects/<board>/application/main.c`：
AT32：`MCU ADC IRQ → BspAdc_CompleteFast → MotorAxis_SampleFast → MotorAxis_ControlFast → ++g_app_fast_samples`。
BSP公开接口负责主/辅ADC配对和清标志；main依次调用采样、控制并递增计数。
SampleFast包含三相/母线电流、电压、零偏校正及编码器反馈，ControlFast只消费本拍结果。
STM32保留`BspAdc_HandleInterrupt → HAL完成回调 → BspApp_OnFastSample → MotorAxis_SampleFast → MotorAxis_ControlFast`，
仍先执行快环再清JEOS。两板由 MotorLifecycle_PostOutcome 登记采样进展。
AT32链接脚本将整个main ADC入口保留在快速SRAM区。

| 项目 | AT32F456 | STM32G4 |
| --- | --- | --- |
| 生命周期 | Bsp_Init配置，Bsp_Start启动 | 同一入口，内部调用原CubeMX/HAL |
| 快触发 | TMR1 CH1同时触发ADC1四rank及ADC2母线电流 | TIM1 CH4触发原注入序列 |
| 完成 | ADC1 IRQ确认四rank及ADC2完成后通知应用 | ADC2 JEOS确认快帧后通知应用 |
| 独立母线电流 | ADC2 PA4注入rank，92.5采样周期 | 无传感器，不置有效位 |
| 辅助量 | NTC与sin/cos由监督触发/DMA采集；读取直接取DMA完成半缓冲 | 无这些板上输入 |
| 内部量 | 温度/VREF；未校准温度不能报告有效 | 原校准温度及VDDA |
| Flash协调 | Adc_Stop关闭触发/转换/DMA；Adc_Start恢复，不等待首帧 | Adc_Stop/Start直接停止/启动转换，无采样状态包装 |

## AT32采样时序配置

ADC公共时钟为180MHz HCLK三分频，即60MHz；ADC1三相电流为12.5周期采样，
母线电压为24.5周期，四rank均保留12位、4次硬件累加且不右移。
三相单次采样保持0.2083µs、母线电压0.4083µs；整组采样加转换理论7.4667µs，
较第一步全部24.5周期的9.8667µs减少约24.32%，较最初30MHz配置减少44%。
20kHz触发及原触发位置不变；预算不含同步、IRQ或软件开销，不是实测耗时。
ADC2母线电流仍为92.5周期单次转换，总计约1.75µs；普通组NTC保持640.5周期，
sin/cos两路为24.5周期。Off工程普通组4次硬件过采样并右移2位平均，
一次触发完成四次采样；被母线电流抢占后继续累加，母线抢占组不启用过采样。
内部温度/参考仍为ADC1普通组单次640.5周期，不跟随ADC2的过采样。
ADC2母线电流每个20kHz快拍采集；INIT阶段由独立电流偏置校正功能与三相共用
2048拍窗口，统一发布偏置后进入正常物理量读取和滤波。
Watch可查看s_current_offset_calibration和s_foc_state中的校正状态及测量值。

| 新板信号 | ADC/引脚 | 硬件触发频率/周期 | 采样周期 | 过采样 | 单通道理论采样加转换 |
| --- | --- | --- | --- | --- | --- |
| 母线电流 | ADC2_IN4 / PA4 | TMR1，20kHz / 50µs | 92.5 | 单次12位 | 1.75µs |
| 电机NTC | ADC2_IN7 / PA7 | TMR6，2kHz / 500µs | 640.5 | 4次硬件平均，12位 | 43.5333µs |
| sin/cos第1路 | ADC2_IN5 / PA5 | 同上 | 24.5 | 4次硬件平均，12位 | 2.4667µs |
| sin/cos第2路 | ADC2_IN6 / PA6 | 同上 | 24.5 | 4次硬件平均，12位 | 2.4667µs |

上表为当前新板普通APP（Off）配置。NTC参数为B3950、R25=10kΩ，下臂1kΩ。
普通序列按NTC→PA5→PA6顺序，DMA1_CH2双半缓冲各3个半字；整组理论48.4667µs，
不含母线抢占延迟。两路顺序采样，不视为同时采样，也没有接入输出轴角度解算或闭环。
其它目标默认不启用sin/cos，NTC仍保留原单次采样；不能将Off配置外推到其它目标。
最新通道周期调整见[单工程实施记录](../plans/active/2026-10-29-sincos-24p5-v1.md)。

sin/cos在AT32 adc.c私有`s_aux_dma`中观察：启用NTC时每半顺序为NTC、PA5、PA6；
两半连续存放，`DMA1_CHANNEL2->dtcnt`用于识别当前写入的半缓冲区。
不再保留`g_at32_sincos_snapshot`及begin/end版本发布协议。

## 数据与职责

两板都只有两个数值读取入口：ReadRawChannel返回等效12位原码，ReadChannel返回A、V或摄氏度。
零偏设置直接写入，返回void；未设置零偏时电流为NAN。未启用、缺参数或公式无定义返回NAN。
ADC完成中断只确认/清标志并通知快环；读取不等待首帧，不判断健康/年龄，不保证多通道同拍。
快慢通道都没有软件缓存；AT32直接取DMA完成半缓冲，STM32直接取ADC1的TS/VREF寄存器。
STM32 system.c中的监督回调在应用读完当前TS/VREF之后触发下一组，保持2kHz软件采样。
Flash停止后旧寄存器/缓冲区值仍可被直接读取；恢复只重设DMA计数、清标志并开放触发。

应用的电压/电流搬运函数直接接收数值，不再依赖BSP帧类型。
`FocState`直接持有母线电压、硬件母线电流及各自滤波值和低通系数；
Axis初始化两系数为0.05，20kHz快环直接读取BSP母线通道并更新。
母线电流通道未提供或未校零时为NAN，恢复有效后以首个有效值重建滤波基准；
FOC内部的估算母线电流继续独立存在；协议反馈来源不由测量搬运函数更换。
电流校零与母线滤波保持各自的应用所有权；母线Watch序号改为监督读数次数，
不再根据ADC序号去重或验证硬件触发连续性。片内温度每次监督调用直接读取DMA。
上电校零和采样新鲜度检查由轴和生命周期推进。

电流偏置校正固定累计2048个快拍，20kHz下理论102.4ms，仅由INIT状态调用。
三相和已启用的母线电流共用窗口；第2048拍计算各自均值，确认处于
1948～2148 counts且仍关相、控制禁用后，一次发布给BSP，三相值同时写入活动配置。
无母线传感器的板卡跳过该通道；启用通道任一失效都会阻止全部偏置发布。
正常采样只读取物理量，监督任务不再处理偏置。失败锁存原故障，不自动重试、保存或启相；
自检额外等待按毫秒向上取整为103ms。
