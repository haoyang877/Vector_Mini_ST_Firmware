# 齿槽转矩标定实机验证（2026-09-17）

使用 J-Link 602722271 对 node=1 左轮、2 mΩ、无阻尼器电机执行 mode 6 标定。正向和反向各完成 1024 点，发布 1024 项 int16 Q15 表，Flash 保存和 MCU 重启回读均通过。

> 质量复核：以上“通过”限定为采集状态机及持久化流程。用户指出波形尖锐后，发现明确的电流零偏残差及测量精度问题；该表的纯齿槽转矩准确性尚未通过验证，未启用运行补偿。详见文末复核。

## 结果

- 完整双向耗时：540.0 s。
- Q15 原始值范围：-60 … 60；均值 0.4580 count。
- 等效保持电流：-0.1511 … 0.1511 A，RMS 0.0694 A。
- 双向去均值曲线相关系数 0.9030，半差 RMS 0.0157 A；反向曲线由量化后的合成表与正向表估算，带有约 1 count 舍入误差。
- 编码量程：32768 对应约 82.5000 A，不是 1 mA/count；表本体 2048 字节。
- 主机离散遥测峰值：速度 0.2517 rad/s，Iq 指令 0.2472 A，Iq 反馈 0.2584 A。此遥测约 80 ms 一次，不代表捕获了每个控制周期的峰值。
- 母线电压 27.790 … 27.814 V。温度通道返回约 -273.15 °C，未作为有效温升测量。
- 重启后 mode=0、fault=0、PWM 关闭、CPU 运行。编码器 reverse=0、电零位 15611、标定标志 3 保留。
- 对比完整 Flash，除了新表和启动后更新的三相 ADC 零偏，其他已存参数保持一致；节点、运行环路增益和编码器标定未改动。

这次验证的是标定、保存和读取。表尚未叠加到运行电流指令，不能据此声称已经验证补偿后的转矩脉动改善。

## 实机调整

最初复用速度 PI 时出现定位超时和保护退出。独立位置保持环提高了定位刚度；速度阻尼改用局部 2 kHz 位置差分和约 90 Hz 低通，目标以 0.1 rad/s 斜坡推进。最终 Kp=20、Ki=80、Kd=0.25，单位及流程见 [使用说明](../../guides/cogging_calibration.md)。保存的正常速度/位置环参数保持不变。

标定电流上限仍为 min(1 A, calib_current, current_limit)，超速退出仍为 1.5 rad/s。位置采样容差仍为 1/4 格，连续稳定 50 ms 后平均 50 ms。首点允许 10 s、其余点 3 s；整程上限 1800 s，未通过放宽单点精度来掩盖定位问题。早期未完成的表未发布；每次失败日志记录停机和 Flash 核验。

## 波形质量复核

保留原始表及已烧录固件，对完整 1024 点作空间 FFT，没有将平滑曲线覆盖原始测量。

| 空间阶次（每机械圈周期数） | 单边正弦幅值 |
| --- | --- |
| 21 | 85.90 mA |
| 126 | 30.48 mA |
| 252 | 19.80 mA |
| 36 | 15.93 mA |

21 阶占去均值信号均方能量约 76.7%，126/252 阶合计约 13.7%。相邻点最大差约 153.6 mA。高阶成分在两方向均出现，不能仅当成随机噪声删除；也不能只凭 21 对极断言 21 阶就是真实齿槽。真实齿槽与槽极组合有关，定子槽数待确认；电流零偏同样能产生电角度一阶分量。参考 [ADI 对电流测量非理想因素的分析](https://www.analog.com/en/resources/technical-articles/impact-of-nonideal-effects-in-a-motor-drive-current-loop.html)及 [TI 对齿槽转矩的说明](https://www.ti.com/document-viewer/lit/html/SSZTBL1/GUID-9F1C872B-7B49-4C59-A9AB-FDF04E4E61CA)。126/252 阶对应电角度 6/12 阶，来源尚未区分，不能仅凭阶次认定为死区误差或真实齿槽。

源码检查：ADC2 使用 4 倍过采样但右移 2 位，输出仍为 12 位刻度；2 mΩ、增益 10 时，单 ADC 码约 40.293 mA。表的 Q15 刻度约 2.518 mA/count 仅是存储单位，不等于采样分辨率。平均可能降低随机量化噪声，但不消除系统零偏。电流零偏字段及上电校准均截断到整数 ADC 码。

随后在 PWM 关闭、mode=0、fault=0 时通过 J-Link 只读采集 400 组三相 ADC 值：均值为 2032.855、2052.090、2037.680；当前零偏为 2032、2051、2036。换算出的表观相电流为 -34.45、-43.92、-67.69 mA。按源码 `alpha=a; beta=(b-c)/sqrt(3); Iq=-alpha*sin(theta_e)+beta*cos(theta_e)`，这组残差对应约 37.08 mA 的电角度一阶幅值。这证实当前零偏存在问题，但该测量在停 PWM 后进行，不能直接拿来扣除先前通电标定中的全部 21 阶分量。

标定代码在 2 kHz 取一次原始 Iq，稳定 50 ms 后采样 50 ms，尚未对 20 kHz 电流反馈先做连续积分再降采样。因此采样相位相关误差、短时定位动态及高阶齿槽仍需进一步区分。优先方向是保留零偏小数、核对 PWM 工作状态下的测量偏差、对完整电流周期平均并延长稳定窗口，然后复测固定点/局部区间，最后重采全圈；不以单纯平滑处理代替测量验证。

原始诊断位于 `outputs/cogging_bench_20260917/quality/`：`idle_adc.json`、`analysis.json`、`quality_spectrum.png`。本轮复核没有发出电机运动命令，没有更改编码器方向、电零位或已存表。

## 位置跟随复核

从同一次实测的 6591 条活动状态记录重建了目标/反馈及误差曲线：`outputs/cogging_bench_20260917/quality/position_tracking.png`，配套 CSV 和统计 JSON 同名。位置原点已核对：本次机械零位为 0，标定绝对网格与编码器反馈可直接比较；图中二者统一减去第一个网格目标以显示相对位置。

整体完成正向一圈和反向返回，没有持续的宏观位置落后。局部可见逐格移动后的过冲和收敛，而不是始终贴合网格目标。网格间隔为 0.3515625°，采样窗口要求误差不超过 ±0.087890625°。

筛选子集仅用于诊断：状态=2、samples=10…90、stable_ticks=100，且目标网格与上一条主机记录相同。原始采样标签中有 22 条超窗记录，许多同时出现 samples=0/99、点号/目标更新等边界字段不一致，说明存在跨点读取；不能简单把这 22 条都认定为真实误差，也不能删去后宣称所有点通过精度验证。完整图和 CSV 保留全部活动记录。

关键限制：编码器位置通过冻结邮箱读取，目标/标定状态随后从运行 RAM 分别读取，并非同周期原子快照；CoggingCalib 自身多字段也可能跨状态更新。主机中位读取间隔为 81.38 ms，长于每点 50 ms 采样窗口，无法捕捉所有采样瞬间和高频振荡；采样标签仅覆盖约 1284 个方向点，不能替代 2048 点完整同步记录。图中的目标是最终网格目标，内部 0.1 rad/s 斜坡参考 hold_position 未被记录。

结论是整体位置跟随成立，已记录的多数采样时刻进入了容差范围；逐点充分静止及其对 Iq 的影响仍需同步高频记录验证。本次只分析已有日志，未再次驱动电机。

换向处为导出正向暂存表，主机在 270.021…270.347 s 之间有约 325 ms 的记录空档；图中已灰色标记。该处曲线无法展示换向额外前进一格的实际峰值，不能按相邻主机点的连线认定电机未到达换向目标。
