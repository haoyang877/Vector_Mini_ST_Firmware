# 同型号新电机调试与验收流程

版本：v0.1，2026-09-29。适用于同一 STM32G431 / 6 mΩ 三低侧分流驱动板及同型号 21 极对电机；阻尼环可有或无。本文是逐台调试流程，不是产线认证或电机额定值。硬件电气检查细节见[电机驱动电气健康检查 v0.1](motor_electrical_health_test_v1.md)，位置环正式判据见[Mode 3 测试计划](mode3_test_plan.md)。

电机型号和驱动板一致，只允许复用硬件/型号配置及经验证的参数起点。每台电机自己的编码器 LUT、电角零位、机械零位、方向和负载摩擦都要独立确认。阻尼环、装配机构或线束改变后，重新核对对应模型与测试条件；不要把一台电机的校准字节复制给另一台。

带阻尼环时，mode15静态电流可能不足以从任意初始角度对齐；轴静止且标定标志
有效并不证明电零位正确。保存/复位核对后，先做有低速、限流和反向运动早停
判据的双向方向回归，再放行摩擦和位置测试。反向加速时STOP并分析原始角度，
不要通过反转编码器或盲目重复速度闭环掩盖问题；若需改变预定位姿态，采用有
明确电流/速度边界的独立固定矢量方法，其电压不是通用限流值。此台pitch的
具体异常与复测见[新pitch计划](../plans/2026-09-29-new-pitch-yaw-parameters.md)。

## 顺序与放行门

| 阶段 | 工作 | 进入下一阶段的条件 |
| --- | --- | --- |
| 0. 建档与安全边界 | 记录板卡/固件/参数哈希、电机和阻尼环、21极对、6 mΩ、电源、可动范围、电流/速度上限、现场断电方式；确认唯一运动命令源 | 有完整台架上下文；STOP、故障读取和三相关断入口已验证 |
| 1. 电气链路检查 | 按硬件健康指南做断电线束/电阻 T0、电流采样 T1、六方向低压功率通路 T2、相电阻 T3、低速方向和编码器关系 T4；首次设计/维修另做 T5 波形覆盖 | 所有必测项 PASS；WARN/INCONCLUSIVE 不伪装成 PASS。相序、采样、编码器方向或电阻异常先定位，不进入标定 |
| 2. 电角标定 | 裸轴或脱开机构后运行 mode 13（编码器线性化 LUT），再运行 mode 15（电角零位）；不反转软件编码器方向来掩盖相线问题 | 每项完成、STOP/关相验证通过；保存后复位读回标志、电零位、方向和 LUT 哈希一致 |
| 3. 机械零位与范围 | 可先把当前线性化编码器位置设为临时零位，以便建立 pitch 软件坐标；pitch 范围为 −0.3～+0.9 rad。安装到目标机构后，再按真实基准重新标机械零位并核对可动范围、软限位、速度和加速度 | 临时零位必须标明“未按机构基准校准”。裸轴软件范围不代表机械止挡或真实行程；最终配置只有在真实基准和可动范围确认后才可用于机构运动 |
| 4. 摩擦辨识 | 参考[摩擦辨识指南](friction_identification.md)，先关闭补偿，在目标装配/负载下做双向低速扫描和稳态窗口，拟合正反向库仑项及速度相关项；至少重复并记录残差/电流 | 模型方向、单位、残差及负载条件有效；不将有/无阻尼环或不同机构的模型互换 |
| 5. 速度闭环 | Mode 2 使用编码器 PLL 反馈，逐级做正反向低速/中速目标；记录指令、反馈均值/标准差、超调、Iq、限流、速度及错误 | 两个方向均能启动、跟随、减速和STOP；波动/噪声及电流满足本次批准的项目阈值。单点能转不代表速度环验收通过 |
| 6. 位置闭环 | 按 Mode 3 测试计划从 HOLD、micro、small、medium、range 到 large_range 递增；启用本机实测摩擦模型；目标一段通过才扩大行程 | 每点有完整采集，末2秒误差≤0.3°、HOLD=100%、编码器错误增量为0；末段与全过程 Iq 仅记录，无固定4 A验收限额；独立执行本台架相电流/速度/行程保护，确认命令接受、STOP及关相。结构抖动另测 |
| 7. 保存与复位验证 | 仅在所需模式、装配零位、范围、增益、限流和补偿都验证后保存参数；写前备份整片 Flash，写后整片回读并复位 | 只允许预期字段变化；CRC、身份、限位、增益、个体校准读回一致；错误/输出保持安全，证据归档 |

任何步骤发现故障、非预期模式、母线或电流超限、编码器离线、命令超时、有效样本缺失或运动越界，立即 STOP 并验证驱动关闭。STOP 或关闭功率输出无法验证时，要求现场断电介入，不自动重试。硬件测试按[专用电气健康方法](motor_electrical_health_test_v1.md)逐项执行；mode 12 开环电压值不是通用电流保护。

本轮用户已删除旧的“末段实测 |Iq|<4 A”条件。当前阻尼 pitch 的位置测试保持运行限流8 A；任一相采样电流绝对值达到8 A时停止，饱和标志仅记录。取消尾段限额不改变位置精度、HOLD、编码器、故障和STOP要求；旧报告中的4 A判据保留历史含义。执行方案见[位置尾段电流验收修订](../plans/2026-09-29-pitch-tail-current-acceptance.md)。

2026-09-29用户对本台架及后续测试明确取消主机母线电压窗口和断母线下载准入：
母线读数仅记录，不据此阻止下载或试验；无法下载时再定位连接/供电。固件自身
欠压/过压保护、实际电流与速度、编码器、故障及STOP/关相检查不取消。下载前先
暂停并核对输出关闭，不无条件恢复未知旧应用。新电机可多圈旋转与现场唯一命令源
仍需有明确上下文；本项用户指示不代替机械条件确认。具体执行见[新pitch计划](../plans/2026-09-29-new-pitch-yaw-parameters.md)。

## 建议的参数起点与本轮证据

同型号新阻尼环裸轴本轮在 mode 3 使用旧 roll 参数作为候选：位置 `cascade_pos_Kp=8`、`cascade_pos_Kd=2`，速度 `speed_Kp=0.5`、`speed_Ki=1.0`。速度轨迹0.1 rad/s、加减速度0.2 rad/s²，临时Iq限值5 A；摩擦辨识结果为正向3.455 A、反向3.101 A，黏性项0。该配置完成两轮相对当前位置±150°分段往返，自动验收通过。90°/s 是试验实测速度停止阈值，不是本轮规划速度；实测峰值最高约71.5°/s。

这些结果只适用于上述电机/驱动、摩擦模型和低速测试条件。每台新电机须重新做电气健康检查、mode 13/15、机械零位、摩擦辨识和速度/位置回归；复用参数不等于免测。推荐每种目标装配的初始重复性至少3轮。本轮仅单轮/两轮基线，结构抖动和温升未验收。

yaw 本轮另记录模式差异：Mode2 的 Kp/Ki=0.06/0.6 通过 ±1/±3 rad/s 低速回归；
Mode3 使用旧 roll 配套内速度0.5/1、位置8/2。两模式均按电流上限缩放速度增益，
但 Mode3 还有10 Hz速度反馈滤波、摩擦整形及积分处理，须分别装载所验收的参数。
本轮最终保存以通过验收的 Mode3 为准；不能据此宣称 Mode2 的0.5/1已通过。

yaw随后在运行6 A的两轮大范围试验中触发90°/s停止门限，全行程未通过。用户已知
此结果后明确要求持久化本轮配置并改为运行8 A、预定位5 A。该次保存必须记录为
用户指定的未完成运动验收配置，不可据此把8 A或全行程标为PASS；普通新电机流程
仍优先保存已验收配置。8 A保存后的具体值与回读证据见[yaw计划](../plans/2026-09-29-yaw-commissioning.md)。

本轮将当前静止位置设为**临时** pitch 零位：raw Q15=62152、经 LUT 线性化后的 Q15=61352；Flash 中 `mechanical_zero_q15=61352`，校准标志为7。AXS1 pitch 记录的范围为 **−0.3～+0.9 rad**、速度上限45°/s，CAN 节点为4；AXS1 启动路径保留已测并写入的增益：位置 Kp/Kd=8/2、速度 Kp/Ki=0.5/1。整片 Flash 写后 SHA-256=`564430a422adf9b9e73f93be7adc1afdef036d9c580802701ad36f198d4e521c`，与候选镜像逐字节一致，运行态读回位置为0 rad。

该零位只是当前轴姿态建立的软件坐标，尚未按 pitch 机构基准校准，也不代表真实机械零点或已确认的物理行程。安装到机构后，必须在真实基准重新标零并检查两侧净空，再按最终行程复核 pitch 限位。保存的电角零位、LUT和方向保持独立。Flash 写后未重启验证；本板启动会自动运行电流零偏采样，因此 MCU 当前保持 halt，三相通道与 MOE 均关闭，未发送任何运动命令。后续上电需先确认台架安全，并观察自动电流零偏流程结束后是否回到 Disable。

## 每台电机的记录清单

保存：电机/阻尼装配与线束标识、板卡与固件/Flash 哈希；电源及仪器设置；T0–T5 项目级结果；mode 13 LUT 和 mode 15 电零位/方向读回；机械零位、限位及照片/基准；摩擦扫描原始点、模型和残差；速度/位置参数及完整样本；异常与 STOP/关相证明；Flash 修改清单、CRC 和复位读回。忽略目录 `outputs/` 保存二进制、日志和原始数据，跟踪文档只记录摘要，不写入探针序列号或工作站绝对路径。
