# 启动、交接和收尾的中断预算优化 v2

日期：2026-10-15。分支 `codex/ovp-36v`，HEAD `3b5457c9` 加工作区修改。
计划：[40 μs 预算优化 v2](../plans/2026-10-15-fast-irq-40us-v2.md)。
基线：[v1 实机记录](2026-10-15-fast-irq-40us-v1.md)。

## 结论与范围

本轮完成剩余热点的代码优化和离线验证，按用户要求未连接 J-Link、未下载、未启动电机。
**完整 ADC 中断最大占用小于 40 μs 尚待整机验证，本报告不提供新实测耗时或单项节省时间。**
旧版启动 50.165 μs、交接 41.171 μs、收尾 42.276 μs 是 v1 主体计时，
既不是本版测量，也不包含完整入口、退出开销。

## 本轮修改

| 环节 | 修改 | 保持的行为与边界 |
|---|---|---|
| 启动工作区 | 8 KiB 静态区替代标定期间堆分配，参数堆由 12 KiB 改为 4 KiB | mode 12/13 互斥共享；mode 13 分拍初始化；候选 LUT 独立于生效表 |
| mode 13 启动 | 准备、启用中性 PWM、首拍 FOC 分开执行 | 原对齐斜坡与持续时间不缩短；使能前重新检查编码器、参数、电流和热准入 |
| 闭环交接 | 首次交接选择一次速度 PI 相位，避开热更新与编码器慢拍 | 首次 PI 在第 2～10 拍，之后每 10 拍；电流环/观测器 20 kHz、速度 PI 2 kHz |
| 热模型更新 | 等价条件比较替代多次 `fminf/fmaxf`，局部累计最大热量 | 保留原除法、阈值、全状态数值结果、20 kHz 采样和 1 kHz 更新；无效输入仍保留相同的部分更新结果 |
| 关相高阻 | 平台层对两个 GPIO MODER 各作一次读改写，替代 HAL 逐引脚配置 | 六个目标引脚之外保持；PUPDR/AFR/OTYPER/OSPEEDR、TIM/CH4/MOE 语义保持；TIM 启停仍走原 HAL |
| 正常收尾 | 关相和候选 LUT 提交分为相邻两拍 | 全部 LUT 在关相后整体提交；提交前 STOP/故障保留旧 LUT；提交后才进入保存 |

准备拍尚未开启 PWM、`ModeLast` 仍为停机。已补齐此时收到 STOP 的清理，避免遗留
`CS_OBS_START_PWM` 和工作区引用，导致下一次标定跳过准备或把错误阶段带入其他标定模式。

没有更改运行电流、热参数、标定残差阈值、编码器方向、Flash 参数结构或 CAN 帧布局。
标定阶段原编号 0～35 保持，新增 `CS_OBS_START_PWM=36`、`CS_OBS_COMMIT=37`；
调试工具如按 `CalibStep` 建数组，需要覆盖这两个新阶段。

PI 错峰仅对有效、连续的热/编码器相位成立。热状态无效时退回原计数相位，
不伪造样本或延后保护；编码器失帧、复位后相位可能重新重叠，须纳入后续最大耗时测试。
锁速转交接的当拍仍包含 FOC、初始相位三角函数和 PI 跟踪，错峰从下一交接拍起生效。
PWM 启用的 TIM 调用、提交拍的 2 KiB 复制与测速复位仍是重点计时对象。

## 离线证据

最终完整回归通过：Python 单元 56 项、集成 36 项、默认 native 26 组，另加 WINDOW16
专项 1 组。normal/HIL 构建均为 0 错误、0 警告；`git diff --check` 通过。
初次回归的 7 项失败来自共享测试桩沿用旧启动变量/查询接口和未明确 UTF-8 的源码读取，
适配后完整重跑通过，未削弱保护或跳过测试。

以下检查针对本版源码，实际结果和产物哈希归档于 `outputs/irq_budget_v2_20261015/summary.json`：

- 启动各拍顺序、两档标定配置、STOP/故障取消、脏工作区复用、原对齐时长、原子提交与保存顺序。
- 200 组热窗口/编码器相位组合；首次 PI 延迟、后续周期、模式选择以及实际 IRQ 中的调用顺序。
- 热更新 288,035 个窗口的全状态逐位对照，覆盖加热、冷却、热点、降额/停机/解除阈值和异常输入。
- 高阻实现与当前仓库 HAL 对照 24,096 个向量；三相重构在 2/6 mΩ 配置下各 21,600 个向量。
- 实际参数记录 2,384 B，在 4 KiB 堆中反复分配/释放 100 次，最低空闲 1,680 B。
- WINDOW16 保持 2 kHz 更新、8 ms 窗口，覆盖方向、跨圈、暖机、停止、复位和无效帧。

ARMCC 反汇编确认高阻函数为两组 MODER 读改写；热限幅函数不再调用上述 min/max 库函数；
标定模块不再引用堆分配/释放。这些仅确认优化已进入机器码，不能换算成未经实测的 μs 收益。

当前旧工作树没有新版 `verify/format/lint` 入口。沿用既有 `tests/run.py`、补充 native 测试、
normal/HIL Keil 构建和 `git diff --check`，不宣称通过了不存在的新入口。
