## 2. 本轮运行边界

- B1基线：轨迹速度10°/s，加速/减速各10°/s²；按现有0.2 s jerk整形约50°/s³。SI写值均为0.174532925 rad/s或rad/s²。
- 位置最高速度45°/s仅是表中配置；第一轮使用较低的临时B1边界，结束恢复原速度/加减速。本轮不保存临时速度或增益。
- 现有位置纠偏参考允许1.5倍轨迹速度，B1参考上限约15°/s，因此记录实际速度峰值，不将轨迹10°/s误称硬速度保护。B1实测速度达到20°/s作为本轮主机停止阈值；固件既有保护继续生效。
- P0/P1/P2/P4沿用每档至少14 s；P3a边界准入降为5°/s与5°/s²（jerk约25°/s³），每档20 s，实测速度停止阈值10°/s；通过后P3b使用B1的10°/s与10°/s²，每档18 s。
- 试验实际位置保护区为−25.5°～+11.5°，触及或越过即STOP，中止后续档；这是附加主机停止阈值，不能代替机械余量或保证惯性停止距离。固件轴边界仍为−26°～+12°。
- 每档按上述时间；只有命令和操作已结束且取得末2 s连续记录才统计该档合格。运动完成不等于目标到达，未取得完整末段记录标为未完成。
- 运行限流7 A；相电流实测绝对值达到7 A停机，IqRef达到配置上限记录饱和。IqRef≥6.85 A且1.5 s内没有向目标推进0.06°也停机，避免长时间顶住机构。0.06°大于已知位置测量噪声约0.05°峰峰值。

## 3. 用例顺序

| ID | 操作 | 重复/时间 | 核心验收 |
|---|---|---|---|
| P0 | mode3保持0° | 10 s | 无自发出力/振荡，末段IqRef/Ui/FF归零 |
| P1 | 0→+2→0→−2→0 | 1轮，每档14 s | 正反都能正常移动；否则停止，不进大角度 |
| P2 | 0→+10→−10→0 | 3轮，每档14 s | 每档误差≤0.5°、平滑停靠、无持续纠偏保持电流 |
| P3a | 0→+11→0→−25→0 | P2通过后1轮，5°/s，每档20 s | 逐侧端点准入，两端均留1°余量；未通过不进跨程换向 |
| P3b | 0→+11→−25→+11→0 | P3a通过后3轮，10°/s，每档18 s | 36°最大跨程、直接换向及靠近两端停靠均通过 |
| P4 | +10°→−10°→+10°，每次实际接近0°时换目标 | 3次，最后到位保持14 s | 参考q/v/a连续、无非计划零电流停顿；正常换向过零不算故障 |
| P5 | 到0°卸流后静置 | 30 s | IqRef/Ui/FF维持零，位置无持续往复助推 |
| D1 | 目标0°，从机构操作端外推约±0.3°后释放 | 正反各3次，每次观察10 s | 位于0.5°内，保持零电流，不启动回位 |
| D2 | 目标0°，外推约±0.8°后释放 | 正反各3次，每次观察10 s | 0.5°～1°滞环内不唤醒；不按正常静态误差≤0.5°条款判本项失败，不能假报精确到位 |
| D3 | 目标0°，外推±1.2°后释放，再测±2°、±5° | 每幅值正反各3次，观察至少14 s | 越界确认后启动轨迹/PI/FF，回到±0.5°并卸流，不反复补偿 |
| P6 | 最后回0°，mode0停止 | 一次 | 模式0、输出关闭，临时参数恢复；保存完整报告 |

外推只在目标0°附近进行，最大±5°；不得在+11°/−25°端点继续向外推。使用机构可操作端轻推后立即释放，不持续顶住驱动，不触碰裸转轴/相线。记录实际偏移，不能仅以手感认为达到1.2°。硬件停机/断电及故障事件中止整个序列，不自动重试；恢复试验须重新核对条件。

## 4. 通过标准与记录指标

| 指标 | 本轮标准 |
|---|---|
| 正常运动静态位置误差 | 每档最后2 s最大绝对误差≤0.5° |
| 定位振荡 | 建议末段位置峰峰值≤0.10°；无超过测量噪声的持续周期往复，现场无明显抖动 |
| 过冲/卸流回弹 | 建议幅值≤0.5°，单独报告过冲与卸流后回退，不能只看最后一个位置 |
| 末段保持电流 | IqRef、速度PI Ui、摩擦/惯量前馈峰值分别≤0.02 A；检查总指令，不能只证明积分为0 |
| 实测电流 | 记录Iq RMS、峰值、三相峰值；不增加旧的“末端Iq<4 A”限制，不用高频测量噪声替代指令是否归零判断 |
| 回位启动等待 | 外力释放到位置实际推进0.05°；B1/2 A/s基线建议≤2.5 s，作为初始性能目标，不作硬件早停门限 |
| 回位到位时间 | 分别报告首次进入±0.5°、完成参考减速/低速确认、总电流归零；建议±1.2°/±2°在6 s内回到误差带并完成卸流，±5°在8 s内；待实机基线校核 |
| 精确到位标志 | 现有0.08°独立记录，不作为0.5°验收的必需条件，不把被动停靠标志当精确到位 |
| 到位后再次唤醒 | 未受外力/新命令时为0次；D1/D2不唤醒，D3每次允许一次受控回位 |
| 参数持久化 | 试验前后Flash比较；临时速度、增益、RAM零位不应自动保存。操作员明确保存的值单独记录 |

闭环相电流停止7 A与指令限流7 A是不同判据。建议性能阈值不自动代替固件保护或证明连续峰值未超限。计时以日志时间戳/实际固件输出频率为准，不能只用LKS显示设置推算时间。

## 5. 曲线和结果表

每次命令及外力释放使用事件时间戳。记录实际采样率、丢帧及对象非原子同步限制。RTT适合动态波形，约30 Hz SWD快照不能证明高频电流峰值或细小停顿。
生成逐档图与整轮总图，至少包含位置/参考、误差±0.5°带、速度、电流指令与反馈、Ui与FF及状态。每档结果表包括：目标/实际中值/末段最大误差/位置峰峰/过冲/回弹/实际速度峰值/IqRef及实测电流峰值/Ui峰值/FF峰值/唤醒次数/首次到位时间/卸流时间/通过或失败原因。
