# Pitch 小电流支撑 v1 离线验证

日期：2026-10-19。基线：`5665ff87`，分支 `codex/ovp-36v`，APP v0.6.0 build0。
本次为未提交的候选功能，不是新版本发布；未访问探针、未烧录、未启动电机。

## 行为与配置

详见 [使用说明](../guides/pitch_support_v1.md) 与
[实施计划](../plans/2026-10-19-pitch-support-v1.md)。

仅带阻尼的 Pitch mode3 启用：到位先卸流至零；相对本次停稳位置漂移 0.1° 后，
按 0.5 A/s 建立反漂移支撑，独立候选上限 1 A，运动剩余电流按 2 A/s 交接。
连续 200 ms 无 0.025° 新位移，或已经向支撑方向回移时，冻结支撑。
保留原 1°/50 ms 外扰回位条件，非零支撑不再阻塞唤醒。

支撑不使用目标残差作积分，不复制大运动电流；保持 Ui 原有诊断语义，
新增独立支撑/调整/限幅快照。运行限流、热限流优先。三个新参数仅 RAM，
原 Flash 记录、CRC、标定字段、CAN 和 RTT 线协议不变。

  支撑/热限幅、非零支撑唤醒、关闭/重置、运动电流不复制、反向漂移减小支撑、
  新目标交接、无效参数拒绝、1/2 kHz 一致性。

## 证据与局限

可复核证据位于 `outputs/pitch_support_20261019/`：`summary.json`、`tests.log`、
`regression/`、`source_hashes.json`、`build.log`、`snapshot/`。
候选产物位于该快照的 `outputs/build/keil/Vector_Mini_ST/`。

测试使用合成反馈，不证明机构的最小支撑电流、温升、真实回弹或稳定性。
没有卷簧/摩擦模型，算法只寻找当前姿态附近足够的支撑，不周期性减流试探，
不保证数学意义的最小值。很慢漂移及超出小电流能力的负载仍需台架验证。
实际工况保持与本轮无关的用户修改，未自动提交、推送或更改软件版本号。
