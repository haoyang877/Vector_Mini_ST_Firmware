## 问题与边界

上一候选 HEX a2a6e97c79735519fef40f5ab8be5f5739060c132dd0f44784e4adeb25fc901f
初始化时尚无母线电压，d/q PI 上下限为零；之后空闲 FastTick 只更新母线，不更新限幅。
该候选获用户另行授权的单次 LUT 试验后，运行时上下限读回约 ±18.00524 V，
说明本轮证据支持空闲刷新遗漏，不支持把取消归因为运行限幅失效。

本修复仅在真实 Vbus_Update 后刷新 d/q PI 的 output_min/output_max，
复用 FOC_MaximumVoltage，不复制调制公式，不调用整体控制器配置或复位。
有效正母线对应动态电压额度；零、负数、NAN、无穷大仍为零额度。
增益、周期、积分和其他动态字段、速度 PI 状态均不改写。
不改变 FOC_CurrentWithReference/FOC_Vq_Mode 的动态配置、PI/SVPWM 数学、
控制/维护门禁、协议和参数 ABI、功率阈值、时基或输出使能。
FastTick 增加一次现有纯计算和四个 float 写入；真实 ISR 耗时仍须另行测量。
