# 电机控制端目标适配 v1

日期：2026-09-28。依据[单轴线路契约 v1](../../protocols/yg_protocol_motor_wire_v1.md)。

## 目标和范围

把 116 解码结果交给电机控制所有者，通信层不写电机全局变量，也不直接调用历史模式切换函数。
本阶段只更新已经 RUNNING 的相同模式目标：电流、速度、绝对位置、q 轴电压。
101 使能、mode 5 低侧制动和跨模式启动仍未开放；MIT 增益未定，仍不支持。
这不是正常启动流程的完成，也不对外声明远程控制能力。

## 实现关系

```text
116 解码（mrad、mrad/s、mA、mV）
  → yg_protocol_motor_adapter（显式映射模式，转换 SI 单位）
  → MotorControlSubmit（services/lifecycle/motor_control_command.h 值接口）
  → board_config 注入 FocRunState_SubmitRemoteControl
  → 单槽邮箱（无覆盖，前台短临界区提交）
  → FocRunState_Tick（2 kHz，worker/故障处理后复核并应用）
  → 下一外环周期使用目标；20 kHz 快环使用控制参考
```

接口只有值对象和一个提交函数，不增加第二套生命周期、动态分配、注册器或通用任务队列。
控制请求只复制一次；邮箱占用返回 BUSY。首次检查与应用前复核涵盖：
功率级已开启、生命周期 RUNNING、模式相同、无故障、有效轴配置、编码器在线且完整标定、
有感路径、母线电压窗口、未使用字段为零、有限值及各模式限值。
位置检查复用轴范围；速度采用当前控制和轴配置中更严格的上限；电压复用 FOC 的调制上限。
这些电压限值不替代产品电压模式的功率/温度评审。

STOP/101 失能取消邮箱；worker 停机、故障、传感器失效或限值变更使待应用目标被丢弃，
不得自行恢复或重新提交。相同模式目标只更新对应参考，不复位轨迹、PI 或电流环。
`FocRunState_Init` 同时清除目标、worker 和紧急关断标记，防止复位后消费旧邮箱。

## 结果和限制

邮箱受理返回线路结果 1（ACCEPTED）；参数、状态、邮箱忙、越限、故障分别映射 4/5/6/11/17。
受理回复及对应 124 保持既有流程，可能仍反映应用前的参考，不能标作 APPLIED 或到位。
本阶段不增加线路字段；后续仍需接入实际完成序号和终态报告，才能确认具体命令已应用。
在未实现 101 制动态和模式切换前，GET_CAPS 的控制模式能力保持零。

软件检查覆盖参数转换、复制所有权、四种模式限值、未使用字段、重复邮箱、
受理后 STOP/故障/限值变化竞争，以及无请求时既有运行状态行为。
PR 验证离线执行；不下载固件、不执行电机动作。
工作区未提交的 `foc_task.c` 自动电流阶跃实验不在本阶段改动或提交范围，
带该实验的工作树不能作为新协议台架验证镜像。

## 后续和回退

后续先验证静止检测、三相电流有效性、mode 5 六路波形与退出/温升边界，再开放 101 和
mode 5 到控制模式的转换。100 ms 只作为初次制动试验窗口建议，尚非产品配置。
回退本阶段时撤销组合层的 submit_control 绑定，116 继续返回 UNSUPPORTED；
统一帧、108/124 布局与 STOP 路径不变。
