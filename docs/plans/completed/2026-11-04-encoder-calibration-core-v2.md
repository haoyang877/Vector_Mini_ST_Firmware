# 编码器标定核心简化 v2

## 目标和基线

在 v1 的 707 行实现上继续删除重复状态和检查，按阶段聚合计时、数据及控制过程。
当前工作区为 `the-system-refactor`，已有修改继续保留。
本轮基线四组原生标定测试通过，快照和日志位于
`outputs/encoder-calibration-core-v2-20261104/baseline/`。

## 决策

- 启动阶段聚合分拍清表、无感启动和连续稳速计数，总计 8 s 超时，取消独立稳速阶段和 5 s 超时。
  稳速要求原始观测器速度达到可用下限，避免复位后暂存的滤波速度提前结束稳速窗口。
- 启动、采样、构表、停止各自持有阶段数据。采样和构表分别保存所依赖的观测器位置代际。
- 采集处理函数聚合固定转速控制与阶段推进，停止处理函数聚合制动准入、减速和卸流。
- 生命周期负责编码器就绪、有效 LUT 和有效配置准入。固定工作区通过接口前置契约约束，
  删除任务每拍对这些条件的重复检查。
- 候选发布依赖调用方全中断临界区，删除内部内存屏障及临时清除标定标志，保留待发布阶段检查。
- 首拍只复位无感启动状态，FOC 和速度 PI 由共用无感启动入口初始化，删除重复调用。
- 保留采样覆盖、环形展开、整数范围、采样与构表期间观测器复位检测、分拍计算和低速停止条件。

## 验收与回退

保持相对 LUT 数学、两遍构表、两段停止、候选发布和电零位结果。
检查公开任务完整流程、分拍工作量、连续稳速重置与超时、取消重入、
采样及构表的代际变化、低速停止、生命周期准入和发布。
执行定向原生测试、PR 检查和双板编译。实机时序与精度需要硬件证据。

回退以本轮基线文件快照为参照，只撤销本轮差异。

## 完成结果

实现从 707 行减至 618 行。LUT 运动阶段由六个减至五个。
会话字段收敛为工作区、阶段和阶段联合体，启动、采样、构表及停止各自持有业务数据。

本轮允许的行为变化为启动和稳速共用 8 s 超时，首次闭环合格拍直接开始稳速计数，
因此正常流程比 v1 少一拍。停止过程使用实际闭环、相位与速度判断可用性，
采样和构表期间继续检查观测器代际。调用方准入和临界区要求写入公开接口契约。

最终双板乘以阻尼环开关的四组原生标定测试全部通过。1、7、21 极对数的合成标定
峰值残差分别为 0、6、4 个 Q15 计数。新增回归覆盖各阶段取消后重入、
采样与构表代际变化、稳速中断后重计、观测器速度复位、8 s 总超时和两段低速停止。
生命周期测试新增无编码器首样本时拒绝三类标定的断言，双板通过。

`verify --profile pr` 全部通过，包含 124 个 Python 单元测试、16 个集成测试、
所有原生入口、格式、lint、项目布局、架构、接口、文档和卫生检查。
证据为 `outputs/runs/encoder-calibration-core-v2-20261104-pr/summary.json`。
定向回归与构建记录位于 `outputs/encoder-calibration-core-v2-20261104/`。
