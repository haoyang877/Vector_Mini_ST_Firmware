# 全速度域阶梯与闭环带宽上限 v1

用户要求全速度域分阶梯测试并寻找速度环闭环带宽上限。沿用AT32F456、YQ-5708、
8比1减速器、自由输出轴，电机侧速度限制±50 rad/s、相电流限制3 A。

## 方法

1. 核对当前HEX、UID、配置及关相状态。备份RAM配置，临时速度包络最高50 rad/s，结束恢复。
2. 用0.015/0.3做正反向阶梯基线，目标幅值1、3、5、10、20、30、40、45、48、49、50 rad/s。
   每档至少6秒。反馈达到50 rad/s立即STOP，边界点记录受限，随后独立复核另一方向。
3. 测各运行点的小信号频响。基线频段2至100 Hz，必要时在截止附近细分。
   对起伏严重的低速点记录拟合残差和重复性，不能强行给出单一线性带宽。
4. 增益保持Ki/Kp=20 rad/s，逐档尝试Kp 0.0175、0.020，必要时细分。
   可用上限暂按频响峰值≤3 dB、无持续增长振荡、无电流饱和或保护截止判定。
   超出可用判据后停止升增益，在较低档复核，不刻意触发发散。
5. 输出每档转速、均值/纹波、电流峰值、闭环带宽、峰值增益和数据适用条件。
   区分单点最高带宽与全域共同可用带宽，保留未完成或保护截止项。

## 边界

所有运动经CAN 117/116/110控制。每次运行固定时限，实时检查状态、故障、母线和电流。
候选增益只写RAM，关相后回读；保持3 A配置限幅，反馈电流超过3.6 A或持续饱和0.1秒停止。
速度上限50 rad/s同时作为反馈截止，因此50 rad/s目标可能因纹波触发边界，按实测如实记录。
每次结束确认关相并恢复原RAM参数。现有Flash增益0.015/0.3作为回滚基线。

证据保存到outputs/speed-domain-20261105/。当前已有约72 Hz的10 rad/s单点数据仅作基线参考。

## 电周期纹波A/B

用户指出电周期同步纹波。新阶梯数据确认30至48 rad/s由电角度基波主导，
现有LUT的14阶项约0.077度机械角，其相位与闭环纹波吻合。
在关相状态下临时从RAM补偿表减去14阶正余弦投影，保留表均值及其他项，
记录完整新旧表。最大电角变化约1.1度，先在10、30 rad/s对照采集，
每次结束恢复原表并核对；依据实测再决定处理与全域频响矩阵。

## 阶段结果

正反向阶梯完成至48 rad/s，49 rad/s触及50 rad/s反馈边界。
完整频响矩阵及关键点复测支持当前中高速可用带宽约70 Hz，低速重复性仍不满足统一保证。
0.0175/0.35在避开主要背景谱线后仍测得约4.6 dB峰值，超过本轮3 dB判据。
LUT电周期项贡献已通过RAM A/B确认，原表在试验结束恢复。
来源追踪发现atan2近似误差，源码修正及离线回归、AT32隔离构建通过。
详见[频响报告](../../reports/2026-11/speed_domain_bandwidth_20261105.md)。
本计划保留低速精度、标定参考质量及修正镜像实时性三项待闭环。

随后在修复版和重新标定的完整 LUT 上保持 PLL、Kp 和 Ki，完成正反向独立扫频复测。±10 rad/s 约 69 Hz，低速仍缺乏可重复的单一截止。详见[新标定表实测](../../reports/2026-11/new_lut_speed_bandwidth_20261105.md)。
