# 两种测速方案的带宽比较 v1

日期：2026-09-24。目标：在当前 ovp36 工作区比较 PLL 与 40 快拍/2 ms 短窗，选择具有更高可用速度闭环带宽的方案。

## 基线与不变项

以本轮开始时的未提交文件为基线，保留用户修改。PLL 为 20 kHz、600/300 Hz 按速调度；短窗为 40 × 50 µs；速度 PI 为 2 kHz。当前已有离线测试比较的是旧 8 ms 窗与固定 300 Hz PLL，不能作为本轮 A/B 证据。

保持角度标定、电流环、参数 ABI、故障保护与正常模式切换不变。优先只新增离线分析与本次证据，不直接修改产品默认参数。

## 方法与验收

1. 从当前源码抽取实际 C 估计器，喂入相同角度序列，比较正反转、回绕、静止、频响和同源噪声。
2. 计算反馈相位对可用穿越频率的约束，统一包含 2 kHz 零阶保持，区分模型预测、估计器响应和机械闭环带宽。
3. 台架仅在确认镜像身份、STOP/三相关断和参数备份后进行。A/B 使用相同工作点、限流及电流环；比较实际参考到编码器角度的频响，另记录环路反馈响应。帧序号用于检查丢帧；饱和、失步、故障或注入不足的点不计入带宽。
4. 可用工作点要求有相位余量且无持续极限环，不以失稳增益作为建议增益。运行后 STOP 与输出关断必须回读验证；失败立即要求现场断电，禁止自动继续。

## 台架上下文

用户已明确确认：HT8115-4、无阻尼环、轮子架空空载、6 mΩ、母线约 32.9 V；最高 5 rad/s、电流指令上限 2 A、现场可随时断电。先用 3 rad/s 工作点，小幅正弦，保留转速上限余量。所有临时参数仅 RAM 修改。任何超界停止本轮，不自动恢复试验。
